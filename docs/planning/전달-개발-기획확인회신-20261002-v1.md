**연번 1 — 교육 종류별 완료 후 수정 범위(공문 상신 전)**

| 교육 | 완료 후 수정 | 시간을 고치면 |
|---|---|---|
| 자체교육 | 교육 정보 전부(회차 일자·시각 포함). **대상자는 바꾸지 않습니다** — 삭제 후 재등록 | 이미 쌓인 이수기록의 인정시간을 함께 갱신하고 갱신 건수를 저장 결과에 알립니다 |
| 기타교육 | 위와 같습니다 | 위와 같습니다 |
| 채용시교육 | 「이수 수정」에서 **이수일만** 고칩니다 | 인정시간은 대상자별 법정 필요시간이라 수정 대상이 아닙니다 |
| 집합교육 | 강사·장소·내용·첨부는 수정합니다. **회차 시간 수정은 보류** | 정의서 두 건이 다르게 적혀 있습니다 — `SCR-EDU-001` 은 「이수기록을 함께 갱신」, `SCR-EDU-004` 는 「이수기록은 참석자 등록부의 실제 참석시간이고 완료기록은 불변, 정정은 등록취소 후 재등록」입니다. 기획에서 정리해 회신드립니다 |

- 공문이 상신되면 종류와 무관하게 수정·삭제·참석자 등록부 신청 취소가 모두 잠깁니다(강사·장소·내용·첨부 포함).
- 제안하신 「일자·시각·교육시간·회차 잠금」은 자체·기타교육에서는 정의서보다 좁고, 채용시교육에서는 이수일 수정을 막게 됩니다.

**연번 3 질의** — 온나라로 결재선을 넘길 때 **기안자로 넘어가는 계정**이 ① 문서에 기록된 기안자입니까, ② 상신 버튼을 누른 계정입니까. 기획은 「상신은 기안 행위」를 전제로 합니다(`_공통_권한정의` §7-2-1). ②라면 예로 드신 경우(김주무관 기안, 검토자인 이주무관이 상신)에 이주무관이 온나라에서 기안자이자 검토자가 되어 결재선이 성립하지 않습니다. 그 경우 대조 대상에 **상신 계정**도 포함해야 합니다.

**연번 4 — 작업환경측정 증빙 등록 허용 범위**

| 상태 | 증빙 등록 |
|---|---|
| 측정 전(계획) | 허용 — 결과보고서가 있어야 측정 완료 처리를 할 수 있습니다 |
| 측정 완료 · 결과 **적정** | 거부 — 끝난 건입니다 |
| 측정 완료 · 결과 **개선 필요**(개선 진행) | **허용** — 조치 후 증빙이 있어야 개선 완료 처리를 할 수 있습니다 |
| 개선 완료 | 거부 — 끝난 건입니다 |

- 보고서를 바꿔 올릴 때는 이전 파일을 지우지 않고 **버전과 등록 이력으로 남깁니다**. 「마지막 파일만 대표」가 되는 것은 맞지만 이전 파일이 사라지면 안 됩니다.
- 개선 완료 뒤에도 최초 결과와 변경 전 증빙은 덮어쓰지 않습니다.

**연번 7 — 첨부 계약**

| 구분 | 형식 | 용량 | 개수 |
|---|---|---|---|
| 일반 업무 증빙 | hwp · hwpx · pdf · doc · docx · xls · xlsx · ppt · pptx · jpg · jpeg · png | 파일당 20MB | 제출 단위당 최대 10개 |

- 새 파일은 이전 파일을 덮지 않고 버전으로 남깁니다.
- 작업환경측정 결과보고서도 같은 계약을 따릅니다(`SCR-WEM-002` §5). 완료 판정이 「대표 첨부 1개」를 참조하는 구조라면 **「보고서가 1개 이상 있다」**로 보면 됩니다. 다시 올린 파일이 앞 파일을 지우지 않는다는 점만 지켜 주십시오.
- 어느 칸이 이미지만 받는 칸인지는 각 화면 정의서를 따르고, 정의서에 따로 없으면 일반 업무 증빙 기준을 씁니다.

- 같은 이벤트가 연달아 생기면 이력에 각각 남깁니다.

| 5 | #41 세션 | 내용 확인했습니다. 세 원인은 **각각 별도 건으로 관리**해 주시고, 하나만 해결된 상태에서 #41을 종결하지 말아 주십시오. 접속 경로는 HTTPS로 고정하는 쪽에 동의합니다(보안 모드 쿠키를 해제하지 않습니다). #9 는 「오류가 아니다」로 닫지 않습니다 — 세션 수명과 남은 시간 표시·연장은 담양군 보안 기준 확인 후 A-3 연번 2와 함께 회신드립니다 |
