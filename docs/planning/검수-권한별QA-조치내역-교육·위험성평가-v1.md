## 4. 검증

- **브라우저 실행** — 로컬 서버에서 계정 8종으로 교육 12개 화면(9메뉴·자체 탭·상세 2)과 정기·수시 위험성평가·내 할일을 돌렸다. 데이터 준비 흐름(교육 6단계 · 정기평가 생성 → 제출 → 보고서 → 전달 → 완료 → 반려 → 재제출 → 확인 → 공문 상신)은 버튼을 실제로 눌러 진행했다. **42건 전부 PASS.**
- **우회 호출 재현** — 단계마다(보고서 전 · 작성 중 · 전달 뒤 · 완료 뒤 · 공문 상신 뒤) 20여 종을 콘솔로 시도 → 전부 거절, 데이터 무변화. 정상 경로는 모두 그대로 동작.
- **검사 스크립트** — `node tools/check-links.js`(6종) · `node tools/check-permissions.js`(8종) · `python3 tools/check-screendefs.py`(10종) · `python3 tools/build-qa-notion.py --check` · 화면정의서 `_lint.py`(76건 위반 0) · 수정한 JS 12개 `node --check` — 전부 통과. 콘솔 오류 0.
- 시험 뒤 브라우저의 예시 데이터는 되돌렸다.

## 6. 커밋 안내

아직 커밋하지 않았다. 작업 트리에는 **세션 전부터 있던 미커밋 수정**이 함께 있다 — `.claude/launch.json` · `README.md` · `cmp-status.html` · `css/style.css` · `doc-detail.html` · `docs-archive.html` · `docs-exec.html` · `onepager-docflow.html` 과 `CLAUDE.md` 의 일부. 이 세션의 변경만 커밋하려면 위 파일은 빼고, `CLAUDE.md` 는 이 세션이 더한 부분만 골라 올려야 한다.

나눈다면 이 단위가 자연스럽다.

1. **교육 조작 권한** — `js/edu-*.js` 9개 + SCR-EDU-001·002·004·006
2. **수시평가 등록 부서** — `js/rsk-occ.js` + SCR-RISK-004
3. **정기평가 저장 가드 · 반려 건 재제출 · 군수 재촉 숨김** — `js/rsk-list.js` · `js/rsk-imp-cards.js` · `js/my-work.js` + SCR-RISK-001
4. **문서** — QA 시나리오 · 이 문서 · `docs/README.md` · `js/screen-defs-data.js`(재생성) · `CLAUDE.md`(이 세션 부분)
