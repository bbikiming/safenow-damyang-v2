# 전 메뉴 미결사항 소거 및 개발 착수 검수 결과

> 기준일: 2026-08-12  
> 범위: 프로토타입 전체 메뉴·연결 화면·공통 팝업·화면 정의서·법령 매핑·업무문서 V2 데이터

## 1. 결론

- 현재 구현 기준 **82화면**을 **화면 정의서 76건**이 전부 덮는다. 의견청취·인력평가·교육 변형 URL은 동일 기능 계약을 공유한다.
- 화면 정의서 §7의 **자체 기획 미결은 0건**이다.
- 남은 것은 담양군 자료와 외부기관 연계 규격 **10건**뿐이며, 모두 미수신 표시·대체 동작·개발 영향이 정해져 있어 기능·UX 개발을 막지 않는다.
- 현재 문서는 기능·UX 개발 계약으로 사용 가능하다. 실제 로그인·서버 영속 저장·외부 연계는 프로토타입 미구현 사항이지 기획 미결이 아니다.

## 2. 이번 전수 검수에서 소거한 핵심 공백

### 2-1. 인벤토리 누락

- 작업환경측정 목록·상세, 건강검진 목록·상세, 예산 총괄·기준 설정, 사업장 관리 정의서를 추가했다.
- 관리감독자 교육 변형 URL 2개를 인벤토리에 포함하고 기존 정기교육·기타교육 계약을 공유하도록 연결했다.
- 결과적으로 화면 82개, 고유 정의서 76건, 미작성 0건으로 정리했다.

### 2-2. 기본정보 세 축의 단일 출처

- 사업장: 시스템 관리의 사업장 마스터가 정본이며 관리대상 현황은 조회 전용이다.
- 공중이용시설: FMS 시설물 대장이 정본이며 법정 판정항목 미확보는 `판정 불가`로 표시한다.
- 원료·제조물: 관리대상 현황의 해당 탭을 품목 대장으로 확정했다. 등록·수정·사용 중지와 안전자료 3상태를 한곳에서 관리한다.
- 사업장·원료제조물 탭의 고정 건수를 제거하고 실제 정본에서 실행 시 산출한다.

### 2-3. 시설물 위험도와 근로자 위험성평가의 경계

- 시설물 위험도는 이용자 안전과 시설물 점검·개선계획의 우선순위 화면으로 확정했다.
- 산업안전보건법 제36조는 시설물 위험도 화면의 직접 근거에서 제거했다.
- 청소·정비 등 종사자 작업 위험을 함께 평가할 필요가 있을 때만 `근로자 위험성평가 연계`를 제공한다.
- 근로자 위험성평가의 개선조치 건수는 시설물 안전점검 완료나 시설물 위험 감소로 집계하지 않는다.

### 2-4. 작업환경측정·건강검진

- 사업장 대상 판정은 `대상 / 비대상 / 검토 중` 세 상태로 통일했다.
- 결과문서 제출, 실제 실시·수검 완료, 개선·사후관리 완료를 서로 다른 사건으로 분리했다.
- 작업환경측정은 결과보고서가 있어야 완료할 수 있고, 내부 개선기한은 법정 제출기한 안에서 관리한다.
- 건강검진 업무함의 완료물은 `검진 결과 통보서`로 확정하되, 문서 제출이 수검 완료를 자동으로 만들지 않는다.
- 작업환경측정 보존기간은 원칙 5년, 고시 대상 물질 기록 30년으로 계약했다.

### 2-5. 예산·업무문서·통계

- 예산 대상 시설은 시설물 대장 식별값을 참조하고 명칭 스냅샷을 함께 보존한다.
- 연도·유형·대상 식별값 중복을 막고, 편성액 0원은 집행률 `산정 불가`로 처리한다.
- 예산 기준 개정 이력은 수정·삭제하지 않고 새 버전 추가 방식으로 고정했다.
- 업무문서 V2 원본 429행은 추적용으로 보존하고 완전 동일 3쌍을 합쳐 유효 426문서를 정본으로 사용한다.
- 과거 `needReview` 38건은 현재 분류·조건부 적용 정책으로 소거됐으며 유효 문서의 검토 대기는 0건이다.
- 통계의 배타 집계 축은 모두 같은 426문서 모집단을 사용하고 축별 합계가 조회 전체와 같아야 한다.

### 2-6. 공통 상태·권한·영속 저장

- 역할별 권한 문구는 개별 화면에서 제거하고 시스템 관리의 메뉴·권한 관리로 통합했다.
- 조회·필터·페이지·로딩·오류·첨부·기한·알림·외부 연계의 공통 계약을 `_규칙.md`에 고정했다.
- 의견청취·위원회·협의체는 본개발 서버에 영속 저장하고 상태 전이·담당 변경·첨부 교체를 추가 이력으로 남긴다. 삭제 대신 취소 상태와 사유를 보존한다.
- 구버전 코드 주석의 `발주처 확인`, `부서 제출물 불명`, `정식 매핑 시트 수령 시 재생성` 같은 활성 지시를 제거하거나 역사적 참고로 격리했다.

## 3. 법령 기준

- 작업환경측정 대상·실시: 산업안전보건법 제125조, 시행규칙 제186조·제190조.
- 작업환경측정 결과 제출·보존: 시행규칙 제188조·제241조.
- 일반·특수건강진단: 산업안전보건법 제129조·제130조, 시행규칙 제197조·제202조.
- 시설물 위험도: 중대재해처벌법 시행령 제10조, 시설물의 안전 및 유지관리에 관한 특별법 제11조·제16조 및 관련 별표.
- 법령은 화면에 직접 의무를 수행하는 경우에만 매핑한다. 단순 이동·참조 연결은 화면 근거로 추가하지 않는다.

## 4. 외부 준비사항

정본은 `docs/screen-definitions/99_미결사항목록.md`다. 현재 항목은 기관정보·조직명단·온나라·FMS·인사연계·공문 샘플·기록관리·관계법령 목록·공중교통수단 자료·원료제조물 실목록의 10건이다.

모든 항목은 미수신 상태에서 `미등록 / 연계 전 / 판정 불가 / 확인 전 자료`를 표시하고, 실제 성공·확정·0건으로 가장하지 않는다.
