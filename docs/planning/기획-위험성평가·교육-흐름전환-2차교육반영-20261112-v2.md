## 1. 정기 위험성평가 — 8단계

### 1-1. 단계별 정의

| 단계 | 주체 | 선행 조건 | 입력 · 유효성 | 결과(상태 · 할 일 · 알림) | 되돌리기 |
|---|---|---|---|---|---|
| ① 생성 | 재난안전과 담당자 | 그 해 정기평가가 없다(연 1건) | 연도 | 평가 1건 «진행중». **부서에는 아무것도 가지 않는다** | 없음 — §1-4 G |
| ② 대상 부서 · 점검일 · 설문 기한 (①과 같은 마법사) | 재난안전과 담당자 | — | 대상 부서 1곳 이상(조직도, 기본 전체 선택) · 부서별 점검일 필수(일괄 적용 가능) · 설문 제출 기한 필수, **오늘 이후** · 점검일이 설문 기한보다 이른 부서가 있으면 **알리기만** 한다 | 평가 카드에 제출 기한 | 없음 — §1-4 G |

| ④ 부서 제출 | 그 부서 담당자(재난안전과 대리 등록 가능) | 요청 공문을 받았고 보고서 등록 전 | 작성본 파일(일반 증빙 형식) | 평가 카드 «제출 n/m» · 제출자·제출일 기록 | 보고서 등록 전까지 교체 |
| ⑤ 용역 보고서 + 조치기한 | 재난안전과 담당자 | 설문 요청 공문을 보냈다(부서 제출 전원을 기다리지 않는다) | 통합 보고서 1개(파일당 30MB) · 조치기한 일괄 또는 부서별, 전 부서 필수, **오늘 이후** | 단계 «조치 요청 전» · 부서별 조치 표에 «요청» 체크 열(기본 전부)과 조치기한 칸 · **설문 제출 마감**(못 낸 부서의 제출 할 일이 사라진다) | [보고서 취소] — 조치 요청 전에만, 보고서와 기한이 풀린다 |
| ⑥ 조치 요청 공문 | 재난안전과 담당자 | 보고서 등록 · 요청 전 | 요청 부서 1곳 이상 · 그 부서 조치기한 존재(**오늘 이후**) · 공문 본문(조각 «요청 안내»·«이행 방법») · 수신 = 고른 부서장 · 붙임 = 보고서 + 별지 «조치 요청 부서와 조치기한» | **보내는 순간** 고른 부서 «조치전» + 내 할일 «부서별 개선조치 작성(기한)» + 알림 · 고르지 않은 부서는 «지적사항 없음»으로 완료 | 없음 — 한 번만 보낸다(§1-4 F) |
| ⑦-1 작성 · 입력 완료 | 그 부서 담당자(재난안전과 담당자가 대신 적을 수 있다) | 조치 요청을 받았고 입력 완료 전 | 작성표 행: 유해위험요인·개선조치(둘 다 있어야 개선조치가 된다) · 분류·원인 · 시설물(지정/해당 없음/미지정 — 셋 다 오류 아님) · 담당자(그 부서 사람만) · 개선 전·후 사진 · 완료 체크 · [입력 완료] 때 0건이면 **사유 필수** | 그 순간 유효 행이 개선조치가 된다(행의 담당자·사진·완료 체크 승계) · 부서 줄 «조치중»(0건이면 «지적사항 없음») · 재난안전과에 «조치 입력 완료» 알림 | [입력 완료 취소] — 완료 처리한 건이 없고 결과 공문 전, 평가 진행 중일 때. 작성표로 돌아간다 |
| ⑦-2 조치 완료 · 기한 연장 | 그 부서 담당자 | 입력 완료로 개선조치가 생겼다 | 완료: 조치 내용 · 개선 후 사진 1장 이상 · 전자서명 · 완료일 / 연장: 기존 기한보다 늦게, **오늘 이후**, 사유 필수 | 완료 → 재난안전과에 «완료 확인 요청» · 연장 → 재난안전과에 알림, 이력 | 완료는 반려로만 되돌아온다(⑧) · 앞당기기는 재난안전과만 |
| ⑧-1 완료 확인 | 재난안전과 담당자 | 개선조치가 완료됐다 | 증빙 열람 체크 → [확인] · [반려]는 사유 필수 · 대기 2건 이상이면 부서 묶음별 «한 번에 확인»(반려는 건마다) | 확인 → 기록(확인자·확인일) · 반려 → 담당자에게 사유 알림, 재제출하면 회차 +1 | [확인 취소] — 결과 공문을 보내기 전 |
| ⑧-2 결과 공문 | 재난안전과 담당자 | 요청 부서 전부 입력 완료 + 개선조치 전 건 완료·확인 | 본문 직접 작성 · 붙임(확인 결과표 · 전후 사진철 · 그 밖 파일) · 관련 근거는 고른 것만 · **결재선은 받지 않는다** | **«온나라로 보내기»** — 온나라 기안함까지(검토·결재는 담당자가 온나라에서 지정해 상신) · 보내는 순간 확인 결과 잠금 · 결재 결과를 사람이 옮겨 적지 않고 진행은 온나라에서 확인(R-6) | 온나라 연계가 반려·반송을 알려 오면 잠금이 풀리고 다시 기안해 보낸다 |

### 1-2. 상태

| 대상 | 상태 | 정하는 규칙 |
|---|---|---|
| 평가 카드 | **진행중 → 확인 대기 → 완료** | 요청 부서 전부 입력 완료 + 개선조치 전부 완료면 평가는 자동 완료되지만, 확인이 남아 있으면 **«확인 대기»**로 보이고 부서 줄 버튼은 [관리]로 남는다. 확인까지 끝나야 «완료»·완료일·[보기]. 반려가 남았으면 «진행중» |
| 보고서 축 | 보고서 미등록 → 조치 요청 전 → 조치 요청 완료 | ⑤·⑥ |
| 부서 줄 | 조치 요청 전 → 조치전(작성 0건) → 조치중 → 완료 / 반려 · 지적사항 없음 | «완료»는 그 부서 개선조치가 전부 완료·확인됐을 때. 발표안 17장은 조치전·조치중·완료 셋을 보이고, 나머지 셋은 화면이 더 쓴다 |
| 개선조치 1건 | 진행중 → 완료 · 확인 축(확인 대기 → 확인 완료 / 반려) | 두 축은 따로 간다 — «완료이면서 확인 대기», «완료이면서 반려»가 정상이다 |
| 내 부서 진행(부서 화면) | 설문 제출 → 보고서·조치 요청 → 개선조치 작성·완료 → 완료 확인 | 보고서 등록 뒤 못 낸 설문은 «미제출 — 마감»으로 남고 다음 단계가 지금 단계가 된다. 조치할 것이 없는 부서는 4단계가 «할 일 없음» |

### 1-6. 결정

**정한 것 (2026-11-11 · 권장안 그대로)**
- R-1 점검일과 설문 제출 기한을 **둘 다** 받는다(점검일 = 용역 방문일 · 사전 공유 대상 / 기한 = 작성본 마감).
- R-2 요청 공문 두 종은 결재선 없이 «온나라로 보내기»(11-06 운영 결정과 같다). 결재 결과는 받지 않는다.
- R-6 (2026-11-12) **결과 공문(⑧-2)도 요청 공문과 같이** 결재선 없이 «온나라로 보내기» — 기안함까지만 보내고 결재 결과(결재완료·반려)를 사람이 이 시스템에 옮겨 적지 않는다(수동 기록 수단 없음). 진행은 온나라에서 확인한다. 온나라 연계가 반려·반송을 알려 오면 잠금을 풀고 다시 기안한다(공통 §7-4 — 연계 회신은 전 경로가 반영). ⚠ 프로토타입의 위험성평가 결과 공문 화면은 동결이라 아직 결재선 지정과 회신 기록이 남아 있다 — 고치려면 발주처 확인이 먼저다. 운영 구현은 이 R-6 이 기준이다.
- R-3 기한 연장은 부서가 직접 — 늦추기만, 사유 필수, 재난안전과 알림.
- R-4 조치기한은 보고서를 올릴 때 **부서별**(일괄 적용). 조치별 기한은 연장으로만.
- R-5 요청하지 않은 부서는 «지적사항 없음»으로 자동 완료.
- (11-12) 평가 카드는 확인까지 끝나야 «완료» · 부서에 주는 기한은 오늘 이후 · 보고서 등록과 함께 설문 제출 마감.

### 2-2. 상태 · 권한

- 교육: **교육 전 → 등록부 받는 중 → 완료**. 목록 상단 필터의 «진행 중»은 앞의 둘을 함께 뜻한다.
- 등록 · 수정 · 삭제 · 종료 · 공문은 **그 교육을 등록한 부서 담당자**(집합교육 = 재난안전과 담당자). 관리·감독 계층(과장 · 팀장 · 군수)은 조회만 한다. 독촉은 위 ⑦.
- **자기 부서는 독촉하지 않는다(2026-11-10 확정)** — 받는 사람이 그 부서 담당자라, 그 부서 담당자가 누르면 자기에게 간다. 재난안전과 담당자에게도 재난안전과 줄에는 선택칸이 없다. 부서장은 자기 부서를 독촉한다.
- 다른 부서 사람의 이름 · 서명파일은 조회 범위 밖이면 가려진다(«#번호»·«제출됨»).

### 2-3. 정한 것

- E-1 사전 신청을 두지 않고 «교육이 끝난 뒤 한 번 등록»(07-16 «신청 = 참석 증빙 한 단계» 유지, 화면 어휘는 «등록»).
- E-2 일괄 등록의 참석시간 기본 = 교육 합계, 예외만 사람별.
- E-3 같은 서명부는 공문 붙임 후보에 한 번만.
- E-4 (2026-11-12) 실시 결과 공문은 결재선 없이 «온나라로 보내기»(기안함까지, 11-06 운영 결정 · 위험성평가 R-6 과 같다). 결재 결과를 사람이 옮겨 적지 않는다.
- E-5 (2026-11-13) 집합교육 등록의 첨부 칸 이름은 운영 화면과 같은 **«참석자 명단 (서명 포함)»**(참석자 명단·출석부). 11-12 에 «서명부 양식»으로 바꿨던 것을 되돌렸다 — 같은 칸을 두 이름으로 부르면 실습 안내와 화면이 어긋난다.
- (11-12) 등록부는 교육이 끝난 날부터 · 등록 기한 = 마지막 회차 + N일 · 기한 전 종료는 경고 뒤 허용.
- (11-13 실습 검수) 등록부 실제 참석시간은 «모두에게 같은 시간» + «사람별로 다르게 적기» · 종료 뒤 «이수 기록 정정» · 공문 지면에 고른 근거 줄 · 반려 공문 [다시 기안](앞 제목 · 본문 · 사유) · 결재 이력은 조회 범위를 따른다(범위 밖 이름 «#번호»). 세부는 개발 전달 문서 §8-2.
