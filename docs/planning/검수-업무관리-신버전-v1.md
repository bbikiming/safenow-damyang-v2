## §1. 와이어프레임 대조 — 화면·기능 전수

### ① 단계별 이행현황 (CMP01-T) — 일치
- 3계층 탭(군/부서/관리대상) + 건수 칩 — **런타임 파생**(L1 72 / L2 55 / L3 41 = 168, 와이어프레임 80/58/39 는 예시 수치라 하드코딩하지 않음이 맞다). ✅
- 계층별 스코프 안내 — 와이어프레임의 별도 띠 대신 `DYV2.notice()` lead 로 합침(§14-12 첫 행 600px 근거, 구현 주석에 사유 명시). 문구 취지(L1 군 1회·조회 전용/L2 39부서/L3 건별·Phase 2) 보존. ✅(의도적 변형)
- KPI 4장: 정기 이행률(게이지)·상시 이행 충족·미이행 단계(지연 병기)·연간 이행 회차. 회차 합계는 부서·시설 배수를 곱하지 않고 그 이유를 카드에 밝힘 — 와이어프레임의 731/772 추산은 근거 데이터가 없어 재현하지 않은 것이 맞다. ✅
- 필터: L1 검색·법령 축·주기·상태 / L2 부서 / L3 시설분류·상태·검색 — `EDUFILTER.bar`. ✅
- 그룹 표: 이행항목 그룹 행(▸▾, 충족 x/y·문서 합계) + 단계 행(주기·회차 n/need·상태 chip(글리프 병기)·수행 주체(· 앞 첫 토막 — 와이어프레임 동일)·문서 N건·법령 ⓘ). **기본 펼침 = 그룹에 지연·미이행 존재**(와이어프레임 동작, 실구동 확인 — IND-06 만 자동 펼침). 첫 클릭이 안 먹는 저장값 함정도 처리돼 있음. ✅
- 법령 ⓘ: hover 툴팁 → **인라인 펼침**(`.lawinfo-inline`) 전환. 내용 3항(법령근거·법정주기·수행시점조건) 동일 + 회차 기한 추정 캡션. DYLAW 스냅샷에 없는 조문은 `조문 미연결` 정직 표기. ✅(규칙 §1·§10에 맞춘 의도적 전환)
- L2 부서별 보기: 부서 행 + `… 나머지 28개 부서 — 명단 미확보(39개 중 11개 등록)` 행. 이행률 바는 **데이터가 없어 `자료 미취합`으로 대체** — 와이어프레임의 % 바는 물순환 표본 데이터 전제라 우리 원장(재난안전과, 부서 귀속 없음)으로는 지어내야만 가능. 갭 노출 방식 타당. ⚠ 단 결함 C-1 참조.
- L2 단계별 보기: 39칸 부서 도트 + 범례(이행/비대상/미취합) + `이행 부서 — / 39`. 도트 전부 미취합임을 명시. ✅
- L3: 관리대상 표(관리대상·소관부서(미등록 노출)·분류·적용 단계 칩·충족 n/m) + Phase 1/2 note 원문 취지 유지. 와이어프레임에 없는 **단계별 보기 세그먼트 추가** — L3 단계 41개의 상세 진입로 확보(추가 없이는 막다른 길). 타당한 보강. ✅
- 범례 5종(충족·진행중·지연·미이행·비해당) chip 실물 렌더. ✅

### ② 이행 상세 (CMP02-D) — 일치
- 2단(좌 340px 정의 / 우 문서, lg 이하 1단). 좌: 코드·항목명·계층(추정 표기)·법령근거·법정주기·**운영주기(재난안전과) 추가**·수행시점조건·적용대상·이행주체 + 연도 이행상태·회차·전년 실적(전년 데이터 있을 때). 와이어프레임 7항 전부 + α. ✅
- 우: `{y}년 등록 문서 (N)` 표(문서명·구분·수발신자·보고일자·결재상태) + `[📁 {전년} 문서 불러오기]` `[＋ 새 문서 등록]`(DOCUP). ✅
- 빈 회차 안내: `{k}회차가 비어 있습니다 (k/need)` + 주기상 기한(말일 추정 명시) + 불러오기·등록 버튼 — 와이어프레임의 "종합점검 회차가 비어 있습니다" 대응(회차명은 원자료에 없어 번호로, §4-4). ✅
- `{전년}년 문서 (N)` + `[지난연도 전체 보기]` → `cmp-docs.html?stage=&year=` 딥링크 수신까지 동작(실구동 46건 필터 확인). ✅
- **연도 셀렉터를 과거로 바꾸면 등록·불러오기 버튼이 사라지고** "지난 연도 — 소급 등록을 막기 위해 등록 버튼을 내지 않습니다" 안내(실구동 확인). 와이어프레임 캡션 동작 그대로. ✅

### ③ 작년 문서 불러오기 — 일치
- 단일 모달(`DYV2.openModal`). 헤더(단계 코드·명·전년 등록 N건) / 검색 + 전체 선택(+선택 해제 보강) / 체크박스 목록(문서명 + 구분·일자·수발신 메타) / 푸터 **불러올 항목: 문서명(고정 ☑)·수발신자(☑)·보고일자(☐)** — 와이어프레임 기본값과 동일 / `불러오기 (n)` 0건 비활성. ✅
- "불러오는 것은 메타데이터뿐 — 본문·결재 PDF는 온나라 연동 필요" 안내 모달 내 상시. ✅
- 실행 시 제목·일자의 연도 치환, 출처·비고에 원본 문서 id 기록(`presetOf`). ⚠ 결함 C-2(중복 가드) 참조.

### ④ 업무문서 목록 (DOC01-L) — 일치
- 필터: 문서명 검색·연도·결재상태·수발신처 검색 + **업무단계는 `DYPICK` 2단 선택기**(78개 드롭다운 금지 규칙 준수, 선택 칩·개별 해제·모두 지우기) + `[＋ 문서 등록]`(DOCUP). ✅ (와이어프레임의 부서 셀렉트는 §4-5 사유로 수발신처 검색으로 대체)
- 표: 문서명 · 업무단계 다중 칩(**2개 초과 +N 접힘 → 클릭 인라인 펼침/접기**, hover 툴팁 금지 준수, 실구동 +1→펼침→접기 확인) · 수발신자 · 보고일자 · 결재상태 chip. ✅
- **연결 수/문서 수 병기** — 상단 notice lead(4,256/4,024)와 조건 결과 줄 양쪽, 전부 런타임 파생. 와이어프레임 note 취지 그대로. ✅
- 미분류(원장)·`이 목록 밖 문서`(현행 426건) 구분 표기 — CLAUDE.md §5 '미분류 34건' 혼동 방지 규칙 준수. ✅

### ⑤ 지난연도 문서 상세 (DOC02-D) — 일치
- 헤더: `{y}년 문서` 태그·제목·메타(출처·일자·id·수발신)·업무단계 칩(이행 관리 딥링크)·분류확인 칩. ✅
- 좌: 결재 완료 문서 영역 — **"PDF 미보유(온나라 연동 전)" 정직 표기, 가짜 미리보기 없음**. 와이어프레임의 안내 문구 취지 그대로. ✅
- 우: 올해 이어받기 카드(메타데이터만 복사 명시, 단계 없는 문서는 등록 뒤 직접 선택 안내) — **지난연도 문서에만** 노출. `{올해} 동일 단계 현황` 카드(judge chip + 다음 회차 기한). ✅
- 이어받기 실행 → 올해 문서 생성 후 그 상세로 전환. ✅ ⚠ 결함 C-2 공유.

### ⑥ 누락 점검 (CMP04-V) — 일치
- 필터: 검색·부서 + **법령 축 세그먼트 5종**(전체/중대산업재해/중대시민재해/산안법/개별법). 축은 id 접두가 아니라 `lawBases` 파생·복수 축 — 두 축에 걸친 항목을 한쪽으로 몰지 않음(§10 검증 6문 #4 취지). 타당한 보강. ✅
- 헤더: `미이행 단계 N개` + `정기 x + 상시 y` + 2년 연속 규칙(전년 자료 없으면 "생략됩니다" 정직 안내). ✅
- 이행항목 그룹 블록(danger 헤더 + 축 칩) / 행: 단계명·법령근거·주기·연도별 건수·`□ 2년 연속`(danger) + `[해당 — 문서 등록]` `[비해당 — 사유 기재]`. ✅
- 비해당: **빈 사유 저장 거부**(화면 + `DYDOCS.transition` 이중, 실구동 확인) · 일괄 처리는 **선택 체크박스 → 대상 목록·건수 명시 확인 모달 → 공통 사유 필수** — 와이어프레임의 무맥락 일괄 버튼보다 안전하게 보강(§4 CRUD 명시 규칙). 선택 0건이면 비활성. ✅
- 하단 note("적용 제외 근거 없음이 더 위험") 원문 취지 유지 + 감사 로그 표현은 실제 없는 기능이라 "기록에 남고 매년 재확인"으로 정직화. ✅

| # | 심각도 | 내용 |
|---|---|---|
| W-1 | **M** | **L2 부서별 보기 행이 눌리지 않는다.** 와이어프레임은 표 위에 *"부서별 보기 — 행 클릭 시 해당 부서의 단계 목록으로 진입"* 이라고 흐름을 명시해 두었다. 우리 표는 `적용 단계(추정) 23개` 를 보여주면서 **그 23개를 볼 방법이 없다** — 부서를 눌러도 아무 일이 없는 막다른 길이다. U-6 에서 단계 행·문서 행에는 행 클릭을 넣었는데 이 표만 빠졌다 |
| W-2 | **S** | **L3 관리대상 행에 클릭 어포던스가 없다.** 와이어프레임은 `tr.stg`(cursor:pointer·hover)로 행을 눌리게 두었다. 다만 목적지가 와이어프레임에도 정의돼 있지 않고, 우리는 적용 단계 칩을 진입점으로 열어 두었다(U-4) — 행 단위 진입을 넣으려면 "시설 1건의 상세"라는 화면이 새로 필요하므로 **기획 확인 대상**이다 |
| W-3 | **M** | **L3 검색창 문구가 실제 동작과 다르다.** placeholder 는 `할 일·법령·수행 주체로 찾기` 인데 관리대상별 보기에서 실제로 검색하는 것은 **시설명·분류·소재지**다. 같은 문제를 L2 부서별 보기에서는 C-1 때 고쳤는데 L3 는 남았다 — 화면이 하지 않는 일을 안내가 약속하고 있다 |

## §4. 기획 확인 필요 — 결함 아님, 결정 대상

1. **기본 기준연도** — 구현은 `DYDOCS.defaultYear()`(=2025, 데이터 최신 연도), 와이어프레임 서사는 2026(올해 이행 + 작년 불러오기). 구현 판단의 근거(첫 화면 통째 조회 전용 방지·기존 이행 목록과 규칙 통일)는 주석에 문서화돼 있고 타당하나, **발주 시연 서사를 2026으로 잡는다면 기본값을 2026으로 뒤집고 "대부분 미이행"이 첫인상이 되는 것을 감수**할지 결정 필요.
2. **엑셀 내보내기 미구현** — 와이어프레임 ①(3계층)·⑥ 필터 바에 있던 `엑셀` 버튼이 없다. 프로토타입 전반에 표 내보내기 관례가 없어 생략됐으나 와이어프레임 명시 요소이므로 결정 필요(모형 버튼이라도 둘지, 실 CSV 로 만들지, 뺄지).
3. **분류확인 확신도** — 와이어프레임 ⑤의 `분류확인 · 확실` 확신도 축이 원자료에 없어 `분류완료/미분류` 2값으로 대체됨.
4. **회차명** — 와이어프레임의 `작동점검 ✓ · 종합점검 미실시` 같은 회차 이름이 원자료에 없어 회차 번호(1/2)로 대체됨. 회차명 관리가 필요하면 데이터 스키마부터 결정 대상.
5. **④ 부서 필터 부재** — 원장의 `sr` 은 수발신 기관이지 부서가 아니라(데이터 계층 주석의 금지 사항) 부서 셀렉트 대신 수발신처 검색으로 대체됨. 담당부서 연계(새올·온나라) 수신 후 부서 축 복원.
6. **화면 정의서 미작성** — SCR-CMP 계열 2건(이행 관리·문서 목록)이 screen-definitions 에 없다. 확정 후 `/screen-def` 로 작성 권장.
7. **DYPOLICY 미연계(선택)** — 부서 귀속·온나라 PDF 의존은 기존 항목(`doc-dept-src` 등)이 이미 다루므로 `DYPOLICY.MAP` 에 cmp 페이지를 연결하면 헤더 `자료 준비` 칩이 이 화면 맥락을 먼저 보여준다.

| U-6 | **행 전체 클릭 불가** — 와이어프레임 `tr.stg` 는 행이 타깃인데 이름 버튼만 눌렸다 | `rowOpen(event, id)` — 행 클릭 진입(안의 버튼·링크·체크박스에는 양보), hover 배경, 터치 타깃이 행 폭으로 확대. 적용: L1/L2 단계 행·문서 목록 행. +N 칩 펼침이 행 클릭에 가로채이지 않음 실측 확인 |
| U-7 | **뒤로가기가 화면을 통째로 이탈** — 상세(드릴다운)에서 브라우저 뒤로가기를 누르면 목록 필터·스크롤을 잃고 페이지 밖으로 나갔다 | 상세 진입 시 `pushState({cmp:'detail'/'doc'})`, `popstate` → URL 재해석·재렌더. 닫기 버튼도 가능하면 `history.back()` 으로 같은 길. 필터 갱신(replaceState)이 상세 표식을 지우지 않게 `history.state` 보존. URL 직접 진입(히스토리 없음)도 안전 |
| U-8 | (회귀 방지) 공유 마법사 수정이 기존 화면을 흔들지 않는지 | docs-exec 에서 무인자 `DOCUP.open(2025)` 정상·빈 마법사 무확인 닫힘·콘솔 오류 0 확인 |

검증: 프리필 STEP2 표시("고른 할 일 1개") → STEP3 → 저장 → 화면 즉시 갱신 전 구간 실측. 테스트 문서 회수(4,256 원복). 콘솔 오류 0 · v2.css 원시값 0. ⚠ 검증 시 `fresh2`(8782)는 브라우저 캐시로 구버전 JS 가 남을 수 있다 — JS 변경 확인은 `demo`(8785, serve-nocache) 사용.

## §5. 검수 중 확인한 구현 판단(타당 — 유지 권장)

- 스코프 바를 notice lead 로 합치고 기본 접힘 — 첫 행 598px 확보, 접힌 한 줄이 '지금 상태'(계층별 건수)라 §14-12 취지 충족.
- L2 이행률·도트를 지어내지 않고 미취합으로 노출, L3 이행 칩은 업무단계 단위 판정임을 명시 — "그럴듯하게 채우지 않는다" 원칙.
- 누락 점검 축을 lawBases 파생·복수 축으로 — 중처법 양축 규칙(§10 #4) 준수.
- 과거 연도 판정 기준을 화면 기준연도로 — 기존 이행 목록과 규칙 한 벌.
- 판정·전이의 단일 출처 준수 — DYCMP 는 파생만, 쓰기는 전부 DYDOCS(스토어 신설 없음). 비해당 = 기존 `해당없음` 재사용으로 축 증식 없음.
