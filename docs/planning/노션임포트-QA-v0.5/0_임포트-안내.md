## 1. 임포트

`Settings → Import → Text & Markdown / CSV` 또는 **사이드바에 파일을 끌어다 놓는다.**
붙여넣기는 쓰지 않는다 — 실시간 처리라 표가 어긋난다.

**CSV 2개를 먼저**, 그 다음 본문 `.md`. 세 개가 사이드바에 **나란히 3개**로 들어온다(본문 안에 표가 들어가지 않는다).

> ⚠ **원본 `검수-QA시나리오-1차-v0.5.md` 는 같이 넣지 않는다.** 그 파일에는 TC 표가 그대로 들어 있어, 함께 임포트하면 **테스트 케이스가 두 벌** 생긴다. 원본은 저장소에 읽기용으로 남겨 둔 것이다.

---

## 2. 임포트 뒤 손으로 할 일 4가지

CSV는 대부분의 열을 **텍스트**로 만든다. 아래를 바꿔야 QA 도구가 된다.

**① 속성 타입** — «QA 테스트 케이스» 각 열 위 드롭다운에서 바꾼다.

| 속성 | 바꿀 타입 | 값 |
| --- | --- | --- |
| TC ID | Title (자동) | — |
| 구분 | Select | 위험성평가 · 안전보건교육 · 공통 UX · 기타 모듈 Smoke |
| 우선순위 | Select | P0 · P1 · P2 |
| 결과 | Select | N/T · PASS · FAIL · N/A · SKIP · BLOCK |
| 테스터 | Person | — |
| 나머지 | Text (그대로) | — |

«QA 결함 기록» 은 `심각도` → Select (Blocker · High · Medium · Low), `상태` → Select, `발견일` → Date, `발견자`·`개발 담당` → Person.

**② 이슈번호를 관계로** — «QA 테스트 케이스» 의 `이슈번호` 를 **Relation → «QA 결함 기록»** 으로 바꾼다. TC ↔ 결함이 양방향으로 이어지고, 결함에서 «관련 TC» 를 거꾸로 볼 수 있다.

**③ 본문 안으로 모으기** — 본문 페이지의 §6~§9 안내 밑에 `/linked view of database` 로 두 데이터베이스를 끼워 넣는다. 원본을 옮기지 말고 **링크 뷰**로 넣어야 한 곳에서 관리된다.

**④ 뷰 만들기** — 이게 마크다운으로는 안 되던 것이다.

| 뷰 | 필터 | 쓰는 사람 |
| --- | --- | --- |
| 내 담당 | `테스터 = 나` · `결과 = N/T` | 테스터 3인 |
| P0 잔여 | `우선순위 = P0` · `결과 = N/T` | §12 종료 기준 추적 |
| 실패만 | `결과 = FAIL` 또는 `BLOCK` | 결함 정리 |
| 진행 현황 | `구분` 으로 그룹 · `결과` 로 나눔 | §13 요약 대체 |

**§13 요약 표는 손으로 채우지 않는다** — ④의 「진행 현황」 뷰가 같은 수치를 낸다. 본문의 전체 TC 수(40 · 41 · 16 · 19 = 116)는 대조용 기준값이다.

## 3. 알아 둘 것

- **CSV 는 BOM 없는 UTF-8 이다** — 노션용이라 그렇다. ⚠ **엑셀로 바로 열면 한글이 깨진다.** 엑셀에서 봐야 하면 「데이터 → 텍스트/CSV 가져오기」에서 인코딩을 UTF-8 로 지정한다.
- **셀에 서식이 없다** — 노션 CSV 셀은 평문이라, 원본의 굵게(`**…**`)·코드(`` ` ``) 표시를 지웠다. 문장은 그대로다.
- **빈 열 4개**(`실제 결과`·`결과`·`테스터`·`이슈번호`)는 테스터가 채울 자리다. `결과` 는 전건 `N/T`(미수행) 로 넣어 두었다.
- 임포트 한도 — 파일당 5 MB(무료)·50 MB(유료), 12시간당 약 120개. 이 세 파일은 합쳐 60 KB 다.
- 나중에 TC 를 고치면 **CSV 를 다시 임포트하지 말 것** — 새 데이터베이스가 하나 더 생긴다. 노션에서 직접 고치거나, 저장소의 원본을 고친 뒤 바뀐 행만 손으로 옮긴다.
