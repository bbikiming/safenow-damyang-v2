## 3. 데이터·판정 — 단일 출처 위에 파생만 얹는다 (MUST)

CLAUDE.md §5 의 "'이행'을 말하는 축이 셋" 규칙 그대로 — 신버전은 **증빙문서 축**이고, 판정 원본은 `DYDOCS` 다. `DYCMP` 는 아래 파생만 담당한다.

### 3-1. 계층(L1/L2/L3) 파생 — `DYCMP.levelOf(stage)`

와이어프레임의 군/부서/관리대상 3계층은 우리 데이터에 필드가 없다. `STAGES[].target` 문자열 규칙으로 파생한다.

| 판정 순서 | target 패턴 | 계층 |
|---|---|---|
| 1 | `군 전체` · `관리주체 1단계` · `재난안전과(전담조직)` · `재난안전과 주관` 포함 | **L1 군 단위** |
| 2 | `시설` · `승강기` · `놀이시설` · `공중이용시설` 등 시설물 지칭(id 접두 `FAC-` 포함) | **L3 관리대상 단위** |
| 3 | `전 부서` · `각 부서` · `현업종사자 배치 부서` 등 부서 지칭 | **L2 부서 단위** |
| 4 | 그 밖 | **L2 로 수렴하되 `derived:true` 표시** — 계층 탭 하단에 "계층 분류는 적용대상 문자열 파생(추정)이며 발주처 확정 대상" 캡션을 상시 노출 |

- 와이어프레임의 탭 카운트(80/58/39)는 **예시 수치**다 — 화면 카운트는 런타임 파생값을 쓴다. 숫자를 하드코딩하지 않는다.
- 판정 함수는 `DYCMP` 한 곳뿐이다. 화면이 target 문자열을 직접 검사하지 않는다.

### 3-2. 주기 코드 파싱 — `DYCMP.cycleOf(stage)`

`opCycle`(재난안전과 운영주기) 우선, 없으면 `legalCycle`. 반환 `{cc, need, label}`.

| 문자열 | cc | 연간 필요 회차(need) |
|---|---|---|
| `연 N회` | YEAR | N |
| `반기 1회` | HALF | 2 |
| `분기 1회` | QUARTER | 4 |
| `월 1회` | MONTH | 12 |
| `주 1회` | WEEK | 52 |
| `정기주기 없음` · `수시` · 파싱 불가 | EVENT | — (상시) |

파싱 불가 문자열은 EVENT 로 수렴하되 콘솔 경고 없이 화면 캡션에 "주기 미파싱 N건 — 상시로 분류" 갭을 노출한다.

### 3-3. 이행상태 판정 — `DYCMP.judge(stage, year)`

와이어프레임 `judge()` 를 따르되, 우리 저장 상태(`DYDOCS`)와 시연 기준일(`DYV2.today()`, §11)을 결합한다.

```
비해당   : DYDOCS statusOfStage === 해당없음 (사유 보유) → 최우선
EVENT    : 해당 연도 문서 n>0 → 충족 / n===0 → 미이행
주기형    : done = min(그 연도 등록 문서 수, need)
           done >= need            → 충족  (n/need 표기)
           0 < done < need         → 진행중
           done === 0 && 도래 회차 존재(기준일이 첫 회차 기한 경과) → 지연
           done === 0 && 아직 도래 전 → 미이행
```

- 문서 수는 `DYDOCS.documentIdsOfStage(stageId, year).length` 하나만 쓴다.
- 도래 회차 기한: 연(12-31)·반기(06-30/12-31)·분기(분기 말일)·월(월 말일) — `DYV2.today()` 파생. 시드에 상태를 박지 않는다(§4-3 대시보드 결함 선례).
- **이 판정은 표시 전용이다.** `DYDOCS` 의 완료/진행중/미이행/해당없음 상태 전이를 대체하지 않는다 — 완료 확인(재난안전과 담당자)의 축은 기존 이행 목록에 그대로 있다.

### 3-4. 상태 어휘 — `DYV2.STATUS_TONE` 추가 (§7)

| 라벨 | tone | 비고 |
|---|---|---|
| `충족` | success | 신규 추가 |
| `비해당` | neutral | 신규 추가 (저장값은 `DYDOCS` 해당없음 — 화면 표기만 비해당) |
| `진행중` `지연` `미이행` `미상신` `결재중` `결재완료` | (기존) | 추가 불필요 |

와이어프레임의 글리프(✓ ◐ ! □ −)는 chip-status 라벨 앞에 텍스트로 병기한다 — 색 단독 의미 금지 규칙(§7)과 합치.

### 3-5. 쓰기 경로 — 전부 `DYDOCS` (MUST)

| 동작 | 경로 |
|---|---|
| 새 문서 등록 | `DOCUP` 업로드 마법사 재사용(가능하면) 또는 `DYDOCS` 문서 추가 API. 등록 직후 상태는 `진행중`(§5) |
| 비해당 처리 | `DYDOCS.transition(… 해당없음, {reason})` — **사유 없이는 저장 거부**(§4-2·§5 와 같은 근거). 일괄 처리도 건별 사유 대신 공통 사유 1개 + 대상 단계 목록을 확인 모달에 명시 |
| 작년 문서 불러오기 | 전년도 문서 메타데이터(문서명·수발신자·보고일자 中 선택)를 복사해 올해 문서로 등록 — `DYDOCS` 의 프리셋 경로(`presetSourceYear` 계열) 재사용. **메타데이터만 복사됨을 모달에 명시**(결재 PDF 는 온나라 연동 전 미보유 — 갭 노출) |
| 올해 이어받기(문서 상세) | 위와 같은 경로 — stageIds·수발신자 복사, 제목 연도 치환 후 등록 폼 프리필 |

## 4. 화면 정의 — 이행 관리 (`cmp-status.html`)

와이어프레임 ①②③⑥ 을 한 화면의 내부 내비게이션으로 담는다. 페이지 상단 `.sub-tabs` 2개: **단계별 이행현황** | **누락 점검**.

### 4-1. 단계별 이행현황 (①)

- **계층 탭 3개** (`.tabs` 표준 + 건수 칩): 군 단위 / 부서 단위 / 관리대상 단위. 건수는 파생값.
- 계층별 **스코프 안내 바**: `DYV2.notice()` 사용(접힘 기억). 와이어프레임의 문구 취지 유지 — L1 "군 전체 1회 수행·부서 이행률 분모 제외", L2 "39개 부서 각각 수행", L3 "시설·공사 건별 수행, 회차 전수 관리는 Phase 2"(와이어프레임 note 그대로).
- **KPI 4장**: 정기 이행률(게이지 `.progress`) · 상시 이행 충족 · 미이행 단계 · 연간 이행 회차(파생 합). 기존 `.kpi-card`(style.css) 재사용.
- **필터 바**: `EDUFILTER.bar` — L1(연도·법령·주기·상태·검색) / L2(연도·부서) / L3(연도·시설분류·소관부서·검색). 검색 재렌더는 `EDUFILTER.rerender` 필수.
- **표** (`.table-figma` + 그룹 행 modifier): 이행항목(그룹 행, 펼침/접힘 `▼▶`, 충족 x/y·문서 합계) → 하위 업무단계 행(단계명·이행주기·회차 n/need·이행상태 chip·수행 주체·문서 N건·법령 ⓘ).
  - 그룹 기본 펼침 조건: 그룹 안에 지연·미이행이 있으면 펼침(와이어프레임 동작).
  - 법령 ⓘ 는 **hover 툴팁이 아니라 인라인 펼침**(`.lawinfo-inline`, §10) — 법령근거·법정주기·수행시점조건 3항.
- **L2 부서 단위**: 세그먼트 토글(부서별 보기 / 단계별 보기).
  - 부서별 보기: 부서 행 + 정기 이행률 바 + 정기/상시 충족 + 미이행 + 문서 수.
  - 단계별 보기: 단계 행 + 부서 이행 도트(39칸) + 이행 부서 n/39.
  - ⚠ **데이터 갭 (MUST 노출)**: 원장(`DYDOCH`)은 재난안전과 문서라 **부서 귀속 데이터가 없다**(`sr` 은 수발신 기관 — 부서 축 사용 금지, doc-history-data 헤더 주석). 부서별 수치는 `DY_DOCS_V2` 의 부서 보유분 + 시연 보강값 범위에서만 채우고, 나머지는 와이어프레임과 같은 방식으로 `자료 미취합` 행·도트(황색)로 **정직하게 드러낸다**. 지어내 채우지 말 것.
- **L3 관리대상 단위**: 시설물 행(관리대상·소관부서·분류·적용 단계 이행 칩·충족 n/m). 시설 데이터는 `facil-data.js`(FMS 80건) 파생. 시설↔적용 단계 매핑은 시설 분류→`FAC-*` 단계 키워드 파생이며 **추정임을 캡션에 명시**. 하단에 와이어프레임의 Phase 1/2 note 유지.
- **범례 행**: 충족·진행중·지연·미이행·비해당 5종 — chip-status 실물로 렌더.

### 4-2. 이행 상세 (②) — 단계 행 클릭 시 진입

같은 페이지 안에서 본문 교체(뒤로 링크 제공). 2단 레이아웃(좌 340px 고정 / 우 가변, `lg` 이하 1단 세로 — 표준 브레이크포인트 §8).

- 좌: 단계 코드·명 + 정의(법령근거 — DYLAW 인라인 / 법정주기·운영주기 / 수행시점조건 / 적용대상 / 이행주체) + 해당 연도 이행상태·회차·전년 실적 건수.
- 우: `{연도} 등록 문서` 표(문서명·구분·수발신자·보고일자·결재상태) + 우상단 `[📁 작년 문서 불러오기]` `[+ 새 문서 등록]`.
  - 미충족 회차가 있으면 `.v2-empty` 로 "○○ 회차가 비어 있습니다" + 불러오기 버튼(와이어프레임 empty 동작).
  - 하단 `{전년} 문서 (N)` 요약 + `지난연도 전체 보기` → `cmp-docs.html?stage={id}&year={전년}` 딥링크.
  - **연도 셀렉터를 과거 연도로 바꾸면 등록 버튼이 사라지고 그 연도 문서만 표시**(와이어프레임 캡션 동작 — 과거 연도에 소급 등록 금지).

### 4-3. 작년 문서 불러오기 모달 (③)

`DYV2.openModal` 단일 모달(§1). 헤더에 단계 코드·명·전년 등록 건수, 검색 입력 + 전체 선택, 체크박스 목록(문서명 / 구분·일자·생산번호 메타), 푸터에 **불러올 항목 체크(문서명·수발신자·보고일자)** + `불러오기 (n)`.
- 하단 안내: **"불러오는 것은 메타데이터뿐"** — 본문·결재 PDF 는 온나라 연동 필요(갭). `DYPOLICY` 기존 항목과 중복 신설하지 않는다.

### 4-4. 누락 점검 (⑥) — 두 번째 서브탭

- 필터: 연도·부서 + 축 토글(전체/중대산업재해/중대시민재해/산안법/개별법 — 이행항목 id 접두 `IND/OSH/DSM/FAC…` 과 lawBases 파생).
- 헤더: `미이행 단계 N개` + `정기 x + 상시 y` + **2년 연속 규칙 설명**(전년에도 0건이면 `□ 2년 연속` chip — danger tone).
- 그룹 블록: 이행항목(또는 축) 단위로 미이행 단계 나열 — 단계명·법령근거·주기·연도별 건수, 우측 `[해당 — 문서 등록]`(등록 흐름) / `[비해당 — 사유 기재]`(사유 필수 모달).
- 하단 note(와이어프레임 그대로): "비해당 처리에는 사유가 반드시 필요합니다 … 비해당 이력은 기록에 남고 매년 재확인합니다."
- `[일괄 비해당 처리]`: 선택 단계 목록 + 공통 사유 입력 + **처리 건수 명시** 확인 모달(§4 CRUD 회수 명시와 같은 기준).

## 6. 권한·조회 범위

- **조회 범위(scope)를 걸지 않는다** — 기존 이행 목록과 같은 근거(§5: 원자료가 재난안전과 원장이라 걸면 타 부서 담당자에게 0건). L2 의 "부서 담당자는 자기 부서 1행" 은 **기본 필터 프리셋**(자기 부서 자동 선택)으로 구현하고 제한이 아님을 밝힌다.
- **조작(등록·비해당·불러오기·이어받기)은 `DYROLE.canAct(deptId)`** — 관리·감독 계층(head/super)은 조회만. 차단 안내는 `DYROLE.readOnlyNote()`.
- 완료 확인 축(재난안전과 담당자)은 기존 이행 목록 소관 — 신버전이 재구현하지 않는다.

## 8. 법령 근거 (§10)

- `DYLAW.MAP` 에 `'cmp-status'` `'cmp-docs'` 추가. 기존 `docs-exec`/`docs-preset` 과 같은 성격(문서 보존·비치)이므로 `['osh-164']` 를 그대로 쓴다 — 검증 6문 중 #2(직접 이행 수단) 판단도 기존 화면과 동일하게 성립.
- `PAGE_FILES`(pageId→파일) 표에 새 파일 2개 등재.
- 행 단위 법령 표기는 `stage.law` 원문 문자열 + `DYLAW.resolveBasis` 흡수 — 화면에서 조문 표기를 조립하지 않는다.

## 9. 갭 — 그럴듯하게 채우지 않는 것 (§14-12)

1. **L2 부서 귀속 데이터 미취합** — 원장은 재난안전과 문서. 부서 도트·부서별 수치는 미취합 표시.
2. **계층(L1/L2/L3)·시설↔단계 매핑은 문자열 파생 추정** — 발주처 확정 대상 캡션 상시 노출.
3. **결재 PDF·본문 미보유** — 온나라 연동 전. 불러오기는 메타데이터만.
4. **회차 기한은 달력 말일 추정** — 실제 공문 기한 아님.
5. **GNB `업무 관리` 라벨 중복** — 발주처 확인 사항(§1).
6. L3 회차 전수 관리는 Phase 2 (와이어프레임 note 유지).
