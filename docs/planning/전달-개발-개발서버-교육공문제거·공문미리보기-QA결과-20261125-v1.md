## 3. 확인해 주세요

### 3-1. 재난안전과 일반 공무원(B) 계정은 화면마다 범위가 다릅니다

| 화면 | 계정 B에서 보이는 것 · 할 수 있는 것 |
|---|---|
| 정기교육 › 자체교육 탭 · 기타교육 | **전 부서** 교육이 보이고, 건설과 증빙 파일도 내려받아집니다 |
| 채용시교육 · 이수현황 · 이행점검 | **재난안전과만** 보입니다 |
| 정기교육 상세(예: `/edu/reg/8`) › 등록 현황 | 건설과 참석자는 «#2, #3», 서명부는 «제출됨»으로 보이고 내려받을 수 없습니다 |
| 같은 상세의 재난안전과 서명부 · 출장 결과 보고서 | 내려받아집니다. 출장 결과 보고서는 할 일로 뜨고 창도 열리지만 파일 업로드는 거절됩니다(2-5) |
| 집합교육 등록 · 이행점검 [점검 배포] | 없습니다(«집합교육은 재난안전과 담당자가 등록합니다») |

- **엇갈리는 점**
  - 건설과 증빙 파일은 받는데, 건설과 참석자 이름은 가려집니다.
  - 출장 결과 보고서는 할 일 · 창이 열리는데(저장은 막힘), 집합교육 등록은 아예 없습니다. 교육 요청서 §8에서는 둘 다 «재난안전과 담당자»의 일입니다.
- **알려 주세요**
  - ① 재난안전과 일반 공무원의 조회 범위는 전 부서입니까, 재난안전과만입니까?
  - ② «재난안전과 담당자»를 무엇으로 판정합니까? 부서입니까, 권한 등급(전담부서)입니까?
- **기획 의견**: 재난안전과 소속이면 전 부서를 조회합니다. 고칠 수 있는 범위는 한 가지 기준으로 화면마다 같게 판정합니다.
- 메뉴 권한과 버튼 판정을 맞추는 일은 11-05 운영 점검 P03에서 따로 논의 중입니다. 이번에는 ① · ②의 지금 동작만 알려 주시면, P03과 함께 정리해 다시 드리겠습니다.
