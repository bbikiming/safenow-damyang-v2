사용자 요약 4줄(교육의 핵심 목적)은 녹취와 **부합**한다. 아래는 요약에 없어 자료에 추가해야 하는 결정 사항이다.

| # | 녹취에서 주무관이 말한 것 | 요약에 있나 | 자료에서 다룰 자리 |
|---|---|---|---|
| 1 | 방식 둘 중 하나를 **미리** 정해야 한다 — ㉠ 알림만 주고 부서가 고르게 / ㉡ 법이 맞는지 우리가 직접 찾아 주기. 어느 쪽이든 알림은 간다 | 없음 | S05 |
| 2 | 법 강의 금지. 컴퓨터실에서 **본인 온나라 계정으로 문서대장**을 열어 법 목록과 일치 여부 확인. 법 **검색 방법**까지 안내 | 「직접 과거 문서를 확인」으로만 | S06·S07 |

## 2. 클로드 디자인 프롬프트 (그대로 붙여 넣기)

```
담양군 중대재해예방 통합관리시스템 「교육 운영 방식 — 부서 검증 워크숍」 설명 자료를 만들어 줘.
16:9 슬라이드 12장 안팎, PowerPoint(.pptx) 내보내기 가능. 이것은 교육 본편이 아니라
「교육을 이렇게 운영하자」를 재난안전과 팀장과 내부 팀에 설명하는 자료다.

■ 듣는 사람
- 재난안전과 팀장(결정권자) · 주무관(기획 당사자) · 수행사 내부(기획·교육 담당).
- 팀장은 이 자료를 보고 「왜 교육이 법 강의가 아니라 검증 워크숍인가」를 납득하고, 과장에게 올려
  각 부서 직원을 참여시키는 공문을 내보내게 되어야 한다.

■ 첨부 문서에서만 사실을 가져온다
- 첨부 「§3 사실」의 수치·고유명사만 쓴다. 없는 숫자는 「(확인 중)」으로 비운다.
- 1차 교육 덱 프롬프트의 디자인 규칙(담양 녹 #2D9270 계열 · 인주색 #BB4B4B 는 빠짐·미확정 전용 ·
  Pretendard · 한글 어절 중간 줄바꿈 금지 · 「 」 괄호 · 본문 18pt 이상)을 그대로 따른다.
- 말투는 존댓말 평서문. 주어는 「부서 담당자」·「재난안전과」·「시스템」. 「수행사」·「당사」 금지.

■ 슬라이드 구성
S01 표지 — 「교육 운영 방식 제안 / 부서 검증 워크숍」 · 부제 「법 강의가 아니라, 우리 부서 문서로 법을 확인하는 자리」 · 일자 비움.

S02 [12일 보고에서 확인받을 것은 두 가지입니다]
  좌우 2칸. ① 「A 부서가 무엇을 안 했는지를 시스템이 눈으로 보여 주는가」 — 이행 관리 화면에서 부서 1곳(예: 공간재생과)을 골라
  「서류 0건인 할 일」이 뜨는 모습(캡처 자리). ② 「온나라 연계」 — 상신·SSO 로그인은 개발 완료, 교육에서는 비중을 낮추고
  실사용 전까지만 되면 된다. 하단 한 줄: 「이 자료는 ①을 교육으로 어떻게 채우는가에 대한 것입니다.」

S03 [왜 교육이 「시스템을 완성하는 자리」인가]
  3단 논리. ① 법이 어느 부서 업무인지는 문서대장으로만 확인할 수 있다 — 공무원은 1~2년 순환이라 사람의 기억이 아니라 과거 공문이 근거다.
  ② 문서대장 AI 분석은 2025년 20개 부서·2021~2024년 6개 부서까지만 됐고 나머지 부서는 원장이 없다(§3-1). 컨설팅은 비용·일정상 불가.
  ③ 그래서 빈 자리는 「그 부서 담당자가 자기 온나라 문서대장을 열어 보는 것」으로만 채울 수 있다 — 그것이 교육이다.
  노트: 「교육을 한두 번 하고 끝내면 절대 완성되지 않습니다. 12월까지 반복합니다.」

S04 [AI 분석이 이미 해 둔 것과 못 한 것]
  표 2열. 해 둔 것: 적용 법령 2종 → 법정 이행항목·업무단계 분류 / 2025년 20개 부서 문서를 한 건씩 판정(증빙 확정·제외·원문 확인) /
  할 일마다 전년도 서류 연결. 못 한 것: 원장이 없는 19개 부서 / 제목만으로 판정 불가한 문서(원문 확인) / 부서 확인 필요 문서 /
  「어느 할 일을 어느 과가 맡는가」(부서별 소관표 — 이것이 없어 부서별 이행률을 못 낸다). 수치는 §3-1.

S05 [방식은 둘입니다 — 먼저 정해야 합니다]
  좌우 비교표. ㉠ 알림만 보내고 부서가 스스로 고른다: 준비 적음 / 담당자도 재난안전과도 「내 일인지」 모르는 채 알림만 간다 / 완성도 낮음.
  ㉡ 법이 맞는지 직접 찾아 준다: 준비 많고 힘들다 / 완성도 높다 / 담당자가 쓸 수 있게 다듬어진다.
  아래 제안 상자: 「시스템이 ㉡의 절반을 이미 합니다 — 후보(원문 확인·부서 확인 필요·서류 0건 할 일)를 부서별로 뽑아 줍니다.
  남은 절반(그 후보가 우리 업무인지 판정)을 교육에서 부서가 합니다. 어느 쪽이든 알림은 갑니다.」
  노트: 「주무관님 표현대로 ㉡은 죽을 각오가 필요하지만, 후보를 시스템이 뽑아 주면 현장에서 판정만 하면 됩니다.」

S06 [검증 워크숍은 이렇게 진행합니다 — 1회차 90분]
  타임라인 5단. ① 15~20분 1차 교육 덱(왜·흐름·역할별 업무) ② 10분 「법을 찾는 법」 — 시스템의 법령 근거 칩과 조문 펼침,
  법제처 검색 요령 ③ 40분 실습 — 본인 온나라 계정으로 문서대장을 열고 배부받은 부서별 시트의 후보를 하나씩 판정
  ④ 15분 「없는데 해야 하는 것」 — 시트에 없지만 우리 부서가 매년 하던 안전보건 업무를 적는다 ⑤ 10분 시트 제출·다음 회차 안내.
  노트: 「법 강의는 머리에 안 들어옵니다. 자기 문서를 보면서 확인하는 것만 남습니다.」

S07 [부서별 검증 시트 — 시스템에서 뽑아 배부합니다]
  시트 서식 그림. 열: 문서(제목·보고일자·수발신) / 시스템이 붙인 할 일(후보) / 판정(3값 고정: 우리 업무 맞음 · 아님→이관 부서 · 할 일 다름→맞는 할 일) / 비고.
  아래 섹션 「서류 0건인 할 일」: 할 일 이름 / 법령 근거 / 판정(해당 · 비해당→사유 · 했는데 원장에 없음→문서 제목).
  하단: 「판정 값을 3개로 고정하는 이유 — 자유 기재는 분류 엑셀에 되돌려 넣을 수 없습니다.」 출처는 §3-2.

S08 [알림에는 과거 공문 제목이 함께 가야 합니다]
  예시 카드: 「근골격계 유해요인조사 — 3년 주기 · 2024년 실시 · 2027년 도래」 밑에 「2024-0X-XX 공문 제목 ○○○」.
  설명 2줄: 담당자는 제목을 보고 「전에도 했으니 해야 한다」를 안다 / 과거 문서대장을 통째로 넣을지는 미결(지저분해질 우려) —
  지금 시스템은 할 일마다 전년도 서류를 보여 주고, 온나라로 바로 건너가는 링크는 아직 없다(문서유통센터 신청·ID 매칭 확인 중).
  수치·상태는 §3-3.

S09 [대상·회차·일정]
  표: 대상 전 부서(읍면 포함) 39개 / 부서당 2명 — 실과·사업소는 차석+서무, 읍면은 재난 담당자+차석 / 컴퓨터실 정원 30명 → 78명을 3회차 /
  첫 회차 10월 셋째 주부터(다음 주는 시스템 수정 주간) / 12월까지 반복, 일정은 미뤄질 수 있음.
  하단: 「참여는 공문으로 요청하되, 팀장·과장이 직접 독려해야 움직입니다 — 그래서 12일 보고가 필요합니다.」

S10 [부서에 요청하는 것 — 공문에 들어갈 다섯 줄]
  ① 부서당 2명 지정(차석·서무 또는 재난 담당자) ② 회차 일시에 컴퓨터실 참석, 본인 온나라 계정 로그인 가능 상태 ③ 배부된 검증 시트의 후보를 전건 판정
  ④ 시트에 없지만 매년 하던 안전보건 업무가 있으면 공문 제목과 함께 기재 ⑤ 판정 결과는 재난안전과로 회신, 다음 회차에서 반영본을 다시 확인.
  노트: 「요청이 아니라 과업으로 적습니다. 요청으로 쓰면 안 옵니다.」

S11 [판정 결과는 이렇게 시스템에 돌아옵니다]
  흐름 4단: 시트 회수 → 분류 엑셀(기준표·문서목록·부서 소관) 반영 → 생성기 재실행 → 화면 갱신(할 일 연결·부서별 이행률 분모·알림 대상).
  한 줄: 「부서가 판정한 「우리 업무다」가 모이면 비로소 부서별 이행률을 낼 수 있습니다 — 지금은 분모가 없어 내지 않습니다.」

S12 [결정해 주실 것 세 가지]
  ① 방식 ㉠/㉡(제안은 「후보는 시스템, 판정은 부서」) ② 대상자 직급 기준과 회차 수 ③ 과거 문서대장 적재 범위(2021~ 6년치 유지 / 2020 이전 통합 적재 / 미적재).
  각 항목 옆에 「정해지면 바뀌는 것」 한 줄.

■ 만든 뒤 점검
- 숫자가 전부 §3 에 있는가. 「39개 부서 전건 분석 완료」처럼 사실과 다른 문장이 없는가(실측은 2025년 20개 부서).
- 「알림 문자 자동 발송」·「온나라 문서로 바로 이동」을 되는 것처럼 쓰지 않았는가.
- 판정 값 3개가 S07·S10·S11 에서 같은 낱말인가.
```

## 3. 사실 (첨부)

### 3-1. 분석이 된 범위

| 항목 | 값 |
|---|---|
| 적용 법령 | 2종(중대재해처벌법·산업안전보건법) · 법정 이행항목 28 · 업무단계 88 (분류기준 v5.0) |
| 2025년 원장 | **20개 부서** · 문서 52,560건 · 이행 증빙 확정 3,994건 · 업무단계 연결 69/88 |
| 원문 확인 필요 | 895건(80유형) — 제목만으로 판정 불가 |
| 부서 확인 필요 | 52건 — 후보 할 일은 붙었으나 확정 목록에 없음 |
| 분류 제외 | 48,172건(사유 5종) — 지우지 않고 목록에 남김 |
| 2021~2024 · 2026 상반기 | **6개 부서만**(재난안전과·물순환사업소·건설과·공공시설사업소·환경과·공간재생과) |
| 원장이 없는 부서 | 대상 39개 중 **19개**(2025 기준) — 교육에서만 채울 수 있다 |
| 부서별 소관표 | 없음 → 부서별 이행률을 내지 않음(「분모 확인 필요」) |

### 3-2. 검증 시트의 출처(시스템에서 뽑는 방법)

- 문서 목록(`cmp-docs`): 부서 조건 + 「원문 확인」·「부서 확인 필요」·「미분류」·「분류 확인」 칩 → CSV 내려받기.
- 이행 관리(`cmp-status`): 부서별 보기 → 「서류 0건인 할 일」 + 법령 근거 + 전년도 서류 → CSV 내려받기.
- 판정 값 3개(우리 업무 맞음 · 아님→이관 부서 · 할 일 다름→맞는 할 일)는 분류 엑셀 「문서목록」의 업무단계 열과 「기준표」 소관 열에 그대로 들어간다.

### 3-3. 시스템 상태(2026-10-08)

| 요구 | 지금 |
|---|---|
| 할 일에 과거 서류 보이기 | 있음 — 이행 관리가 할 일마다 전년도 서류를 보여 주고 「작년 서류로 채우기」가 있다 |
| 알림에 과거 공문 제목 | 없음 — 헤더 알림은 고정 시드. 본개발 반영 항목 |
| 온나라 문서로 바로 이동 | 없음 — 문서유통센터 신청 목적이 그것이나 온나라 문서 ID 매칭이 필요(개발 확인) |
| 온나라 결재 상신 · 새올 SSO 로그인 | 개발 완료 도메인에서 확인 중(10-08 현장 확인) |
| 과거 문서대장 적재 범위 | 미결 — 2021~ 6년치 유지 / 2020 이전 통합 / 미적재 중 결정 필요 |
| 재촉·알림 문자 자동 발송 | 없음 — 권고만, 발송은 사람 |

### 3-4. 녹취의 결정·일정

- 대상 전 부서·부서당 2명(차석+서무 / 읍면 재난 담당자+차석) · 컴퓨터실 30명 · 78명 3회차.
- 10-12(월) 재난안전과 팀장 보고(하늘 팀장·기획 참석) → 다음 주 시스템 수정 주간 → **10월 셋째 주부터 교육** · 12월까지 반복.
- 교육 시간: 덱 15~20분 + 온나라 문서 확인 실습. 세인 이사는 12·13일 불가, 목·금 재협의.
- 주무관 역할: 직원 참여를 끌어내는 것. 공문 발송 전 팀장·과장 납득 필요.
