# 운영 서버 2권한 실습 — 원페이퍼 (2026-10-08 · 군청 PC)

**주소** `https://safety.damyang.go.kr/login` · **브라우저** Microsoft Edge (IE 모드 끄기 · 배율 `Ctrl+0` · 팝업 «항상 허용» · 비밀번호 저장 «안 함»)

## ① 계정 — 창 두 개를 나란히

| 창 | 권한 | 아이디 | 비밀번호 | 부서 | 할 수 있는 것 |
|---|---|---|---|---|---|
| **일반 창** | 🟦 재난안전과 담당자 | QA박안전1 | ______________ | 재난안전과 | 전 부서 조회 · 등록 · 확인 · 상신 · 독촉 |
| **InPrivate 창** (`Ctrl+Shift+N`) | 🟩 부서 담당자 | QA하정수1 | ______________ | 물순환사업소 | 내 부서 일만 |
| (로그인 안 함) | 결재선 검토 · 결재 | QA박안전2 · QA박안전3 | — | 재난안전과 | 공문 결재선에서 고르기만 |

- 비밀번호는 개발자에게 받은 값을 적는다(이 문서에 미리 적혀 있지 않다). **5번 틀리면 잠김** → 개발자에게 해제 요청
- 로그인 **30분** 뒤 끊김 · 5분 전부터 맨 위 [연장]. 끊기면 다시 로그인해 이어서 한다
- 로그인 후 두 창의 **오른쪽 위 이름·부서**가 위 표와 같은지 먼저 본다

## ② 지킬 것 (운영 서버)

만드는 것은 이름을 **«현장_»** 으로 시작 · [독촉]·[재촉]·[알림 발송]은 실습 7번에서 1번만 · 남이 만든 데이터는 손대지 않기 · 🟩 창에 **남의 부서 것을 바꿀 수 있는 버튼**이 보이면 누르지 말고 캡처
