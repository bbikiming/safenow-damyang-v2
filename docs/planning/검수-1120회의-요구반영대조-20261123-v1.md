## 1. 결론

- **이번 단계 범위(교육 공문 제거 · 등록 간소화) 6건은 전부 «반영»이다**(R32~R37). 감사가 찾은 결함(교육 상세가 부서 실시 교육을 열어 대리 정정 가능 · 인사기록 이관 기록 정정 가능 · 채용시 묶음 일괄 취소 · 집합교육 삭제 기록 없음 등)과 문서 불일치는 이번에 고쳤다(정본 기획 §7-3).
- **회의 근거 없이 넓힌 것 두 가지는 유지하기로 정했다(2026-11-23 사용자 결정)** — 종료한 집합교육도 [수정] · 교육일을 늦추는 저장 제한. 공문 잠금이 없어진 뒤 «기록이 정본이니 고칠 수 있어야 한다»에서 나왔다.
- **나머지 영역은 사용자가 정한 순서상 아직이다** — 현업근로자 «근로자별 이수시간» 화면, 반기 의무이행 점검 개편(33건 중 26건), 온나라 문서 양식·붙임 분리, 엑셀 다운로드, 도급(회의가 보류). 일부는 기존 기능이 이미 충족한다(아래 표 «기존기능으로충족» 9건).
- **12월 실습 전에 꼭 고칠 것** — 이미 만든 2차 실습 사용 가이드 7부와 실습 설계 문서가 옛 공문 흐름을 가르친다(정본 기획 §5-4에 이름으로 적음). 개발 전달문도 아직이다.
