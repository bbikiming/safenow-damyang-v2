# 교육 자료 캡처 지시 — 어디를 · 어떻게 · 어떤 이름으로 (2026-11-19)

발표 자료 «2차 시스템 교육 · 1회차 재난안전과»에 넣을 화면을 **프로토타입에서** 찍는 작업 지시다. 다른 세션에서 이 문서만 보고 할 수 있게 썼다.

- 짝 문서: [`요청-교육자료-수정-최종-20261119-v1.md`](요청-교육자료-수정-최종-20261119-v1.md) — 그림이 들어갈 쪽과 번호 설명
- 그림 수: **51장**(위험성평가 16 · 안전보건교육 17 · 의견청취 6 · 이행점검 12) — 표의 줄 수와 같다

## 1. 공통 규칙

| 항목 | 값 |
|---|---|
| 여는 주소 | 저장소 루트의 HTML 파일(`rsk-list.html` 등). 로컬 서버 권장: `python3 -m http.server 8785` → `http://localhost:8785/` |
| 브라우저 | 크롬. **인터넷이 되는 PC에서 찍는다** — 화면이 Tailwind(CDN)와 Pretendard 글꼴을 인터넷에서 받는다. 막힌 환경에서는 입력 칸이 모달 밖으로 넘치고 글꼴이 달라진다 |
| 창 크기 | 1440 × 900 · 배율 2배(레티나) |
| 저장 폴더 | `docs/planning/교육자료-수정요청-캡처-20261119/` |
| 파일 이름 | 아래 표의 이름 그대로 · PNG |
| 찍는 범위 | 브라우저 전체가 아니라 **그 영역만** — 창(모달)은 창 하나, 카드 · 표는 그 블록 하나 |
| 번호 표시 | 넣지 않는다(원본만). 번호는 자료 제작자가 얹는다 |
| 가릴 것 | 위쪽 «단계별 안내» 바 · 첫 방문 도움말 배너 · 오른쪽 아래 안내 패널 · 토스트는 닫고 찍는다 |
| 남길 것 | «예시 자료» 칩은 가리지 않는다 |
| 고치지 않는 것 | 저장소의 코드 · 문서. 화면에서 만든 데이터는 브라우저에만 남는다 |

**계정 바꾸기** — 헤더 오른쪽 이름을 눌러 고른다.

| 부르는 이름 | 계정 | 쓰는 곳 |
|---|---|---|
| 재난 | 박안전 · 재난안전과 안전관리 주무관 | 재난안전과 화면 전부 |
| 부서 | 하정수 · 물순환사업소 주무관 | 부서 화면 전부 |
| 팀장 | 김중대 · 중대재해팀장 | 필요할 때만(재난안전과가 낸 이행점검 제출 검토) |

**주의**
- 데이터는 **브라우저 탭 하나**에 남는다. 한 탭에서 계정만 바꿔 가며 순서대로 진행한다. 새 탭을 열면 처음부터다.
- 처음으로 되돌리려면 헤더 `[?]` 도움말 › «예시 데이터 되돌리기».
- 날짜는 실제 오늘 날짜로 판정한다. **집합교육 일자는 오늘**로 넣어야 교육 뒤 단계가 열린다. 부서에 주는 기한은 오늘 이후만 들어간다.
- 못 만드는 상태는 비슷한 화면으로 대신하지 말고 «못 찍음 + 이유»로 남긴다.
- 찍지 않는 것: 위험성평가 **결과 공문 기안 창**(프로토타입은 옛 화면이다).

## 6. 끝나면

1. 폴더의 파일 이름이 위 표와 같은지 본다(빠진 번호 · 다른 이름 없음).
2. 한 장씩 열어 **의도한 상태인지 · 글자가 잘리지 않았는지** 본다.
3. 못 찍은 그림은 이 문서 아래에 «파일 이름 — 이유»로 적는다.
4. 화면이 이 문서의 설명과 다르게 움직인 곳이 있으면 함께 적는다(그 자체가 교육 자료에 반영할 정보다).

## 참고 — 이 세션에서 확인된 화면 동작

- 정기평가 생성 창은 두 걸음이다: «1. 부서 선정» → «2. 점검일 · 설문 기한».
- `[입력 완료]`는 한 번에 끝나지 않는다. 블록 안에 «n건이 개선조치가 됩니다» 확인 줄이 펼쳐지고 거기서 한 번 더 누른다.
- 조치 요청 때 고르지 않은 부서는 표에서 빠지고, 표 아래 «지적사항 없는 부서 n개 제외» 한 줄로 나온다.
- 조치 요청 뒤 부서 줄에는 `[관리]`와 `[입력 재촉]`이 함께 나온다.
- 종결 버튼의 전체 이름은 `[평가 종결 — 조치 대상 없음]`이다.
- 평가 카드 머리에는 «조치 완료 n개 · 지적사항 없음 n개» · «제출 n/n» · «개선 n/n (%)»가 보인다.
