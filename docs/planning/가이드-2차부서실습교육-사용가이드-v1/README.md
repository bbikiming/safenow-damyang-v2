시스템 관리를 뺀 **모든 사용자 메뉴**를 덮는 사용 가이드 7부의 원고·조판·배포본이다. 10-26 에 부서 사용자용 4부를 냈고, 11-03 에 재난안전과 운영 가이드 2부와 부서용 «그 밖의 메뉴» 1부를 더하고 자주 묻는 질문에 재난안전과 묶음을 넣었다(근거 `기획/전체메뉴가이드_기획_v1.md`). 화면은 운영 서버(safety.damyang.go.kr) 2026년 10월 기준이다.

## 다시 뽑기

```bash
cd 조판
python3 -P build.py 1 release      # 1 · 2 · faq · doc · ops1 · ops2 · etc — release 를 빼면 편집 메모가 남는 초안
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=out.pdf guide1_rel.html
```

- Pillow 와 Pretendard 글꼴이 필요하다. 산출물(`img/`·`*.html`·`*.pdf`)은 `.gitignore` 로 뺀다.
- 배포본 모드는 편집 메모가 하나라도 남으면 멈춘다.
- 실명이 찍힌 원본 캡처(`*_원본실명.jpg`)는 저장소에 넣지 않았다. 조판은 그 파일을 쓰지 않는다.

## 남은 것

- **원고를 11월 프로토타입 화면에 맞춰 고쳤다 (2026-11-13) — 배포본·조판은 아직 옛 원고 그대로다.** 운영 가이드 ①·② · 프로그램 업무 · 과장·팀장 · 자주 묻는 질문 원고를 예시 데이터 «11월 운영 기준» 화면과 대조해 고쳤다(위험성평가 설문·조치 요청 흐름 · 결과 공문은 옛 화면 그대로임을 밝힘 · 집합교육 일괄 등록·사람별 참석시간·정정 · 교육 공문 «온나라로 보내기»·다시 기안 · 이행점검 배포→결과 제출→검토→마감 · 경영방침 게시 확인 · 내 할일 «배정 대기» · 과장 계정 조회 전용). **배포본 PDF는 `조판/build.py`로 원고에서 다시 뽑아야 한다** — PDF 를 손으로 고치지 않는다. 각 원고 맨 끝 «그림 다시 찍기» 표의 그림은 화면과 달라 다시 찍어 `그림/`에 넣은 뒤 조판한다(배포본 모드는 «⚠ 확인 필요»가 남아도 빠지지만, 그림이 옛 화면이면 그대로 실린다).

- **2차 교육 흐름(2026-11-11) 새 캡처** — 원고는 새 흐름(설문·조치 요청 공문 · 부서 직접 작성·[입력 완료] · 기한 연장)으로 고쳤고 그림 자리만 남았다: 운영 가이드 ① 2-10~2-13 · 프로그램 업무 2-21~2-23. 운영 서버 반영 뒤 찍는다(S2-07 은 설문 기한 칸이 없는 옛 화면).
- **옛 화면이라 뺀 그림** — S6-02·04·06·07 · R08 · N3-03 · E02·E03 · U1-02·03 · U2-01 · T1-05 · T2-05. 교육 뒤 다시 찍어 넣는다(11-06 간소화 결정 — 교육 전에는 다시 찍지 않는다). 그 밖에 연도·자료 줄만 다른 그림도 교육 뒤.
