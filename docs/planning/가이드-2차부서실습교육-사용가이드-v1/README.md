구성의 근거는 [`기획/2차교육_사용가이드_기획_v3_업무유형.md`](기획/2차교육_사용가이드_기획_v3_업무유형.md)이다 — 업무 유형 3가지(① 내 할일에서 처리 · ② 메뉴에서 처리 · ③ 문서 업무)로 나누되 ①·②는 한 부로 묶고 ③만 따로 낸다.

## 폴더

| 폴더 | 내용 |

| `배포본/` | 가이드 다운로드에 올리는 PDF. 편집 메모·«⚠ 확인 필요»·빈 그림 자리를 뺀 판 |

| `기획/` | 구성 기획 v3 · 메뉴 전수 조사(부서 담당자 / 재난안전과 비교) — **내부 자료, 배포하지 않는다** |

## 다시 뽑기

```bash
cd 조판
python3 -P build.py 1 release      # 1 · 2 · faq · doc — release 를 빼면 편집 메모가 남는 초안
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=out.pdf guide1_rel.html
```

- Pillow 와 Pretendard 글꼴이 필요하다. 산출물(`img/`·`*.html`·`*.pdf`)은 `.gitignore` 로 뺀다.
- 배포본 모드는 편집 메모가 하나라도 남으면 멈춘다.
- 실명이 찍힌 원본 캡처(`*_원본실명.jpg`)는 저장소에 넣지 않았다. 조판은 그 파일을 쓰지 않는다.

## 남은 것

- 문서 업무 가이드 **3부(업무단계별 문서 목록)** — 재난안전과가 처리유형 «미확인» 44개 단계를 분류한 뒤 2판에서 채운다.
- 문의처 전화번호 빈칸(«☎ __________»).
- 원고의 «⚠ 확인 필요» — 과장 계정 화면, 새올 포틀릿 진입 캡처, 연간 일정, «2025년 문서 불러오기» 흐름, «부서 도착»의 뜻. 자주 묻는 질문의 확인하지 못한 답은 «재난안전과 문의»로 적었다.
- 되돌릴 수 없는 저장(수시평가·기타교육·측정/검진 계획·의견 등록)은 운영 서버에 저장하지 않아 저장 뒤 화면을 찍지 않았다.
