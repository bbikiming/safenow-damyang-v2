# 사용 가이드 — 남은 메뉴 전체 기획 v1.1

> 2026-11-03 · v1.1 — 4장 결정 반영(같은 날) · 앞서 만든 4부(프로그램 업무 · 문서 업무 · 과장·팀장 · 자주 묻는 질문)에 이어, **시스템 관리를 뺀 모든 사용자 메뉴**를 가이드로 덮기 위한 기획이다. 아직 원고·캡처는 하지 않는다.
> 근거: 운영 서버 메뉴 전수 조사 2건(2026-10-23, 부서 담당자 QA하정수1 · 재난안전과 QA박안전1) · 기존 4부 원고. **조사 뒤 열흘이 지났으므로 로그인 뒤 메뉴를 다시 훑어(읽기만) 바뀐 곳부터 반영한다.**

## 5. 로그인과 촬영 순서

**로그인할 곳** — Claude 데스크톱 앱 안의 **브라우저 창**(오른쪽 패널). 지금 `https://safety.damyang.go.kr/login` 을 열어 두었다. 크롬이 아니라 이 창에서 로그인한다(제가 보는 화면이 이 창이다). 비밀번호는 제가 넣지 않는다.

| 순서 | 계정 | 무엇을 하나 | 쓰는 곳 |
|---|---|---|---|
| ① | **재난안전과 담당자**(QA박안전1 — TEAM) | 메뉴 다시 훑기(읽기만) → 운영 ①·② 캡처 | 가이드 5·6 |
| ② | **부서 담당자**(QA하정수1 — 물순환사업소) | «보기만» 화면 · 통계·보고 캡처 | 가이드 7 |
| ③ | 가능하면 **과장 계정**(재난안전과장 또는 부서장) | 과장 화면이 실제로 무엇을 보는지 — 기존 과장·팀장 가이드의 «⚠ 확인 필요» 해소 | 가이드 3 보완 |

- 계정을 바꿀 때는 말씀해 주시면 제가 로그아웃까지 하고, 로그인은 직접 해 주신다.
- 저장 규칙은 지금과 같다 — «저장해서 완료 화면까지 찍고 바로 되돌리거나 지운다. 되돌릴 수 없는 저장은 하기 전에 묻는다.»
- 실명이 찍힌 그림은 흐림 처리본만 쓴다.
