## 3. 개발·담양에 물을 것

1. 보낸 뒤 안내 문구는 «온나라 **연계기안함**에서…»로 — 정정판 v2 가 Q2 답 전이라 «기안함»으로 적어 보냈다.
2. 결재 결과 읽어 오기(문서조회)가 **교육 전에** 붙는가 — 안 붙으면 «반려되면 잠금이 풀린다»가 교육 때 성립하지 않는다. 가이드 문장 세기를 이것으로 정한다.
3. 미리보기·확인 문구 «문서번호 미채번 · 상신할 때 확정» / «문서번호가 채번되고» — 이제 틀린 말. 고치는지.
4. 보고서·제증명 `[온나라 결재]`(운영② 381) — 상신 경로 목록에 없다. 실제로 무엇을 하는지.
5. 의견 등록 작성자 `부서명` «-»(프로그램 549 ⚠) — 어느 요청서에도 없다. 새로 요청.
6. 과장·팀장 `[담당자 지정]`(P03·P04 보류) — 교육 전에 등급 구성원을 바꾸지 않는지. 바꾸면 과장 가이드 26·106·167 이 틀린다.
7. 개선조치 `[조치 상세 →]`의 «담당 미지정» 표시(프로그램 254 — 결함을 정상이라 적음), 수시평가 흐름 끝 «확인» 단계(프로그램 306) — 운영 동작 확인.
