# 메뉴 전수 조사 — 재난안전과 계정, 부서 담당자 계정과 비교

> 2026-10-23 · 운영 서버 `safety.damyang.go.kr` · 계정 **QA박안전1 (TEAM · 재난안전과)** — QA박안전5로 안내받았으나 로그인된 계정은 QA박안전1이었다. 같은 등급(TEAM)이라 그대로 조사했다.
> 방법은 부서 담당자 조사(`2차교육_메뉴전수조사_부서담당자.md`)와 같다. 화면을 열어 글자와 버튼만 기록했고 **아무것도 저장하지 않았으며 등록 창도 열지 않았다.**

## 1. 한눈에

- 재난안전과 계정에는 **35개** 화면이 보인다. 부서 담당자(33개)보다 **`인력·예산 › 평가 설정`**과 **`인력·예산 › 예산 기준 설정`** 2개가 더 있다. 이 계정에도 `시스템 관리`는 보이지 않는다.
- 두 계정의 차이는 크게 셋이다.
  1. **보는 범위** — 재난안전과는 전 부서, 부서 담당자는 소속 부서
  2. **여는 일** — 집합교육 등록, 공문 기안, e호조 계약 반입, 기준값 설정 같은 «업무를 여는» 버튼은 재난안전과에만 있다
  3. **전 부서에 대해 하는 일** — 이행점검의 `[확인 등록]`·`[독촉]`이 재난안전과에는 67개 부서 전부에 붙는다
- 반대로 **두 계정에 똑같이 보이는 버튼**이 많다(경영방침 `[+ 등록]`, 조직 `[+ 선임 등록]`, 산업안전보건위원회 `[+ 위원 추가]`, 협의체, 인력 평가 `[결재상신]`, 예산 `[+ 점검표 생성]`, 이행점검 `[반기 마감 · 온나라 상신]`). 서버가 이 화면들에서 두 등급을 가르지 않는다는 뜻이다 — 교재에서는 «누가 하는 일인가»를 업무 규칙으로 정해 써야 한다(4장).

## 3. 교재 권별로 쓰는 법

### 3-1. 2권 (과장·팀장) — 재난안전과 계정 화면을 «예시»로 쓸 때 가릴 것

과장·팀장은 관리·감독 계층이라 조회만 한다(권한정의 §4-4). 재난안전과 계정으로 찍은 화면에서 아래는 **가리거나 잘라 낸다.**

| 화면 | 가릴 것 |
|---|---|
| 통합 현황 | «전사 범위» 문구 → «우리 부서» 범위로 설명 |
| 내 할일 | `[확인하러 가기]` `[평가 보기]` 카드 전체 |
| 이행점검 | 다른 부서 줄 전체, 모든 `[확인 등록]` `[독촉]`, `[미이행 65개 부서 독촉]`, `[반기 마감 · 온나라 상신]` |
| 정기·수시 위험성평가 | `[관리]` `[결재 상태]` `[해제]` `[검토파일 등록]`, 다른 부서 줄 |
| 교육 화면 전부 | `[집합교육 등록]` `[공문 기안]` `[삭제]` `[수정]` `[참석자 등록부 등록]` |
| 업무 관리 | `[＋ 문서 등록]` `[＋ 새 문서 등록]` |

2권에 싣는 화면은 **통합 현황 · 내 할일(우리 부서 진행) · 위험성평가 진행 상황 · 이행점검 우리 부서 줄 · 교육 이수현황 · 업무 관리 부서 줄** 정도로 좁힌다. 과장 계정이 실제로 무엇을 보는지는 1판 전에 과장 한 분께 확인받는다(기획 v2 §7-1).

### 3-3. 1권 (부서 담당자) — 지난 조사에서 «?»였던 화면

두 계정의 버튼이 같아 서버로는 가를 수 없다. **누가 하는 일인지 업무 규칙으로 정해 주셔야** 1권에 넣을지 정한다.

| 화면 | 두 계정에 같이 있는 버튼 | 제안 |
|---|---|---|
| 경영방침 | `[+ 등록]`(새 버전) | 재난안전과 일 → 1권에서 «보기만» |
| 조직 | `[+ 선임 등록]` `[점검 완료 확정]` `[수행평가 작성]` 등 | 재난안전과 일 → 1권 «보기만» |
| 산업안전보건위원회 | `[+ 위원 추가]` | 재난안전과 일(군 단위 위원회) → 1권 «보기만» |
| 협의체·점검표 | `[+ 위원 추가]` `[+ 운영 결과 등록]` | 도급 발주 부서 일 → 1권 9장(도급, 보류)에 함께 |

| 예산 총괄표 | `[+ 점검표 생성]` | 편성 주체 확인 필요 — 1판에서 뺀다 |
