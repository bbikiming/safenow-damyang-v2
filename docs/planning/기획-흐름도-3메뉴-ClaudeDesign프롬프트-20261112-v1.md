## 1. 디자인 기획 (제안)

### 1-1. 한 장의 모양 — «역할 줄(레인) × 순서»

| 결정 | 이유 |
|---|---|
| 가로 = 순서(왼쪽 → 오른쪽), 세로 = **사람 줄**(재난안전과 담당자 · 재난안전과 팀장·과장 · 부서 담당자 · 부서장 · 군수) + 맨 아래 **«온나라» 줄** | «권한별로 누가 무엇을 하나»가 줄만 보면 보인다. 온나라에서 일어나는 일을 따로 한 줄로 빼야 «시스템에서 끝나는 일»과 «온나라에서 이어지는 일»이 갈린다 |
| 블록 하나 = **동사 하나**(«공문 보내기», «결과 내기») + 한 줄 설명 | 초등학생 기준 — 블록 제목만 읽어도 흐름이 따라와야 한다 |
| 블록마다 **번호표**(이-1, 위-5, 교-3) | 보는 사람이 «위-5가 틀려요»라고 짚을 수 있게 — 맞다/아니다를 받는 장치 |
| 아직 정하지 않은 곳에 **노란 메모지** | 그림에서 «여기는 아직 안 정했어요»가 보여야 질문이 넘어간다(지어내 채우지 않는다) |
| 위에 **«누구 눈으로 볼까요?»** 버튼(전체 / 재난안전과 담당자 / 부서 담당자 / 과장·팀장 / 군수) — 고르면 다른 줄은 흐려진다 | 부서 담당자에게 9단계를 다 보여 주면 자기가 9번 일하는 줄 안다. 흐리게만 하고 지우지 않는다 — «내가 왜 기다리는지»가 보여야 한다 |
| 그림 아래 **«이 사람은 이것만 해요»** 카드 | 역할별 요약 — 부서 담당자는 «딱 2가지» 같은 말로 끝낸다 |

### 1-2. 블록 모양 6가지 (약속)

| 모양 | 뜻 | 보기 |
|---|---|---|
| 흰 네모 + 왼쪽 색띠(사람 색) | 사람이 이 시스템에서 하는 일 | 결과 내기 |
| **주황 봉투 모양(접힌 모서리) + 굵은 테두리 + «온나라» 딱지** | **온나라로 공문 보내기** — 가장 눈에 띄어야 한다 | 실시 통보 공문 |
| 보라 점선 둥근 칩 + 종 그림 | 시스템이 **저절로** 하는 일(할 일·알림 생김) | «부서에 할 일이 생겨요» |
| 회색 점선 구름 | **시스템 밖**에서 하는 일 | 교육 실시 · 용역 현장 점검 |
| 흰 마름모 | 갈림길(맞으면 / 아니면) | 승인? 반려? |
| 짙은 회색 + 자물쇠 | 잠김(더 못 고침) | 이번 반기 잠김 |

온나라 봉투 블록은 딱지가 둘이다 — **«시작 공문»**(보내면 부서에 할 일이 생겨요) · **«마감 공문»**(보내면 잠겨요). 비전문가가 공문을 «왜 보내는지»로 구분할 수 있게 한다.

### 1-3. 화살표 3가지

- 굵은 실선 = 다음 차례
- 보라 점선 = 알림·할 일이 넘어감
- **빨간 곡선** = 되돌아감(반려·다시 내기)

### 1-4. 판형

16:9 한 메뉴 한 장(발표·화면 공유) + 맨 앞 «그림 읽는 법» 한 장 = 4장. 각 장은 1920×1080 에서 글자 최소 16px. 인쇄(A3 가로)도 깨지지 않게.

## 2. Claude Design 에 붙여 넣을 프롬프트

```text
[무엇을 만드나]
담양군청 공무원에게 보여 줄 «업무 흐름 그림» 4장짜리 슬라이드(16:9, 1920×1080)를 만들어 주세요.
보는 사람은 컴퓨터 화면 설명을 들어도 흐름을 잘 못 따라오는 분들입니다. 초등학생이 봐도 알 수 있을 만큼 쉬워야 합니다.
이 그림을 보여 주고 «이 흐름이 맞나요, 아닌가요?»를 확인받는 것이 목적입니다.

장 구성
 0장. 그림 읽는 법(약속) — 블록 모양 6가지, 화살표 3가지, 사람 색 5가지, 번호표·노란 메모지 뜻
 1장. 반기 이행점검
 2장. 정기 위험성평가
 3장. 안전보건교육(정기 집합교육)

[그림 모양 — 모든 장 공통]
- 가로는 순서(왼쪽에서 오른쪽), 세로는 «사람 줄»입니다. 줄 이름은 왼쪽에 크게.
  줄 순서(위→아래): 재난안전과 담당자 / 재난안전과 팀장·과장 / 부서 담당자 / 부서장(과장·팀장) / 군수 / 온나라(맨 아래, 바탕을 연한 주황으로)
  할 일이 거의 없는 줄(군수 등)은 얇게, 줄 안에 «보기만 해요»라고 적습니다.
- 블록 하나에는 «동사 하나»만. 제목 최대 10자 정도, 아래 설명 한 줄(해요체). 어려운 말 금지:
  쓰지 말 것 → 연계기안함, 생산등록번호, 호출기안, 시행문, 모집단, 파생, 상태 전이
  대신 → 온나라 기안함, 문서번호, 공문, 대상자
- 블록마다 왼쪽 위에 작은 번호표(예: 이-1, 위-5, 교-3). 보는 사람이 번호로 짚을 수 있게.
- 블록 모양 6가지:
  ① 사람이 이 시스템에서 하는 일 — 흰 네모, 왼쪽에 사람 색 띠
  ② 온나라로 공문 보내기 — 주황 봉투 모양(오른쪽 위 모서리 접힘), 굵은 주황 테두리, «온나라» 딱지, 봉투 그림. 그림에서 가장 눈에 띄게.
     딱지 두 종류: «시작 공문 — 보내면 부서에 할 일이 생겨요» / «마감 공문 — 보내면 잠겨요»
     봉투 블록에서 맨 아래 온나라 줄로 굵은 화살표가 내려갑니다.
  ③ 시스템이 저절로 하는 일 — 보라 점선 둥근 칩, 종 그림 («부서에 할 일·알림이 생겨요»)
  ④ 시스템 밖에서 하는 일 — 회색 점선 구름 («시스템 밖»)
  ⑤ 갈림길 — 흰 마름모 («승인? / 반려?»)
  ⑥ 잠김 — 짙은 회색 네모 + 자물쇠
- 화살표 3가지: 굵은 실선(다음 차례) / 보라 점선(알림·할 일이 넘어감) / 빨간 곡선(되돌아감·다시 내기)
- 사람 색(차분한 색, 원색 금지): 재난안전과 담당자 = 파랑 / 재난안전과 팀장·과장 = 연한 파랑 / 부서 담당자 = 초록 / 부서장 = 연한 초록 / 군수 = 회색.
  온나라 주황, 자동 보라, 반려 빨강, 노란 메모는 사람 색과 겹치지 않게. 색만으로 뜻을 말하지 말고 늘 글자를 같이 씁니다.
- 노란 메모지(살짝 기운 포스트잇) = «아직 안 정했어요». 해당 블록 옆에 붙이고 질문을 한 줄로 씁니다.
- 각 장 위쪽: 제목 + 한 줄 요약 + «누구 눈으로 볼까요?» 버튼 5개(전체 / 재난안전과 담당자 / 부서 담당자 / 과장·팀장 / 군수).
  하나를 고르면 그 사람 줄만 진하게, 나머지는 흐리게(지우지 말 것).
- 각 장 아래쪽: «이 사람은 이것만 해요» 카드 줄(사람별 1장, 할 일 개수를 큰 숫자로).
- 글씨는 Pretendard, 블록 제목 22px 이상, 설명 16px 이상. 블록 사이 넉넉히. 그림자 약하게. 장식 아이콘은 단순 선 아이콘.
- 블록이 많아 한 줄이 넘치면 두 단(위·아래 단)으로 접고 «→ 이어서» 표시를 합니다. 가로 스크롤 금지.
- 각 장 제목 바로 아래 얇은 «상태 띠»: 그 업무가 화면에서 어떤 상태 이름으로 보이는지 왼쪽→오른쪽으로(각 장에 적어 둔 대로).
- 각 장 맨 아래 작은 글씨: «틀린 곳은 번호로 알려 주세요 (예: 위-5가 달라요)».
- A3 가로로 인쇄해도 한 장이 한 쪽에 들어가게. 인쇄할 때는 «누구 눈으로 볼까요?» 버튼을 숨기고 전체 보기로 찍힙니다.

[0장. 그림 읽는 법]
블록 6가지 모양을 실제 크기로 하나씩 놓고 옆에 뜻을 씁니다. 화살표 3가지, 사람 색 5가지, 번호표, 노란 메모지.
맨 아래 큰 글씨 한 줄: «주황 봉투가 나오면 → 온나라로 공문이 가는 곳이에요. 이 시스템은 온나라 기안함까지만 보내고, 검토·결재는 온나라에서 담당자가 정해요.»

[1장. 반기 이행점검 — 반기마다 한 번]
한 줄 요약: «재난안전과가 점검표를 보내면 → 부서가 써서 내고 → 재난안전과가 확인하고 → 군수께 보고해요.»
(산업재해·시민재해 두 가지를 따로 하지만, 그림은 한 번만 그리고 블록 이-1 옆에 «산업재해·시민재해 따로 한 번씩»이라고 작게 씁니다.)
상태 띠: 이번 반기 — 배포 전 → 진행 중 → 기한 지남 → 마감 보고됨(잠김) / 부서 한 줄 — 안 냄 → 확인 기다림 → 확인 완료 (또는 반려 → 다시 냄 · 대상 아닌 부서는 «대상 아님»)

 이-1 [재난안전과 담당자 · 흰 네모] 점검 준비
      «점검표 양식, 안내, 제출 기한, 대상 부서를 정해요»
 이-2 [재난안전과 담당자 · 주황 봉투 · 시작 공문] 실시 통보 공문 보내기
      «공문을 쓰고 → 미리 보고 → 온나라로 보내요. 결재자는 여기서 안 골라요»
      → (보라 칩) «보내는 순간 대상 부서에 ‘결과 제출’ 할 일과 알림이 생겨요» → 부서 담당자 줄로 점선
      → (작은 글씨) «못 보내면 점검이 시작되지 않아요»
      → 온나라 줄: [온나라 기안함에 도착] → [담당자가 온나라에서 검토·결재 정하고 올림] → [결재 끝 → 부서마다 공문 도착]
         옆 작은 글씨: «부서는 시스템 알림을 먼저, 온나라 공문은 결재 뒤에 받아요»
         옆 작은 글씨: «온나라에서 공문을 돌려보내도 점검은 계속돼요 — 공문만 다시 보내요»
 이-3 [부서 담당자 · 흰 네모] 점검표 내려받아 쓰기
      «부서장 확인을 받아요»
 이-4 [부서 담당자 · 흰 네모] 결과 내기
      «셋 중 하나를 골라요: 전부 했어요 / 일부 못 했어요 / 우리 부서는 해당 없어요 — 쓴 점검표를 붙여요»
      «일부 못 했으면 → 무엇을, 언제까지 할지 적어요. 해당 없으면 → 이유를 적어요»
      «내고 나면 우리 부서 할 일은 끝! (결과가 무엇이든)»
      «우리 부서 사람이면 누구나 낼 수 있어요. 다른 부서 것은 대신 못 내요»
      → (보라 칩) «재난안전과에 ‘검토해 주세요’ 알림»
      옆 가지: 안 내면 → [독촉] 블록(재난안전과 담당자·팀장·과장 줄과 부서장 줄에 걸쳐) «안 냈거나 반려 뒤 다시 안 내면 → 재난안전과나 우리 부서장이 재촉해요»
 이-5 [재난안전과 담당자 + 팀장·과장 줄의 ‘팀장’ · 흰 마름모] 검토
      «점검표를 열어 보고 → 승인 / 반려(이유 꼭)»
      «자기가 낸 것은 자기가 검토하지 않아요»
      반려 → 빨간 곡선으로 이-4로 돌아감 + (보라 칩) «부서에 ‘다시 내 주세요’ 알림»
 이-6 (보라 칩) «모두 승인됐거나 기한이 지나면 → ‘마감 보고할 차례예요’ 알림» → 재난안전과 담당자
 이-7 [재난안전과 담당자 · 주황 봉투 · 마감 공문] 반기 마감 · 군수 보고
      «보고서를 미리 보고(부서별 결과, 못 한 일과 계획, 안 낸 부서) → 온나라로 보내요»
      «안 낸 부서가 있어도 보낼 수 있어요»
      «마감 보고는 산업재해·시민재해를 합쳐 반기에 한 번이에요» (이-1의 «따로 한 번씩»은 점검·실시 통보 공문까지만)
      → [잠김 · 자물쇠] 이번 반기 잠김 «내기·검토·독촉을 더 못 바꿔요. 온나라에서 돌려보내면 다시 열려요»
      → 온나라 줄: [기안함 도착] → [담당자가 온나라에서 검토·결재 정하고 올림] → [결재 끝 → 군수께 보고]
 이-8 [부서 담당자 · 흰 네모 · 점선 테두리] 다음 반기에
      «지난번 ‘일부 못 했어요’였던 부서는 → 그 일을 했는지 같이 적어요»
      이-8에서 이-1로 큰 점선 고리 화살표 «다음 반기»

 군수 줄: «보기만 해요» / 재난안전과 과장: «보기 + 독촉» / 부서장: «보기 + 우리 부서 독촉 (우리 부서에 담당자 계정이 없으면 부서장이 결과를 내요)»
 아래 카드: 재난안전과 담당자 «준비 · 공문 · 검토 · 독촉 · 마감 보고 + 우리 부서(재난안전과) 결과도 내요» / 재난안전과 팀장 «검토 · 독촉» / 재난안전과 과장 «보기 · 독촉» / 부서 담당자 «쓰고 내기 1가지» / 부서장 «확인 · 독촉» / 군수 «보기»

 위-1 [재난안전과 담당자 · 흰 네모] 올해 평가 만들기
```
