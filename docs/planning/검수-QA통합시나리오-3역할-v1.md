# 2. 진행 규칙

**① 채팅 신호** — 내 차례가 끝나면 번호와 함께 올린다. 다음 사람은 그 신호를 보고 시작한다.

```
[A-3 끝] 재난안전과 → 부서1·2 : 평가 만들었어요
[A-4 끝] 부서1 : 확인했어요
[A-4 이슈] 부서2 : 알림에 안 떠요 (캡처)
```

**② 부서의 «3곳 확인»** — 재난안전과에서 일이 넘어오면, 하기 전에 세 곳에 **같은 건이 있는지** 먼저 본다. 한 곳이라도 없으면 이슈로 올린다.

> 대시보드 > **내 할일** · 화면 맨 위 **알림(종)** · 해당 **메뉴**

**③ 매 단계 함께 보는 것**

- 버튼을 눌렀는데 아무 일이 없거나 오류 창이 뜨면 이슈
- 첨부한 파일 이름이 **새로고침(F5) 뒤에도** 남아 있다
- **상대가 올린 파일**을 눌러 실제로 열린다 («…연계 후 제공됩니다» 안내면 메모만)
- 이력에 **내 계정 이름**이 남는다

**④ 이슈 올리는 법** — 번호 · 화면 · 한 일 · 기대한 것 · 실제 · 캡처. 막혀서 못 넘어가면 `[보류]`.
