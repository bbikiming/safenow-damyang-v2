# 2. 브라우저 설정 — Microsoft Edge

실제 사용자인 공무원이 엣지를 쓰므로 **세 사람 모두 엣지로만** 테스트한다.

**엣지 설정 7가지 (시작 전에 한 번)**

1. **엣지로 연다** — Microsoft Edge 실행 → 주소창에 `https://safety.damyang.go.kr/login`
    - 주소창에 «Internet Explorer 모드» 표시가 있으면 끄고 다시 연다
2. **버전을 적어 둔다** — 오른쪽 위 `…` → 도움말 및 피드백 → Microsoft Edge 정보 → 버전 숫자를 채팅에 올린다
3. **화면 배율 100%** — `Ctrl + 0`. 창은 최대화한다
4. **내려받을 때마다 묻게 한다** — `…` → 설정 → 다운로드 → «다운로드 시 수행할 작업 확인» 켬 · «브라우저에서 Office 파일 열기» 끔
5. **팝업 차단 풀기** — 주소창 오른쪽에 «팝업이 차단됨»이 뜨면 «항상 허용»
6. **묻는 창은 거절한다** — 비밀번호 저장 → 안 함 · 페이지 번역 → 안 함
7. **한 창에는 한 계정만** — 다른 계정을 봐야 하면 `Ctrl + Shift + N`(InPrivate 창)

**자주 쓰는 키**

| 하고 싶은 것 | 키 |
| --- | --- |
| 새로고침 | `F5` (화면이 옛 모습 같으면 `Ctrl + F5`) |
| 화면 캡처 | `Win + Shift + S` → 영역 선택 → 채팅에 `Ctrl + V` |
| 내려받은 파일 보기 | `Ctrl + J` |
| 오류 자세히 보기(이슈가 났을 때만) | `F12` → «콘솔» 탭의 빨간 줄을 캡처 |

- 로그인이 끊기기 **5분 전**부터 화면 맨 위에 남은 시간과 [연장] 버튼이 뜬다. [연장]을 누르면 이어진다. 끊겨서 로그인 화면이 나오면 다시 로그인하고 이어서 한다

- **내 할일** — 맨 위 «대시보드» → 왼쪽 «내 할일»
- **알림** — 화면 맨 위의 종 모양. «해당 화면 바로 열기 →»가 붙은 알림만 누르면 그 화면으로 간다
- **메뉴를 못 찾겠으면** — 맨 위 [전체메뉴]

**① 채팅 신호** — 내 차례가 끝나면 번호와 함께 올린다. 다음 사람은 그 신호를 보고 시작한다.

```
[A-3 끝] 재난안전과 → 부서1·2 : 평가 만들었어요
[A-4 끝] 부서1 : 확인했어요
[A-4 이슈] 부서2 : 알림에 안 떠요 (캡처)
```

**② 부서의 «도착 확인»** — 재난안전과에서 일이 넘어오면, 하기 전에 아래를 먼저 본다.

- **메뉴** — 그 업무 화면에 내 부서 건이 있다 (항상 확인)
- **알림(종)** — 왔는지 📝 본 대로 적는다 (어떤 일에 알림이 오는지 아직 모른다)
- **내 할일** — 위험성평가(정기 · 수시 개선조치)만 카드로 온다. 교육 · 측정 · 검진 · 이행점검은 내 할일에 뜨지 않는 것이 정상이다

**③ 매 단계 함께 보는 것**

- 버튼을 눌렀는데 아무 일이 없거나 오류 창이 뜨면 이슈
- 첨부한 파일 이름이 **새로고침(F5) 뒤에도** 남아 있다
- 이력에 **내 계정 이름**이 남는다
- 필수 칸을 비우면 **저장 버튼이 눌리지 않는(흐린) 화면**이 많다. 안내 문구가 없어도 정상이다

**④ 이슈 올리는 법** — 번호 · 화면 · 한 일 · 기대한 것 · 실제 · 캡처. 막혀서 못 넘어가면 `[보류]`.

**⑤ 운영 서버다**

- 만드는 것은 전부 이름을 **«통합_»** 으로 시작한다 → 끝난 뒤 개발자에게 일괄 삭제 요청
- **독촉은 C-31에서 1번만** 누른다. 그 밖의 [독촉] · [재촉] · [알림 발송] 버튼은 누르지 않는다
- 앞선 QA가 남긴 다른 사람 이름의 데이터는 건드리지 않는다
- 부서 계정 화면에 **남의 부서 것을 바꿀 수 있는 버튼**이 보이면 누르지 말고 캡처해서 이슈 후보로 올린다

# A. 정기 위험성평가

**들어가는 곳**: 맨 위 «위험성평가» → 왼쪽 «정기 위험성평가». 따로 적지 않으면 A는 모두 이 화면에서 한다.

**무슨 일인가**: 재난안전과가 한 해에 한 번 평가를 열어 부서를 지정한다 → 부서가 설문조사표를 낸다 → 재난안전과가 용역 보고서를 올리고 부서별 개선조치를 적어 내려보낸다 → 부서가 조치하고 사진을 올린다 → 재난안전과가 **부서 단위로** 확인(또는 반려)한다 → 전 부서가 확인되면 공문을 올린다.

```
🟦 평가 만들기·부서 지정 → 🟩🟧 설문조사표 제출 → 🟦 보고서·개선조치 입력 → 🟦 부서로 전달
→ 🟩🟧 조치 완료 → 🟦 부서별 확인·반려 → 🟩 재제출 → 🟦 공문 상신
```

**화면은 세 번 바뀐다** — ① 보고서를 올리기 전: 부서 표(양식 · 제출본 칸) ② 보고서를 올린 뒤: 부서별로 펼치는 개선조치 작성표 ③ 부서로 전달한 뒤: 부서 표 + 줄마다 [관리] 버튼.

| 🟩 부서1 | 통합_1-2 해당 없음 | 시설물 [해당 없음]을 누른 행 |
| 🟩 부서1 | 통합_1-3 늦게 완료 | 마지막까지 남겨 두는 건 |
| 🟧 부서2 | 통합_2-1 정상 | 그대로 완료 |

확인과 반려는 건마다가 아니라 **부서 전체에 한 번에** 한다. 그래서 길을 부서별로 나눈다.

| 부서 | 가는 길 |
| --- | --- |
| 🟩 부서1 | 2건만 완료(확인이 안 열림) → 3건 모두 완료 → **반려** → 재제출 → **또 반려(2회차)** → 재제출 → 확인 |
| 🟧 부서2 | 기한 변경 → 3건 모두 완료 → **바로 확인** |

# B. 수시 위험성평가

**들어가는 곳**: 맨 위 «위험성평가» → 왼쪽 «수시 위험성평가»

**무슨 일인가**: 설비가 바뀌거나 사고가 나는 등 사유가 생기면 그때그때 올리는 평가다. 등록하면 개선조치가 바로 생긴다. 재난안전과는 조치를 확인하지 않고 **안전관리자 검토파일만** 붙인다(정기평가와 다른 점).

```
🟦 부서를 골라 등록 → 🟩🟧 조치 · 🟦 검토파일   /   🟩🟧 직접 등록 → 🟦 검토파일 → 🟩🟧 조치
```

# C. 안전보건교육

**들어가는 곳**: 맨 위 «안전보건교육». 왼쪽 메뉴가 세 묶음이다 — **현업근로자**(정기교육 · 채용시교육 · 기타교육) / **관리감독자**(정기교육 · 채용시교육 · 기타교육) / **교육 현황·관리**(이수현황 · 근로자 명단 관리 · 결재 이력).

**무슨 일인가**: 먼저 교육받을 사람(근로자 명단)을 등록한다 → 교육을 등록하고 참석자를 붙인다 → 이수현황에 시간이 쌓인다 → 안 받은 사람을 독촉한다 → 실시 결과를 공문으로 올린다.

**누가 무엇을 하나** — 집합교육 등록 · 교육 종료 · 교육 삭제 · 공문 기안 · 관리감독자 정기/기타교육 등록은 **재난안전과만** 한다. 부서는 근로자 등록 · 참석자 등록부 · 자체교육 · 채용시교육 · 기타교육 등록을 한다. 교육은 **내 할일에 카드가 뜨지 않는다**(정상) — 부서는 메뉴에서 직접 찾는다.

# 참고 — 결함이 아닌 것

- 필수 칸을 비우면 안내 문구 없이 버튼만 눌리지 않는 화면이 많다
- 조치 완료의 서명은 직접 적지 않고 로그인한 이름이 자동으로 들어간다
- 정기평가의 확인 · 반려는 건마다가 아니라 부서 전체에 한 번에 한다
- 수시평가는 재난안전과의 조치 확인 단계가 없다
- 교육 · 측정 · 검진 · 이행점검은 내 할일에 카드가 뜨지 않는다
- 교육 공문 기안과 교육 삭제는 재난안전과만 한다
- 업무 관리는 서류를 올리면 바로 «이행»이 된다(확인 · 반려 단계 없음)
- 정기평가 화면의 양식 · 제출본 · 보고서는 파일 이름만 보인다
- 의견청취 · 시설물은 부서 구분 없이 다 보인다
- 과장 · 팀장의 담당자 지정은 계정이 없어 이번 범위 밖
