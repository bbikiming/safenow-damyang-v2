# 기획 회신 — 운영 서버 재검수 회신에 대한 답 (2026-11-10)

> 회신 잘 받았습니다. 정해 달라고 하신 것 셋(독촉 · 보고서 한도 · 농업기술센터)을 정했고, 위험성평가 등록 방법은 말씀대로 받습니다. 1-6 · 1-8 · 2-12 는 회신대로 진행해 주세요.

---

## 1. 독촉 «자기 자신» — **나**로 해 주세요

**자기 부서 줄의 `[독촉]`은 그 부서 담당자 계정에서 내립니다.** 정본의 «자기 자신에게는 보내지 않는다»는 부서 단위로 읽습니다.

| 누르는 사람 | 자기 부서 줄 | 다른 부서 줄 |
|---|---|---|
| 그 부서 담당자(부서 안전보건 담당자) | **버튼 없음** | 버튼 없음(주관부서가 아니므로) |
| 부서장(과장 · 소장 · 읍면장) | 있음 — 자기 부서 담당자를 독촉 | 없음 |
| 재난안전과 담당자 | **없음**(재난안전과 줄) | 있음 — 나머지 38개 부서 |

- 적용 범위는 받는 사람이 «그 부서 담당자(없으면 부서장)»인 독촉 셋입니다 — **이행점검 · 경영방침 · 교육**. 선택칸도 함께 내립니다(버튼이 없는 줄에 선택칸만 남기지 않습니다).
- **위험성평가 조치기한 재촉은 그대로**입니다 — 받는 사람이 조치 담당자 한 사람이라 지금처럼 누른 사람 본인만 빼면 됩니다.
- 부서 계정에서는 결과적으로 이행점검 · 경영방침의 독촉 버튼이 모두 사라집니다. 가이드의 «독촉은 재난안전과가 씁니다»와 맞습니다. 재검수 요청서 2-1(부서 계정 반기 마감 · 점검표 작성)을 고치실 때 함께 고쳐 주시면 됩니다.
- 정본에 반영했습니다 — 알림 관리 정의서 §6 · 이행점검 · 경영방침 · 교육 이수현황 정의서.

## 2. 위험성평가 보고서 — **한도를 올려 주세요(나)**

**정기 위험성평가의 «용역 통합 보고서» 첨부 칸만 파일당 30MB** 로 올려 주세요.

- 다른 첨부 칸은 그대로 20MB 입니다 — 전체 한도를 올리지 않습니다. 형식(12종)과 개수(10개)는 일반 증빙과 같고 용량만 다릅니다.
- 이유 — 용역 보고서는 하나의 결과물이라 나눠 올리면 «어느 파일이 정본인가»가 흐려지고, 담양군이 받은 원본과 시스템의 파일이 달라집니다. 2026년 보고서가 755쪽 · 24MB 이고, 다음 해에도 비슷한 분량이 옵니다.
- 정본에 반영했습니다 — 화면 정의서 공통 규칙 §5(첨부) · 정기 위험성평가 정의서.
- 교육 전 배포에 넣어 주시고, 올라가면 알려 주세요. 그 뒤에 저희가 등록합니다.

## 3. 2026년 정기 위험성평가 등록

말씀하신 방법(**생성 → 보고서 첨부, 설문조사표 양식은 올리지 않음**)으로 넣겠습니다. 알림이 나가는 자리를 짚어 주셔서 고맙습니다.

| 항목 | 정한 것 |
|---|---|
| 2026년 평가가 이미 있는지 | **없습니다** — 11-10 재난안전과 계정 화면에 «2026년 정기 위험성평가가 등록되지 않았습니다»로 나옵니다. 확인하지 않으셔도 됩니다 |
| 대상 부서 | **19곳** — 행정과 · 재무과 · 향촌복지과 · 문화체육과 · 관광과 · 경제교통과 · 건설과 · 산림정원과 · 축산원예과 · 환경과 · 보건행정과 · **농촌지원과 · 기술보급과 · 미래농업연구단** · 공공시설사업소 · 물순환사업소 · 담양읍 · 대덕면 · 무정면 |
| 농업기술센터 | 보고서의 «담양군농업기술센터»는 그 아래 **세 과를 모두** 대상으로 고릅니다. 세 과 모두 점검단위(39)에 있어 생성 화면을 39개로 좁힌 뒤에도 고를 수 있습니다 — 조직도는 따로 손대지 않으셔도 됩니다 |
| 점검일자 | 보고서에 부서별 날짜가 없어 **실시 시작일 2026-04-08 로 통일**합니다 |
| 보고서 첨부 | 위 2번 한도가 배포된 뒤 |
| 개선조치 | 지적사항을 개선조치로 돌릴지(`[부서 전달]`)는 재난안전과가 보고서를 보고 따로 정합니다 — 그 전에는 누르지 않습니다 |

- 생성 화면 안내(«생성 시 대상 부서에 점검예정일이 통보됩니다 …»)와 이력의 «점검일자 통보» 문구를 사실대로 고치시는 것 — 그대로 진행해 주세요.
