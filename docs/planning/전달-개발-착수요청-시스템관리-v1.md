## 2. 착수 판정 — 기획 확인 대기 0건

- 다섯 정의서의 **§7 미결사항이 전부 「없음」**입니다. 기획 확인을 기다릴 항목이 없습니다.
- 항목 41개 중 **34개는 외부 의존 없음**, **7개는 값의 원천이 밖에 있는 연계 데이터 축**입니다.
- **연계 데이터 축도 「나중에 만들 것」이 아닙니다** — 미수신 동안의 동작이 확정돼 있어 **화면·상태·문구를 지금 완성**하고, 값이 붙으면 표시가 바뀝니다.

항목별 판정은 [전달-개발-시스템관리-구현범위-v1.md](전달-개발-시스템관리-구현범위-v1.md) §2에 표로 있습니다.

## 3. 완료 기준 — 무엇이 되면 끝인가

| 화면 | 완료 기준 |
|---|---|
| 사업장 관리 | 목록 7열 조회 · 등록/수정(조건부 필수 검증 포함) · 비활성화(사유·처리자·시각) · 측정대상 3상태 |
| 프리셋 양식 관리 | 양식 목록(표준/사용자) · **양식 식별값+버전 단위 저장** · 항목 편집(입력 형식 10종) · 사용중 항목 삭제 차단 |
| 사용자 관리 | 사용자 목록 · 등급 요약 · **접근 메뉴 역조회(근거 포함)** · 조직 직접 등록 4상태 · 병합·승계 |
| 알림 관리 | 이벤트 20행 규칙 표 · 시점·수신대상 설정과 검증 · 발송 이력 조회 · **내부 알림 발송** |
| 연계 관리 | 카드 4장(7상태) · FMS·법제처 **실제 파생** · 로그 표 + 조회 조건 · 재시도(대상 집계·3회 게이트) |

**연계 데이터 축이 비어 있는 상태가 정상 완성 상태입니다.**

- 사용자 관리 — 조직도 등록분만 표시 + **갭 상시 노출**, 「최근 접속」은 `없음` 명시
- 알림 관리 — 내부 알림으로 동작, **외부 발송 성공을 가장하지 않음**
- 연계 관리 — 온나라·행정포털 카드는 **「연계 이력 미구현」**. 정상·지연·실패 어느 것으로도 표시하지 않는 것이 맞습니다(버그 아님)

## 4. 반드시 지킬 계약 5

전부 각 정의서 §6에 근거가 있습니다. 구현 중 판단이 갈리는 자리라 앞에 모읍니다.

1. **성공을 가장하지 않는다** — 동기화·발송이 실제로 일어나지 않았으면 성공 문구를 쓰지 않습니다. **「받았는데 0건」과 「한 번도 안 받음」을 같은 문구로 쓰지 않습니다.**
2. **정본이 밖에 있는 값은 만들지 않는다** — 조직도가 정본입니다. 사용자 명단을 이 시스템이 따로 두면 인사이동 때 여기만 옛 상태로 남습니다. 연계 수신분은 **읽기 전용**, 보완값은 **별도 축**, 출처는 **행마다 표시**.
3. **지우지 않고 사용중지한다** — 조직·양식·항목·사업장 전부. 물리 삭제하면 과거 권한·업무·결재 참조가 끊깁니다.
4. **소급하지 않는다** — 양식을 바꿔도 **기존 문서는 당시 버전**으로 보이고, 규칙을 바꿔도 이미 나간 알림은 그때의 규칙으로 나간 것입니다. ※ 프리셋에서 가장 놓치기 쉬운 계약이고, 놓치면 나중에 저장 구조를 뒤집어야 합니다.
5. **상태판과 작업 화면을 섞지 않는다** — 연계 관리는 「지금 연결이 살아 있는가」만 답합니다. 수신·검토·반영과 연계 파라미터는 도메인 화면(`SCR-FAC-004·005`)이 갖고, **재시도는 연계 관리 한 곳**, 그 화면 안에서도 **누를 자리가 하나**입니다.

**만들지 말 것 7건**(결재 회신 알림 · 「부분 실패」 상태 · 재정 시스템 카드 등)은 구현범위 문서 §5에 이유와 함께 있습니다 — 「빠진 것 아닌가」 싶은 자리라 먼저 보시길 권합니다.

## 6. 회신이 필요한 것

- **연계 규격은 이 저장소에 없습니다.** 어느 값이 연계 데이터이고 받기 전까지 화면이 어떻게 동작하는지까지가 기획 몫이라, **어떻게 받아 오는가는 개발에서 정해 주시면 됩니다.**
- 정의서를 읽고 **기획 판단이 더 필요한 지점이 나오면 알려 주세요.** 저희 판단으로는 없지만, 있으면 그건 정의서의 공백이므로 채워 드리겠습니다.
- 담양군 제공 대기 자료(부서 명단 11/39 · 기관정보·관인 등)는 화면에서 **「미등록」으로 드러나게** 만들어 두었습니다. 그럴듯하게 채우지 말아 주세요 — 빈자리가 보여야 결정이 넘어갑니다.
