# 검수 — 안전보건교육 · 작업환경측정: 업무 주체 · 히스토리 · 플로우 (2026-11-16)

> 읽기 전용 검수다. 코드·문서 대조로 확인했고 브라우저 실측은 하지 않았다. 이 문서는 수정 지시가 아니다.
> 목적: 두 메뉴가 «주무관 단독 관리 메뉴»인지 «부서 취합 업무»인지 판정하고, 현재 UI/UX·플로우의 누락을 찾고,
> 지향점인 **«파일 첨부 → 공문 기안 → 온나라 보내기» 단순 플로우**와의 거리를 잰다.

## 1. 결론 요약

- 두 메뉴 모두 **혼합형**이다 — 부서가 넣고 재난안전과가 마감한다. 주무관 단독은 교육의 이수현황·결재 이력 2화면뿐이다.
- **교육**: 공문 축(단순 기안 · 결재선 없음 · 이미 올린 파일에서 붙임 · 보낸 뒤 잠금)은 이미 단순 플로우 모양이다. 문제는 그 앞이다 — 기안 차례가 재난안전과에 알려지지 않는다.
- **작업환경측정**: 공문 경로가 **아예 없다**. 실제 업무의 공문 두 종(MSDS 대상조사 요청 · 측정 결과 안내)을 다룰 수단이 없다.

## 5. 단순 플로우(«파일 첨부 → 공문 기안 → 온나라»)와의 거리

### 5-1. 이미 그 모양인 것
- 교육 공문 축 전체 — `EDUDOC` 단순 기안, 결재선 없음, 이미 올린 파일에서 붙임, 이수자 명단 별지 자동, 보낸 뒤 잠금.
- 기타·자체 교육의 첨부 1칸(`done` 프로필), 채용시 «교육 추가»(증빙 필수).

### 5-2. 작업환경측정 — 충돌 거의 없음
«측정 완료 처리» 뒤(또는 연 1회 대상조사 시작 때) `DYDOC.define({ simple: true })` 로 공문 기안 단계를 붙이면 된다. 기존 MUST 와 충돌하는 결정이 거의 없다.

### 5-3. 안전보건교육 — 걷어 내면 바뀌는 결정

단순화하면 잃는 것: 개인별 법정 이수 판정(이수현황·D-day·미이수 독촉), 대시보드 이수율·부서 할 일, 별지 이수자 명단의 근거(이수기록 파생), 채용시 미이수 탭.

충돌하는 CLAUDE.md §4 MUST: 집합교육 인정시간 = 등록부 실제 참석시간 · 등록부는 교육 뒤에만 · 할 일은 `deptTodos` 한 곳 · 채용시 기준일(채용일·지정일 중 늦은 쪽) · 지정일 없으면 판정 불가 · 특별교육 갈음 · 정기 주기 달력 반기 · 시간은 회차 파생 · 이수현황 모집단 공유 · 시연 투어 제거 금지 · `edu-data.js` 삭제 금지 · «현업근로자» 모집단. 근거가 07-30·11-12·11-13 발주처·주무관 결정이라 **담양군 확인이 먼저**다.

충돌하지 않는 것: 공문 규칙(교육 1건 단위 · 재난안전과 기안 · 잠금).

### 5-4. 확인 없이 할 수 있는 단순화(제안)
1. 자체·기타 교육 첨부를 필수로.
2. 재난안전과 내 할일에 «종료 대기 · 기안 대기» 추가.
3. 채용시 «교육 추가»를 묶음(교육 1건) 기본으로.
4. 작업환경측정에 공문 기안 단계 추가(5-2).

## 6. 확인이 필요한 것
- 교육: 집합교육 등록부 취합·개인별 이수 판정을 유지할지, «교육 1건 = 첨부 + 공문»으로 줄일지(담양군).
- 작업환경측정: 공문 두 종 중 시스템에서 기안할 것(대상조사 요청 / 결과 안내 / 둘 다), 대상조사 회신을 이 화면에서 받을지.
