## 1. 쓰는 법

아래 블록을 그대로 붙여 넣고, **사실 원장 문서를 함께 첨부**한다. 수치를 프롬프트에 직접 적지 않는다 — 분류 축이 늘면 프롬프트만 옛 수치로 남는다.

---

```
담양군 공무원을 대상으로 「담양군 중대재해예방 통합관리시스템」 교육 발표자료를 만들어 줘.

■ 대상과 목표
- 대상: 담양군 부서 담당자(주 대상) · 과장·소장(부 대상) · 재난안전과 담당자
- 이 사람들은 시스템을 처음 본다. 안전보건 전문가가 아니고, 자기 업무가 늘어날까 봐 경계하고 있다.
- 20분 안에 세 가지만 이해시킨다:
  ① 이 시스템이 무엇이고 왜 있는지
  ② 법령을 근거로 흩어진 문서를 한곳에 모은다는 것
  ③ 업무문서 이행 관리를 어떻게 하는지 (가장 중요)

■ 사실 근거
첨부한 「자료-공무원교육-사전자료-v1.md」의 수치와 문장만 쓴다.
- 그 문서 §7 「말하면 안 되는 것 9」를 반드시 지킨다.
- 특히 2026년 수치는 예시 자료이므로 담양군 실적으로 말하지 않는다.
- 문서에 없는 수치는 지어내지 말고 비워 둔다.

■ 형식
- 슬라이드 11장 안팎, 한 장에 메시지 하나.
- 발표자 노트를 각 장에 단다(진행자가 무엇을 말할지). 화면에서 켜고 끌 수 있게.
- 키보드 ← → 로 넘길 수 있고, 인쇄하면 장별로 페이지가 나뉜다.

■ 서사 (사전자료 §10 뼈대를 따른다)
표지 → ①왜 만들었나 → ②무엇이 문제였나 → ③법이 요구하는 것 → ④법을 일로 쪼갰다
→ ⑤2025년 실제 모습 → ⑥내 할 일은 어디 있나 → ⑦네 걸음 → ⑧놓친 것이 드러난다
→ ⑨자주 나오는 질문 → 한 문장 마무리

■ 핵심 시각 장치 (반드시 넣을 것)
법정 업무단계 177개를 칸 하나씩 격자로 그리고, 2025년에 증거가 있던 135개와 없던 42개를 다르게 칠한다.
분야별(중대산업재해·중대시민재해·산업안전보건·시설물·재난안전관리·관리업무)로 줄을 나누고
줄마다 이름과 「N개 중 M개 비었음」을 붙인다. 비율이 높은 줄은 강조한다.
→ 「이게 우리가 해야 하는 일 전부이고, 이만큼이 비어 있다」가 한 장에 보여야 한다.

■ 한국어 조판 (필수)
- CSS 에 word-break: keep-all; overflow-wrap: break-word; line-break: strict; 를 반드시 넣는다.
  없으면 「무 / 슨 일」처럼 어절 중간에서 끊긴다.
- 한글에 letter-spacing 을 크게 주지 않는다(0.02em 이하). text-transform: uppercase 는 한글에 무의미하다.
- 겹화살괄호 « » 를 쓰지 않는다. 인용은 「 」 로 한다 — 공문서에서 실제로 쓰는 괄호다.
- 프로젝터를 전제로 본문은 최소 16px, 설명 문단은 15px 이상으로 한다.

■ 어휘
- 담당자가 실제로 쓰는 말로 쓴다: 「법으로 해야 하는 일」·「서류」·「했다는 증거」·「빈칸」.
- 설계 용어를 화면에 내지 않는다: 이행항목·업무단계·증빙·회차·원장은 처음 나올 때 쉬운 말을 함께 적는다.
- 전문용어를 못 피하면 괄호로 풀어 준다. 예) 업무단계(실제로 하는 일)

■ 디자인
- 담양의 대숲에서 온 짙은 녹을 강조색으로, 공문서 관인의 인주색을 「비어 있음」에 쓴다.
- 밝은 화면과 어두운 화면 모두에서 읽히게 한다.
- 375px 폭에서 가로 스크롤이 없어야 한다.
```

## 2. 1차 산출물에서 실제로 고친 것

만들고 나서 공무원 사용성 관점으로 검토해 **6가지를 보완**했다. 다시 만들 때 같은 실수를 반복하지 않도록 남긴다.

| # | 문제 | 어떻게 보였나 | 보완 |
|---|---|---|---|
| 1 | **한국어 줄바꿈** | 카드 제목이 「서류 올리고 «무 / 슨 일»인지 표시」로 쪼개졌다 | `word-break:keep-all` — **가장 큰 결함**이었다 |
| 2 | **겹화살괄호 «»** | 28곳에 썼는데 개발 문서 어휘라 공무원에게 낯설고, 프로젝터에서 작게 보이면 못 알아본다 | 전부 「 」 로 |
| 3 | **발표용 글자 크기** | 본문 14.5~17px — 읽기용 크기라 회의실 뒤에서 안 보인다 | 본문 16~19px, 설명 15.5px |
| 4 | **격자가 해독되지 않음** | 177칸이 한 덩어리라 「이게 뭔데?」에서 멈춘다. 가장 중요한 사실(중대시민재해 13개 중 11개 빔)이 안 보였다 | 분야별 6줄 + 이름·부제·건수 + 미이행 비율 높은 줄 강조 |
| 5 | **자간** | 한글 라벨에 `letter-spacing:.14em`+`uppercase` — 「2 0 2 5 년 ,  실 제 로」처럼 벌어졌다 | 제거 |
| 6 | **발표자 노트 없음** | 진행자가 무엇을 말할지 자료에 없었다 | 장마다 노트 + `[노트]` 토글·`N` 키 |

**접근성·인쇄도 함께** — 격자 셀 177개에 `aria-hidden`(스크린리더 소음 제거)하고 격자 전체에 설명을 달았다. 인쇄 시 `print-color-adjust:exact` 로 색이 나가고 노트가 함께 인쇄된다.

## 3. 교육 당일 준비 (사전자료 §9 요약)

발표자가 화면 앞에서 당황하지 않으려면 알고 있어야 한다.

- 시스템의 「오늘」은 **2026-07-16 고정** — 실제 날짜와 D-day가 다르다.
- **로그인 화면이 없다** — 헤더 우측 「권한 전환」으로 페르소나를 고른다.
- **올린 파일의 실물은 저장되지 않고**, 저장 위치가 서버가 아니라 그 브라우저다. 옆자리 화면에는 안 보인다.
- **아직 안 되는 것이 36곳** — 누르면 「연계 적용 후 제공됩니다」 안내가 나온다.
- ⚠ **54개 화면이 외부 CDN에서 스타일을 받는다.** 인터넷이 막힌 내부 행정망에서 열면 깨질 수 있다 — **교육 전 반드시 그 망에서 한 번 열어 본다.**

## 4. 다음 판을 만들 때

- **수치를 프롬프트에 박지 않는다.** 사전자료 문서를 첨부하고 「이 문서의 수치만 쓴다」고 지시한다.
- **분량이 늘면 대상을 쪼갠다** — 부서 담당자용(4걸음 중심)과 과장·소장용(현황·책임 중심)은 필요한 장이 다르다.
- **실습을 붙이려면** 7장(네 걸음) 뒤에 실제 화면 시연을 넣는다. 시스템 안에 이미 「단계별 안내」가 있어 그대로 따라가면 된다.
