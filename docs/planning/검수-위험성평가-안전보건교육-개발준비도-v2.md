# 위험성평가·안전보건교육 구현 정합 검수 v2

> 검수일: 2026-08-11 · **개정 2026-08-13** — 법제처 원문 대조 재검증으로 아래 판정 여러 건을 뒤집었다(§8).  
> 범위: 실제 프로토타입 메뉴·화면과 현행 화면 정의서 12종  
> 정본 우선순위: 현재 프로토타입 기능·UX → 활성 화면 정의서 → 법령 보완 참고문서

## 1. 최종 판정

- **메뉴 구조:** 현재 구현과 화면 인벤토리가 일치한다.
- **화면 정의서:** 위험성평가 3종, 개선조치 2종, 안전보건교육 7종을 현재 구현 동작으로 수정했다.
- **문서-구현 불일치:** 2026-08-11 판정은 **0건이었으나 사실이 아니었다.** 2026-08-13 재검증에서 안전보건교육 축의 차단급 불일치 12건을 확인했고 전부 코드·문서 수정으로 해소했다(§8). 검수는 "찾지 못했다"와 "없다"를 구분해 적어야 한다 — 그 구분을 놓친 것이 이 문서의 가장 큰 결함이었다.
- **기획 미결사항:** **0건 선언을 철회한다.** 업무 분장·조직 실태·외부 자료 수신은 우리가 정할 수 없어 자체 기획으로 소거되지 않는다. 현재 열린 항목은 §7에 있다.
- **법령 보완:** 관리감독자 지정일 이력, 실제 참석시간, 위험성 판정·참여·공유 등은 현행 구현이 아니며 별도 변경요청 후보로 관리한다(§6).

### 3-1. 2026-08-13 판정 정정 — 왜 틀렸었는가

검수 문서는 결과보다 **판정 이력**이 자산이다. 뒤집힌 판정은 지우지 않고 이유와 함께 남긴다.

| 화면 | 2026-08-11 판정 | 무엇이 틀렸나 | 근거 |
|---|---|---|---|
| SCR-EDU-003 기타 교육 | `현업·관리감독자 동일 3종` — **일치** | **거짓 판정이었다.** 화면 둘이 같은 목록을 쓰는 것을 확인하고 "정의서와 구현이 같다"로 닫았을 뿐, **그 목록이 법과 같은지**는 보지 않았다. 별표4는 제1호(근로자)와 **제1호의2(관리감독자)** 를 다른 표로 두고, 제1호의2에는 ① 건설업 기초안전보건교육이 **없고** ② 일용·1주 이하 갈래가 **없다**. 관리감독자 화면이 법에 없는 의무 3종을 있다고 표시하고, 건설업 기초 4시간을 기준으로 미달(위법) 표시까지 붙이고 있었다 | 시행규칙 별표4 제1호의2 가~라목 · 산업안전보건법 §31①(건설업 기초의 대상을 「건설업의 사업주가 채용하는 건설 일용근로자」로 한정) |
| SCR-EDU-004 정기교육 상세 | `완료 후 신청 취소와 기록 회수` — 일치 | 동작 서술은 맞았으나 **막지 않는 것을 적지 않았다.** 같은 부서가 여러 번 등록되면 이수기록이 이중으로 붙어 법정 이수 완료가 오판정되고, 공문 붙임 별지는 열 때마다 현재 이수기록에서 다시 만들어지므로 **이미 결재가 올라간 공문의 이수자 명단이 사후에 줄어든다** | 기록 무결성 — 상신된 원본은 고칠 수 없다(CLAUDE.md §4·§7-1) |
| SCR-EDU-007 결재 이력 | `신규 상신 차단` — 일치 | 상신을 막는 것이 발주처 요구인 줄 알았으나, 요구는 차단이 아니라 **순서**였다(*"결재 상신하는 프로세스가 먼저 공문이 가야 되고"*). 2026-08-12 공문 골격 도입으로 「기안 → 미리보기 → 상신」이 갖춰졌고, 이 화면은 그 결과만 보는 조회 전용이다 | [기획-안전보건교육-온나라결재상신-v1](기획-안전보건교육-온나라결재상신-v1.md) v1.2 · CLAUDE.md §7-1 |

> **다음 검수가 반복하지 않을 것** — "구현과 정의서가 같다"는 것은 정합의 절반이다. 나머지 절반은 **그 구현이 법·발주처 요구와 같은가**이고, 위 3건은 전부 그 절반을 건너뛰어 생긴 오판정이다. 법령 근거가 걸린 항목은 조문을 열어보고 판정한다(CLAUDE.md §10 검증 6문 #1).

## 4. 구현 정본에서 제외한 선행 기획

- 관리감독자 지정일·해제일 **별도 이력**(현행은 지정일 최신값만 보관한다 — 지정일 자체는 이미 주기 기산점이다).
- 정기교육의 대상자별 실제 참석시간과 완료기록 정정 이력.
- 채용시교육의 업무 투입일과 실제 교육일 기반 선행 이수 판정.
- 특별교육의 **최초 작업일·단기간·간헐적 작업 여부**에 따른 시간 판정(대상 작업 선택은 2026-08-13 반영 완료 — §8).
- 정기·수시 위험성평가의 근로자 참여, 위험성 수준·허용 여부, 실시 전·결과 공유 기록.
- 확인완료만 위험성평가 완료율에 포함하는 집계.
- 위 항목은 법령 보완 참고문서의 내용이며 현재 화면을 재현할 때 구현하지 않는다.

> **2026-08-13 이관** — 종전 이 목록에 있던 `관리감독자 기타 교육 종류 분리`는 **보완 후보가 아니었다.** 보완은 없는 기능을 더하는 것이고, 이 건은 화면이 **법에 없는 의무를 있다고 표시하던 오표시**라 고치는 것이 정정이다. §3-1로 옮겨 반영 완료로 기록한다.

## 5. 개발 전달 기준

1. 개발자는 12개 활성 화면 정의서를 현재 기능·UX의 정본으로 사용한다.
2. 권한값은 화면별 문서에 중복 정의하지 않고 SCR-ADMIN-005·006 설정 결과를 적용한다.
3. SCR-RISK-003과 SCR-PRC-001은 파일만 남은 폐지 화면으로 신규 메뉴에 연결하지 않는다.
4. 실제 파일 처리, 외부 연계, 알림 발송과 엑셀 파싱은 프로토타입 시연 동작으로 본다.
5. 법령 보완 참고문서의 항목은 별도 변경요청이 승인되기 전 개발 범위에 넣지 않는다.
6. 화면 정의서 §5의 유효성 메시지와 §6의 현재 상태·집계 규칙을 인수시험 기준으로 사용한다.

이 표는 현재 화면의 미결사항이 아니라 향후 범위 변경 시 검토할 법령 보완 목록이다.

> **종전 `기타 교육 — 두 대상군 동일 3종` 행은 삭제했다** — 보완 후보가 아니라 오표시였고 2026-08-13 정정을 마쳤다(§3-1).

**별표4 비고 3의 '2분의 1' 감면은 담양군에 적용되지 않는다.** 그 감면은 「영 별표1 **제1호**에 따른 사업」과 「상시근로자 50명 미만 도매업·숙박 및 음식점업」에만 걸리는데, 담양군(공공행정)은 영 별표1 **제4호**다. 관리감독자 표(제1호의2)의 비고도 *"사업주가 제1호의 비고 제3호 각 목의 어느 하나에 해당하는 경우"* 를 조건으로 걸어 같은 결론이다. **따라서 교육시간은 별표4 값을 그대로 쓴다** — 다음 검수가 같은 질문을 반복하지 않도록 근거와 함께 남긴다.

| 1 | **교육 공문을 누가 기안·상신하는가** | 교육 공문에는 권한 가드가 없어 누구나 기안·상신할 수 있다. 위험성평가는 주관부서 담당자로 좁혀 두어 **두 도메인이 다른 규칙**이다. 자체·채용시 교육은 부서가 등록하므로 부서 기안이 업무상 맞을 수 있어 임의로 좁히지 않았다 |
| 2 | **관리감독자 지정 명단**(성명·부서·직위·지정일) | 직위명 규칙으로 자동 판정하는 개발자 폴백을 쓴다. 명단을 받으면 규칙을 지우고 명시값으로 바꾼다 |
| 3 | **관리감독자 채용 시 교육 8시간을 어느 화면이 받는가** | 별표4 제1호의2 나목에 실재하는 의무인데 시스템 어디에도 없다. 채용시교육 화면은 관리감독자를 모집단에서 제외한다 |
| 4 | **담양군이 건설업 기초안전보건교육 대상을 갖는가** | 현업근로자 화면에 3유형으로 노출한다. 시드에 건설 일용근로자는 0명이다. 답이 '아니오'여도 발주처가 3종을 직접 지정했으므로 임의로 빼지 않는다 |
| 5 | **현업업무 종사자 지정명단 + 명단의 사무/판매/현업 구분** | 조직도 인원 전원을 모집단에 넣는다(§6) |
| 6 | **교육시간 면제·감면 운용 여부** | 적용하지 않는다. 업무 문서 원장에 '담양군 정기안전보건교육 교육시간 면제 증빙자료'가 실재해 확인이 필요하다 |
| 7 | **채용시교육 소급 등록의 증빙 요건** | 일괄 이수처리에는 첨부 칸이 없고, 이 경로로 만든 기록은 이수일이 채용일과 같아 언제나 정상 이수로 표시된다 |
| 8 | **공문 샘플 미수신 상태로 전달 범위에 넣을지** | 표준 별지 제1호서식 지면으로 초안을 만들고 담양군 고유값은 `미등록`, 문서번호는 임시 채번으로 표시한다 |
| 9 | **온나라 결재 회신(완료·반려) 수신 방식과 이력 보존 기간** | 연동 전이라 상신된 사실과 문서만 보여준다. 결재완료·반려 지표는 값이 생겼을 때만 칸이 늘어난다 |

**교육시간 면제·감면(시행규칙 §27)은 지금 넣지 않는다.** ① 조문이 *"100분의 50 **범위에서** 면제**할 수 있다**"* 는 **재량**이고 ② 판정 입력(전년도 산업재해 발생 이력, 사업장 단위, 이직 전 경력)이 시스템에 없으며 ③ 해당 조문이 법령 스냅샷에 없어 근거 칩을 붙일 수 없다(CLAUDE.md §10). 시스템이 자동 계산하면 **조문에 없는 값으로 법정 필요시간을 낮추게 된다.**

## 8. 2026-08-13 외부 검수 대조 결과

외부 검수(안전보건교육 축 13건 지적)를 **법제처 국가법령정보 원문**(시행규칙 별표4·별표5·§26·§27, 산업안전보건법 §29·§31, 시행령 별표1)과 저장소 실측에 각각 대조했다. 지적을 그대로 받지도, 그대로 반박하지도 않고 **조문을 열어보고** 판정했다.

### 8-1. 확인되어 코드로 해소한 것

| 무엇이 틀렸나 | 왜 위험한가 | 조치 |
|---|---|---|
| 관리감독자 기타교육이 근로자와 같은 3유형·시간표를 냈다 | 법에 없는 의무를 있다고 표시하고, 건설업 기초 4시간을 기준으로 **미달(위법) 표시**까지 붙였다 | 별표4 제1호의2에 따라 **2유형**(작업내용 변경 2시간 · 특별교육 16시간, 단기간·간헐 2시간)으로 갈랐다. 유형 목록은 데이터 단일 출처의 창구 하나에서 나오고 **저장 경로에도 가드**를 둔다 — 목록만 감추면 전역 호출로 뚫린다 |
| 같은 부서가 참석자 등록부를 여러 번 등록할 수 있었다 | 이수기록이 이중으로 붙어 **법정 이수 완료가 오판정**되고 공문 수치가 함께 틀어진다 | 데이터 계층이 중복을 저장하지 않고 실패를 돌려준다. 화면은 등록 전에 미리 묻는다. 인원·서명파일 정정은 **신청 취소 후 재등록** 경로다 |
| 기타교육 시간을 수정해도 이미 쌓인 이수기록이 옛 시간으로 남았다 | 교육 카드의 시간과 개인 이수기록·공문 붙임 별지가 조용히 어긋난다 | 저장 시 이수기록 인정시간을 함께 갱신하고 갱신 건수를 안내·이력에 남긴다(정기교육이 이미 쓰던 방식) |

| 결재 이력 화면이 폐기된 상신 단위 3종(총괄·교육별·개인별)을 조건으로 광고했다 | 고르면 영구 0건이다 — 없는 기능을 UI로 약속한다 | 구분 조건을 제거하고 표의 축을 **교육 구분**(정기/자체/기타/채용시)으로 바꿨다. 도달 불가였던 차단 안내도 함께 제거 |
| 공문 문서번호가 특정 부서명으로 고정돼 있었다 | 담양읍 명의 공문에 다른 과 이름이 찍힌다 | 접속자 부서에서 파생한다(위험성평가 공문이 같은 결함을 한 번 냈고 그 재발 금지가 문서에 남아 있었다) |
| 관리감독자 자동 판정이 **읍·면장**을 놓쳤다 | 담양읍장은 현업 부서장인데 사무직 6시간으로 집계되고 있었다 | 직위 규칙에 읍장·면장 추가. **부서장 플래그로 갈아타지 않았다** — 그러면 국장 2명·팀장 4명이 통째로 빠진다. 산업안전보건법 §16①이 관리감독자를 "소속 직원을 직접 지휘·감독하는 직위"로 정의하므로 팀장이야말로 전형적 관리감독자다 |

| 별표4 스냅샷 발췌가 **비고를 통째로 빠뜨렸다** | 비고 없이 시간을 절대값으로 읽으면 1/2 감면 조건과 일용 재종사 면제를 놓친다. 실제로 이 발췌 누락이 관리감독자 오표시를 검토에서 통과시켰다 | 별표4 재수집(비고 전체 + 라목 한정구 복원), 시행령 별표1 제4호·산업안전보건법 §31 신규 수록, 교육 7화면 근거 매핑 갱신 |

### 8-2. 반증되어 채택하지 않은 것

| 지적 | 채택하지 않은 이유 |
|---|---|
| 교육 화면에서 공문 기안·미리보기·상신을 제거하라 | 발주처 요구는 제거가 아니라 **순서**였다 — *"결재 상신하는 프로세스가 먼저 공문이 가야 되고"*. 제거하면 요구의 정반대가 된다. 근거로 인용된 문서는 스스로 *"활성 화면 기능의 정본이 아니다"* 를 선언한 보완 후보 보존소다 |
| 메뉴명 '현업근로자'를 '근로자'로 넓혀라 | **법적으로 틀렸다.** 시행령 별표1 제4호가목상 공공행정은 안전보건교육(제3장)이 원칙적으로 적용 제외이고, 고시된 **현업업무 종사자만** 그 제외에서 다시 빠져 대상이 된다. 넓히면 법정 대상 범위를 잘못 말한다. 실제 결함은 **모집단이 넓은 것**이며 §6·§7에 갭으로 둔다 |
| 완료된 교육의 수정·삭제를 원본 보존 + 정정이력으로 바꿔라 | 기록 보존은 이미 **잠금 축**으로 구현돼 있다(상신 전 자유 회수 / 상신 후 전면 잠금). 시연 반복 요구와 양립시킨 형태이며, 정정이력은 그 위에 더하는 보완 후보다(§4) |
| 채용시교육 인정시간을 `min(실제, 필요)` 로 바꿔라 | 같은 별표4 갈래인 기타교육의 선례는 **실시시간을 그대로 저장하고 미달을 드러내는 것**이다. 값을 깎으면 "실제로 몇 시간 했는가"를 영구히 잃는다 |
| 관리감독자 기타교육에 '채용 시 교육'을 3번째 유형으로 넣어라 | 판정 축이 다르다 — 채용시교육은 **사람 축**이고 기타교육은 **건 축**이라, 건 축에 넣으면 미이수자 추적이 불가능해진다. 관리감독자 채용 시 교육 8시간의 수용 화면은 별도 결정 대상이다(§7 3번) |
| 관리감독자 정기교육·기타교육 정의서를 별도 파일로 분리하라 | 나머지 계약(필터·목록·등록·수정·삭제·잠금)이 실제로 같아 대부분이 중복 서술이 되고, 한쪽만 갱신되는 표류가 시작된다. **같은 문서 안 모집단별 분기 절**로 쓴다 |
| 교육시간 면제·감면을 반영하라 | 재량 조문이고 판정 입력이 없으며 근거 조문이 스냅샷에 없다(§7). **코드가 아니라 문서를 고친다** |

> **한 문장은 정의서로 옮기지 않는다** — *"관리감독자는 정의상 일용근로자가 아니다"* 는 법적으로 틀렸다. 산업안전보건법 §16①은 관리감독자를 **직위**로 정의하고 시행규칙 §27③도 "관리감독자의 **지위에 있는 사람**"이라 쓴다. 별도 신분이 아니다. 건설업 기초를 관리감독자 화면에서 빼는 정확한 근거는 **§31①의 대상 한정**과 **별표4 제1호마목의 교육대상 칸('건설 일용근로자')** 이다.
