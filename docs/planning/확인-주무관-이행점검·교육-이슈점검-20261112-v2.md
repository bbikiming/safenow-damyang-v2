## A. 반기 이행점검

### 바뀐 흐름 — 4단계

| 단계 | 누가 | 하는 일 |
|---|---|---|
| 1. 배포 | 재난안전과 | 점검표 양식 · 안내 · 기한 · 대상 부서를 올리고 `[점검 배포]` → 대상 부서에 할 일 · 알림 |
| 2. 제출 | 부서 | 점검표 내려받기 → 작성(부서장 확인) → `[결과 제출]` (결과 + 작성한 점검표) |
| 3. 확인 | 재난안전과 | 부서마다 `[확인]` 또는 `[보완 요청]`(사유) → 보완 요청이면 부서가 고쳐 다시 제출 |
| 4. 보고 | 재난안전과 | `[반기 마감 · 온나라 상신]` → 군수 보고 → 그 회차 잠금 |

- 부서가 하는 일은 **«받아서 써서 올린다» 하나**다.
- 미이행은 제출할 때 조치계획만 적는다. 조치했는지는 **다음 반기 점검에서 확인한다** — 따로 조치 결과를 올리는 단계를 두지 않는다.

**눌러 볼 곳**

### 바뀐 흐름 — 3단계

| 3. 종료 처리 | 재난안전과 | 기한이 지나면 종료 → 이수 반영 → 실시 결과 공문 |
