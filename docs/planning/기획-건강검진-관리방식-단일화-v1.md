# 건강검진 — 관리 방식 단일화(3탭 → 단순 첨부형 하나)

> 2026-09-09 · 대상 화면 `health-exam.html` · `health-exam-detail.html` (SCR-HEX-001·002)
> **확인 요청용 문서다.** 무엇을 왜 좁혔는지와 담양군에 물을 것 하나를 담는다.

---

## 1. 무엇을 바꿨나

건강검진 화면 상단에 있던 **관리 버전 탭 3종**(`단순 첨부형(권장)` / `상세 관리형` / `절차 진행형`)을 없애고, **단순 첨부형 하나**로 확정했다. 메뉴·화면 수는 그대로다.

| | 종전 | 지금 |
|---|---|---|
| 관리 방식 | 탭 3종 중 선택 | **하나** — 인원수·수검률·결과보고서 증빙 |
| 개인별 검진 결과 | `상세 관리형`에서 권한 열람(성명·수검일·결과) | **보관하지 않는다** |
| 대상자 명단·문진표 발송 | `절차 진행형` 1·2단계 | 없앴다 |
| 부서 결과 문서 제출 | `절차 진행형` 담당부서 제출함 | **업무함**(「검진 결과 통보서」)이 받는다 |
| 알림 발송 | 상세 공통 액션 + 절차 4단계 | 상세 공통 액션 하나(연계 적용 후 실제 전송) |

---

## 2. 왜 좁혔나

### 2-1. 개인별 검진 결과는 담을 이유가 없다

- 건강진단 결과는 **민감정보**다(「개인정보 보호법」 §23). 「산업안전보건법」 §132②가 본인 동의 없는 개별 결과 공개를 금지한다.
- 사업주가 실제로 받는 법정 문서도 개인 임상기록이 아니라 **집계형 결과표**(시행규칙 별지 제85호)다.
- 종전 `상세 관리형` 탭은 우리가 조사 끝에 **「보건인력 상주 대형 사업장용, 지자체엔 부적합」**이라 판정하고 반대편 탭에 「권장」을 붙여 둔 것이었다. 화면이 스스로 「쓰지 마세요」라고 표시한 선택지를 남겨 두면 담당자는 무엇이 정답인지 판단해야 한다.

### 2-2. 절차 진행형 4단계에는 담양군 실측 근거가 없다

2025년 문서 원장에서 특수건강검진 흐름은 **`실시 계획(안)` → `실시 안내`(부서 발송 6건) → `결과 안내`(6건) → `비용 지급`** 이다.

| 종전 단계 | 실측 |
|---|---|
| ① 대상자 선정(개인 명단) | 개인 명단은 위 2-1 이유로 담지 않는다 |
| ② **문진표 발송** | **원장에 근거 0건** |
| ③ 결과 문서 업로드(부서 제출) | 업무함이 이미 같은 문서를 받는다(아래 2-3) |
| ④ 새올 포틀릿 알림 | 연계 미구현 — 누르면 이력에 「발송 완료」가 남지만 실제로는 나가지 않았다 |

### 2-3. 부서 제출함이 두 곳이었다

업무 발행의 `W-HLT-EXE`(근로자 특수건강검진 실시)가 부서에 **「검진 결과 통보서」 슬롯**을 내려보낸다. 건강검진 화면에도 제출함을 두면 같은 문서를 올릴 자리가 두 곳이 되고 완료 판정도 두 곳에 쌓인다.

---

## 3. 되살릴 수 있다

제거는 **별도 커밋 하나**로 분리했다. 외부 참조가 0이라(다른 화면이 `procStep`·`deptInbox` 등을 쓰지 않는다) 되돌리기도 깨끗하다. 담양군이 개인별 관리를 요구하면 그 커밋만 되돌리면 된다.

---

## 4. 담양군에 물을 것 — 하나

> **일반건강진단(공직자 종합건강검진)도 이 시스템에서 관리합니까, 아니면 특수건강검진만입니까?** (미결사항 **EXT-20**)

- 발주처는 이 업무를 일관되게 **「특수건강검진」**으로 부르고 예산 과목도 그 이름이다(2026-07-30 회의 — *"작업 환경 측정 그리고 특수 건강 검진 이 항목은 예산 과목에 들어 있어요"*).
- 반면 문서 원장의 일반건강검진은 **「종합건강검진 수검계획 제출」·「검진비 청구서 제출」** 축이라 복지·회계 소관으로 보인다.
- 갈리면 **검진 유형 선택지와 메뉴 라벨**이 함께 바뀐다. 확인 전까지는 두 유형을 모두 다루되 화면이 유형을 분리해 표시한다.

---

## 5. 배경 — 이 3탭은 발주처가 검토한 적이 없다

2026-07-30 회의에서 건강검진에 대한 발화는 셋뿐이다.

> *"증빙 등록은 난 뭔 말인지 모르겠는데 어쨌든 일단 이거는 넘어가고 이거는 **아예 안 봤어요**. 제가 왜냐하면 건강검진은 솔직히 **건들기가 애매한 게 직접 해보지 않으면**… 일단 이건 넘길게요."*
> *"건강 검진도 **특수 건강검진으로 해가지고 따로 놔둬**[주세요]"*
> *"작업 환경 측정 그리고 특수 건강 검진 이 항목은 **예산 과목에 들어 있어요**"*

즉 **화면 형태·첨부 방식에 대한 피드백은 없었고**, 3탭은 개발측이 대안 시안으로 만들어 둔 것이다. 이번 정리는 발주처 확정을 뒤집는 것이 아니라 **아직 정해지지 않은 것을 하나로 좁혀 확인받는** 절차다.
