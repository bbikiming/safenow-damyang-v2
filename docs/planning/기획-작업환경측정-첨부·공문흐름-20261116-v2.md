> 상태: **구현 완료 (2026-11-16) — 결정 4건 권장안으로 확정.** 구현하면서 C-5 를 한 가지 바꿨다: 공문은 «반기 전 행 결과 입력 뒤 한 번»이 아니라 **«결과가 들어온 사업장부터, 필요하면 2차·3차»**로 보낸다. 예시 자료에서 환경과 노출기준 초과 건(10-14 측정)이 같은 반기의 11월 측정 2곳을 기다리느라 60일 법정 기한 안에 알리지 못하는 구조가 드러났기 때문이다. 정의서 SCR-WEM-001 §4-4 · SCR-WEM-002 §4 가 정본이다.
> **추가 단순화 (같은 날, 사용자 지시 «재난안전과에서 파일 첨부해서 딸깍»)** — 재난안전과의 평소 일을 **2단계**로 줄였다: ① [＋ 결과 등록] 한 창(보고서 파일 + 사업장별 결과, 계획 없어도 됨) ② 결과 안내 공문. 결과보고서 첨부·측정 완료 처리를 한 창으로, 개선 증빙·개선조치 완료를 한 창으로 합쳤고(C-2 의 «함께 등록»도 이 창이 대신한다), 상세의 진행 순서는 그 건에 해당하는 단계만 보인다. 건강검진도 [검진 완료 처리] 한 창(파일 필수)으로 끝난다.

## 1. 업무 사실

### 1-1. 실측(온나라 원장 2024·2025)
재난안전과가 반기마다 측정기관에 위탁 → 측정기관 «결과 통보 및 대금 청구» 수신 → 측정비 지급(내부결재) → **물순환사업소장에게 «작업환경측정 결과 안내» 공문 발신**. 부서가 제출한 기록은 없다. 농업기술센터기술보급과는 자체 측정 후 내부결재로 끝낸다.

### 1-2. 이 화면이 할 일과 하지 않을 일

| 할 일 | 하지 않을 일(이유) |
|---|---|
| 사업장별 계획·결과보고서·결과·개선조치 기록(현행) | 측정 결과 노동관서 보고 — 위탁 측정기관이 전자 제출하면 보고한 것으로 본다(법 §125⑤ 단서 · 시행규칙 §188②) |
| **결과 안내 공문**(신규) — 부서에 결과를 알리고 근로자 고지를 요청 | 측정비 지급 — 예산 소관 |
| **노출기준 초과 건의 60일 제출 기록**(신규) | 실시 안내 공문 — 실측 1회, 필요하면 온나라에서 직접 쓴다 |
| | MSDS 대상조사 — 업무 자동발행 `W-ENV-MSD`(첨부형) 현행 유지(시행규칙 §189①4 정보 제공) |

## 3. v2 변경 — 6가지만

| # | 어디 | 무엇 | 왜 |
|---|---|---|---|
| C-1 | 데이터 `addWorkEnv` | 등록한 쪽을 남긴다: `regBy: 'owner' \| 'dept'`(재난안전과 담당자가 등록하면 `owner`). 기존 예시 행은 `owner` | 공문 대상을 사람이 고르지 않고 가른다 — 자체 측정(부서가 등록) 행은 공문에 들어가지 않는다 |
| C-2 | 결과보고서 등록 창(목록·상세 공용) | **파일 이름을 저장**한다(현행은 «첨부됨» 참/거짓뿐이라 공문 붙임 후보를 만들 수 없다). 같은 반기·같은 위탁업체 행 중 보고서가 없는 행을 체크박스로 보여 «같은 보고서로 함께 등록» | 측정기관 보고서 한 부가 여러 사업장을 덮는다 — 같은 파일을 네 번 올리는 반복과 누락을 없앤다 |
| C-3 | 상세 «측정 완료 처리» | 개선 필요일 때 **«노출기준 초과» 체크**(기본 해제). 체크하면 기존 60일 검사 + 3개월 재측정 안내 + «노동관서 제출일» 칸(재난안전과, 상세에서 나중에 입력) | §188③·§190① 단서(§2) |
| C-4 | 상세 | **[결과 수정]** — 결과 공문을 보내기 전까지만. 같은 창·같은 검사를 다시 쓴다. 수정은 이력에 남는다 | 현행은 오타를 고칠 수단이 없다 |
| C-5 | 목록 상단(재난안전과에게만) | 반기마다 **한 줄**: «2026 하반기 · 결과 3 / 4곳 · `[결과 안내 공문]`». 버튼은 전 행에 결과가 있을 때 켜지고, 아니면 «결과 미입력: ○○정수장» 처럼 **무엇이 남았는지** 이름으로 보인다. 보낸 뒤에는 «기안함 전송 · YYYY-MM-DD» + `[문서 보기]` | 공문 진입점은 한 자리 |
| C-6 | 내 할일 | 부서: 결과 공문에 실린 «개선 필요 · 미완료» 행 → «작업환경측정 개선조치». 재난안전과: «결과 안내 공문 기안 대기»(전 행 결과 입력 · 공문 전), «노동관서 제출 기한»(초과 건 · 제출일 없음) | 기안 차례·법정 기한이 묻히지 않는다(교육 검수 «높음» 결함을 여기서는 만들지 않는다) |

**걷거나 바꾸지 않는 것**: 계획 등록 폼·권한(10-06 소속 고정), 첨부 용도 둘(10-06 3-1), 목록 열·요약 타일, 상세의 개선 증빙·개선 완료·기한 재설정·미완료 사유·이력, 사업장 관리 연결, 인력평가 연계. `[알림 발송]` 은 남기되 토스트를 «알림을 기록했습니다 — 전송은 새올 연계 후»로 고친다(§15).

| D-1 | 공문 대상을 «재난안전과가 등록한 행»으로 가르는가 | **그렇다**(C-1) | 기안 때 수신 부서로만 가른다 — 사람이 매번 빼야 한다 |

| D-3 | 노출기준 초과 건의 노동관서 제출을 기록하는가 | **기록한다** — 제출일 한 칸(재난안전과) | 기록하지 않는다(§188③ 이행을 시스템이 모른다) |
| D-4 | 근로자 고지 확인을 받는가 | **받지 않는다** — 공문 요청 문구까지. 확인을 받으면 부서 취합 업무가 새로 생긴다 | 부서가 «게시함»을 표시 |

## 7. 수용 기준

1. 재난안전과 계정: 사업장 4곳 계획 → 결과보고서 1부를 «함께 등록»으로 4곳에 → 4곳 측정 완료 처리 → 목록 한 줄 `[결과 안내 공문]` → 미리보기 → 온나라로 보내기. 다른 화면으로 가지 않는다.
2. 결과 1곳을 비우면 버튼이 꺼지고 그 사업장 이름이 보인다.
3. 보낸 뒤 [결과 수정]·결과보고서 등록·측정 완료 처리가 버튼과 전역 호출 모두에서 거절되고, 개선 증빙·개선 완료는 열린다. 반려 회신이면 다시 열린다.
4. 개선 필요 부서 담당자의 내 할일에 «작업환경측정 개선조치»가 공문 뒤에 생기고, 적정 부서에는 생기지 않는다.
5. 부서 담당자가 자기 부서 계획을 등록하면(자체 측정) 그 행은 공문 줄에 세지 않고, 결과 첨부·완료로 끝난다.
6. 노출기준 초과를 체크하지 않은 개선 필요 건은 60일 검사에 걸리지 않고, 체크한 건은 걸리며 재난안전과 내 할일에 제출 기한이 뜬다.
7. 공문 별지 사업장 수 = 목록 줄의 «n곳» = 요약 타일 «전체 대상»(같은 반기 필터).
8. 공문 근거 칩에 조문 문자열 하드코딩이 없다.

## 8. 함께 고칠 문서
`SCR-WEM-001`·`002`(§4·§5·§6), 사용 가이드 «결과 첨부» 절, `SCR-MYW-001`(할 일 두 종), `SCR-ADMIN-002` 알림 규칙(개선조치 요청 · 노동관서 제출 기한).

## 공문 시점 재검수 반영 (2026-11-16)

시행규칙 §188·§209·§210 현행본(2026-08-01 시행)으로 공문 보내는 시점을 다시 대조했다.

- **작업환경측정** — 공문 시점은 맞았다(결과가 들어온 건부터 · 노동관서 제출은 공문과 따로). 공문 할 일에 기한이 없던 것만 고쳤다: 실을 사업장 중 노출기준 초과가 있으면 «시료채취 + 60일»의 가장 이른 날이 공문 기한이다(`DYSH.noticeDue`). 종전 내 할일은 측정일을 기한으로 내보내 공문 할 일이 늘 «지남»으로 보였다.
- **건강검진** — 사후관리 30일을 실시일부터 세고 일반검진까지 걸었다. 법은 «결과표를 받은 날부터 30일» · 특수·수시·임시검진의 근로 금지·작업전환 등 소견에만(§210③·④)이다. 결과 등록에 «결과 통보서 받은 날»과 «노동관서 보고 소견»을 받고, 재난안전과 «노동관서 제출 기록» 단계를 더했다(작업환경측정과 같은 모양). 공문 기한은 보고 대상의 «받은 날 + 30일».
- **예시 자료** — 건강검진 공문이 부서 조치보다 늦게 나가던 날짜(2025 연말 일괄 · HC-2026-01)를 결과가 들어온 직후로 다시 맞췄다(2025 3건 · 2026 5건). HC-2026-09(환경과 특수 · 11-10 수령 · 노동관서 보고 대상)는 공문 전으로 남겨 실습 자리로 둔다. 저장 키 `damyangShV8`.
