# 위험성평가·안전보건교육 법령 보완 기준 v2 (현행 미반영 참고)

> 확정일: 2026-08-11  
> 적용 범위: 향후 법령 보완 변경요청 검토  
> 목적: 현재 프로토타입에는 없는 법령 보완 후보와 근거를 보존한다.  
> 주의: 이 문서는 활성 화면 기능의 정본이 아니다. 현재 기능·UX는 화면 정의서 12종을 따른다.

## 1. 적용 원칙

1. 현재 구현과 화면 정의서가 일치하지 않으면 화면 정의서를 현재 구현에 맞춘다.
2. 아래 기준은 현행 화면 기능으로 간주하지 않고 향후 변경요청의 법령 근거로 사용한다.
3. 변경요청이 승인되면 대상 화면, 데이터 전환, 상태 이력과 인수시험을 별도로 확정한다.
4. 메뉴 접근과 수정 권한은 시스템 관리의 메뉴 관리·권한 관리에서 설정한다.
5. 실데이터와 공문 샘플이 없는 항목은 임의 데이터나 문서 레이아웃을 만들지 않는다.

## 3. 권한 처리 확정

- 업무 화면의 §2에는 역할표를 두지 않고 시스템 관리에서 설정한다는 연결만 둔다.
- 초기값은 재난안전과 중심으로 설정하되 운영 관리자가 메뉴별 보기·수정을 변경할 수 있다.
- 결재 이력은 화면 자체가 읽기 전용이며 초기 메뉴 노출 대상은 재난안전과다.
- 수시평가 등록, 개선조치 수행, 완료 확인과 같은 업무 분장은 각 흐름에 남긴다. 이것은 메뉴 권한 프리셋이 아니라 상태 전이의 수행 주체다.

## 4. 관리감독자 지정과 교육주기

### 4-1. 데이터 분리

- 근로자 기본 정보의 근무 구분(사무직·판매·비사무직)과 관리감독자 지정 여부를 분리한다.
- 관리감독자 지정은 재난안전과 담당자가 별도 이력으로 등록한다.
- 필수값: 근로자 식별자, 지정일, 상태, 등록자, 등록일시, 변경 사유.
- 해제 시 해제일과 사유를 기록하며 기존 이력을 삭제하지 않는다.
- 같은 날짜 구간에 복수의 활성 지정 이력이 겹칠 수 없다.

### 4-2. 판정 규칙

- 지정일 전은 해당 근로자의 근무 구분에 따른 반기 정기교육으로 판정한다.
- 지정일부터 해제일 전날까지는 관리감독자 연간 16시간으로 판정한다.
- 해제일에는 근로자 반기 주기를 새로 시작한다. 이는 법령에 없는 운영 기본값이며 이중 산정을 막기 위한 기준이다.
- 지정일을 과거로 정정하면 교육 원본 기록은 변경하지 않고, 영향받는 과거·현재 판정만 정정된 지정일 기준으로 전부 재계산한다.
- 정정 저장 전 영향받는 사이클과 이수 판정 건수를 보여주고, 정정 전·후 값과 사유를 이력으로 남긴다.

## 5. 교육 기록·판정

### 5-1. 공통

- 교육 원본은 실시일시, 교육 종류, 교육내용, 강사, 대상자, 실제 교육시간, 증빙을 가진다.
- 법정 완료는 등록 여부가 아니라 대상자별 필요시간과 실제 인정시간으로 판정한다.
- 완료된 교육은 삭제하거나 원본을 덮어쓰지 않는다. 정정은 사유와 정정 전·후 값을 가진 별도 이력으로 처리한다.
- 초안만 삭제할 수 있고, 완료 교육의 참석자 정정은 개인별 정정으로 처리한다.

### 5-2. 채용 시 교육

- 채용일과 실제 업무 투입일을 구분한다. 업무 투입일 기본값은 채용일이다.
- 교육일시는 실제 실시값을 입력하며 채용일로 소급해 자동 완료 처리하는 기능을 두지 않는다.
- 정상 이수는 교육 완료일시가 업무 투입일시보다 늦지 않은 경우다. 이후 이수는 지연 이수로 표시하되 이수 기록은 보존한다.

### 5-3. 기타 교육

- 현업근로자 화면: 작업내용 변경 시 교육, 특별교육, 건설업 기초안전보건교육.
- 관리감독자 화면: 채용 시 교육, 작업내용 변경 시 교육, 특별교육.
- 관리감독자 화면에 건설업 기초안전보건교육을 노출하지 않는다.
- 특별교육은 대상 작업, 최초 작업일, 단기간·간헐적 작업 여부를 받아 필요시간과 선행 이수 조건을 판정한다.
- 기타 교육은 정기교육 시간에 합산하지 않는다. 별표 4가 명시한 다른 법령 교육의 정기교육 인정 예외는 별도 인정 근거가 있는 기록만 합산한다.

## 6. 교육 결재 이력

- 신규 상신, 결재 완료 처리, 반려 처리, 재상신 기능은 전 교육 화면 설계에서 제거한다.
- 결재 이력 화면은 기존 연계 이력의 문서번호·상신일·문서명·대상·상태·문서를 조회하는 기능만 제공한다.
- 실데이터가 없으면 전 지표를 0으로 표시하고 “연계된 기존 결재 이력이 없습니다”라고 안내한다.
- 빈 상태에서 존재하지 않는 상신 버튼으로 이동하라고 안내하지 않는다.
- 향후 공문 작성 화면과 샘플이 확정되면 별도 변경요청으로 상신 흐름을 다시 설계한다. 현재 개발 범위의 미결사항으로 보지 않는다.

## 7. 위험성평가·개선조치

### 7-1. 정기평가

- 용역 보고서 업로드는 파일 보관과 수기 입력 시작 신호다. 문서 자동 추출·자동 분류를 하지 않는다.
- 부서별로 참여 근로자·근로자대표와 참여 방법을 기록한다.
- 모든 유해·위험요인에 위험성 수준과 허용 여부를 기록한다. 허용 불가능한 항목만 감소대책과 개선조치를 필수로 만든다.
- 지적사항이 없다는 이유로 평가 기록을 제외하지 않는다. “허용 불가능한 항목 0건”으로 남긴다.
- 평가 완료 조건은 필수 평가기록 완료, 모든 개선조치 확인 완료, 결과 공유 기록 완료다.

### 7-2. 수시평가

- 등록은 법정 6개 사유 선택에서 시작한다.
- 재해 발생 사유는 재해 개요와 작업 재개 예정일을 추가로 필수 입력하며 작업 재개 전에 평가를 완료한다.
- 유해·위험요인과 감소대책의 유효 행은 개선조치로 자동 생성한다.
- 외부 안전관리자가 서명한 검토파일을 재난안전과 담당자가 등록한 시점을 검토 완료로 본다.
- 검토파일 교체·정정은 사유와 버전을 남기며 물리 삭제하지 않는다.

### 7-3. 개선조치

- 상태는 조치중 → 확인대기 → 확인완료 또는 반려 → 재제출 순환으로 관리한다.
- 담당자는 조치 내용, 완료일, 개선 후 사진, 완료 확인 서명을 제출한다. 개선 후 사진은 운영상 필수 증빙이다.
- 재난안전과는 증빙을 확인하거나 사유를 입력해 반려한다.
- 위험성평가 진행률과 완료 판정에는 확인완료 건만 포함한다.
- 조치와 확인 이력은 삭제하지 않는다.

## 8. 향후 법령 보완 변경요청의 완료 기준

1. 승인된 변경요청이 활성 화면 정의서에 반영되어야 한다.
2. 교육 화면 어디에도 신규 결재 상신·반려·재상신 지시가 없어야 한다.
3. 관리감독자 지정일 변경 시 영향 판정을 재계산하고 원본 교육 기록은 보존해야 한다.
4. 수시평가 사유는 6개이고 유효한 감소대책 행마다 개선조치가 1건 생성되어야 한다.
5. 정기평가 보고서 업로드로 자동 추출된 항목이 생기면 안 된다.
6. 위험성평가 완료는 참여·판정·개선조치 확인·결과 공유 기록을 모두 충족해야 한다.
7. 조회·목록 화면은 로딩, 실데이터 없음, 조회 실패 상태를 각각 제공해야 한다.
8. 삭제 대신 비활성·정정·버전 이력으로 원본을 보존해야 한다.

## 9. 미결사항

없음. 아래 법령 기준의 현행 적용 여부와 적용 시점은 별도 변경요청에서 결정하며, 현재 프로토타입 재현 범위의 미결사항으로 계산하지 않는다.
