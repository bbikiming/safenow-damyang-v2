# 프로토타입 — 운영 서버 이슈·최신 사양 반영 (2026-11-05)

> 운영 서버(safety.damyang.go.kr) 점검에서 나온 오류·권한·문구 지적과, 운영에 먼저 들어간 사양을 **프로토타입(화면 정의의 정본)에도 같은 규칙으로** 넣었다. 운영과 프로토타입이 다른 말을 하면 다음 개발 지시가 프로토타입의 옛 동작을 되살린다.

## 4. 남은 것 (이번 범위 밖에서 본 것)

- 대시보드 과장 화면 «담당자 제출 확인 대기 [확인]»이 저장 없이 «확인 처리되었습니다»만 낸다(§15 위반).
- 은퇴 화면 `doc-detail-ledger.js`·`doc-exec.js` 는 아직 옛 판정(`documentIdsOfStage`)으로 세고 «데이터 구분» 줄을 그린다(메뉴 밖).
- 체계 점검 §4-7 의견청취 줄은 회차별 건수를 세지 않는다(의견청취 시드가 `opinion()` 안에 있다).
- `DYDOC` 지면 «시행» 칸의 «임시 채번 — 실제 번호는 온나라가 부여» · 교육 예시 서명파일 이름이 부서 영문 코드.
- 가이드 시드의 업무단계 길잡이는 36쪽(`downloads/` 파일 실측) — 운영 QA 기록은 40쪽이라 운영에 새 판이 있을 수 있다. 영상 3편은 주소를 문서에서 찾지 못해 넣지 않았다.
- `evl-eval.html` 의 `TODAY` 가 `DEMO_TODAY` 파생이 아니다(§11).
