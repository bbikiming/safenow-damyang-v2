## 1. 온나라 공문 — 추가

| 공문 | 어디서 | 언제 | 보내는 사람 | 수신 | 단위 |
|---|---|---|---|---|---|
| **교육 안내**(변경 · 취소 안내 포함) | 집합교육 | 교육 저장 직후 · 일시·장소 변경 · 교육 취소 | 재난안전과 담당자 | 대상 부서 전부(재난안전과 제외) · 외부발송 | 교육 1건 |
| **참석자 등록부 제출** | 집합교육 | 교육 뒤 부서가 등록부를 저장한 직후 | 그 부서 담당자 | 재난안전과 | 교육 × 부서 |
| **출장 결과 보고** | 집합교육 | 교육이 끝난 날부터 | 재난안전과 담당자 | 내부결재 | 교육 1건 |
| **실시 결과 보고** | 자체 · 채용시 · 기타교육 | 부서가 교육을 등록하면서 바로 | 그 부서 담당자 | 재난안전과 | **등록 한 번**(여러 명을 한 번에 등록해도 1건) |

**공통 규칙**

- **결재선 없이 «온나라로 보내기»** — 검토·결재는 담당자가 온나라 기안함에서 지정한다.
- **순서**: 기록 저장 → **같은 창**이 기안 폼으로 바뀜 → 본문 작성 → [문서 미리보기 →] → [온나라로 보내기] → 확인 → 보내기. 저장 버튼 이름은 **«저장하고 (안내) 공문 작성 →»**.
- 기안 폼 맨 위 한 줄: «✓ … 저장했습니다 — 이 공문을 보내야 할 일이 끝납니다».
- **수신은 고정 표시**(고르는 수단 없음).
- **본문은 비어 있다**(자동 작성 없음). 삽입 칩(교육 개요 · 참석 결과 · 실시 결과 · 근거 문구)을 누르면 문장이 들어간다.
- **붙임은 이미 올린 파일에서 고른다**(방금 올린 파일은 미리 체크) · 명단은 별지. 한도 5개 · 파일당 10MB · 합계 30MB.
- 기안 창을 닫으면 기록은 남고 공문만 «공문 미기안» → 내 할일에 «공문 보내기»가 남는다. 다시 열면 기안 폼부터.
- 연계 실패 → 기록은 남고 공문 미기안 · [다시 보내기].
- 반려 · 반송 → 사유를 보이고 앞 제목 · 본문을 이어 쓴다.
- **잠금**: 기안함 전송 · 결재 미완료 · 결재 완료 = 잠김 / 반려 · 반송 = 풀림.

| 공문 | 보낸 뒤 잠기는 것 |
|---|---|
| 교육 안내 | 없음 — 수정하면 변경 안내 공문 · [삭제] 대신 [교육 취소] |
| 등록부 제출 | 그 부서 등록부 취소 · 정정 / (한 부서라도 보내면) 교육 회차 · 시간 |
| 출장 결과 보고 | 출장 결과 보고서 수정 |
| 실시 결과 보고 | 그 등록 묶음의 등록 취소 |

- 종전 «실시 결과 공문»(재난안전과 기안)은 **새로 만들지 않는다**. 이미 있는 것은 «실시 결과(이전 방식)»로 열람만, 반려·반송이면 재난안전과가 [다시 보내기].

## 2. 집합교육

### 2-1. 플로우

| 단계 | 누가 | 버튼 | 결과 |
|---|---|---|---|
| 1. 등록 | 재난안전과 담당자 | [＋ 집합교육 등록] → [저장하고 안내 공문 작성 →] | «안내 공문 전» · 같은 창이 교육 안내 공문 기안으로 |
| 2. 교육 안내 공문 | 재난안전과 담당자 | [온나라로 보내기] | «교육 전» · 대상 부서에 예정 안내 알림 · **이때부터 부서에 보인다** |
| 3. 교육 실시 | — | — | 마지막 회차 날부터 «등록부 받는 중» · 대상 부서 할 일 생김 |
| 4. 서명부 올리기 | 재난안전과 담당자 | 상세 [서명부 올리기] | 여러 부서가 서명한 한 장을 교육에 한 번 올림 · 미등록 부서에 알림 |
| 5. 등록부 + 등록부 제출 공문 | 각 부서 담당자 | [＋ 참석자 등록부 등록] → [저장하고 공문 작성 →] | 공문을 보내야 부서 할 일 끝 · 참석자가 없으면 [참석자 없음] |
| 6. 출장 결과 보고 | 재난안전과 담당자 | [출장 결과 보고서 작성] → [저장하고 공문 작성 →] | 교육 자료 · 사진 · 참석 인원(대략) |
| 7. 종료 처리 | 재난안전과 담당자 | [교육 종료 처리] | 남은 것(미등록 · 미기안 부서 수 · 출장 보고 미작성)을 보여 주되 막지 않음. 등록부 공문 · 출장 보고 할 일은 남고, 미등록 부서의 등록 할 일은 사라진다(늦은 등록부는 [＋ 등록부 추가]) |

### 2-2. 상태

**안내 공문 전 → 교육 전 → 등록부 받는 중 → 완료** (+ 취소). 앞의 셋은 공문 기록에서 파생, 완료 · 취소만 저장. 부서에는 «안내 공문 전»이 보이지 않는다(목록 · 상세 주소 · 내 할일 모두).

### 2-3. 바뀐 규칙

- **교육 안내 공문 뒤 수정** — 막지 않는다. 일시 · 장소를 바꾸면 «변경 안내 공문» 할 일이 생긴다(제목 · 강사 · 첨부만 바꾸면 없음). 회차 · 시간은 부서가 등록부 제출 공문을 한 곳이라도 보내면 잠긴다.
- **교육 취소** — 안내 공문 뒤 교육 전에는 [삭제] 대신 [교육 취소](사유 필수) → 취소 안내 공문. 취소된 교육은 «취소» 칩으로 남고 할 일 · 이수 집계에서 빠진다.
- **안내 공문을 안 보낸 채 교육 날이 지나면** 부서 할 일이 생기지 않는다. 재난안전과 카드에 경고.
- **등록부**
  - 부서 칸 [조직도] · [＋ 일괄 등록(여러 부서)] **없앰** — 누구든 소속 부서 고정, 대리 등록 없음.
  - 서명부 칸: «재난안전과가 올린 서명부 사용» / «직접 올리기». 사용은 파일 참조(새 파일 없음) · 공문 붙임에 자동 체크.
  - [참석자 없음]: 공문 · 사유 없이 할 일 끝. 이수 · 인원 집계는 그대로. 종료 전 [되돌리기].
  - 재난안전과 직원 몫은 등록 현황 표의 **재난안전과 줄에서만**.
- **출장 결과 보고서** — 교육 자료(등록 때 파일 참조) · 교육 사진 · 참석 인원(1 이상, 대략) 필수. 참석 인원은 보고용이고 이수 판정에 쓰지 않는다. 부서에는 보이지 않는다.
- **등록부 제출 공문을 안 보낸 부서의 등록부도 이수로 센다**(할 일은 남는다).

## 3. 부서 실시 교육 (자체 · 채용시 · 기타)

### 3-1. 플로우

| 단계 | 누가 | 결과 |
|---|---|---|
| 1. 등록 → [저장하고 공문 작성 →] | 그 부서 담당자 | 교육 기록 저장 · 이수 즉시 반영(기존 그대로) · 같은 창이 실시 결과 보고 기안으로 |
| 2. 실시 결과 보고 공문 | 그 부서 담당자 | 수신 재난안전과 · 보내면 할 일 끝 · 그 등록 묶음 잠김 |
| 3. 검토 | 재난안전과 | 목록에서 결재 상태 칩 + [공문 보기] (시스템 안 확인 단계 없음) |

- **등록 묶음** — 한 번 저장으로 생긴 교육 기록은 한 묶음 · 공문 1건 · 이수자 명단 별지는 묶음 전원.
- 공문: 제목 «{교육 제목} 실시 결과 보고({부서})» · 칩 교육 개요 · 실시 결과(대상 n명 · n시간) · 근거 문구 · 붙임 교육일지·사진 + 이수자 명단 별지.
- 할 일 기한 = **등록일 + 7일**.

| 없음 | 공문 미기안 |
| 기안함 전송 · 결재중 | 결재 미완료 |
| 결재완료 | 결재 완료 |
| 반려 / 반송 | 반려 / 반송 |

- 🔒 잠금 버튼 없앰 — 잠금은 «고치는 버튼이 없음»으로 표현.
- «문서 보기» → **«공문 보기»** · 공문이 없으면 버튼 없음.
- «결재 미완료»에 마우스를 올리면 «온나라 기안함에서 검토·결재를 지정해 상신하세요».
- 집합교육 · 교육 상세 · 결재 이력도 같은 어휘.

| 공문 미기안 | «등록 취소» 후 다시 등록 |
| 반려 · 반송 | 주 버튼 [다시 보내기] · 보조 링크 «등록 취소» |
| 결재 미완료 · 결재 완료 | 시스템에서 고치지 않음 — 온나라에서 정정 후 재난안전과에 알림 |

- 등록 취소 = **묶음 전체** · 그 부서 담당자만 · 확인 창에 회수 시간 · 인원.
- 반려 공문이 있던 묶음을 취소하면 공문은 «등록 취소»로 남는다(결재 이력 표시 · 반려 수에서 제외).
- [이수 수정] · [상세] · [수정] · [삭제] · 행의 [공문 기안]은 **기능째 없앤다**(버튼만 숨기지 않는다).

### 3-5. 기존 기록

- 전환일 전 기록은 공문 할 일 없음 · «공문 미기안»으로 보이지 않는다(«—» 또는 «이전 방식»).
- 기존 실시 결과 공문이 있으면 그 칩 + [공문 보기] · 반려면 재난안전과 [다시 보내기].

## 4. 현업근로자 관리 (대메뉴 신설)

### 4-1. 메뉴

| | 기존 | 변경 |
|---|---|---|
| 위치 | 안전보건교육 › 교육 현황·관리 › 근로자 명단 관리 | **현업근로자 관리**(안전보건교육 앞) |
| 하위 | — | 현업근로자 명단 · **작업내용 변경 이력** |
| 안전보건교육 › 교육 현황·관리 | 이수현황 · 결재 이력 · 근로자 명단 관리 | 이수현황 · 결재 이력 |

- 대메뉴 11 → 12개. 기존 주소는 그대로 열린다. 두 화면 모두 메뉴 권한 «개인정보».

### 4-2. 현업근로자 명단 — 추가 항목

| 항목 | 규칙 |
|---|---|
| **현업업무** | 6가지 중 복수 선택. 구분 «비사무직(현업)»이면 **1개 이상 필수**, 그 밖은 선택 |
| **작업내용 변경** | 수정에서 현업업무를 바꾸면 **변경일 필수**(기본값 오늘 · 고칠 수 있음) · «변경 전 → 변경 후» 이력 저장 |

현업업무 6가지(고용노동부고시 제2020-62호 별표 1):

| 번호 | 짧은 이름 | 고시 문구 |
|---|---|---|
| 1 | 시설·설비 유지관리 | 청사 등 시설물의 경비, 유지관리 업무 및 설비·장비 등의 유지관리 업무 |
| 2 | 도로 유지보수 | 도로의 유지·보수 등의 업무 |
| 3 | 환경미화 | 도로·가로 등의 청소, 쓰레기·폐기물의 수거·처리 등 환경미화 업무 |
| 4 | 공원·녹지 | 공원·녹지 등의 유지관리 업무 |
| 5 | 산림 | 산림조사 및 산림보호 업무 |
| 6 | 조리·급식 | 조리 실무 및 급식실 운영 등 조리시설 관련 업무 |

- 표시: 목록 · 이력 · 대상자는 짧은 이름 칩(마우스 올리면 고시 문구) · 등록 창은 짧은 이름 + 고시 문구.
- 목록: «현업업무» 열 · 필터(업무별 · 종사자만 · 미지정) · 맨 위 «현업업무 종사자 n · 업무 미지정 n · 사무직 등 n»(누르면 필터).
- 직접 등록 · 수정이 같은 검사. 인사 연동분은 필수 검사 제외(«미지정»으로 들어옴).
- **엑셀 일괄 등록은 없앤다** — 명단은 인사 연동과 직접 등록으로만 들어온다.
- 현업업무는 **그 부서 담당자만** 바꾼다(재난안전과도 다른 부서 사람은 안 됨).

### 4-3. 작업내용 변경 이력 (신설 화면)

| 열 | 값 |
|---|---|
| 변경일 · 부서 · 성명 · 고용형태 | |
| 변경 전 → 변경 후 | 짧은 이름 칩 |
| 작업내용 변경 시 교육 | **이수함**(교육일) / **시간 미달**(들은 / 필요) / **미이수** |
| 등록자 | |

- 이수 판정: 변경일 **이후(같은 날 포함)** «작업내용 변경 시 교육»이 **법정 최소 시간**(근로자 일용·1주 이하 1h · 그 밖 2h / 관리감독자 2h)을 채움. 기타교육 «법정 최소 미달»과 같은 판정.
- 미이수 · 시간 미달 줄 [기타 교육 등록] → 그 사람 · «작업내용 변경 시 교육»을 고른 채 기타교육 창.
- 위에 «작업내용 변경 n건 · 교육 미이수 n건»(0건이면 안 보임).
- 조회 범위: 부서 = 자기 부서 / 재난안전과 · 군수 = 전 부서.

### 4-4. 다른 화면과의 연결

- **기타교육** — «작업내용 변경 시 교육»을 고르면 «작업내용 변경 후 미이수» 사람이 맨 위에 미리 선택된다. 그 창의 모집단만(관리감독자 창 = 관리감독자, 현업근로자 창 = 현업근로자). 저장은 화면에 보이는 대상자만.
- **이수현황** — 집계 대상 줄 끝에 «· 현업업무 미지정 n명»(누르면 명단 «미지정» 필터). **이수 판정 분모는 바꾸지 않는다**(1단계). 교육 대상을 «현업업무 선택된 사람»으로 좁히는 것은 명단이 채워진 뒤(2단계).

## 6. 내 할일 · 알림 · 자동발행 · 결재 이력

### 6-1. 내 할일 (교육 카드)

| 받는 사람 | 카드 | 생김 → 끝남 |
|---|---|---|
| 재난안전과 | 교육 안내 / 변경 안내 공문 보내기 | 등록 · 일시·장소 수정 → 보냄 |
| 재난안전과 | 서명부 올리기 · 출장 결과 보고서 작성 | 교육 끝난 날 → 올림 · 보냄 |
| 부서 | 참석자 등록부 등록 → 등록부 공문 보내기 | 안내 공문 보낸 교육이 끝난 날 → 공문 보냄 · 참석자 없음 |
| 부서 | ○○ 실시 결과 보고 공문 보내기 (기한 등록일 + 7일) | 등록 → 보냄 · 등록 취소 |
| 기안자 | 다시 보내기 | 반려 · 반송 → 다시 보냄 |
| 대상 부서 | 예정 교육 — 알림 | 할 일로 세지 않음 |

- 카드 주 버튼은 그 공문 기안 창을 **바로 연다**.
- 교육 자동발행 카드는 내 할일에 내지 않는다(중복 제거). 대시보드 «교육» 잔여 = 내 할일과 같은 목록.

### 6-2. 알림

| 알림 | 받는 사람 | 때 |
|---|---|---|
| 집합교육 예정 안내(변경 · 취소 포함) | 대상 부서 | 안내 공문을 **보낸 순간**(기존: 등록 저장 순간) |
| 참석자 등록부 등록 요청 | 대상 부서 | 교육 끝난 날 |
| 서명부가 올라왔습니다 | 등록부 미등록 대상 부서 | 서명부 올린 순간 |
| 교육 공문 반려 · 반송 | 기안자 | 연계 회신 |
| 등록부 독촉 | 그 부서 | 재난안전과가 보낼 때 |

- 재난안전과에 등록부 · 실시 결과 보고 도착 알림은 내지 않는다.
- 교육 알림 분류 «이행» → «교육».

### 6-3. 업무 자동발행 완료 판정

| 업무 | 완료 |
|---|---|
| 월 정기 안전보건교육 | 그 달 집합교육 등록부 제출 공문 보냄(또는 참석자 없음) |
| 분기 안전보건교육 실시 결과 제출 | 그 분기 부서 실시 교육 공문을 **모두** 보냄 · 0건 분기는 대상 아님 |

### 6-4. 결재 이력

- 공문 종류: 교육 안내 · 변경 안내 · 취소 안내 · 등록부 제출 · 출장 결과 보고 · 자체/채용시/기타교육 실시 결과 · 실시 결과(이전 방식).
- 상태 어휘 §3-2 + «등록 취소». 상단 수치: 전체 · 결재 미완료 · 결재 완료 · 반려.
- 필터 추가: **보낸 부서**. «대상» 열 없앰.

## 7. 없어지는 것

| 없어지는 것 | 대신 |
|---|---|
| 재난안전과의 실시 결과 공문(교육 종료 뒤 기안) | 출장 결과 보고(집합) · 실시 결과 보고(부서) |
| 재난안전과 등록부 일괄 · 대리 등록 · 등록부 부서 [조직도] | 서명부 올리기 + 부서가 선택 |
| 재난안전과의 채용시 · 기타 등록 버튼 | 부서 등록 · 재난안전과 검토 |
| [이수 수정] · 기타 [상세] · 자체·기타 [수정] · [삭제] · 행 [공문 기안] | 등록 취소 후 다시 등록 |
| 🔒 잠금 버튼 · [문서 보기] | 결재 상태 칩 하나 · [공문 보기] |
| 안전보건교육 › 근로자 명단 관리 메뉴 | 현업근로자 관리 › 현업근로자 명단 |
| 근로자 명단 엑셀 업로드 | 직접 등록(인사 연동분은 그대로) |
| 교육 등록 «내용» 칸 | «제목» 칸 |

**만들지 않는다** — 분기 실시 결과 보고(부서 × 분기 한 장 공문) · 채용시 미이수 재난안전과 독촉 · 공문 화면 결재선 칸.
