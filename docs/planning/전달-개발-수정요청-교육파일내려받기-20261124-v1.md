# 기획 수정 요청 — 안전보건교육: 기록으로 남긴 파일은 누르면 내려받기 (2026-11-24)

> 앞서 드린 «개발 요청 — 안전보건교육 공문 제거 · 공문 미리보기»(2026-11-24)에 **이 부분 하나만 더합니다.** 나머지는 그대로입니다.

## 왜

- 교육 기록의 정본은 이 시스템입니다. 그런데 교육 화면에 올린 파일을 **다시 열 수 없었습니다.**
- 서명부 · 교육일지 같은 자료는 기록으로 남기려고 받는 것입니다. 지금은 파일 이름만 글자로 보입니다.
- 부서 실시 교육(자체 · 채용시 · 기타)은 상세 화면이 없습니다. 그래서 증빙을 볼 자리가 아예 없습니다.

## 요청

**교육에서 기록으로 받은 파일은 이름을 누르면 원본을 내려받게 해 주세요.**

| 파일 | 보이는 곳 | 누가 보나 |
|---|---|---|
| 집합교육 첨부(참석자 명단 · 교육 자료) | 정기교육 상세 요약 | 모두 |
| 재난안전과 서명부 | 정기교육 상세 요약 | 재난안전과 · 군수. 대상 부서에는 파일 이름만 보임(여러 부서 서명이 한 장 — 2026-11-24 회신으로 정정) |
| 부서 등록부 서명부 | 정기교육 상세 › 등록 현황의 서명부 열 | 재난안전과 · 군수 · 그 부서. 그 밖은 «제출됨»만 보임(지금 규칙 그대로) |
| 출장 결과 보고서 교육 자료 · 교육 사진 | 정기교육 상세 요약의 출장 결과 보고서 줄 | 재난안전과 · 군수 |
| 부서 실시 교육 증빙(교육일지 및 교육사진 등) | 자체 · 기타교육 카드, 채용시교육 행의 «등록 {부서} {사람} · {월-일}» 줄 옆 | 그 목록의 열람 범위 |

- 파일 이름은 링크 모양(밑줄)으로 보이게 하고, 누르면 올린 원본을 내려받습니다.
- 올리는 창(교육 등록 · 등록부 · 서명부 · 출장 결과 보고서)에서 고른 파일 이름도 같은 링크로 해 주세요.
- 볼 수 있는 사람은 **지금 열람 범위 그대로**입니다. 범위 밖이면 이름도 내지 않습니다.
- 원본 파일이 없는 기록(옮겨 온 기록 · 예시 자료)은 이름을 눌렀을 때 «내려받을 파일이 없습니다»를 보여 주세요. 받은 척하지 않습니다.

## 확인 (개발서버)

1. 집합교육 첨부, 서명부, 등록부 서명부, 출장 결과 보고서 자료 · 사진의 이름을 누르면 올린 원본이 내려받아집니다.
2. 자체 · 기타교육 카드와 채용시교육 행에서 증빙 이름을 누르면 내려받아집니다.
3. 등록부 서명부는 범위 밖 부서 계정에서 «제출됨»만 보입니다. 출장 결과 보고서 파일은 부서 계정에 보이지 않습니다.
4. 재난안전과 서명부는 부서 계정에서 이름만 보이고 눌러지지 않습니다(2026-11-24 회신으로 정정).
