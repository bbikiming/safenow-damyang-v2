# 정기 위험성평가 — «지금 할 일» 강조 (v1)

> 작성 2026-11-12 · 대상 정기 위험성평가 화면 · 정본 단계 정의는 `기획-위험성평가·교육-흐름전환-2차교육반영-20261112-v2.md` §1
> 목적: 단계마다 **지금 이 사람이 눌러야 할 버튼 하나**가 화면에서 바로 보이게 한다. 화면 배치·버튼 크기·색 체계는 바꾸지 않는다.

## 1. 원칙

1. **한 화면에 하나만** — 강조가 둘이면 어느 것도 강조가 아니다.
2. **차례가 남에게 있으면 버튼을 강조하지 않고 무엇을 기다리는지 말한다** — 기다리는 사람에게 «누를 것이 있다»고 말하지 않되, 강조가 사라지기만 하면 고장인지 할 일이 없는지 모른다(§2-1).
3. **담당자(실무자)에게만** — 과장·팀장·군수는 조회 계층이라 강조하지 않는다.
4. **화면을 덮지 않는다** — 오버레이·코치마크는 쓰지 않는다. 작업을 막고, 처음 쓰는 사람을 위한 «단계별 안내»가 이미 그 역할을 한다. 단계별 안내가 켜져 있으면 이 강조는 끈다(두 강조가 겹치지 않게).
5. **단계는 저장하지 않고 그때그때 판정한다** — 평가·부서·개선조치의 상태에서 파생하므로, 손으로 처리했든 내 할일에서 처리했든 다음 화면에서 맞는 버튼으로 옮겨 간다.

## 2-1. «지금 할 일» 한 줄 (2026-11-12 검토 뒤 보완)

강조 버튼은 화면 아래쪽(1280×800 기준 816~2,393px)에 있어 첫 화면에서 보이지 않았다. 그래서 **연도 선택 줄 바로 아래**(첫 화면 안, 약 570px)에 한 줄을 둔다.

| 경우 | 한 줄 | 버튼 |
|---|---|---|
| 내 차례 | «**지금 할 일** — 용역 보고서와 부서별 조치기한을 올립니다» 처럼 위 표의 일을 한 문장으로 | [바로 가기 ↓] — 강조 버튼으로 옮기고 초점을 주며 맥동을 한 번 더 돌린다 |
| 남의 차례 | «**기다리는 중** — 부서 작성 차례입니다 · 입력 완료 1 / 4곳» 처럼 무엇을 기다리는지와 진척 | 없음 |

기다리는 중 문구 — 재난안전과: 부서 작성(입력 완료 n/m곳) · 부서 조치(완료 n/m건) · 반려 재제출 · 결과 공문 결재 / 부서: 요청 공문 · 보고서 등록 · 조치 요청 부서 고르는 중 · 지적사항 없음 · 재난안전과 확인 중 · 모두 끝남.

부서 화면에서는 «내 부서 진행 상황»의 지금 단계에 누를 버튼이 없으면(작성표에 있으면) 같은 [바로 가기 ↓]를 단다 — «지금»이 두 군데로 갈리지 않게.

## 3. 모양 (디자인 시스템 안에서)

| 요소 | 규칙 |
|---|---|
| 고리 | 흰 틈 2 + 브랜드 녹색 테두리 2 + 옅은 녹색 바깥 빛 — 그림자 토큰 «지금 할 일 고리» 하나로 정의 |
| 맥동 | **강조 대상이 바뀔 때**와 [바로 가기]를 눌렀을 때만 두 번(1.6초) — 같은 단계에서 화면을 다시 그릴 때는 고리만 · **움직임 줄이기 설정이면 맥동 없음** |
| 버튼 모양 | 보조 버튼(파일 버튼·외곽선 버튼)은 이때만 주 버튼과 같은 **진한 녹색**으로 채운다(흰 글자 대비 5:1 이상 — 밝은 녹색은 3.85:1 로 미달). 크기·자리·문구는 그대로 · 주 버튼은 고리만 |
| 꼬리표 | 버튼 바로 옆 «지금 할 일» 알약(옅은 녹색 바탕 · 진한 녹색 굵은 12px) · 좁은 화면(560px 미만)에서는 숨기고 고리만 |
| 잠긴 버튼 | 강조 대상이 잠겨 있으면(예: 요청 부서 0곳) 고리만 두고 채우지 않는다 — 왜 잠겼는지는 옆 문구가 말한다 |
| 접근성 | 색만으로 말하지 않는다(꼬리표 글자) · 꼬리표를 버튼 설명으로 이어 화면 낭독기도 «지금 할 일»을 읽는다 · 한 줄은 상태 알림으로 읽힌다 · 고리는 레이아웃을 밀지 않는다 |

## 4. 하지 않는 것

- 화면 전체 어둡게 덮기(스포트라이트) — 다른 정보를 못 보게 하고 닫기 동작이 하나 더 생긴다.
- 버튼 크기 키우기 — 줄 높이(컨트롤 32·36·40)가 갈려 옆 컨트롤과 밑변이 어긋난다.
- 단계마다 다른 색 — 상태 색(성공·경고·위험)과 섞여 «문제가 생겼다»로 읽힌다.

## 5. 넓히기 (후속)

같은 규칙과 모양을 수시 위험성평가 · 안전보건교육 · 이행점검에 쓸 수 있다. 화면마다 «지금 할 일» 판정 한 곳과 강조 대상 표만 정하면 된다.
