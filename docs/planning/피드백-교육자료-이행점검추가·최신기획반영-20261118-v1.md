## 1. 이행점검 — 교육 자료에 넣을 내용

발표 자료에 그대로 옮길 수 있게 썼다. 가이드 원고에는 이미 같은 흐름이 있으므로(부서 6-1 · 운영 ② 3장 · 과장 6장) 원고는 2-2의 정정만 하면 된다.

### 1-1. 한 장 요약

> **반기마다 한 번. 재난안전과가 점검표를 내려보내고, 부서가 써서 올리고, 재난안전과가 확인해 군수에게 보고한다.**

- 근거: 중대재해처벌법 시행령 제5조제2항(산업 — 반기 1회 이상) · 제10조제5호 · 제11조제2항(시민)
- 메뉴: `안전보건관리체계 › 이행점검`
- 탭 두 개: `중대산업재해 이행점검` · `중대시민재해 이행점검`. 대상이면 탭마다 한 번씩 낸다.
- **부서는 공문을 따로 보내지 않는다.** 시스템 제출이 곧 제출이다.

### 1-2. 네 단계

| 단계 | 누가 | 화면에서 | 끝나면 |
|---|---|---|---|
| 1. 배포 | 재난안전과 담당자 | `[점검 배포]`(양식 · 안내 · 기한 · 대상 부서) → `[공문 기안 →]` → `[문서 미리보기 →]` → `[온나라로 보내기]` → `[보내기]` | 보내는 순간 대상 부서에 할 일 · 알림. 되돌릴 수 없음 |
| 2. 제출 | 부서 실무자(누구나 · 자기 부서만) | 내 할일 카드 `[제출하러 가기]` → `⬇ 점검표` 받아 작성 → 우리 줄 `[결과 제출]` → 결과 고르기 → 점검표 올리기 → `[제출]` | «확인 대기». 내 할일 카드 사라짐 |
| 3. 검토 | 재난안전과 담당자 · 팀장 | 줄의 `[검토]` → 점검표 열어 보고 `[승인]` 또는 `[반려]`(사유 필수) | «확인 완료» 또는 «반려 · 사유» → 부서 `[다시 제출]` |
| 4. 마감 보고 | 재난안전과 담당자 | `[반기 마감 · 군수 보고]` → 보고서 미리보기 → `[온나라로 보내기]` → `[보내기]` | 회차(두 탭) 잠김. 되돌릴 수 없음 |

### 1-3. 부서 담당자에게 강조할 것

- **결과는 셋 중 하나**
  - `전 항목 이행`
  - `일부 미이행` — 미이행 내용 · 조치계획 · 조치 예정일을 적는다
  - `해당없음` — 사유가 없으면 저장되지 않는다
- **«미제출»과 «미이행»은 다르다.** 미이행을 정직하게 적어 낸 부서는 할 일이 끝난 부서다. 독촉은 안 낸 부서에만 간다.
- 지난 반기에 «일부 미이행»이었으면 이번 제출 창 맨 위에 «지난 반기 미이행 조치 결과»(조치 완료 · 조치 중 · 미조치)를 먼저 적어야 한다.
- 확인 전에는 `[제출 고치기]` · `[제출 취소]`로 고친다. 확인 뒤에는 재난안전과에 확인 취소를 요청한다.
- 과장 · 소장 · 읍면장은 제출하지 않는다. 우리 부서 줄을 보고 `[독촉]`만 한다.

### 1-4. 재난안전과에 강조할 것

- 배포는 **탭마다 따로** 한다(공문도 탭마다 1건). 마감 보고는 두 탭을 묶어 1건이다.
- 자기가 낸 재난안전과 제출은 자기가 검토하지 않는다(팀장 또는 다른 담당자).
- 마감 보고를 보내면 회차가 잠겨 **미제출 부서는 더 낼 수 없다.** 기한이 지났거나 전 부서 확인이 끝난 뒤에 보낸다.
- 배포 · 마감 공문은 온나라 연계기안함에 들어갈 뿐이다. **온나라에서 결재선을 지정해 상신해야** 결재가 시작된다.

### 1-5. 실습 시나리오 (프로토타입 기준)

2026년 하반기 회차는 «배포 전»으로 비워 두었다. 교육 중에 배포부터 해 본다.

1. 박안전(재난안전과 담당자) — `중대산업재해 이행점검` · 2026년 하반기 → `[점검 배포]` → `[지난 회차 양식 이어받기]` → 기한 · 대상 확인 → 공문 보내기
2. 하정수(물순환사업소 담당자) — 내 할일 카드 → `[결과 제출]` → `일부 미이행`으로 제출(조치계획 칸 체험)
3. 박안전 — `[검토]` → `[반려]`(사유 적기)
4. 하정수 — 알림 확인 → `[다시 제출]`
5. 박안전 — `[승인]` → `[반기 마감 · 군수 보고]` 미리보기까지(보내기는 설명만)

## 2. 원고 정정 — 메뉴별

표의 «지금»은 원고에 있는 말, «바꿀 내용»은 최신 기획이다.

### 2-1. 안전보건교육 · 현업근로자 관리

**바뀐 원칙 세 가지 — 각 장 머리에 넣는다**

1. 기록을 올린 부서가 그 공문을 보낸다. **공문을 보내야 그 일이 끝난다.**
2. 부서가 한 교육(자체 · 채용시 · 기타)은 **부서가 등록하면서 바로** 실시 결과 보고 공문을 보낸다. 재난안전과는 결과를 볼 뿐이다.
3. 근로자 명단은 새 대메뉴 `현업근로자 관리`에 있다(`현업근로자 명단` · `작업내용 변경 이력`).

**공문 네 종 — 표로 싣는다**

| 공문 | 어느 교육 | 언제 | 누가 보냄 | 받는 곳 |
|---|---|---|---|---|
| 교육 안내(변경 · 취소 포함) | 집합교육 | 교육 저장 직후 | 재난안전과 담당자 | 대상 부서 |
| 참석자 등록부 제출 | 집합교육 | 부서가 등록부를 저장한 직후 | 그 부서 담당자 | 재난안전과 |
| 출장 결과 보고 | 집합교육 | 교육이 끝난 날부터 | 재난안전과 담당자 | 내부결재 |
| 실시 결과 보고 | 자체 · 채용시 · 기타 | 부서가 등록하면서 바로 | 그 부서 담당자 | 재난안전과 |

공통: 저장 버튼 이름이 `[저장하고 공문 작성 →]`(집합교육 등록은 `[저장하고 안내 공문 작성 →]`)이고, 같은 창이 기안 폼으로 바뀐다. 본문은 비어 있고 삽입 칩을 눌러 채운다. 결재선 칸은 없다. 창을 닫으면 내 할일에 «공문 보내기»가 남는다.

**결재 상태 칩 — 화면 전체가 같은 말**

공문 미기안 / 결재 미완료 / 결재 완료 / 반려 / 반송. 버튼 이름은 `[공문 보기]`. 🔒 표시는 없다.
