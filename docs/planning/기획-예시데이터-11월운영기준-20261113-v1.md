## 3. 남은 것 (예시 데이터로 메우지 않는다)

- 관리감독자 지정일 전원 미등록(EXT-12) · 현업업무 종사자 지정명단(EXT-11) — 담양군 자료 대기.
- 위험성평가 결과 공문의 «임시 채번» 표기 — 동결 화면.
- 경영방침 점검표 문서가 판마다 하나라 반기별로 쓸 수 없다 — 예시를 넣지 않았다(하반기 점검표를 막지 않으려고). 반기 축은 후속 판단.
- 인력 평가 평가표 행은 모든 연도에 지금 조직도를 쓴다.
- 예산 연계 번호 앞머리가 «온나라-2026-»으로 고정.
- 예시 이력의 시각은 고정값이라 실제 시계보다 늦게 보일 수 있다.
