# 자료 — 공무원 교육자료 사전 자료 v1

작성 2026-08-19 · 성격: **사실 원장** — 교육자료·발표자료가 인용할 수치와 문장의 단일 출처
조사 방법: 저장소 전수 조사(6축 병렬) + 수치 주장 214건 교차 검증 → **정정 24건 반영 완료**

> **이 문서를 쓰는 법** — 교육자료에 넣을 숫자는 여기서만 가져온다. 규칙 문서·코드 주석에는
> **옛 수치가 남은 자리가 다수**라(§7 금지 ⑦) 거기서 옮겨 적으면 틀린다.

---

## 1. 한 문장

> 이 시스템은 흩어진 공문을 모으는 **문서함이 아니라**, 법이 요구하는 일을
> **이행항목 80개 · 업무단계 177개**로 쪼갠 뒤 그 하나하나에 **«했다는 증거»가 붙어 있는지**를
> 담당자·부서장·군 전체가 같은 화면에서 보게 하여, **놓친 것이 놓친 채로 드러나게** 하는 시스템이다.

**부서 담당자용 한 문장** — 내가 무엇을 언제까지 해야 하는지 **찾아다니지 않아도 되고**, 올린 서류가 **어느 의무의 증거로 남았는지** 나중에 다시 찾을 수 있게 하는 시스템.

**이름이 곧 성격이다** — 「중대재해 시스템」이 아니라 **「담양군 중대재해예방 통합관리시스템」**이다. 사후 처리가 아니라 **예방 의무의 이행을 관리**한다.

## 2. 왜 존재하는가 — 실측으로 확인된 문제 6

담양군 5개 부서(건설과·공간재생과·공공시설사업소·물순환사업소·환경과)의 **2021.07~2026.06 문서 원장 430,089행**을 실측한 것이 설계 근거다. 「그럴 것 같다」가 아니라 실제 공문 43만 건을 세어 만들었다.

| # | 문제 | 실측 근거 |
|---|---|---|
| ① | **취합이 안 된다** | 같은 업무 회신 제목이 1,518건 중 유니크 **548개**(편차 36%) — 총괄부서가 제목으로 집계할 수 없었다 |
| ② | **놓친다** | 통보→제출 소요 중앙값 2023년 24일 → 2026년 **34일**. 2026년 D+31 이상 지연이 **25곳 중 16곳** |
| ③ | **재촉이 사람 손이다** | 중대재해계 문서 3,608건 중 촉구·재요청 **65건(1.8%)**, 그중 45건이 2026년에 몰림 |
| ④ | **손으로 되풀이한다** | 12개 업무 패밀리 반복 확인 · 부서 1곳당 **연 25~30건**, 전 부서 **연 1,000~1,200건** |
| ⑤ | **문서가 있다 ≠ 이행했다** | 4개 부서에 **340,434건**이 쌓여 있지만 원장에 업무단계 분류 열이 없어 이행 여부를 말하지 못한다 |
| ⑥ | **종전 화면은 질문을 못 했다** | 기본 단위가 «세트»여서 «이 법정 의무를 이행했나»를 물을 수 없었다. 진행률의 분모가 «문서»였다 |

**②가 특히 중요하다** — 통보를 05.31에서 05.14로 **앞당겼는데도** 제출은 더 밀렸다. 필요한 것은 「일찍 통보」가 아니라 **중간 리마인드와 진행 가시화**라는 실측 결론이다.

**부서별 문서 보유량**(실측) — 건설과 144,710 · 물순환사업소 102,137 · 공간재생과 64,122 · 공공시설사업소 29,465. 전체 430,089행은 접수 303,550 · 생산 126,539이고, 전자 408,454 · 비전자 21,635이다.

## 3. 법령 축 — 무엇이 근거인가

- 근거는 **법제처 국가법령정보센터 OPEN API 스냅샷 한 벌**에서만 나온다. 화면에 법령을 문자열로 쓰지 않는다.
- 현재 **9개 법령 · 66개 조문**, 수집일 **2026-08-13**. 조문 본문은 **요약·의역 없이 원문 그대로**다.
- 법이 바뀌면 화면 66곳을 고치는 게 아니라 **스냅샷 파일 하나를 다시 받는다**.
- 근거가 붙는 화면은 53개 중 **37개**이고, 나머지 **16개는 빈 배열로 명시**한다 — **근거 없음도 정보**다(시스템 관리 8종 등은 법령이 명한 의무가 아니라 운영 기능이다).

**수록 법령 9종** — 중대재해처벌법 / 같은 법 시행령 / 산업안전보건법 / 같은 법 시행령 / 같은 법 시행규칙 / 산업안전보건기준에 관한 규칙 / 사업장 위험성평가에 관한 지침(고용노동부고시) / 시설물의 안전 및 유지관리에 관한 특별법 / 같은 법 시행령

### 3-1. 담양군에 걸리는 두 축

중대재해처벌법은 **중대산업재해**(법 §4·§5)와 **중대시민재해**(법 §9) 두 축이고, 담양군은 공중이용시설·원료제조물을 관리하므로 **양쪽 다 적용**된다. 한 축만 대면 절반만 근거를 댄 것이다.

**중대산업재해 축** — 시행령 §4의 **9개 의무**: 목표·경영방침 / 전담조직 / 유해·위험요인 확인·개선 / 예산 / 책임자 권한·평가 / 전문인력 배치 / 종사자 의견청취 / 매뉴얼 / 도급 기준·절차.
그중 **3·5·7·8·9호**가 「반기 1회 이상 점검」을 명시한다. ⚠ **1호(목표·경영방침)에는 그 문구가 없다** — 관리 편의로 반기 점검을 두는 것은 되지만 **법정 의무라고 쓰면 안 된다**.

**중대시민재해 축** — ⚠ **「시민재해는 연 1회」라고 말하면 틀린다.** 기본은 반기 1회다.

| 주기 | 무엇 |
|---|---|
| **반기 1회 이상** | 원료·제조물 축(시행령 §8·§9) · 공중이용시설 관리체계 이행 점검(시행령 §10 5호) |
| **연 1회 이상** | 공중이용시설 안전계획 **수립**(§10 4호) · 도급·용역·위탁 기준·절차 점검(§10 8호) · 관계 법령 의무이행 점검(§11 2항) |

### 3-2. 주기는 법률이 아니라 하위 법령이 정한다

법률 조문은 대개 「대통령령으로 정한다」로 **위임만** 한다. 주기를 화면에 표시하려면 **주기를 정한 조문을 함께** 대야 한다.

| 업무 | 주기 | 주기를 정한 곳 |
|---|---|---|
| 안전보건교육 시간 | 정기 매반기 6h(사무직)·12h(그 밖) / 관리감독자 연 16h | 산안법 **시행규칙 별표4** |
| 작업환경측정 | 대상이 된 날부터 30일 내 최초, 이후 **반기 1회 이상** | 산안법 **시행규칙 §190** |
| 위험성평가 | 최초(작업 시작 전) · 정기(다음 연도부터 매년 1회 이상) · 수시 | 산안법 **시행규칙 §37** + 고용노동부 **고시** |
| 산업안전보건위원회 | 분기 1회 | 산안법 **시행령 §37** |

**담양군 특례 2가지** — ① 별표4 비고3의 **교육시간 2분의 1 감면은 담양군에 안 걸린다**(그 감면은 시행령 별표1 제1호 사업과 50인 미만 도매·숙박음식점업 전용이고 담양군은 제4호다). ② 공공행정은 산안법 제3장 적용 제외이나 **「청소·시설관리·조리 등 현업업무 종사자」는 제외에서 다시 빠진다** — 그래서 교육 의무 대상은 **현업업무 종사자**다.

## 4. 업무문서 이행 관리 — 교육의 핵심

### 4-1. 4단 계층

```
법령  →  법정 이행항목 80개  →  업무단계 177개  →  증빙문서
       (무슨 의무인가)      (실제로 하는 일)    (했다는 증거)
```

**«법을 지켰는가»를 묻는 최소 단위가 법 조문이 아니라 업무단계 177개**라는 점이 이 시스템의 출발점이다.

**이행항목 80개 구성** — 재난안전관리(DSM) 33 · 시설물(FAC) 16 · 중대산업재해(IND) 11 · 산업안전보건(OSH) 11 · 관리업무(MGT) 5 · 중대시민재해(CIT) 4
**업무단계 177개 구성** — DSM 62 · OSH 35 · FAC 33 · IND 25 · CIT 13 · MGT 9

- 80개 항목이 인용하는 법령은 **27개**이고, 인용 빈도는 재난안전기본법 49회 · 산안법 39회 · 중처법 17회 순이다.
- **근거 없는 업무단계는 0개**다 — 177개 전부가 조문 문자열을 갖는다.
- 이 분류는 손으로 고치는 파일이 아니라 **「담양군_안전보건_문서분류기준_v3.csv」의 생성물**이다. 바꾸려면 화면이 아니라 원본 CSV를 고치고 다시 만든다.

### 4-2. 두 화면의 단위가 다르다

| 화면 | 기본 단위 | 묻는 것 |
|---|---|---|
| **업무 목록** | 문서 1건 | 그 문서가 **어디 있나** |
| **이행 목록** | 법정 이행항목 1개 (카드 1장) · 카드 안 한 줄 = 업무단계 1개 | 이 의무의 **증빙이 갖춰졌나** |

같은 데이터를 쓰지만 **수치를 서로 맞추려 하지 않는다** — 이행 목록은 이행 여부를, 업무 목록은 문서 건수를 센다. 연결은 **한 방향뿐**이다(이행 목록의 업무단계 이름을 누르면 그 조건이 걸린 업무 목록으로 간다).

### 4-3. 상태와 그 전이

**업무단계 이행 상태 4가지** — `미이행` · `진행중` · `완료` · `해당없음`

| 규칙 | 내용 |
|---|---|
| 올리면 **무조건 진행중** | 담당자 화면에 «완료 처리» 수단이 **아예 없다** |
| **완료는 재난안전과만** | 증빙을 확인해야 붙고, 확인자·확인일시가 함께 남는다 |
| 완료 버튼은 **서류가 있어야 나온다** | 0건이면 완료 처리 수단을 제공하지 않는다 |
| 고치면 **되돌아간다** | 완료 뒤 파일·연결을 고치면 자동으로 «진행중» + «재확인 필요» |
| **해당없음은 사유 필수** | 사유 없으면 저장 자체가 거부된다. 검사를 **데이터 계층**에서 하므로 우회되지 않는다 |
| **반려는 상태를 안 바꾼다** | 반려해도 «진행중» 그대로이고 사유·반려자·회차가 따로 쌓인다 |

### 4-4. 2025년 실측 — 증빙의 실제 모습

| 값 | 수치 |
|---|---|
| 원본 매핑 행 | 4,082행 |
| → 완전중복 24행 제거 | 4,058행 |
| → 복합키(문서명·수발신자·보고일자) 묶음 | **문서 3,830건** |
| 여러 단계에 걸린 문서 | 210건 (한 문서 **최대 11개 단계**) |
| 미분류(원장에 분류 없음) | 34건 — 지우지 않고 **교정 대상으로 드러낸다** |
| **증빙이 확인된 업무단계** | **135개** |
| **문서가 0건인 업무단계** | **42개** |

⚠ **「4,082 − 24 = 3,830」이 아니다.** 행을 줄인 것(4,058)과 문서로 묶은 것(3,830)은 다른 단계다. 「행 수」와 「문서 수」를 구분하지 않으면 같은 자료로 다른 숫자가 나온다.

**화면이 다루는 문서 모집단 4,338건** = 2025 원장 3,830 + 현행 업무문서 426 + 2026 예시 자료 82.

## 5. 어떻게 「놓치지 않게」 하는가

### 5-1. 자동발행 — 「언제·누구에게·언제까지」를 시스템이 만든다

- 업무 카탈로그 **26종** 중 **8종만 정기 자동발행**이다. **16종은 담당자 확인 후 발행**, **2종은 발생 시 수동**.
  ⚠ 「주기가 있으면 전부 자동으로 나갑니다」라고 말하면 안 된다(§7 금지 ④).
- **발행 주체는 사람이 아니라 시스템**이다 — 이력에 «시스템 자동발행»으로 남고, 발행일은 화면을 연 날이 아니라 **규칙상 날짜**를 쓴다.
- **같은 업무·같은 회차는 두 번 발행되지 않는다**(멱등키 = 템플릿ID|회차).
- **지나간 회차를 소급하지 않는다** — 최근 30일 창만 보고, 창 밖 회차는 숨기지 않고 «빠진 회차 N건 — 소급하지 않습니다»로 **건수를 드러낸다**.
- **대상 부서를 코드에 박지 않는다** — 부서 속성(현업근로자·공중이용시설·화학물질·유해인자·위험성평가 대상)에서 파생하고, 도메인이 대상을 이미 알면 그쪽을 쓴다.
- 휴무일 처리: 발행일이 휴무면 **직전 영업일로 당기고**, 기한이 휴무면 **다음 영업일로 민다**.

### 5-2. 기한

- 표시 규칙 — `지연(D+N)` / `이번주(D-7 이내)` / `예정`. 내 할일은 **D-3 이내를 별도 강조**.
- **기한 없는 건을 빈칸으로 두지 않는다** — «기한 미지정»으로 표시한다. 빈칸이면 초과 집계에서 조용히 빠져 관리 대상에서 사라진다.
- 상대일수는 **중앙값이 아니라 p75**를 쓴다 — 중앙값을 기한으로 잡으면 정의상 절반이 발행 즉시 지연이 된다.
- 기한 값 옆에 **표본 수와 연도를 함께** 싣는다. 표본 3건짜리가 255건짜리와 같은 확신으로 보이면 안 된다.

### 5-3. 재촉 — 시스템은 권고만 한다

실측 촉구율이 **1.8%**(3,608건 중 65건)이고 전부 사람이 보낸 2차 공문이었다. 그래서 시스템은 «촉구 권고 N곳»을 띄우고 **발송은 사람이 누른다**. 권고 시점은 템플릿마다 다르다(자동발행 8종 실측 21·28일 등).

### 5-4. 누락 점검

- 그 해 **증빙이 0건인 할 일**과 **기한이 지난 할 일**만 모아 이행항목별로 묶어 보여 준다.
- 이행상태 5가지(`충족`·`진행중`·`지연`·`미이행`·`비해당`)로 **«아직 때가 아님»과 «때를 놓침»을 구분**한다. 3월에 도래하지 않은 연 1회 업무와 기한이 지난 업무가 같은 색으로 보이면 안 된다.
- 전년도에도 증빙이 없던 할 일은 **«2년 연속»**으로 따로 강조한다.

### 5-5. 이행을 말하는 축이 셋 — 합치지 않는다

| 축 | 화면 | 단위 |
|---|---|---|
| 증빙문서 | 업무문서 > **이행 목록** | 이행항목 80 × 업무단계 177 |
| 부서 점검 | 안전보건관리체계 > **이행점검** | 부서 39 × 반기 |
| 발행·배정 | (구)업무관리 > **업무 발행 관리** | 템플릿 26 × 회차 × 부서 |

**서로의 완료 판정을 읽지도 쓰지도 않는다** — 합치면 완료가 두 곳에서 판정되어 조용히 어긋난다.

## 6. 담당자가 실제로 하는 일 — 4걸음

시스템에 이미 들어 있는 **업무문서 사용법 4걸음**이 교육 시나리오의 뼈대다.

| 걸음 | 하는 일 | 누가 | 어디서 |
|---|---|---|---|
| **①** | **할 일 찾기** — 맨 위 초록 줄의 `[내 부서 미이행 먼저 보기]` | 부서 담당자 | 이행 목록 |
| **②** | **서류 올리기** — 파일 + «무슨 일»인지 표시 | 부서 담당자 | 이행 목록 → 업무 업로드 |
| **③** | **확인·완료** — 증빙을 보고 «완료» 도장 | 재난안전과 | 이행 목록 |
| **④** | **문서 찾기** — 나중에 그 서류를 다시 | 누구나 | 업무 목록 |

**②가 핵심이다.** 그냥 파일만 올리는 게 아니라 **이 서류가 «어떤 의무의 무슨 일»을 했다는 증거인지** 함께 표시한다. 그래야 이행 현황에 반영된다. 서류 한 장이 여러 일의 증거일 수 있어 **여러 개 고를 수 있다**.

**고르는 방식** — 채용 사이트에서 직무 고르는 것과 같다. **왼쪽 「어떤 의무인가요」 → 오른쪽 「무슨 일인가요」**, 칸마다 검색창, 고른 것은 아래에 모인다. 항목 80개·단계 177개를 드롭다운으로 고를 수는 없다.

**업로드 3단계** — ① 파일·문서명·보고일자·담당 ② 할 일 고르기(2단 선택기) ③ 무엇이 어떻게 바뀌는지 확인하고 `[이대로 등록]` → 고른 일이 **«진행중»**으로.

## 7. 말하면 안 되는 것 9 (MUST)

교육자료가 **거짓을 가르치지 않게** 하는 목록이다. 전부 저장소 규칙에 근거가 있다.

| # | 금지 | 이유 |
|---|---|---|
| ① | **2026년 수치를 담양군 실적으로** | 2026 실적(단계 48·문서 82)은 **2025 실측에서 규칙으로 만든 예시 자료**다. 실측은 2025 원장 3,830건뿐 |
| ② | **대시보드 첫 화면 수치 인용** («이행률 72%»·«사업장 23개소»·부서별 이행률) | 전부 시연용 예시 자료이고 화면에도 «예시 자료» 라벨이 붙어 있다 |
| ③ | **교육 이수율 «실측 38~56%»** | 실측 원장에 이수율 통계가 없다. **출처 확인 전까지 미확인**이다 |
| ④ | **«주기가 있으면 전부 자동»** | 26종 중 **8종만** 자동. 16종은 확인 후 발행, 2종은 수동 |
| ⑤ | **«기한이 되면 재촉 문자를 보냅니다»** | 시스템은 **권고만** 하고 발송은 사람이 누른다. 실제 발송 채널도 아직 없다 |
| ⑥ | **«해당없음으로 넘기면 됩니다»** | 사유 없으면 **저장 자체가 거부**된다. 종이 서식의 실패 모드가 바로 이것이었다 |
| ⑦ | **문서·주석에서 수치를 옮겨 적기** | 옛 수치가 남은 자리가 많다. 규칙 문서는 «7법령 48조문»·«이행항목 78·단계 168»로 남아 있다. **실측은 9법령 66조문 · 80항목 177단계** |
| ⑧ | **«이행»을 한 뜻으로** | 축이 셋이고 단위가 각각 다르다(§5-5) |
| ⑨ | **메뉴 경로를 정의서에서 옮겨 적기** | 정의서의 «업무 관리 > 업무 발행 관리»는 현재 GNB에서 **«(구)업무관리»**다. «업무 관리»는 신설 그룹이 쓴다 |

## 8. 공무원이 가장 먼저 묻는 5가지

| 질문 | 답 |
|---|---|
| **«안 하면 제가 처벌받나요?»** | **처벌 대상은 담당자가 아니라 경영책임자인 군수**다. 중처법 §4가 의무를 지우는 상대는 「사업주 또는 경영책임자등」이다. 다만 **담당자의 미이행이 곧 군수의 책임 요건**이 되는 구조다 |
| **«제 일이 늘어나나요?»** | **아니다.** 자동발행은 「언제·누구에게·언제까지·누가 할지」만 만드는 앞단이고, 점검표 작성·교육 등록·개선조치·검진은 **기존 전용 화면이 그대로** 한다. 카탈로그 26종 중 기존 화면을 대체하는 것은 **0개** |
| **«올린 서류는 그다음 어떻게 되나요?»** | 올리면 무조건 «진행중», **재난안전과가 확인해야 «완료»**. 스스로 완료로 만드는 수단은 없고, 완료 뒤 고치면 자동으로 되돌아간다 |
| **«우리 부서가 대상인지 어떻게 아나요?»** | 명단을 사람이 관리하지 않고 **부서 속성에서 자동으로** 뽑는다. 교육·위험성평가처럼 담당 도메인이 대상을 알면 그쪽 값을 쓴다 |
| **«부서 목록에 우리 과가 없는데요?»** | **맞다.** 대상 39개 중 **11개만 등록**돼 있고, 화면 상단이 «11 / 39개 등록 · 나머지 28개 명단 미확보»를 **상시 표시**한다 |

## 9. 교육 당일 주의 — 시연 환경

발표자가 알고 있어야 화면 앞에서 당황하지 않는다.

| 사실 | 무슨 일이 생기나 |
|---|---|
| 시스템의 **«오늘»이 2026-07-16으로 고정** | 실제 날짜와 D-day가 어긋난다. 기준일을 옮기면 2026 예시 자료를 다시 만들어야 한다 |
| **로그인 화면이 없다** | 헤더 우측 **「권한 전환」**으로 페르소나(9인)를 골라 들어간다. 실제 접속은 행정포털 SSO 연계 범위 |
| **올린 파일의 실물은 저장되지 않는다** | 이름·크기·형식만 기록한다. 올린 문서를 나중에 열어 볼 수 없다 |
| **저장 위치가 서버가 아니라 그 브라우저** | 내가 올린 것을 **옆자리 동료 화면에서는 볼 수 없다** |
| **아직 안 되는 것이 36곳** | 누르면 «…은 연계 적용 후 제공됩니다» 안내만 나온다 |
| 알림은 **고정 5건** | 자동발행·기한 초과가 새 알림을 만들지 않는다 |
| 정보센터는 **내용이 고정 예시** | 공지 3·자료 3·우수사례 2건이 화면에 박혀 있다 |
| 54개 화면이 **외부 CDN**에서 스타일을 받는다 | 인터넷이 차단된 내부 행정망에서 열면 깨질 수 있다 — **교육 전 반드시 확인** |
