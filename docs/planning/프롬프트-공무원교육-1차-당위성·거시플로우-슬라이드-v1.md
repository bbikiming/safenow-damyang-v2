## 1. 교육 1차의 위치 — 무엇을 가르치고 무엇을 미루나

| | 1차 (이 문서) | 2차 (후속) |
|---|---|---|
| 물음 | **왜 이걸 써야 하고, 쓰면 무엇이 좋아지고, 전체가 어떻게 이어지나** | 내 화면에서 **실제로 무엇을 누르나** |
| 깊이 | 거시 — 메뉴 11축 · 4계층 · 업무 흐름 7개 · 연계 5종 | 미시 — 이행 관리 4걸음 · 위험성평가 9단계 실습 · 교육 등록 실습 |
| 형식 | **착수보고회·중간보고 자료의 장 구성을 계승** (장 구분 · 헤더 띠 · 한 줄 메시지 제목) | 화면 캡처 중심 실습 자료 + 시스템 안 「단계별 안내」 |
| 분량 | 30~35장 · 40분 강의 + 10분 질의 | 미정 |
| 대상 | 각 과·사업소·읍면의 **안전보건 실무 담당자**(주) · 과장·소장·읍면장(부) · 재난안전과 | 부서 담당자 |

**보고 자료와 다른 점 — 반드시 지킬 것**
- 보고는 「우리가 이만큼 했다」를 말하고, 교육은 「**여러분이 이렇게 쓰게 된다**」를 말한다. 주어가 수행사가 아니라 **듣는 사람**이다.
- 보고 자료의 「개발 추진현황(완료 6·진행 12)」 같은 **사업 관리 수치는 싣지 않는다**. 담당자에게는 정보가 아니다.
- 보고 자료의 **AS-IS/TO-BE 대비 · 4계층 구성도 · 거시 일정** 세 장은 형식을 그대로 가져오되, 내용을 담당자 관점으로 다시 쓴다.

## 2. 클로드 디자인 프롬프트 (그대로 붙여 넣기)

```
담양군청 공무원 대상 「담양군 중대재해예방 통합관리시스템」 1차 교육용 슬라이드를 만들어 줘.
PowerPoint(.pptx)로 내보낼 수 있는 16:9 슬라이드 덱이다.

════════════════════════════════════════
■ 0. 반드시 먼저 읽을 것 — 첨부 문서 두 개
════════════════════════════════════════
- 첨부 A 「§3 사실 원장」: 슬라이드에 들어가는 모든 숫자·고유명사·법령 표기는 이 표에서만 가져온다.
  표에 없는 숫자는 지어내지 말고 「(확인 중)」으로 비워 둔다. 숫자를 반올림하거나 합산하지 않는다.
- 첨부 B 「화면 캡처」: 시스템 화면을 그려 넣을 자리에는 첨부한 캡처를 쓴다.
  캡처가 없는 화면은 상상해서 그리지 말고 「캡처 자리」라고 표시한 빈 틀을 둔다.
- 「§3-9 말하면 안 되는 것」은 금지 목록이다. 한 장이라도 어기면 그 장은 다시 만든다.

════════════════════════════════════════
■ 1. 누구에게, 무엇을, 왜
════════════════════════════════════════
대상
- 주 대상: 담양군 각 과·사업소·읍면에서 안전보건 실무를 맡는 담당자(주무관·팀장). 시스템을 처음 본다.
  안전보건 전문가가 아니다. 「또 시스템이 하나 늘어서 내 일이 늘겠구나」라고 경계하고 있다.
- 부 대상: 실과장·사업소장·읍면장. 「우리 과가 뭘 해야 하는지, 내가 뭘 확인해야 하는지」를 알고 싶다.
- 함께 듣는 사람: 재난안전과(주관부서) 담당자. 이 사람들은 2차 교육에서 운영 주체로 다시 다룬다.

이 교육이 끝났을 때 듣는 사람이 말할 수 있어야 하는 세 문장
① 「이 시스템은 서류 보관함이 아니라, 법이 군에 시킨 일을 하나하나 쪼개서 「했다는 증거」가 붙었는지 보는 시스템이다.」
② 「내가 처벌받는 게 아니라 군수가 처벌받는 구조인데, 내가 놓친 한 건이 그 책임의 근거가 된다. 그래서 놓치지 않게 시스템이 내 앞에 할 일을 가져다 놓는다.」
③ 「메뉴는 11개지만 내가 매일 보는 건 「내 할일」 하나이고, 큰 흐름은 「할 일이 생긴다 → 전용 화면에서 한다 → 증거를 올린다 → 재난안전과가 확인한다 → 공문으로 온나라에 올린다 → 대시보드에 반영된다」 한 줄이다.」

이 교육에서 하지 않는 것(2차 교육으로 미룬다)
- 화면별 버튼 조작 실습. 이번에는 「어디에 무엇이 있다」까지만 보여 준다.
- 위험성평가 작성표 작성법, 교육 등록 폼 입력법, 업무 업로드 3단계 입력법.
→ 마지막 장에서 「2차 교육에서 실제 화면으로 실습합니다」라고 예고만 한다.

■ 2. 형식 — 착수보고회·중간보고 자료의 장 구성을 그대로 계승
════════════════════════════════════════
이 군청은 2026-03 사업수행계획서(착수)와 2026-08-07 추진현황 중간보고 자료를 이미 봤다.
그 자료와 「같은 집안의 문서」로 보여야 한다. 아래 골격을 지킨다.

슬라이드 골격(보고 자료 계승)
- 표지: 상단 소제목 「담양군 중대재해예방 통합관리시스템 구축」 / 중앙 큰 제목 「담당자 교육 1차」 /
  부제 「왜 쓰는가 · 무엇이 달라지는가 · 업무는 어떻게 이어지는가」 / 하단 일자 「2026. ○○. ○○(○)」 — 일자는 비워 둔다.
- 목차(CONTENTS): 2열 6개 장을 번호와 함께. 보고 자료의 CONTENTS 장과 같은 배치.
- 장 구분 슬라이드: 「제 N 장」 작은 글자 → 장 제목 큰 글자 → 한 줄 부제. 장마다 1장.
- 본문 슬라이드 공통 헤더 띠: 왼쪽 「Ⅰ. 왜 이 시스템인가」처럼 장 로마숫자+장 제목, 오른쪽 「담당자 교육 1차」 러닝 타이틀. 우하단 쪽 번호.
- 본문 슬라이드 제목은 「한 줄 메시지」다 — 「사업 개요」 같은 명사가 아니라
  「문서가 있다는 것과 이행했다는 것은 다릅니다」처럼 주장 문장으로 쓴다. 그 아래 한 줄 부제로 근거를 단다.
- 마무리: 「감사합니다」 장 + 「질의응답」 안내. 연락처 칸은 비워 둔다.

보고 자료와 달리 할 것
- 주어는 「여러분」·「담당자」·「우리 과」다. 「당사」·「수행사」·「본 사업」을 쓰지 않는다.
- 사업 관리 수치(기능 21개 중 18개 착수, 진척률 등)를 싣지 않는다.
- 말투는 존댓말 평서문. 「~합니다 / ~됩니다」. 느낌표·물음표 남발 금지.
- 영어 약어는 첫 등장에 한글 풀이를 붙인다. 예) FMS(시설물통합정보관리시스템), e호조+(지방재정관리시스템).

슬라이드 1장의 정보량
- 한 장에 메시지 하나. 본문 글머리는 5개를 넘기지 않는다. 한 글머리는 두 줄 이내.
- 글자 크기 최솟값: 본문 18pt, 표·캡션 14pt, 제목 28~32pt. 프로젝터 뒤에서 읽혀야 한다.
- 표는 6행 × 4열을 넘기지 않는다. 넘치면 두 장으로 나눈다.

발표자 노트
- 모든 본문 슬라이드에 발표자 노트를 단다. 2~5문장. 「이 장에서 강사가 입으로 말할 것」이고
  슬라이드 본문을 다시 읽는 문장이 아니다. 담당자가 던질 반문(「그럼 저는 뭘 하나요?」)에 미리 답하는 문장을 하나 넣는다.
- 노트에도 §3 에 없는 숫자를 쓰지 않는다.

■ 3. 디자인 시스템 — 시스템 화면과 같은 색으로
════════════════════════════════════════
색 (시스템 디자인 토큰과 같은 값 — 캡처와 슬라이드 색이 맞아야 한다)
- 주색(담양 녹): #2D9270 / 진한 녹 #24785C / 가장 진한 녹(헤더 띠·장 구분 배경) #0F3D2E / 연한 녹(배경 칠) #DFF1E9 / 아주 연한 녹 #F1FAF5
- 「비어 있음·미이행·지연」 강조색(관인 인주색): #BB4B4B — 이 색은 오직 빠짐·지연·경고에만 쓴다. 장식에 쓰지 않는다.
- 정보·연계 표시: #0077A9
- 본문 글자: #1F2937 / 보조 글자: #6B7280 / 표 머리 배경: #FAFAFA / 선: #E5E7EB
- 그라데이션·그림자·3D 효과를 쓰지 않는다. 평면(flat), 모서리 반경 8px.
- 배경은 흰색. 장 구분 슬라이드만 #0F3D2E 배경에 흰 글자.

글꼴
- 한글: Pretendard(없으면 Noto Sans KR). 영문·숫자도 같은 글꼴. 제목 Bold, 본문 Regular, 강조 SemiBold.
- 한글에 자간(letter-spacing)을 주지 않는다. 대문자 변환(uppercase)은 한글에 무의미하니 쓰지 않는다.
- 줄바꿈: 어절 중간에서 끊기지 않게 한다(word-break: keep-all 에 해당하는 설정). 「무 / 슨 일」처럼 쪼개지면 안 된다.
- 괄호·인용은 「 」 를 쓴다. « » 와 “ ” 를 쓰지 않는다 — 공문서에서 실제로 쓰는 괄호다.

도형·아이콘
- 흐름도 상자: 흰 배경 + 1px 선 + 반경 8px. 현재 강조 상자만 #DFF1E9 배경 + #24785C 선.
- 화살표는 가는 실선, 머리는 작게. 「→」 글자 화살표를 본문 문장 안에 쓰지 않는다.
- 아이콘은 선(outline) 스타일 단색(#24785C). 이모지를 쓰지 않는다.
- 사람 역할은 색이 아니라 라벨로 구분한다 — 군수 / 과장·소장·읍면장 / 담당자 / 재난안전과. 색만으로 뜻을 전하지 않는다.

■ 4. 슬라이드 구성 — 장별 상세 (총 33장 안팎)
════════════════════════════════════════
아래 번호 순서대로 만든다. 각 항목은 [제목(한 줄 메시지)] / [부제] / [본문 구성] / [시각 장치] / [쓸 수치: §3 표 번호] / [발표자 노트 요지] 다.

── 표지 · 목차 ──────────────────────────
S01 표지 — 위 골격대로.
S02 목차 — 6개 장:
  Ⅰ 왜 이 시스템인가 / Ⅱ 무엇이 달라지는가 / Ⅲ 시스템의 전체 그림 / Ⅳ 업무는 어떻게 이어지는가 /
  Ⅴ 내 자리에서 보이는 것 / Ⅵ 지금 어디까지 왔고 다음은 무엇인가

── 제 Ⅰ 장. 왜 이 시스템인가 (당위성) ──────
S03 장 구분 — 「제 1 장 / 왜 이 시스템인가 / 법이 군에 요구하는 것과 지금 방식의 한계」

S04 [법은 「서류」가 아니라 「이행」을 요구합니다]
  부제: 중대재해처벌법은 두 축이고, 담양군은 양쪽 다 적용됩니다
  본문: 좌우 2칸. 왼쪽 「중대산업재해」(법 §4·§5 — 군 소속 종사자의 안전) / 오른쪽 「중대시민재해」(법 §9 — 군이 관리하는 공중이용시설·원료제조물을 이용하는 시민의 안전).
  각 칸 아래 「담양군에 왜 걸리나」 한 줄: 본청·사업소·읍면의 현업 종사자 / 군이 관리하는 공공시설.
  시각: 두 기둥이 하나의 지붕(「경영책임자 = 군수」)을 받치는 그림.
  수치: §3-2 법령 축.
  노트: 「한 축만 알고 계신 분이 많습니다. 시설을 관리하는 과는 시민재해 축도 함께 걸립니다.」

S05 [시행령은 의무를 9가지로 쪼개고, 그중 5가지는 「반기마다 점검」을 명시합니다]
  부제: 중대재해처벌법 시행령 제4조 — 안전보건관리체계 구축 의무
  본문: 9개 의무를 3×3 격자 카드로. 각 카드에 번호·이름(목표·경영방침 / 전담조직 / 유해·위험요인 확인·개선 / 예산 / 책임자 권한·평가 / 전문인력 배치 / 종사자 의견청취 / 매뉴얼 / 도급 기준·절차).
  반기 점검이 명시된 3·5·7·8·9호 카드에 「반기 1회 이상 점검」 작은 배지. 1호에는 배지를 달지 않는다(법에 그 문구가 없다).
  시각: 격자 + 배지. 각 카드 하단에 「이 시스템의 어느 메뉴가 받는가」 한 단어(경영방침 / 조직 / 위험성평가 / 예산 / 인력 평가 / 조직 / 의견청취 / 이행점검 / 도급관리).
  수치: §3-2.
  노트: 「9가지가 곧 메뉴 이름이 됩니다. 3장에서 다시 봅니다.」

S06 [처벌 대상은 담당자가 아니라 군수입니다 — 그러나 근거는 담당자의 한 건입니다]
  부제: 「제가 처벌받나요?」에 대한 답

S07 [지금 방식으로는 「취합이 안 되고, 놓치고, 사람이 되풀이합니다」]

  시각: 큰 숫자 + 짧은 설명. 그래프 그리지 않는다(숫자 3개면 숫자가 그래프보다 세다).
  수치: §3-3 만. 다른 숫자 금지.
  노트: 「통보를 보름 앞당겼는데도 제출은 더 늦어졌습니다. 일찍 알리는 것으로는 안 된다는 뜻입니다.」

S11 [담당자에게 좋아지는 다섯 가지]

   ⑤ 기존 전용 화면은 그대로다(점검표·교육·개선조치는 지금처럼 그 화면에서 — 자동발행은 「언제·누가·언제까지」만 만든다)
  시각: 카드마다 선 아이콘 하나.
  수치: §3-5 자동발행(「대체하는 기존 화면 0개」).
  노트: ⑤를 강조. 「점검표 양식을 새로 배우는 게 아닙니다. 할 일이 생기는 방식만 달라집니다.」

S12 [과장·소장·읍면장에게 좋아지는 세 가지]

  노트: 「과장님이 직접 올릴 일은 없습니다. 보고, 정하고, 재촉하는 것이 과장님 화면입니다.」

S13 [이 시스템이 「하지 않는 것」 네 가지]
```
