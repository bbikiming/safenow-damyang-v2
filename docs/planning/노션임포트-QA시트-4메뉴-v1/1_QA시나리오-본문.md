# 1. 테스트 운영 기준

## 1.1 계정 (화면 우측 상단 권한 전환)

| 약칭 | 이름 · 직위 | 계층 | 이 시트에서 보는 것 |
| --- | --- | --- | --- |
| 주관 담당 | 박안전 · 안전관리 주무관(재난안전과) | 담당자 | 전 부서 조작 — 대부분의 등록·확인·공문 |
| 주관 과장 | 홍길동 · 재난안전과장 | 관리·감독 | 전 부서 조회만 |
| 부서 담당 | 하정수 · 주무관(물순환사업소) | 담당자 | 자기 부서만 조작 |
| 타 부서 담당 | 정환경 · 주무관(환경과) | 담당자 | 남의 부서 건을 건드릴 수 없는지 |
| 총괄 | 김담양 · 군수 | 관리·감독 | 전 부서 조회만 · 재촉 없음 |

## 1.2 데이터와 초기화

- 기준일은 **2026-07-16** 로 고정돼 있다. 기한·D-day 는 이 날짜 기준이다.
- 2025년 문서는 **문서 원장 실측**, 2026년은 **예시 자료**다(«예시 자료» 칩이 붙는다). 둘 다 정상이다.
- 입력한 데이터는 **브라우저 탭마다** 저장된다. 처음 상태로 돌리려면 **새 탭**을 연다(또는 헤더 [?] 도움말의 «예시 데이터 되돌리기»).
- 권한을 바꾸면 같은 탭의 데이터는 그대로 이어진다 — 한 탭에서 주관 담당으로 만들고 부서 담당으로 바꿔 이어서 처리하는 흐름을 그대로 탈 수 있다.

## 1.3 결과 표기

| 값 | 뜻 |
| --- | --- |
| N/T | 아직 안 함 (임포트 기본값) |
| PASS | 기대 결과와 같다 |
| FAIL | 다르다 — «QA 결함 기록»에 등록하고 이슈번호를 잇는다 |
| BLOCK | 앞 단계가 막혀 수행할 수 없다 |
| N/A | 이 환경에서 판정할 수 없다(연계 후 검증 등) |

## 1.4 결함으로 올리지 않는 것 (정상 동작)

- «…연계 후 제공됩니다»·«…연계 적용 후 제공됩니다» 안내 — 외부 연계 전이라 **의도적으로** 막은 기능이다.
- 관리·감독 계층(과장·군수)에게 등록·수정 버튼이 **없는 것**, 그리고 그 자리에 «누가 하는지» 안내가 뜨는 것.
- 부서 담당자에게 **남의 부서 행의 버튼이 없는 것**.
- 시설물 보완입력·FMS 전송은 아직 **역할 구분이 없다**(발주처 정책 확정 대기) — 부서 담당자도 저장된다.
- 교육 공문 상태가 «결재중»에서 더 바뀌지 않는 것 — 교육은 온나라 회신을 받지 않는 도메인이다.

# 4. 위험성평가

> 위험성평가 > 정기 위험성평가 · 수시 위험성평가. 개선조치는 정기평가 화면 안과 내 할일에서 처리한다.
> 화면 상단 «단계별 안내 시작»을 켜면 9걸음(정기)·5걸음(수시)의 다음 버튼을 짚어 준다 — 흐름 TC 에서 그대로 따라가면 된다.

> **이 절의 테스트 케이스 18건은 별도 데이터베이스에 있다** — 「QA 테스트 케이스」 데이터베이스에서 `구분 = 위험성평가` 로 거른다. (원본: `2_QA-테스트케이스.csv`)

# 5. 안전보건교육

> 안전보건교육 > 현업근로자(정기·채용시·기타) · 관리감독자(정기·채용시·기타) · 이수현황 · 근로자 명단 관리 · 결재 이력.

# 6. 결함 등록

FAIL 은 «QA 결함 기록» 데이터베이스에 한 건씩 등록하고, TC 의 `이슈번호` 에 잇는다.

| 심각도 | 기준 |
| --- | --- |
| Blocker | 흐름이 그 자리에서 멈춘다(저장 불가·화면 오류) |
| High | 잘못된 데이터가 저장되거나 권한이 뚫린다 |
| Medium | 안내·표시가 틀리거나 되돌릴 수 없다는 사실을 말하지 않는다 |
| Low | 문구·조사·정렬 |
