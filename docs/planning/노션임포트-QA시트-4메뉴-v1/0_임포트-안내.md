# 노션 임포트 안내 — 4개 메뉴 QA 시트 v1

관리대상(시설물) · 업무 관리 · 위험성평가 · 안전보건교육 네 메뉴의 QA 시트다. 이 폴더의 3개 파일이 한 세트이고, **같이 골라서 한 번에 임포트할 수 있지만 서로 자동으로 연결되지는 않는다.**

| 파일 | 임포트 결과 |
| --- | --- |
| `1_QA시나리오-본문.md` | 페이지 1개 (운영 기준 · 계정 · 결과 표기 · 결함 기준 · 결과 요약) |
| `2_QA-테스트케이스.csv` | 데이터베이스 «QA 테스트 케이스» — 87건 |
| `3_QA-결함기록.csv` | 데이터베이스 «QA 결함 기록» — 빈 상태 (헤더만) |
| `2b_QA-테스트케이스-추가분.csv` | 첫 배포라 아직 없다 — 시트를 개정하면 바뀐 TC 만 담아 여기에 생긴다(이미 넣은 DB 에 Merge 용) |

> 1차 QA 세트(`노션임포트-QA-v0.5`)와 **따로** 쓴다. 두 세트를 같은 워크스페이스에 넣으면 데이터베이스 이름이 같으니, 임포트 직후 이 세트의 두 DB 이름 앞에 «4메뉴 —» 를 붙여 구분한다. TC ID 접두어(FAC·CMP·RSK·EDC)가 1차 세트(RISK·EDU·COM·SMK)와 달라 서로 덮어쓰지 않는다.

---

## 1. 임포트

`Settings → Import → Text & Markdown / CSV` 또는 **사이드바에 파일을 끌어다 놓는다.** 붙여넣기는 쓰지 않는다 — 표가 어긋난다.

**CSV 2개를 먼저**, 그 다음 본문 `.md`. 사이드바에 **나란히 3개**로 들어온다.

> ⚠ **원본 `검수-QA시트-4메뉴-v1.md` 는 같이 넣지 않는다.** 원본에는 TC 표가 그대로 있어 함께 넣으면 **테스트 케이스가 두 벌** 생긴다.

---

## 2. 임포트 뒤 손으로 할 일 4가지

**① 속성 타입** — «QA 테스트 케이스» 각 열 위 드롭다운에서 바꾼다.

| 속성 | 바꿀 타입 | 값 |
| --- | --- | --- |
| TC ID | Title (자동) | — |
| 구분 | Select | 관리대상(시설물) · 업무 관리 · 위험성평가 · 안전보건교육 |
| 우선순위 | Select | P0 · P1 · P2 |
| 결과 | Select | N/T · PASS · FAIL · N/A · SKIP · BLOCK |
| 테스터 | Person | — |
| 나머지 | Text (그대로) | — |

«QA 결함 기록» 은 `심각도` → Select (Blocker · High · Medium · Low), `상태` → Select, `발견일` → Date, `발견자`·`개발 담당` → Person.

**② 이슈번호를 관계로** — «QA 테스트 케이스» 의 `이슈번호` 를 **Relation → «QA 결함 기록»** 으로 바꾼다.

**③ 본문 안으로 모으기** — 본문 페이지의 각 메뉴 절(§2~§5) 안내 밑에 `/linked view of database` 로 «QA 테스트 케이스»를 넣고 `구분` 으로 거른다.

**④ 뷰 만들기**

| 뷰 | 필터 | 쓰는 사람 |
| --- | --- | --- |
| 내 담당 | `테스터 = 나` · `결과 = N/T` | 테스터 |
| P0 잔여 | `우선순위 = P0` · `결과 = N/T` | 종료 기준 추적 |
| 실패만 | `결과 = FAIL` 또는 `BLOCK` | 결함 정리 |
| 진행 현황 | `구분` 으로 그룹 · `결과` 로 나눔 | 본문 §7 요약 대체 |

## 3. 알아 둘 것

- 입력 데이터는 **브라우저 탭마다** 저장된다. 처음 상태가 필요한 TC(사전조건 «새 탭»)는 새 탭에서 시작한다.
- 권한은 화면 우측 상단에서 바꾼다. 같은 탭에서 바꾸면 데이터가 이어진다 — 주관 담당으로 만들고 부서 담당으로 처리하는 흐름을 그대로 탄다.
- 이 세트는 `python3 tools/build-qa-notion.py --src docs/planning/검수-QA시트-4메뉴-v1.md --dst docs/planning/노션임포트-QA시트-4메뉴-v1` 로 원본에서 만든다. **CSV·본문을 손으로 고치지 말고** 원본을 고친 뒤 다시 돌린다.
