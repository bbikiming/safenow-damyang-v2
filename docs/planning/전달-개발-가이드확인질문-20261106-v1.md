# 가이드 고치기 전 확인 부탁 (2026-11-06)

> 사용 가이드 7부를 오늘 결정(기안까지만)에 맞춰 고치려고 합니다. 가이드 문장을 정하는 데 아래 답이 필요합니다. 짧게라도 답해 주시면 그대로 반영합니다.

## 교육 전에 꼭 필요한 것

**1. 보낸 뒤 안내 문구는 «연계기안함»으로 해 주세요.** 정정판 v2 는 Q2 답을 받기 전이라 «온나라 기안함에서 검토·결재를 지정해 상신하세요»로 적어 드렸습니다. «온나라 **연계기안함**에서…»로 바꿔 주세요.

**2. 결재 결과 읽어 오기가 교육(11월 셋째 주) 전에 붙습니까?** 붙으면 가이드에 «온나라에서 반려되면 화면을 열 때 반영되어 다시 고칠 수 있습니다»라고 쓰고, 안 붙으면 «결과는 온나라에서 확인합니다»로 낮춥니다. 반송(상신 안 하고 지움)은 이미 된다고 하셨으니 그대로 씁니다.

**3. 미리보기·확인 창의 문서번호 문구도 바뀝니까?** 지금 화면에 «문서번호 미채번 · 상신할 때 확정됩니다»(미리보기), «문서번호가 채번되고 결재 이력에 남습니다»(확인 창)가 있습니다. 이제 번호는 결재가 끝나야 생기므로 맞지 않습니다. 고치실 예정인지, 고친다면 어떤 문구인지 알려 주세요.

**4. 버튼 이름이 바뀌면 알려 주세요.** 가이드에는 지금 이름(`[공문 기안]` · `[결재 상신]` · `[상신]` · 경영방침 `[온나라 결재 상신]` · 이행점검 `[반기 마감 · 온나라 상신]` · 인력 평가 `[결재상신]`)으로 적혀 있습니다. 바꾸지 않으면 답하지 않으셔도 됩니다.

## 동작 확인

**5. 보고서·제증명의 `[온나라 결재]`는 무엇을 합니까?** 말씀하신 «상신 경로 일곱 곳»과 저희 상신 경로 목록 어디에도 없습니다. 다른 공문처럼 기안만 보내는지, 동작하지 않는 버튼인지 알려 주세요. 동작하지 않으면 숨겨 주세요.

**6. 과장·팀장의 `[담당자 지정]`은 교육 때도 지금처럼 됩니까?** 1차 요청서 P03·P04(등급 구성원 지정)를 교육 전에 하시면 과장·팀장의 지정 버튼이 막힐 수 있습니다. 교육 전에는 하지 않는 것으로 알고 «같은 부서 직원이면 쓸 수 있다»고 적겠습니다. 다르면 알려 주세요.

**7. 의견 등록 창의 작성자 `부서명`이 «-»로 비어 보입니다.** (의견청취 › 의견 등록, 부서 담당자 계정) 요청서에 넣지 못했던 것입니다. 소속 부서가 나오게 해 주세요.

**8. 담당자를 정한 개선조치가 `[조치 상세 →]`에서는 «담당 미지정»으로 보입니다.** (내 할일의 개선 카드, 부서 담당자 계정) `[담당자 지정]`으로 저장하면 카드에는 이름이 보이는데, 같은 건을 `[조치 상세 →]`로 열면 «담당 미지정»입니다. 같은 값이 보이게 해 주세요.

## 가이드 그림 다시 찍기 (배포 뒤)

**9. 찍을 자료를 하나 남겨 주세요.** QA 자료를 지우고 나면 종료 처리된 교육과 보낸 공문이 하나도 남지 않아 공문 화면을 다시 찍을 수 없습니다. 배포 뒤 재난안전과 계정으로 연습 교육 하나를 종료 처리하고 공문을 연계기안함에 한 번 보낸 뒤, 지워서 반송 화면까지 찍으려 합니다. 운영 서버에서 이렇게 시험해도 되는지(온나라 쪽에 남는 것이 없는지) 알려 주세요.
