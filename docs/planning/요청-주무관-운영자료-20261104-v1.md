# 재난안전과 주무관 요청 자료 — 운영 환경 세팅 · 2차 교육 전 (2026-11-04)

> 2026년 의무이행 점검(중대산업재해·중대시민재해)과 경영방침을 교육 전에 미리 입력하고, 운영 환경을 세팅하기 위해 담양군에서 받아야 할 자료를 한 곳에 모았다.

## 1. 교육 전에 꼭 필요한 것 (입력·세팅용)

### 1-1. 2026년 의무이행 점검 — 중대산업재해 · 중대시민재해

| 받을 자료 | 왜 필요한가 | 형식 |
|---|---|---|
| ① **2026년 상반기 점검 결과** — 부서별 `이행 / 미이행 / 해당없음` (하반기를 이미 했으면 하반기도) | 이행점검 화면은 **부서 한 줄에 하나**를 등록한다(산업·시민 2탭 × 반기 회차). 항목별 결과는 그 줄의 증빙(부서 점검표 원본)으로 붙는다 | 부서가 낸 점검표 원본(한글·엑셀) + 부서별 결과 취합표 |
| ② **`이행` 항목의 증빙 파일과 위치** | 시스템은 증빙과 위치가 없으면 `이행`으로 저장하지 않는다 | 사진·문서 파일 + «어디에 게시·비치했는지» 한 줄 |
| ③ **`해당없음` 항목의 사유** | 사유 없는 `해당없음`은 저장되지 않는다(종이 서식에서 «해당 없음으로 적고 빠져나가는» 문제를 막는 규칙) | 항목마다 한 줄 |
| ④ 반기 마감 보고를 이미 공문으로 올렸다면 그 **생산등록번호·결재일** | 마감 보고 이력을 온나라 원본과 맞추기 위해 | 번호·날짜 |
| ⑤ 점검 대상 **부서 범위**(39개 전부인지, 산업/시민별로 다른지) | 점검 회차를 열 때 대상 부서를 정한다 | 부서 목록 |

### 1-2. 경영방침

| 받을 자료 | 왜 필요한가 | 형식 |
|---|---|---|
| ① **확정된 경영방침 원문** — 안전보건 목표 · 경영방침 문장 · 버전(예: v1.0) · 시행일 | 경영방침 화면에 실제 방침을 등록한다 | 결재받은 한글 파일 |
| ② 그 방침의 **결재 공문 생산등록번호 · 결재일** — ⚠ 화면에서 결재 결과를 적는 칸은 **이 시스템에서 상신한 뒤에만** 열린다. 이미 온나라에서 결재가 끝난 방침이면 화면으로는 현행본을 만들 수 없어 **개발자 입력이 필요하다** | 결재가 끝난 방침이어야 **현행본**이 되고, 현행본이 있어야 «게시 현황»이 집계된다. 지금은 현행본이 없어 게시 현황이 «집계할 수 없습니다»로 나온다. 결재 결과를 옮겨 적으려면 생산등록번호가 필요하다 | 번호·날짜 |
| ③ (있으면) 이전 버전 방침 · 개정 이력 | 버전 이력을 남긴다 | 파일 |
| ④ (있으면) 부서별 **게시 현황** — 게시 위치·사진 | 2차 교육 전에 게시 현황을 채워 두면 부서 실습에서 «우리 부서 게시 등록»을 실제 화면으로 보여 줄 수 있다 | 부서별 사진 + 위치 |

### 1-3. 사람·권한 (이게 없으면 부서 화면이 실제와 다르게 보인다)

| 받을 자료 | 왜 필요한가 | 형식 |
|---|---|---|
| ① **부서별 안전보건 담당자 명단**(부서·성명·직위) — EXT-16 | 권한 관리의 «부서 안전보건 담당자» 등급에 넣는다. 지금은 예시 2인뿐이라 나머지 실무자는 «일반 공무원(조회 전용)»으로 보인다. 부서로 가는 알림·독촉의 받는 사람도 이 명단이 정한다 | 엑셀 |
| ② **관리감독자 지정 명단 + 지정일**(성명·부서·직위·지정일) — EXT-12 | 지정일이 없으면 관리감독자 채용시교육이 전원 «판정 불가»로 나온다 | 엑셀 |
| ③ **현업업무 종사자 지정 명단** — EXT-11 | 교육 의무 대상은 현업업무 종사자다. 명단이 없으면 이수율 분모가 전 직원이라 이수율이 실제보다 낮게 나온다 | 엑셀 |
| ④ 공무직·기간제 등 **근로자 명단**(고용형태·채용일·계약기간) — 조직도 연계로 오지 않는 사람만 | 채용시교육 필요시간(1·4·8h)이 고용형태·계약기간으로 갈린다 | 엑셀 |
| ⑤ **과장 또는 팀장 QA 계정 1개** (30분 확인용) | 과장·팀장 가이드가 실제 화면과 대조하지 않은 유일한 가이드다 | 계정 발급 |

### 1-4. 2차 교육 운영

| 받을 것(정할 것) | 왜 필요한가 |
|---|---|
| ① **실습 서버** — 별도 연습 서버를 둘지, 운영 서버에서 연습 계정·연습 자료로 할지 | 운영 서버라면 2차 실습 연습 자료가 실제 데이터와 섞인다 |
| ② **실습 계정 수와 부서 배정** (부서 × 담당자 2 + 관리자 1 규모) | 한 계정을 여럿이 쓰면 앞사람이 누른 것이 뒷사람 화면에 남는다 |
| ③ **끝까지 누르지 않을 처리** — 개선조치 완료 처리(전자서명)·반려·공문 상신을 실제로 누를지, 확인 창에서 멈출지 | 되돌릴 수 없는 처리다. 상신은 실제 온나라로 간다 |
| ④ **컴퓨터실 좌석 수** · **대상 부서 범위**(39개 중 몇 개) | 회차 수와 부서별 연습 자료 범위가 정해진다 |
| ⑤ **영상을 볼 수 있는 경로** (내부 게시판 / 시스템 내 파일 / QR) | 군 내부망에서 외부 영상 사이트가 막혀 있을 수 있다 |
| ⑥ **재난안전과 연간 운영 일정**(월별 — 정기평가·교육·반기 점검·측정·검진 시기) | 가이드 3부의 «언제 무슨 일이 오나» 표가 비어 있다 |

## 4. 요청하지 않는 것 (목록에 넣지 말 것)

| 항목 | 이유 |
|---|---|
| 관인 이미지 · 기관 주소·전화·팩스 · 처리과 기호 | 정본 공문은 온나라가 만든다. 처리과 기호는 생산등록번호에 함께 온다 |
| 공문 샘플 · 기록관리 기준표 | 지면은 법정 서식이고, 보존은 법정 최소기간으로 확정했다 |
| 교육시간 감면 기준 | 재량 조항이라 미적용으로 확정했다 |
| 공중교통수단 존부(EXT-09) · 도급 점검 대상 선별 기준(EXT-14) | 담양군 확인(08-31) — **문서 분류 이후에 정해진다.** 지금 물어도 답이 없다 |
| 원문 확인 문서 분류(EXT-19) | 다온플레이스가 방문해 확인한다 |

## 우선순위 한 줄

**교육 전 필수 = 1장 전부.** 그중에서도 ① 경영방침 원문 + 결재 생산등록번호(현행본) ② 2026 상반기 점검 결과 + 증빙·사유 ③ 부서별 안전보건 담당자 명단 ④ 과장·팀장 계정 ⑤ 실습 서버·계정 결정 — 이 다섯이 없으면 2차 교육 화면이 실제 업무와 다르게 보인다.
