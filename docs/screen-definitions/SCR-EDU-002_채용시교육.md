### 분기 로직

- **탭이 대상자 모집단을 가른다** — 전체 / 미이수 / 이수 세 갈래이고, 이수 탭에서만 **정상 이수와 지연 이수**가 다시 갈린다(채용일 기준 법정 시점을 넘겼는지로 판정). 구 `교육 건` 탭은 폐지했으므로 되살리지 않는다.
- **일괄 이수 처리에는 축이 둘이고, 둘이 서로를 강제한다.**
  - **이수일 방식** — 기본은 **각자 채용일**(권장 · 정상 이수)이고, **일괄 이수일**을 고르면 전원 같은 날로 기록한다. 일괄 이수일이 채용일보다 늦으면 그 사람은 **지연 이수**가 된다.
  - **교육 건 생성 방식** — 기본은 **근로자별 개별 건**(1명당 1건)이고, **한 건으로 묶기**를 고르면 여러 명이 한 교육 건에 들어간다.
  - **묶기를 켜면 일괄 이수일로 자동 전환된다** — 한 건에 이수일이 여럿일 수 없기 때문이다. 반대로 **각자 채용일로 되돌리면 묶기가 자동 해제된다**.
- **묶기를 골라도 필요시간이 다르면 건이 나뉜다** — 1h·4h·8h는 **법정 교육시간이 다른 별개 과정**이라 한 건에 담을 수 없다. 담당자가 정하는 값이 아니며, 화면이 **예상 생성 건수와 시간대별 인원**을 미리 보여준다.
- **묶은 건은 부서를 비운다** — 여러 부서가 섞이므로 집합교육과 같은 방식으로 부서별 신청 행으로 나눠 담는다.
- **상태에 따라 나타나는 수단이 다르다** — 미이수자에게는 선택 상자와 일괄 이수 처리가, 이수자에게는 **이수 수정**이 나타난다. 같은 자리에 두면 이미 처리한 사람을 다시 처리하게 된다.
- **필요시간은 고용형태에서 파생한다** — 사람마다 값이 다른 것이 정상이며 화면에서 직접 입력하지 않는다.
- **회수는 수정 안에 들어 있다** — 전면 라벨이 '취소'가 아니라 **수정**이다. 이수를 되돌리면 그 사람 기록이 지워지고, 연결된 교육에 **남은 대상자가 없으면 교육 건까지 함께** 회수된다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 미이수자를 한 명도 고르지 않고 일괄 처리 | 처리하지 않고 "미이수자를 1명 이상 선택하세요" |
| 일괄 이수일을 고르고 날짜를 비운 채 저장 | 저장을 막고 "일괄 이수일을 입력하세요" |
| 묶기를 켠 상태에서 각자 채용일로 되돌림 | 묶기가 자동 해제된다 — 이수일이 사람마다 달라지면 한 건으로 묶을 수 없다 |
| 필요시간이 다른 인원을 묶으려 함 | 막지 않고 **건을 나눠** 만들며, 몇 건이 생기는지 미리 알린다 |
| 이수 수정에서 이수일을 비운 채 저장 | 저장을 막고 **그 입력란으로 커서를 옮긴다** |
| 되돌릴 이수 건이 없는 상태에서 회수 시도 | 아무 일도 하지 않고 그 사실을 알린다 |
| 이수 회수 실행 | 회수되는 **이수기록 건수**와 함께 삭제되는 **빈 교육 건수**를 결과에 밝힌다 |
| 결재가 올라간 사람의 이수 수정·회수 | 잠그고 "반려 후 다시 시도하세요"로 다음 행동을 알린다 |
| 채용시교육 추가에서 미이수 대상자가 0명 | 등록할 대상이 없다는 사실을 알린다 |
| 회차 입력이 잘못됨 | 정기교육과 같은 규칙으로 그 회차 탭에서 막는다 |
| 조회 결과가 0건 | 조건을 풀 수 있음을 함께 안내한다 |

## 4. 화면 구성별 정리

### 4-1. 대상자 탭과 필터
- 탭은 전체, 미이수, 이수로 구성한다.
- 이름·부서 검색어와 **부서 · 고용형태 · 채용연도** 세 조건으로 조회한다. 이수 탭에서는 이수구분 조건이 하나 더 붙는다.
- **부서별 / 채용일별 / 안 묶기** 세 가지로 목록 묶음 기준을 전환한다. 묶으면 그룹 머리 행에 그 묶음의 인원이 함께 나온다.
- 이수 탭에서는 정상 이수와 지연 이수를 구분한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 전체·미이수·이수 중 해당 대상자만 남긴다 | 구 “교육 건” 탭은 두지 않는다 |
| 검색어 입력 | 이름·부서를 함께 찾아 즉시 좁힌다 | — |
| 고용형태·채용연도 선택 | 선택 즉시 목록과 건수를 갱신한다 | — |
| 묶어보기 전환 | 부서별·채용일별·안 묶기로 목록 묶음을 바꾼다 | 대상자 구성은 바뀌지 않는다 |

- 상태: 탭은 **전체 / 미이수 / 이수** 셋이다(구 '교육 건' 탭은 폐지했으므로 되살리지 않는다). 이수 탭 안에서 **정상 이수**와 **지연 이수**가 갈리며, 지연은 채용일 기준 법정 시점을 넘긴 건이다. 그룹 축은 **부서별 / 채용일별 / 안 묶기** 셋이고 조건과 독립적으로 걸린다. 조건 결과가 0건이면 목록 자리에 빈 상태를 낸다.

### 4-2. 대상자 목록
- 이름, 부서, 고용형태, 채용일, 필요시간, 이수일과 상태를 표시한다.
- 미이수자는 선택할 수 있고 이수자는 이수 수정을 제공한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 대상자 선택 | 이수 처리 대상에 넣는다 | 미이수자에게만 선택칸이 있다 |
| 묶음 전체 선택 | 그 묶음의 미이수자를 한 번에 고른다 | — |
| [이수 수정] | 이미 이수한 건의 수정 입력을 연다 | 이수자 행에만 나타난다 |

- 상태: 한 사람의 단계상태는 **미이수 → 이수**이며, 이수는 다시 **정상 / 지연**으로 나뉜다. 미이수자에게만 선택 수단이 나타나고 이수자에게는 수정 수단이 나타난다 — 같은 자리에 두면 이미 처리한 사람을 다시 처리하게 된다. 필요시간은 고용형태에 따라 달라지므로 사람마다 다른 값이 정상이다.

### 4-3. 선택 이수 처리
- 선택한 인원 수와 이름을 먼저 보여준 뒤 두 가지를 묻는다 — **이수일 처리 방식**(각자 채용일 / 일괄 이수일)과 **교육 건 생성 방식**(근로자별 개별 건 / 한 건으로 묶기).
- 두 축은 서로를 강제한다 — 묶기를 켜면 일괄 이수일로 전환되고, 각자 채용일로 되돌리면 묶기가 풀린다.
- 묶기를 고르면 **필요시간이 다른 인원은 건이 나뉘며**, 예상 생성 건수와 시간대별 인원을 미리 보여준다.
- 대상자별 필요시간을 인정시간으로 저장한다. 강사·주관과 내용을 함께 받는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [선택 이수 처리] | 고른 대상자의 이수 처리 입력을 연다 | 한 명도 고르지 않으면 “미이수자를 1명 이상 선택하세요” |
| 처리일 방식 전환 | 각자 채용일 처리와 공통 처리일 지정을 오간다 | 기본값은 각자 채용일 처리 |
| 묶음 방식 전환 | 개인별 교육 건과 한 건으로 묶기를 오간다 | 필요시간이 같은 대상자끼리만 묶인다 |
| [처리] | 대상자별 필요시간을 인정시간으로 저장한다 | 목록이 이수 상태로 갱신된다 |

- 상태: 처리일 축은 **각자 채용일로 처리**(기본)와 **공통 처리일**이다. 묶임 축은 **필요시간이 같으면 한 교육 건으로 묶음**, 다르면 **개인별 교육 건**이며 이는 선택이 아니라 자동 판정이다 — 필요시간이 다른 사람을 한 건으로 묶으면 인정시간이 어긋난다. 한 명도 고르지 않으면 처리할 수 없다.

### 4-4. 채용시교육 추가
- 회차별 일자·시작·종료, 강사, 장소, 내용과 미이수 대상자를 입력한다.
- 저장 시 선택 대상자별 완료 교육을 만들고 필요시간을 인정시간으로 기록한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [채용시교육 추가] | 회차·강사·장소·내용과 대상자를 받는 입력을 연다 | 미이수 대상자만 고를 수 있다 |
| [저장] | 대상자별 완료 교육을 만들고 필요시간을 인정시간으로 기록한다 | 목록이 즉시 갱신된다 |

- 상태: 등록 단계는 **작성 중 → 저장됨**이고, 저장하면 대상자별 **완료** 교육이 만들어진다. 미이수 대상자가 한 명도 없으면 이 수단 자체가 의미를 잃으므로 그 사실을 알린다. 회차 구조와 시간 파생 규칙은 집합교육과 같다.

### 4-5. 이수 수정
- 이수일, 강사와 내용을 수정한다.
- 이수 취소 시 개인 기록을 삭제하고 연결 교육에 대상자가 남지 않으면 교육 건도 함께 삭제한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 이수일 수정 후 저장 | 그 사람의 이수일을 바꾼다 | 이수일이 비면 “이수일을 입력하세요” |
| 결재가 올라간 건을 수정 시도 | 막고 사유를 알린다 | “결재 (상태)라 수정할 수 없습니다 — 반려 후 다시 시도하세요” |
| 수정 입력에서 [이수 취소] | 회수 규모를 밝힌 확인 단계를 연다 | 함께 묶인 다른 대상자가 있으면 그 건은 유지된다고 밝힌다 |
| 확인 단계에서 실행 | 본인 이수기록만 회수하고 미이수로 되돌린다 | “이수기록 N건 회수 · 미이수로 되돌렸습니다” |

- 상태: **이수 상태**에서만 나타난다. 전면 라벨은 '취소'가 아니라 **수정**이며, 회수(이수 취소)는 이 안에 들어 있다. 이수를 취소하면 그 사람의 기록이 지워지고, 연결된 교육에 남은 대상자가 없으면 **교육 건까지 함께 회수**된다 — 대상자 0명인 교육이 목록에 남지 않게 한다. 결재가 올라간 건은 수정·취소가 모두 잠긴다.

## 6. 정책

- **공문 기안·상신은 정기교육(SCR-EDU-001 §4-6)과 같은 규칙을 따른다** — 진입점은 [공문 기안] 하나, 단위는 **교육 1건**, 상신은 미리보기에만 있다. 채용시교육도 이수 처리된 교육 건 단위로 기안하며 기간을 묶지 않는다 — 기간 단위 제출은 업무 축이 담당한다.

- 필요시간은 일용근로자와 계약기간 1주 이하 기간제근로자 1시간, 1주 초과 1개월 이하 기간제근로자 4시간, 그 밖의 근로자 8시간이다.
- 가장 최근 채용시교육 이수일이 채용일보다 늦지 않으면 정상 이수, 늦으면 지연 이수로 표시한다.
- 선택 이수 처리의 기본값은 대상자 각자의 채용일이며 실제 교육일을 별도로 요구하지 않는다.
- 교육 추가의 회차 합계시간과 무관하게 대상자별 법정 필요시간을 인정시간으로 기록한다.
- 이수 수정에서 기존 기록을 직접 변경하거나 취소할 수 있다.
- 신규 결재 상신 기능은 표시하지 않는다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록하며 업무 투입일·실제 참석시간·증빙 기반 판정은 현 화면 기능에 포함하지 않는다.
