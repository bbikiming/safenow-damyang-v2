# 화면 정의서 — 업무 발행 관리

> 화면 ID: SCR-WRK-001 · 화면 유형: 목록·설정 · 기획 관점(v7) · 구현 정합 2026-08-12
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.
>
> **메뉴 제외 화면 (2026-08-28)** — 이 화면은 대메뉴·좌측 메뉴에 나오지 않는다. 다른 화면의 링크로만 열리며 **대체 화면은 업무 관리 > 이행 관리 (SCR-CMP-001)**다. 사유: 대메뉴 이름이 "(구)업무관리"로 신버전과 겹쳐 있었다. 대체 관계가 확정되어 메뉴에서 뺐다.
> 정의서를 남기는 이유는 화면이 살아 있고 링크로 도착하는 사용자가 있기 때문이다 — 아래 §3~§7은 그 사용자가 만나는 동작의 정의로 계속 유효하다. 메뉴 구조 규칙은 SCR-COM-002 §6·SCR-COM-003 §6이 정한다.

반복·사건형 안전보건 업무를 회차와 대상 부서 단위로 발행하고 배정·제출·확인·반려·회수 현황을 관리한다. 카탈로그 26종 중 일정과 대상 규칙이 안정된 8종만 자동 발행하고, 16종은 캘린더에서 담당자가 확인해 발행하며, 2종은 원본 사건·공문 발생으로만 생성한다.

## 2. 권한 정보

- 메뉴 접근·발행·대상 조정·독촉·종결은 시스템 관리의 메뉴·권한 관리에서 설정한다.
- 재난안전과 또는 권한 관리에서 지정한 주관부서 담당자가 발행한다.
- 재난안전과는 대상 부서까지만 정하며 타 부서 개인 담당자를 지정하지 않는다.

### 분기 로직

- **자동발행** — 카탈로그의 `정기 자동발행` 8종만 발행일 도래 시 생성한다. 같은 업무·회차 키가 있으면 다시 만들지 않는다.
- **담당자 확인 후 발행** — 16종은 캘린더에서 발행할 때 대상·기한·사유를 필수 입력한다. 화면 진입만으로 생성하지 않는다.
- **원본문서 발생형** — 2종은 관련 공문·사건이 생성될 때 원본 식별값을 연결해 발행한다. 일반 캘린더에서 수동 생성하지 않는다.
- **기한 우선순위** — 공문·원본 기한이 있으면 그것을 사용하고, 없으면 카탈로그의 회차 기준 기한을 사용한다.
- **완료 파생** — 이행점검·교육 등 원본 화면의 완료 상태를 읽고 이 화면에서 완료를 직접 체크하지 않는다.

## 4. 화면 구성별 정리

### 4-1. 발행 건

- 조회: 업무명·연도·상태·미회수 있는 건만.
- 표: 업무·회차·발행 방식·대상 부서·기한·미배정·회수율·상태·상세.
- 행 선택 시 대상 부서를 조정한다. 이미 제출·완료된 부서 제거는 막고 사유 있는 회수 절차를 사용한다.

### 4-2. 연간 캘린더

- 월별로 발행 예정일과 업무를 표시한다.
- 자동발행은 정보만 제공하고, 담당자 확인 업무는 선택 시 발행 확인 모달을 연다.
- 이미 발행된 회차는 발행 상세로 이동한다.

### 4-3. 부서 이행

- 진행 중 발행 건을 업무×부서 매트릭스로 표시한다.
- 부서별 대상·완료·미배정 수와 업무별 완료·미배정·제출·미제출을 보여 준다.
- 완료는 원본 화면에서 파생하고 이 표에서 수정하지 않는다.

### 4-4. 발행 규칙

- 업무 ID·업무명·발행 방식·주기·시점·대상 범위·기한 근거를 조회한다.
- 표본이 적거나 시점 편차가 큰 규칙은 근거와 표본 수를 표시하되 자동발행으로 승격하지 않는다.

### 4-5. 발행 상세·대상 부서

- 부서별 담당자·배정일·상태·제출일·확인/반려·독촉 이력을 표시한다.
- 제출 확인은 완료로 확정하고, 반려는 사유를 필수로 받아 같은 담당자에게 되돌린다.
- 회수·종결은 사유와 수행자·시각을 이력에 보존한다.

## 6. 정책

- **안정된 8종만 자동 발행한다** — 반복 시점과 대상이 검증되지 않은 업무를 자동화하지 않는다.
- **중복키는 업무·회차다** — 사용자가 다시 선택하거나 배치가 재실행돼도 발행 건을 둘 만들지 않는다.
- **기한은 공문·원본 우선, 없으면 업무 규칙이다** — 임시 표본 기한을 확정 운영값으로 위장하지 않는다.
- **재난안전과는 개인 담당자를 정하지 않는다** — 부서까지만 발행하고 개인 배정은 부서 업무함이 맡는다.
- **회수·종결·대상 변경은 이력을 지우지 않는다** — 누가 언제 왜 바꿨는지 보존한다.
- **자동발행 소급은 30일까지만 확인하고 실제 생성은 도래 규칙을 따른다** — 오래된 회차를 한꺼번에 만들어 현재 할일을 오염시키지 않는다.

## 7. 미결사항

없음. 자동·담당자 확인·원본문서 발생 범위, 기한 우선순위, 중복 방지, 대상 부서, 회수·종결·독촉·확인·반려를 모두 §3~§6에서 확정했다. 전체 조직 명단(행정포털)과 외부 알림 채널(SMS·Push)은 **연계 구현 범위**이며([미결사항 목록 §4](99_미결사항목록.md)), 연계 전에는 일부 명단·내부 알림으로 개발한다.
