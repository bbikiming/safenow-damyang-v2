법적의무 재분류 V2의 유효 문서와 유해·위험요인 의견 접수·추진결과 등록률을 연도·반기 조건으로 집계한다. 문서 통계는 원본 429행 중 완전 동일 3쌍을 합친 **426건**을 정본 모집단으로 사용하고, 의견 통계는 의견청취의 접수·추진결과 등록 자료를 별도 모집단으로 사용한다. 서로 다른 모집단을 합산하지 않으며 각 카드에 집계 기준을 표시한다.

## 2. 권한 정보

- 메뉴 접근·보기는 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면은 조회 전용이며 수치·상태를 직접 수정하지 않는다.
- 데이터 범위는 권한 관리의 기본 데이터 범위를 먼저 적용한 뒤 화면 조회 조건을 적용한다.

### 분기 로직

- **조회 순서** — 권한 데이터 범위 → 연도(`updated`의 연도) → 기간(1~6월/7~12월) → 대메뉴 순으로 AND 적용한다.
- **근거 구분은 배타 그룹** — `legalBasis`에 중처 문자열만 있으면 중처법, 산안 문자열만 있으면 산안법, 둘 다 있으면 복합근거, 둘 다 없으면 기타근거다.
- **이행률** — 전체 중 완료 문서의 백분율을 가장 가까운 정수로 반올림한다. 대상 0건은 0%가 아니라 `대상 없음`이다.
- **상태 축** — 완료·진행·미시행 외 값이 들어오면 집계 오류로 기록하며 임의 상태로 바꾸지 않는다.
- **의견 추진결과 등록률** — 선택 기간의 의견 접수 건수를 분모, 그중 추진결과가 등록된 건수를 분자로 계산해 가장 가까운 정수로 반올림한다. 접수 0건은 `자료 없음`이며 0%로 성과 판정하지 않는다. 추진결과 등록은 조치 완료와 같은 뜻이 아니므로 `조치완료율`로 부르지 않는다.

## 4. 화면 구성별 정리

### 4-1. 조회 조건

| 항목 | 값 | 초기값 | 동작 |
|---|---|---|---|
| 연도 | 전체·2026·2025 | 2026 | 최종 수정 연도 필터 |
| 기간 | 전체·상반기·하반기 | 전체 | 최종 수정 월 필터 |
| 대메뉴 | 전체·V2 9대메뉴 | 전체 | 대메뉴 필터 |

조건을 바꾸면 별도 조회 버튼 없이 즉시 재집계한다.

### 4-2. 요약 지표

- 조회 문서 전체 · 중처법 · 산안법 · 복합근거 · 기타근거.
- 불변식: `전체 = 중처법 + 산안법 + 복합근거 + 기타근거`.

### 4-3. 분포

- 대메뉴별 문서 분포: V2 9대메뉴를 모두 표시한다.
- 처리유형: 프로그램·전자문서·첨부파일.
- PDCA: P·D·C·A.
- 각 축은 배타적이며 각 축의 합이 조회 전체와 같아야 한다.

### 4-4. 대메뉴별 이행 현황표

- 열: 대메뉴 · 전체 · 완료 · 진행 · 미시행 · 이행률.
- 불변식: `행 전체 = 완료 + 진행 + 미시행`.
- 대메뉴명은 문서 목록(SCR-CMP-002)의 같은 분야 조건으로 이동한다 — 옛 목록 화면(메뉴 제외)으로 보내던 링크는 2026-08-31에 옮겼고 건수가 같은 것을 확인했다.

### 4-5. 의견 접수·추진결과 등록률(SFR-019)

- 구성: 전체 접수·추진결과 등록·추진결과 등록률 요약, 분류(위험신고/안전제안/아차사고/청취조사)별 접수·추진결과 등록·등록률 표, 의견청취 이동.
- 연도·반기 조건은 문서 통계와 같이 적용한다. 대메뉴 조건은 문서 전용이므로 의견 통계에는 적용하지 않는다.
- 추진결과 등록률은 접수 건수 중 추진결과가 등록된 건수가 차지하는 비율을 백분율로 반올림한다. 추진 중·반려 등 결과가 등록되지 않은 건은 분자에서 제외하며, 접수 건수가 0이면 `자료 없음`으로 표시한다.
- 프로토타입 숫자는 시연용 접수 자료이며 본개발에서는 SCR-OPN-001의 접수·처리 상태에서 실시간 집계한다.

### 4-6. 엑셀 다운로드

- 범위: 권한 범위와 현재 연도·기간·대메뉴 조건을 모두 적용한 결과.
- 열: 화면 현황표 열 + 문서 ID·문서명·세트·PDCA·처리유형·법적근거·담당부서·담당자·상태·최종 수정일.
- 파일명: `현황통계_{연도또는전체}_{기간}_{대메뉴}_{다운로드일시}.xlsx`.
- 화면에 표시된 조회 건수와 파일 행 수가 같아야 한다.

## 6. 정책

- **V2 유효 문서 426건을 통계 정본으로 쓴다** — 원본 429행은 감사 추적용이며 완전 동일 3쌍을 이중 집계하지 않는다.
- **모든 시각화는 같은 필터 결과를 쓴다** — 카드마다 별도 표본이나 고정값을 두지 않는다.
- **축 내부 합계를 보장한다** — 중첩 가능한 ‘법률 포함 건수’ 대신 배타 근거 그룹을 사용한다.
- **수치를 화면에서 고치지 않는다** — 정정은 원본 업무문서에서 하고 통계는 재계산한다.
- **0과 대상 없음을 구분한다** — 대상 문서가 있는데 완료가 0이면 0%, 문서 자체가 없으면 대상 없음이다.
- **다운로드는 화면 조건과 동일하다** — 화면과 파일이 다른 모집단을 쓰지 않는다.
- **의견 통계는 문서 통계와 별도 모집단이다** — 같은 연도·반기 조건을 공유하되 문서 건수와 의견 건수를 더하지 않는다. 접수 0건은 `자료 없음`으로 표시하고 등록률 0%로 단정하지 않는다.
