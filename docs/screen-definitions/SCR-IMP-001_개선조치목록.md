## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 대시보드 | 개선조치 미완료·지연 카드 선택 — 조회 목적 |
| 진입 | 의견청취 | 개선조치중 상태의 연결 조치 확인 |
| 진입 | 시설물 위험도 | 시설물에 걸린 조치 확인 |
| 이탈 | 개선조치 상세 | 목록 행 선택 |
| 연계 | 시설물 대장 | 시설물이 지정된 조치 확인 |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 출처와 상태를 선택한다 | 조회 범위 안의 개선조치 목록 갱신 |
| 2 | 미지정 조치의 담당자를 선택한다 | 담당자 저장 및 예정에서 진행중 전환 |
| 3 | 수동 개선조치의 관리대상·내용·기한을 등록한다 | 수동 출처의 예정 조치 생성 |
| 4 | 목록 행을 선택한다 | 개선조치 상세 화면으로 이동해 내용을 조회한다 |

**분기 로직**

- **조회 범위와 조작 권한이 다른 축이다** — 총괄 책임자와 주관부서는 전 부서를 보고 그 밖은 자기 부서만 본다. 반면 등록·배정은 주관부서 **담당자**만 하며, 조회만 되는 사용자에게는 그 사유와 자기 몫을 처리할 곳(이 목록의 자기 부서 건)을 함께 안내한다.
- **담당자 유무가 그 행의 다음 행동을 정한다** — 담당자가 없으면 지정 수단이 나오고, 지정하면 예정에서 진행중으로 넘어간다. 담당자가 이미 있으면 이름만 표시한다.
- **기한 상태가 세 갈래로 갈린다** — 초과·임박·그 밖으로 나뉘어 색이 달라지며, 완료된 건은 기한 강조를 하지 않는다. 끝난 일을 붉게 칠하면 남은 일이 묻힌다.
- **출처에 따라 만들어진 경로가 다르다** — 위험성평가(정기·수시)·안전점검·의견청취·경영방침 점검·사고·수동 중 무엇에서 왔는지 배지로 구분한다. 수동 등록만 이 화면에서 직접 만든다.
- **시설물 축은 앞 단계에서 정해진 세 상태를 그대로 물려받는다** — 지정 / 해당 없음(확인 결과 붙지 않음) / 미지정(아직 판단 안 함). **미지정만 줄을 만들지 않고**, ‘해당 없음’은 그 말 그대로 표시한다. 확인이 끝난 사실을 감추면 담당자가 앞 단계로 되돌아가 같은 확인을 다시 하기 때문이다. 이 판정은 목록·상세·공용 카드·담당자 화면이 같은 한 곳을 쓴다.

**엣지케이스**

- **조회 범위 밖 건은 목록에서 지우는 것으로 끝내지 않는다** — 상세로 가는 경로에도 같은 판정을 두어 주소로 열리지 않게 한다.
- **기한이 없는 건은 빈칸으로 두지 않고 "미지정"으로 표시한다** — 수시평가는 조치기한이 선택이라 실제로 생기며, 이 건들은 기한 초과 집계에서 빠진다.
- **조회 결과가 0건이면** 표 자리에 빈 상태 안내를 둔다.
- **담당자 지정 후보는 직책자로 한정된다** — 아무나 고를 수 있으면 지휘 계통이 무너진다.
- **수동 등록에는 시설물·담당자·조치 전 사진 입력이 없다** — 이 화면에서 만드는 건은 출처가 "수동"으로 고정되며, 나머지는 상세 화면에서 채운다.
- **완료된 건의 담당자 미지정은 강조하지 않는다** — 이미 처리가 끝났으면 손댈 것이 없는데 경고색으로 띄우면 헛걸음하게 된다.

## 4. 화면 구성별 정리

### 4-1. 필터와 범위 안내
- 출처 전체 또는 개별 출처와 상태 전체·예정·진행중·완료로 조회한다.
- 현재 역할에서 조회만 가능한 경우 조회 전용 사유와 소관 범위를 안내한다.
- 배정받은 부서 담당자는 이 목록에서 자기 몫을 **조회**한다. **완료 처리는 이 화면에서 하지 않는다** — 내 할일 또는 위험성평가 화면의 조치 상세 카드가 그 창구다(SCR-IMP-002).

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 출처 선택 | 그 출처의 개선조치만 남긴다 | — |
| 상태 선택 | 예정·진행중·완료 중 해당 건만 남긴다 | — |
| 조회 전용 상태로 진입 | 조작 수단을 내지 않고 사유와 소관 범위를 안내한다 | — |

- 상태: 조회 권한 축은 **조작 가능**(주관부서 담당자)과 **조회 전용**(그 밖) 둘이고, 조회 전용일 때 이 영역은 사유와 소관 범위를 함께 낸다. 조건 축은 **조건 없음**(전건)과 **조건 적용 중**이며, 조건이 걸린 상태에서 결과가 0건이면 빈 상태(4-5)로 넘어간다. 조회 범위 밖 부서의 건은 조건과 무관하게 처음부터 목록에 오르지 않는다.

### 4-2. 목록
- 출처, 부서·관리대상, 제목·유해위험요인, 담당자, 기한과 상태를 표시한다.
- 유해위험요인의 분류와 법령 근거가 있으면 함께 표시한다.
- 시설물이 지정된 조치는 시설물명(없으면 시설물번호)을, ‘해당 없음’으로 확인된 조치는 “해당 없음”을 유해위험요인 아래에 낸다. 미지정만 줄을 만들지 않는다.
- 완료되지 않은 건은 기한 임박과 초과를 시각적으로 구분한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 행 선택 | 그 건의 상세·조치 화면으로 이동한다 | 개선조치 상세(SCR-IMP-002) |
| 시설물 줄 | 지정이면 시설물명, 확인 결과 붙지 않으면 “해당 없음”을 낸다 | 미지정만 줄을 만들지 않는다 |
| 기한 임박·초과 | 완료되지 않은 건만 강조 표기한다 | — |
| 기한이 없는 건 | 기한 칸을 비우지 않고 “미지정”으로 표시한다 | 수시평가는 조치기한이 선택이라 실제로 생긴다 |

- 상태: 개선조치 1건의 단계상태는 **예정 → 진행중 → 완료**이며, 담당자를 지정하면 예정에서 진행중으로 넘어간다. 기한 축은 **여유 / 임박 / 초과 / 미지정** 네 가지이고 완료된 건에는 강조를 붙이지 않는다 — 이미 끝난 일에 붉은 표시가 남으면 할 일과 구분되지 않는다. 행 단위로 **시설물 미지정**과 **담당자 미지정**이 정상 상태로 존재한다. 목록이 비는 경우는 4-5에서 다룬다.

### 4-3. 담당자 지정
- 담당자가 없는 건은 조직 구성원 중 담당자를 선택한다.
- 지정하면 예정 상태를 진행중으로 바꾼다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 담당자 [지정] | 조직 구성원 중에서 한 명을 고른다 | 담당자가 없는 건에만 나타난다 |
| 담당자 선택 완료 | 담당자를 저장하고 상태를 진행중으로 바꾼다 | 목록이 즉시 갱신된다 |

- 상태: **미지정**일 때만 지정 수단이 나타나고, 지정되면 담당자 이름 표시로 바뀐다. 조회 전용 접속자에게는 미지정이어도 수단이 나타나지 않고 미지정 사실만 보인다. 지정은 상태를 진행중으로 바꾸지만 되돌리는 수단은 두지 않는다 — 담당자를 바꾸는 것은 재지정이지 해제가 아니다.

### 4-4. 수동 등록
- 관리대상, 제목·내용과 기한을 입력해 수동 출처 개선조치를 등록한다.
- 수동 등록 화면에는 시설물, 담당자와 조치 전 사진 입력이 없다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [개선조치 등록] | 수동 등록 입력을 연다 | — |
| 저장 | 출처가 수동으로 고정된 개선조치를 만든다 | 목록에 즉시 반영된다 |

- 상태: 등록 수단은 **조작 권한이 있을 때만** 나타난다. 입력 단계는 **작성 중 → 저장됨** 둘이고 임시 보관을 두지 않는다. 저장된 건은 출처가 수동으로 고정되며, 시설물·담당자·조치 전 사진이 비어 있는 상태로 시작한다 — 이는 결측이 아니라 이 경로의 정상 시작점이다.

### 4-5. 빈 상태
- 필터 결과가 없으면 “조건에 맞는 개선조치가 없습니다”를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 조회 결과 0건 | 표 자리에 빈 상태 안내를 표시한다 | “조건에 맞는 개선조치가 없습니다” |

- 상태: 빈 상태는 **조건에 맞는 건이 없음** 하나다. 조회 범위 자체가 비어 있는 경우(대상 부서가 아닌 접속자)와 조건이 좁아 0건인 경우를 같은 문구로 내지 않도록, 조건이 걸려 있으면 조건을 풀 수 있음을 함께 안내한다. 로딩·오류 상태는 프로토타입에 없으며 실서비스에서는 이 시스템 공통 규칙을 따른다.

## 6. 정책

- 목록 상태는 예정, 진행중, 완료의 3값을 사용한다.
- 정기·수시 위험성평가에서 생성된 조치는 원본 평가와 연결한다.
- 시설물 연결은 선택 사항이며 위험성평가(정기 검수 행·수시 등록 행)에서 정해진 세 상태를 그대로 승계한다. 이 화면에서 시설물을 새로 정하지 않는다.
- 이 목록에는 확인대기·반려·확인완료를 별도 상태값으로 표시하지 않는다.
- 담당 부서의 완료 이후 재난안전과 확인 상태는 위험성평가의 부서별 조치 카드에서 별도로 관리한다.
- **조치 실시(완료 처리)의 경로로 이 화면을 쓰지 않는다** — 위험성평가 화면 안의 조치 상세 카드와 내 할일이 그 창구다. 이 화면은 전 출처 조회용으로만 남는다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록한다.
