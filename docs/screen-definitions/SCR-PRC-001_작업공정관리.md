# SCR-PRC-001 작업공정 관리 — 폐지(파일 보존)

> v6 · 기획 관점 · 위험성평가 모듈(작업공정)
> **[폐지 안내]** 재설계(정기·수시·개선조치)로 이 화면은 현행 메뉴에서 제외되었다. 정기 위험성평가는 작업공정 단위 입력 대신 **부서 단위 + 용역업체 보고서 검수** 방식으로 대체되어, 작업공정 관리 화면은 흐름에서 빠졌다. 파일은 보존하나 신규 작업의 근거로 삼지 않는다. 아래 본문은 폐지 이전 설계 기록이다.

## 1. 화면 정보

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-PRC-001 |
| 화면명 | 작업공정 관리 — 폐지(파일 보존) |
| URL 경로 | rsk-proc.html (현행 메뉴 미노출) |
| 상위 메뉴 | (폐지) 위험성평가 |
| 화면 유형 | 목록 |

- 관리대상(시설·사업장)의 **작업 공정**을 등록·관리하고, 각 공정에 **설비·유해인자·유해위험요인**을 매핑하는 화면이다. 여기서 정리된 공정과 유해위험요인이 위험성평가의 **원본**이 된다.
- 공정은 카드로 나열되며, 카드마다 하나의 [수정]으로 공정명·담당 평가자·설명과 설비·유해인자·유해위험요인을 **카드 안에서** 편집한다.
- 유해위험요인은 **공정·설비·유해인자 세 축이 각각** 표준 유해위험요인을 끌어와 **합집합**으로 자동 구성되며, 사용자가 가감하거나 직접 추가할 수 있다.
- **확정(잠금) 단계가 없다.** 저장하면 즉시 활성이며, 정기 위험성평가는 저장된 현재 공정 전체를 대상으로 읽는다. 설비·작업방법이 바뀌면 반영 시 수시 위험성평가 생성을 확인한다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.

- 이 화면은 현행 메뉴에 노출되지 않는 **폐지 화면**(파일 보존)이다. 공정·유해위험요인 관리 흐름은 §3~§6에 기록으로 남긴다.

**사용자 시나리오**

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 관리대상을 고른다 | 그 대상의 공정 카드 목록을 보여준다 |
| 2 | [공정 추가] 또는 카드 [수정]을 누른다 | 해당 카드가 편집 상태로 펼쳐진다 |
| 3 | 설비·유해인자를 선택한다 | 선택 항목이 반영되고 유해위험요인이 자동 합산된다 |
| 4 | 유해위험요인을 가감하거나 직접 추가한다 | 목록이 갱신된다 |
| 5 | [반영]을 누른다 | 저장하고, 설비·작업방법 변경이면 수시평가 생성을 확인한다 |

**분기 로직**

> **이 화면은 폐지됐다** — 현행 메뉴에 노출되지 않으며 파일만 보존한다. 아래 분기는 폐지 시점의 동작 기록이다.

- **관리대상을 고르기 전에는 공정 목록이 나오지 않는다** — 대상이 정해져야 그 대상의 공정이라는 개념이 성립하기 때문이다.
- **카드가 조회 상태와 편집 상태 두 모습을 오간다** — [공정 추가]나 카드의 [수정]을 누르면 그 카드만 편집으로 펼쳐지고, 나머지 카드는 조회 상태로 남는다. 한 번에 한 카드만 편집한다.
- **유해위험요인은 두 경로로 들어온다** — 설비·유해인자를 고르면 그에 딸린 요인이 자동으로 합산되고, 목록에 없는 것은 직접 추가한다. 자동 합산분도 가감할 수 있다.
- **반영 후 수시평가 생성 여부가 갈린다** — 설비나 작업방법이 바뀐 경우에는 수시 위험성평가를 만들 것인지 확인하고, 단순 정리면 저장으로 끝난다.

**엣지케이스**

- **공정이 하나도 없으면** 목록 자리에 공정을 먼저 추가하라는 안내가 나온다. 위험성평가는 공정이 있어야 시작할 수 있어 이 화면이 선행 단계였다.
- **설비·유해인자·유해위험요인이 비어 있는 공정 카드**는 "없음 — [수정]으로 추가"로 표시해 빈 카드를 방치하지 않게 했다.
- **선택 항목이 많으면 칩을 줄이고 나머지 개수만 표시**해 카드 높이가 무너지지 않게 했다.
- **선택 패널에서 검색 결과가 없으면** "일치 항목 없음"을 표시한다.
- **폐지 이후 이 주소로 직접 들어오면** 화면은 그려지지만 메뉴에서는 도달할 수 없다. 현행 흐름은 정기 위험성평가(SCR-RISK-001)의 보고서 검수로 대체됐다.

## 6. 정책

- **확정 개념 폐기:** 별도 확정·개정 단계를 두지 않는다. 저장 즉시 활성이며, 정기 위험성평가는 저장된 현재 공정 전체를 대상으로 읽는다.
- **자동매핑 원칙:** 유해위험요인은 공정·설비·유해인자 세 축이 **각각 독립적으로** 표준 유해위험요인을 끌어온 합집합이다. 설비에서 유해인자를 자동으로 파생시키지 않으며, 설비·유해인자는 각각 선택한다.
- **수시평가 트리거(법정 사유 한정):** 설비 추가·변경·제거, 작업방법·절차 변경, 점검에서 발견된 유해위험요인 추가만 수시 위험성평가 사유로 본다. 유해위험요인 목록을 정리(가감)하는 것 자체는 사유가 아니다. (근거: 산업안전보건법 제36조, 사업장 위험성평가에 관한 지침 제15조)
- **법령근거는 법령 매핑을 그대로 쓴다(TBD-002 확정)** — 이 화면이 근거 문자열을 자체 보관하지 않는다. 유해위험요인에는 **조문 키만** 붙이고 표기·원문·개정 감지는 법령 근거 연계(SCR-COM-008)가 맡는다. 근거가 아직 정해지지 않은 항목은 "법령 매핑 대기"로 두며, **그럴듯한 조문을 임시로 붙이지 않는다** — 임시 근거는 검증을 거치지 않았는데도 검증된 근거와 똑같이 보인다. 연계 시점은 별도 단계가 아니라 항목을 만들 때이며, 근거를 고르는 자리에서 조문 목록을 그대로 제공한다.
- **표준 마스터는 이 시스템이 만들지 않는다(TBD-001 확정)** — 표준 공정·설비·유해인자·유해위험요인 목록은 안전보건공단 등이 배포하는 자료이고, 담양군이 자체 목록을 만들어 유지하면 배포본이 갱신될 때마다 두 목록이 갈린다. **배포 자료를 그대로 싣고 갱신은 자료를 다시 실어 반영**한다 — 법령 조문을 다루는 방식과 같다. 담양군이 더할 것이 있으면 **표준 항목을 고치지 않고 자체 항목으로 따로 추가**하며, 목록에서 표준과 자체를 구분해 보여준다. 갱신 주체는 시스템 관리자이고, 담당 부서가 항목을 임의로 고치지 않는다.
- **담당 평가자는 조직도에서 고른다(TBD-003 확정)** — 이름을 직접 입력하면 같은 사람이 여러 표기로 쌓여 부서별 집계가 어긋난다. 공용 조직도 선택기를 쓰며, 이는 다른 화면의 담당자 지정과 같은 방식이다. 다만 **공정의 담당 평가자는 부서 배정을 대체하지 않는다** — 정기 위험성평가는 부서 단위로 나가고(SCR-RISK-001), 여기서 지정하는 사람은 그 공정을 아는 실무자를 가리키는 표시다. 지정하지 않아도 평가는 진행되며, 비어 있으면 그 공정의 소관 부서 담당자가 기본으로 읽힌다.
- **참조되는 공정은 지우지 못한다(TBD-004 확정)** — 진행 중인 위험성평가가 참조하는 공정을 지우면 그 평가의 유해위험요인이 무엇에서 나온 것인지 설명할 수 없게 되고, 완료된 평가라면 기록 자체가 훼손된다. 그래서 **삭제는 참조 0건일 때만** 허용하고, 참조가 있으면 삭제 대신 **사용 중지**로 표시한다 — 새 평가에서는 고를 수 없지만 기존 평가의 이력은 그대로 남는다. 삭제를 막을 때는 몇 건이 참조하고 있는지와 어디서 참조하는지를 함께 밝힌다. 시설물을 지우지 않고 폐지로 두는 것과 같은 원칙이다(SCR-FAC-004 §6).

## 7. 미결사항

없음. 표준 마스터의 채택 범위와 갱신 주체·법령 매핑 연계·담당 평가자 지정 방식·삭제 통제는 모두 §6에서 확정했다.

이 화면은 재설계(2026-07-21)로 메뉴에서 빠졌고 직접 주소로만 열린다. 파일이 남아 있는 동안에는 정의서도 함께 유지한다.
