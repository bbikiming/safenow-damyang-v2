## 4. 화면 구성별 정리

### 4-1. 총괄 목록

- 총 대상, 총 편성액, 총 집행액, 집행률을 현재 필터 모집단에서 산출한다.
- 대상, 항목 수, 편성액, 집행액, 집행률, 상태와 관리수단을 표시한다.
- 집행률은 편성액이 0이면 숫자 0퍼센트로 단정하지 않고 `산정 불가`로 표시한다.

### 4-2. 점검표 생성

- 대상은 기준 설정에 등록된 기관 또는 시설에서 선택하고 예방항목은 말단 항목을 1개 이상 고른다.
- 대상 식별값·이름·유형·원천과 선택 당시 명칭을 보존한다. 마스터 개명은 새 화면 표시에는 반영하되 과거 결재문서 제목은 스냅샷을 유지한다.
- 연도·대상유형·대상 식별값 조합을 중복키로 사용한다.

### 4-3. 점검표 상세·편집

- 작성 중·반려는 편성액·집행액·비고를 수정할 수 있다.
- 결재 중은 모든 편집을 잠근다. 그래서 **회신 등록 경로가 반드시 있어야 한다** — 없으면 상신한 점검표가 결재중에 갇혀 집행액을 영영 입력할 수 없다.
- **결재선 스키마가 바뀌면 저장본을 갈아탄다** — 옛 저장본을 그대로 두면 이미 쓰던 사람만 옛 결재 이력을 보게 되어 화면이 사람마다 달라진다.
- **결재선은 기안 → 검토 → 결재 3단계이고 서로 다른 계정이어야 한다(2026-08-27 확정)** — 상신은 결재선 전체를 **한 번에** 온나라로 넘기므로(호출기안) 한 계정이 두 단계에 들어가면 결재선이 성립하지 않는다. 규칙과 판정은 공통 권한 정의 §7 이 정본이며 전 도메인이 같은 형태를 쓴다.
  - **결재선을 코드에 고정하지 않는다** — 결재권자는 지자체 위임전결규칙 소관이라 조직 개편·규칙 개정으로 바뀐다. 기본값만 조직도에서 직위명으로 파생하고 변경은 조직도 선택기로 받는다.
  - **위반은 고르는 단계에서 먼저 막는다** — 기안자와 이미 지정된 사람은 조직도에서 사유와 함께 고를 수 없게 표시하고, 상신 경로에서 다시 확인한다.
  - **결재선은 이름이 아니라 계정 식별자로 보관한다** — 온나라 결재선이 계정 식별자 배열이고, 동명이인·개명에 어긋나지 않아야 한다.

- 승인 완료는 편성액을 잠그고 집행액·비고만 수정한다.
- 숫자는 0 이상 정수의 천원 단위로 저장하고 화면 합계는 행 합산값만 사용한다.

### 4-4. 전자결재

- 작성 중·반려에서 상신한다. **상신 앞에 결재선 지정 단계를 둔다** — 결재선을 고르지 않으면 상신할 수 없다.
- 결재 중에는 상태 조회와 **결재 결과 회신 등록**을 제공한다. 예산은 **결재 결과가 후속 업무를 여는 도메인**이므로(승인완료라야 집행액·비고를 입력할 수 있다) 회신을 받는다 — 공통 권한 정의 §7-4.
  - **자체 결재가 아니다** — 온나라가 보낸 결과를 옮겨 적는 자리이며 화면에 「연계 전 수동 기록」임을 밝힌다. 연계가 붙으면 온나라 응답이 대신한다.
  - **승인 단계·처리자는 그 점검표 결재선에서 파생**한다. 고정된 이름·단계를 쓰지 않는다.
  - 회신 등록은 결재가 아니므로 **결재선과 무관하게 담당자가** 한다.
  - **반려는 사유 없이 등록되지 않는다.**
- 승인·반려는 온나라 수신 결과로만 바뀌며 화면에서 임의 승인하지 않는다.
- 반려 사유는 필수로 보존하고 재상신 시 이전 결재 이력을 유지한다.
- 결재 이력의 처리자·단계는 **그 점검표에 저장된 결재선에서 파생한다.** 고정된 이름·단계를 표시하지 않는다.

## 6. 정책

- 「중대재해 처벌 등에 관한 법률」 제4조와 같은 법 시행령 제4조제4호에 따라 재해예방 인력·시설·장비, 유해·위험요인 개선 등에 필요한 예산의 편성·용도에 맞는 집행을 확인할 수 있게 한다.
- 기관 대상은 조직도의 활성 부서, 시설 대상은 시설물 대장의 유효 시설을 단일 출처로 사용한다. 자체 명단을 별도로 만들지 않는다.
- 결재 전 편성액과 결재 후 집행액의 책임 시점을 분리한다. 승인 뒤 편성 변경이 필요하면 기존 결재문서를 고치지 않고 변경 점검표를 새 버전으로 상신한다.
- 집행액이 편성액을 넘는 입력은 사실 기록을 위해 허용하되 초과 경고와 사유를 필수로 남긴다.
- 온나라 미연계 상태에서 자동 성공으로 표시하지 않는다. 온나라 연계는 연계 구현 범위이며, 연계 전 확정 동작(미결사항 목록 §4)을 사용한다.
