## 4. 화면 구성별 정리

### 4-1. 총괄 목록

- 총 대상, 총 편성액, 총 집행액, 집행률을 현재 필터 모집단에서 산출한다.
- 대상, 항목 수, 편성액, 집행액, 집행률, 상태와 관리수단을 표시한다.
- 집행률은 편성액이 0이면 숫자 0퍼센트로 단정하지 않고 `산정 불가`로 표시한다.

### 4-2. 점검표 생성

- 대상은 기준 설정에 등록된 기관 또는 시설에서 선택하고 예방항목은 말단 항목을 1개 이상 고른다.
- 대상 식별값·이름·유형·원천과 선택 당시 명칭을 보존한다. 마스터 개명은 새 화면 표시에는 반영하되 과거 결재문서 제목은 스냅샷을 유지한다.
- 연도·대상유형·대상 식별값 조합을 중복키로 사용한다.

### 4-3. 점검표 상세·편집

- 작성 중·반려는 편성액·집행액·비고를 수정할 수 있다.
- 결재 중은 모든 편집을 잠근다.
- 승인 완료는 편성액을 잠그고 집행액·비고만 수정한다.
- 숫자는 0 이상 정수의 천원 단위로 저장하고 화면 합계는 행 합산값만 사용한다.

### 4-4. 전자결재

- 작성 중·반려에서 상신하고 결재 중에는 상태 조회만 제공한다.
- 승인·반려는 온나라 수신 결과로만 바뀌며 화면에서 임의 승인하지 않는다.
- 반려 사유는 필수로 보존하고 재상신 시 이전 결재 이력을 유지한다.

## 6. 정책

- 「중대재해 처벌 등에 관한 법률」 제4조와 같은 법 시행령 제4조제4호에 따라 재해예방 인력·시설·장비, 유해·위험요인 개선 등에 필요한 예산의 편성·용도에 맞는 집행을 확인할 수 있게 한다.
- 기관 대상은 조직도의 활성 부서, 시설 대상은 시설물 대장의 유효 시설을 단일 출처로 사용한다. 자체 명단을 별도로 만들지 않는다.
- 결재 전 편성액과 결재 후 집행액의 책임 시점을 분리한다. 승인 뒤 편성 변경이 필요하면 기존 결재문서를 고치지 않고 변경 점검표를 새 버전으로 상신한다.
- 집행액이 편성액을 넘는 입력은 사실 기록을 위해 허용하되 초과 경고와 사유를 필수로 남긴다.
- 온나라 미연계 상태에서 자동 성공으로 표시하지 않는다. 외부 준비사항 EXT-03의 대체 동작을 사용한다.
