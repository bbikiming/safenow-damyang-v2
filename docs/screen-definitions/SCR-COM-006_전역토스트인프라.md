# 화면 정의서 — 전역 토스트 인프라

> 화면 ID: SCR-COM-006 · 화면 유형: 공통 인프라 · 기획 관점(v6) · 구현 정합 2026-08-11
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.

| 상위 메뉴 | 공통/전역 |
| 화면 유형 | 공통 인프라 |

처리 결과나 막힌 이유를 **잠깐 띄웠다 사라지는 한 줄**로 알리는 공통 수단이다. 저장·삭제·차단처럼 사용자가 무언가를 한 직후에는 결과를 알려 줘야 하지만, 확인 버튼을 눌러야 사라지는 팝업으로 처리하면 흐름이 매번 끊긴다. 화면 요소는 한 줄 안내 하나뿐이며, 전 화면이 같은 자리·같은 모양으로 쓴다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 이 수단은 권한을 판단하지 않는다 — 권한 차단 사실을 **알리는 쪽**이며, 판단은 각 업무 화면이 한다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 모든 화면 | 저장·삭제·차단·안내가 필요한 처리 직후 |
| 이탈 | — | 잠시 뒤 스스로 사라진다 |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 무언가를 저장하거나 실행한다 | 결과를 한 줄로 알린다 |
| 2 | 계속 작업한다 | 조작을 막지 않는다 |
| 3 | 잠시 지난다 | 스스로 사라진다 |

### 분기 로직

- **분기가 거의 없다** — 이 수단은 성공·실패에 따라 모양을 바꾸지 않는다. 색으로만 뜻을 전하면 색을 구분하기 어려운 사람에게 아무것도 전달되지 않으므로, **문구 자체가 무슨 일이 있었는지 말하게** 한다.
- **연달아 나오면 마지막 것만 남는다** — 여러 줄을 쌓지 않는다. 쌓으면 화면을 가리고, 지금 중요한 것이 무엇인지 알 수 없게 된다.
- **되돌릴 수 없는 동작에는 쓰지 않는다** — 삭제·확정처럼 확인이 필요한 동작은 팝업(SCR-COM-005)으로 먼저 묻고, 이 수단은 **결과를 알리는 데만** 쓴다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 짧은 시간에 여러 번 호출 | 마지막 내용으로 바꾸고 표시 시간을 다시 잰다 — 겹쳐 쌓지 않는다 |
| 화면을 옮김 | 따라가지 않고 사라진다 — 다음 화면의 맥락에서는 뜻이 없다 |
| 긴 문장 | 화면 폭 안에서 줄바꿈해 보여 준다. 다만 이 수단은 **한두 줄 분량**이며, 설명이 길면 팝업이나 화면 안내로 옮긴다 |
| 사용자가 놓침 | 다시 볼 수 없다 — 그래서 **놓치면 안 되는 정보를 이 수단에만 담지 않는다**(§6) |
| 프로토타입 안내 | 아직 동작하지 않는 기능임을 이 수단으로 밝힌다 — 없는 동작을 약속하지 않기 위해서다 |

## 4. 화면 구성별 정리

### 4-1. 한 줄 안내

- 구성: 화면 위에 잠시 떠 있는 한 줄. 확인 버튼이 없다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면이 안내를 요청 | 한 줄을 띄운다 | 조작을 막지 않는다 |
| 표시 시간 경과 | 스스로 사라진다 | 사용자가 닫지 않아도 된다 |
| 표시 중 다시 요청 | 내용을 바꾸고 시간을 다시 잰다 | 쌓지 않는다 |

- 상태: **표시 / 사라짐** 둘뿐이다. 빈 상태·오류 상태를 갖지 않는다 — 부를 때만 존재하기 때문이다.

## 6. 정책

- **놓쳐도 되는 정보만 담는다** — 스스로 사라지고 다시 볼 수 없으므로, 반드시 확인해야 하는 내용은 팝업(SCR-COM-005)이나 화면 안내로 낸다. 예를 들어 회수되는 건수·되돌릴 수 없다는 경고는 팝업이 맡고, 이 수단은 그 결과를 알린다.
- **색으로만 뜻을 전하지 않는다** — 문구가 무슨 일이 있었는지 말한다.
- **쌓지 않는다** — 마지막 것만 남긴다.
- **조작을 막지 않는다** — 확인을 눌러야 사라지면 흐름이 끊긴다.
- **화면마다 따로 만들지 않는다** — 한 수단만 쓴다. 화면별로 만들면 자리와 지속 시간이 제각각이 되고, 같은 화면에서 두 종류가 동시에 뜨는 일이 생긴다.
- **없는 동작을 약속하지 않는다** — 아직 붙지 않은 기능은 이 수단으로 그 사실을 밝힌다.
- **법령 근거를 붙이지 않는다** — 표시 인프라는 법령이 명한 의무의 직접 이행 수단이 아니다. 규칙은 공통 근거 연계(SCR-COM-008)를 따른다.
