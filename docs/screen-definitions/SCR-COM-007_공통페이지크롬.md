# 화면 정의서 — 공통 페이지 크롬 자동 주입

> 화면 ID: SCR-COM-007 · 화면 유형: 공통 인프라 · 기획 관점(v6) · 구현 정합 2026-08-11
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.

## 1. 화면 정보

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-COM-007 |
| 화면명 | 공통 페이지 크롬 자동 주입 |

| 상위 메뉴 | 공통/전역 |

각 화면 본문 맨 위에 **페이지 제목·부제·되돌아가기 줄**을, 목록에는 **쪽 넘김**을, 법령 근거가 있는 화면에는 **근거 칩**을 자동으로 붙인다. 화면마다 직접 만들면 제목 크기와 되돌아가기 위치가 제각각이 되고, 근거 칩은 붙이는 것을 잊는 화면이 생긴다. 구성은 페이지 머리·근거 칩·쪽 넘김 세 덩어리이며, 근거는 공통 근거 연계(SCR-COM-008)가 관리하는 값을 그린다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 이 인프라는 권한을 판단하지 않는다 — 화면에 들어온 사람에게 그 화면의 크롬을 그릴 뿐이다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 모든 화면 | 화면이 열릴 때 자동으로 붙는다 |
| 이탈 | 되돌아갈 목록 화면 | 되돌아가기 줄 선택 |
| 연계 | 법령 조문 상세 | 근거 칩 선택 — 조문 원문을 그 자리에서 편다 |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 화면에 들어온다 | 제목과 부제를 본문 맨 위에 붙인다 |
| 2 | 상세 화면에 들어온다 | 되돌아갈 목록으로 가는 줄을 제목 위에 둔다 |
| 3 | 근거 칩을 고른다 | 조문 원문을 화면 안에서 편다 |
| 4 | 목록이 길다 | 쪽 넘김을 목록 아래에 붙인다 |

### 분기 로직

- **화면이 제목을 선언했을 때만 붙인다** — 선언하지 않은 화면에는 아무것도 넣지 않는다. 빈 제목 줄을 만들면 본문이 그만큼 아래로 밀린다.
- **되돌아갈 곳을 선언한 화면에만 되돌아가기 줄을 둔다** — 목록 화면에는 없고 상세 화면에만 있다. 되돌아갈 이름도 화면이 정한다.
- **근거 칩은 매핑이 있는 화면에만 나온다** — 매핑이 비어 있으면 그리지 않는다. 억지로 조문을 붙이지 않는 것이 이 시스템의 규칙이며, **근거 없음도 판정 결과**다.
- **한 주소가 여러 화면을 겸하면 실제 화면 기준으로 근거를 고른다** — 주소에 붙은 조건까지 보고 어느 화면인지 판정한다. 주소만 보면 여러 업무가 같은 근거를 갖게 된다.
- **이미 제목이 있는 화면에는 덧붙이지 않는다** — 같은 제목이 두 번 나오지 않게 한다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 제목을 선언하지 않은 화면 | 페이지 머리를 그리지 않는다 |
| 되돌아갈 곳만 선언하고 제목이 없음 | 되돌아가기 줄만 그린다 |
| 근거 매핑이 비어 있음 | 칩을 그리지 않는다 — 근거 없음이 정상인 화면이 있다 |
| 근거는 있으나 화면에 제목 영역이 없음 | 칩을 붙일 자리가 없어 표시되지 않는다 — 이 사실을 근거 관리 화면이 경고로 드러낸다(SCR-ADMIN-008) |
| 쪽 넘김 표시 대상이 1쪽뿐 | 쪽 넘김을 그리지 않는다 — 넘길 곳이 없으면 없는 편이 낫다 |
| 화면이 이미 제목을 갖고 있음 | 덧붙이지 않는다 |
| 크롬 조립 중 문제가 생김 | 본문은 그대로 보여 준다 — 크롬 때문에 화면 전체가 안 보이면 안 된다 |

## 4. 화면 구성별 정리

### 4-1. 페이지 머리 — 제목과 부제

- 구성: 제목 한 줄과 (있으면) 부제 한 줄. 본문 맨 위에 붙는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면이 제목을 선언 | 제목을 그린다 | — |
| 부제를 함께 선언 | 제목 아래에 덧붙인다 | 부제는 선택이다 |
| 선언하지 않음 | 그리지 않는다 | 빈 줄을 만들지 않는다 |

- 상태: **없음 / 제목만 / 제목+부제** 세 가지다. 화면이 정한 값을 그대로 쓰며 이 인프라가 문구를 만들지 않는다.

### 4-2. 되돌아가기 줄

- 구성: 되돌아갈 목록으로 가는 한 줄. 제목보다 위에 온다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면이 되돌아갈 곳을 선언 | 줄을 그린다 | 되돌아갈 이름도 화면이 정한다 |
| 선택 | 그 목록으로 이동한다 | 브라우저 뒤로가기와 달리 **정해진 목록**으로 간다 |
| 선언하지 않음 | 그리지 않는다 | 목록 화면에는 필요 없다 |

- 상태: **있음 / 없음** 둘이다. 이름을 정하지 않으면 기본 이름을 쓴다.

### 4-3. 법령 근거 칩

- 구성: 그 화면의 근거 조문을 짧게 줄인 칩. 제목 옆에 붙는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 매핑이 있는 화면 | 조문 수만큼 칩을 그린다 | 표시 순서는 매핑 순서를 따른다 |
| 칩 선택 | 조문 원문을 **그 자리에서 편다** | 새 팝업을 띄우지 않는다 |
| 매핑이 없음 | 그리지 않는다 | 근거 없음도 판정 결과다 |

- 상태: **없음 / 있음** 둘이다. 칩의 내용·표기·순서는 이 인프라가 정하지 않고 근거 연계(SCR-COM-008)가 관리한다.

### 4-4. 쪽 넘김

- 구성: 목록 아래에 붙는 쪽 이동 줄.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면이 쪽 넘김 자리를 표시 | 현재 쪽과 전체 쪽을 그린다 | — |
| 전체가 1쪽 | 그리지 않는다 | 넘길 곳이 없다 |

- 상태: **없음 / 있음**이며, 있을 때는 현재 쪽이 강조된다.

## 6. 정책

- **크롬을 화면마다 만들지 않는다** — 제목 크기·되돌아가기 위치·쪽 넘김 모양이 화면마다 달라지는 것을 막는다. 한 곳에서 그리면 고칠 때도 한 곳만 고친다.
- **선언하지 않은 것은 그리지 않는다** — 빈 제목 줄이나 빈 쪽 넘김을 만들지 않는다. 정보가 0인 자리가 본문을 아래로 밀면 첫 데이터까지의 거리가 늘어난다.
- **근거 칩을 화면이 직접 그리지 않는다** — 화면마다 근거를 문자열로 적으면 조문이 개정될 때 어디를 고쳐야 하는지 알 수 없다. 근거는 한 곳에서 관리하고 이 인프라가 그린다.
- **근거 없음을 감추지 않는다** — 매핑이 비어 있는 것은 아직 안 붙인 것이 아니라 **붙이지 않기로 판정한 것**일 수 있다. 그 구분은 근거 관리 화면(SCR-ADMIN-008)이 보여 준다.
- **되돌아가기는 정해진 목록으로 간다** — 브라우저 뒤로가기와 다르다. 여러 경로로 들어온 상세에서 어디로 돌아갈지 화면이 정해 두면 사용자가 헤매지 않는다.
- **크롬이 본문을 가로막지 않는다** — 조립에 문제가 생겨도 본문은 보여 준다.
- **법령 근거를 이 인프라 자체에 붙이지 않는다** — 크롬은 법령이 명한 의무의 직접 이행 수단이 아니다. 규칙은 공통 근거 연계(SCR-COM-008)를 따른다.

---

## 7. 미결사항

없음. 무엇을 언제 그릴지·근거 칩의 소속과 표시 조건·되돌아가기의 성격·조립 실패 시 처리는 모두 §6에서 확정했다.

근거 칩이 표시되지 않는 화면(제목 영역이 없는 경우)은 미결이 아니라 **개발 수정 대상**이며, 근거 관리 화면이 그 목록을 드러낸다.
