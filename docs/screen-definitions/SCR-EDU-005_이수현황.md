## 4. 화면 구성별 정리

### 4-1. 탭과 필터
- 부서별 요약과 대상자별 상세 탭을 제공한다.
- 이름 또는 부서 검색, 대상 구분, 고용형태, 채용연도와 완료율로 조회한다.
- 현재 집계 기준일을 요약 표에 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 부서별 요약과 대상자별 상세를 바꿔 표시한다 | 조회 조건 구성도 함께 바뀐다 |
| 검색어 입력 | 이름·부서를 함께 찾아 즉시 좁힌다 | — |
| 구분·고용형태·채용연도 선택 | 집계 모집단 자체를 바꾼다 | 요약의 완료율도 같은 조건으로 다시 센다 |
| 조건이 걸린 상태로 조회 | 어떤 모집단으로 계산한 값인지 함께 표시한다 | 전체 수치로 오독되지 않게 한다 |

- 상태: 탭은 **부서별 요약 / 대상자별 상세** 둘이고 조건은 두 탭이 **같은 모집단 기준**을 공유한다 — 요약의 완료율도 상세와 같은 조건으로 다시 집계한다. 조건이 걸린 상태에서는 **집계 모집단 배지**를 함께 노출해 전체 수치로 오독되지 않게 한다. 집계 기준일을 요약 표에 항상 표시한다.

### 4-2. 부서별 요약
- 부서, 대상 인원, 완료 인원, 완료율과 상세 이동을 표시한다.
- 전체 대상자 수와 완료 인원을 함께 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 부서 행의 [상세] | 그 부서 대상자만 걸러 상세 탭으로 넘어간다 | 미달자만 보는 형태로도 열 수 있다 |
| 조회 범위 밖 부서 열람 시도 | 개인 이수이력을 내지 않고 사유를 알린다 | “(부서) 부서원의 개인 이수이력은 열람할 수 없습니다” |

- 상태: 부서 단위 상태는 완료율 구간으로 읽으며 **0% / 진행 / 100%** 셋이 대표적이다. 대상 인원이 0명인 부서는 완료율을 계산하지 않고 **대상 없음**으로 표시한다 — 0명을 0%로 내면 아무 대상도 없는 부서가 최하위로 올라온다. 상신이 꺼져 있는 동안 개인 결재 열은 함께 접힌다.

### 4-3. 대상자별 상세
- 대상자, 부서, 구분, 사이클 기간과 남은 일수, 필요시간, 인정시간, 미달시간, 완료 여부를 표시한다.
- 미이수자를 개별 또는 복수 선택해 독촉할 수 있다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 대상자 선택 | 독촉 대상에 넣는다 | 미이수자에게만 선택칸이 있다 |
| [독촉] | 고른 대상자의 소속 부서로 묶어 발송 처리한다 | 한 명도 고르지 않으면 “미이수자를 1명 이상 선택하세요” |
| 발송 실행 | 부서 수와 인원을 세어 알린다 | “N개 부서, N명 독촉 발송 완료” |

- 상태: 한 사람의 상태는 **미이수 / 부족(인정시간이 필요시간에 미달) / 완료 / 초과**이며, 남은 일수에 따라 **기한 임박**과 **기한 초과**가 덧붙는다. 미이수·부족인 사람만 독촉 대상으로 고를 수 있다 — 이미 채운 사람에게 독촉이 가면 안내가 신뢰를 잃는다.

### 4-4. 독촉 이력
- 미이수자 소속 부서 담당자에게 알림을 보낸 것으로 처리하고 발송 이력을 표시한다.
- 실제 문자·메일 발송이 아닌 프로토타입 알림 기록이다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 독촉 발송 | 발송 이력에 부서·인원·일시를 남긴다 | 실제 발송이 아님을 화면에 밝힌다 |

- 상태: **발송 이력 없음**과 **있음** 둘이다. 프로토타입에서는 실제 문자·메일을 보내지 않고 알림 기록만 남기며 그 사실을 화면에 밝힌다 — 숨기면 보냈다고 오해한다. 이력은 조회 전용이다.

### 4-5. 상태
- 대상자나 조건 결과가 없으면 빈 상태를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 조회 결과 0건 | 목록 자리에 빈 상태 안내를 표시한다 | — |

- 상태: 빈 상태는 **대상자가 없음**(그 부서·구분에 근로자가 등록되지 않음)과 **조건에 맞는 결과가 없음** 둘이며 문구를 달리한다 — 앞은 근로자 명단 관리(SCR-EDU-006)에서 할 일이고 뒤는 조건을 풀 일이라 갈 곳이 다르다.

## 6. 정책

- 정기교육 기록만 현재 사이클 인정시간에 합산하고 기타 교육은 합산하지 않는다.
- 현업근로자는 채용일부터 6개월 사이클, 관리감독자는 현재 구현에서도 채용일부터 12개월 사이클을 사용한다.
- 필요시간은 사무직·판매업무 6시간, 그 밖의 현업근로자 12시간, 관리감독자 16시간이다.
- 인정시간이 필요시간 이상이면 완료, 미만이면 미이수로 표시한다.
- 부서 요약과 대상자 상세는 같은 판정 결과를 사용한다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록하며 관리감독자 지정일 이력과 과거 판정 재계산은 현 화면 기능에 포함하지 않는다.
