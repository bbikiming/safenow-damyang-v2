## 4. 화면 구성별 정리

### 4-1. 개요·보고서

- 사업장, 유해인자, 기관, 예정일·실시일, 대상 근거, 보존기간과 상태를 표시한다.
- 보고서는 교체 시 이전 파일을 지우지 않고 버전과 등록 이력을 보존한다.

### 4-2. 측정 완료

- 실시일과 결과를 입력한다.
- 결과가 개선 필요이면 개선 요구사항과 내부 완료기한을 함께 받는다.
- 완료 저장 시 보고서가 이미 등록돼 있어야 하며 보고서 첨부를 완료로 가장하지 않는다.

### 4-3. 개선관리

- 내부 개선기한과 시료채취 완료일부터 산정한 법정 제출기한을 함께 표시한다.
- 개선 완료 시 조치 결과, 완료일, 조치 후 증빙을 필수로 받고 처리자·시각을 남긴다.
- 기한 변경은 이전 날짜와 새 날짜, 변경 사유를 이력에 보존한다.

### 4-4. 미실시·알림·이력

- 예정일이 지났으면 미실시 사유와 예상 완료일을 입력한다.
- 알림은 내부 알림을 먼저 기록하고 외부 채널의 실제 성공 여부를 별도로 표시한다.
- 모든 결과·기한·첨부·알림 변경은 삭제하지 않는 시간순 이력으로 표시한다.

## 6. 정책

- 시행규칙 제188조에 따라 노출기준 초과 공정의 개선 증명서류 또는 개선계획 제출기한은 시료채취 완료일부터 60일이다. 화면의 내부 개선기한은 이 법정기한을 넘을 수 없다.
- `개선 필요`는 결과보고서를 근거로 담당자가 확정한다. 시스템이 단순 수치나 사업장 메모만으로 법 위반을 판정하지 않는다.
- 적정 결과도 보고서와 실시일을 보존하고, 개선 필요는 개선 완료 뒤에도 최초 결과와 변경 전 증빙을 덮어쓰지 않는다.
- 기한 재설정은 법정기한 변경이 아니다. 법령상 연장 근거가 있는 경우 근거 문서를 별도 첨부하고 그 범위에서만 법정기한을 조정한다.
- 완료 결과는 인력 평가에 참고지표로 연계하되 평가자가 근거를 열람하고 별도로 판단한다.
