### 분기 로직

- **교육 상태는 넷이다** — **안내 공문 전 → 교육 전 → 등록부 받는 중 → 완료**, 그리고 교육 전에 거둔 교육은 **취소**. «안내 공문 전»은 ① 을 아직 보내지 않은 교육이고 **재난안전과에만 보인다**(주소로 들어와도 부서에는 «아직 안내되지 않은 교육입니다»). «교육 전»은 ① 을 보냈고 마지막 회차 전이다. «등록부 받는 중»은 마지막 회차가 끝난 날부터 종료 처리 전까지다.
- **보는 사람에 따라 두 화면이다** — 재난안전과·조회 계층(재난안전과 과장·팀장, 군수)은 교육 전체(①·②·③ 요약, 대상 부서 전부의 줄)를, 부서 담당자·부서장은 **우리 부서 몫**(우리 부서 ② 한 줄, 등록한 줄만)을 본다.
- **등록부는 교육이 끝난 뒤에만 받는다** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 사전 신청·불참자 처리는 없다 — 부서가 하는 일은 «끝나고 한 번 올린다» 하나다.
- **등록부는 그 부서 담당자만 올린다** — 부서 칸은 소속 부서로 고정된다. 재난안전과도 다른 부서 몫을 대신 올리지 않는다(대리 등록·일괄 등록 없음). 재난안전과에 대상자가 있으면 등록 현황 표의 **재난안전과 줄에서만** [＋ 우리 부서 등록부 등록]을 낸다.
- **서명부는 두 갈래다** — 재난안전과가 서명부를 올렸으면 등록부 창에서 «재난안전과가 올린 서명부 사용» / «직접 올리기» 중 하나를 고르고, 안 올렸으면 «직접 올리기»만 있다. «사용»은 그 파일을 가리킬 뿐 파일을 새로 받지 않는다.
- **회차 수에 따라 일정 표시가 갈린다** — 단일 회차는 일자·시간을, 다회차는 회차별 일자·시간과 합계를 함께 보인다.
- **한 부서는 한 번만 등록한다** — 이미 등록한 부서의 재등록은 막는다. 고치려면 ② 를 보내기 전에 [등록 취소] 후 다시 올린다.
- **고치는 수단은 공문 상태가 정한다** — ② 를 보냈으면(결재 미완료·결재 완료) 그 부서 등록부를 고치는 버튼이 **없다**. 반려·반송되면 다시 열린다. 잠금을 자물쇠 버튼으로 따로 표시하지 않는다 — 상태는 «공문» 칸의 칩 하나가 말한다.
- **종료 전 취소와 종료 뒤 정정을 구분한다** — 종료 전에는 이수기록이 없으므로 등록부를 지운다([등록 취소]). 종료 뒤에는 원래 등록부를 «정정됨»으로 남기고 그 부서 이 교육 이수시간만 뺀다([이수 기록 정정]). 바른 명단은 [＋ 등록부 추가]로 다시 올린다.
- **이전 방식 기록** — 이 흐름 전에 만든 교육·등록부는 «이전 방식»이다. 공문 할 일이 없고, 옛 실시 결과 공문이 있으면 제목 줄에 상태 칩과 [공문 보기]가 보인다.

| 근로자를 한 명도 고르지 않고 저장 | 창 안에 «근로자를 1명 이상 선택하세요 — 아무도 참석하지 않았으면 [참석자 없음]을 누릅니다» |
| 서명부 없이 저장 | 창 안에 «서명부를 올려 주세요 (필수)» |
| 실제 참석시간이 0 이하이거나 회차 합계 초과 | 저장을 막고 허용 범위를 알린다 |
| 다른 모집단의 사람을 담음 | 저장하지 않고 사유를 창 안에 남긴다 — 현업근로자 교육에 관리감독자, 관리감독자 교육에 근로자를 담지 않는다 |
| 이미 등록한 부서로 다시 등록 | «(부서)는 이미 등록된 부서입니다 — 등록 취소 후 다시 등록하세요» |
| 등록부 저장 뒤 공문 창을 닫음 | 등록부는 남고 «공문» 칸이 «공문 미기안». 다시 [공문 보내기]로 이어 쓴다 |
| ② 를 보낸 뒤 등록부를 고치려 함 | 고치는 버튼이 없다. 주소·직접 호출이면 «등록부 공문이 (상태) 상태라 등록부를 고칠 수 없습니다 — 온나라에서 정정한 뒤 재난안전과에 알려 주세요» |
| 등록이 0건인 채 교육 종료 | 종료할 수 있다 — 아무도 등록하지 않은 교육이 목록에 계속 남지 않게 한다 |
| 교육이 끝나기 전에 종료 처리 | 막고 «교육이 끝난 뒤 종료 처리합니다» |
| 등록부·공문·출장 결과 보고가 남은 채 종료 | 막지 않고 확인창에 남은 것을 수로 밝힌다(등록부 미등록 n개 부서 · 등록부 공문 미기안 n개 부서 · 출장 결과 보고서). 등록부 공문 · 출장 결과 보고는 종료 뒤에도 할 일로 남고, **미등록 부서의 등록 할 일은 종료하면 사라진다** — 확인창이 둘을 갈라 말한다(늦게 내는 등록부는 [＋ 등록부 추가]) |
| 등록 기한 전에 종료 처리 | 할 수 있고, 확인창에 «아직 등록 기한 전 — 종료한 뒤에 내는 부서의 등록부는 [＋ 등록부 추가]로 받습니다» |
| 출장 결과 보고 공문을 보낸 뒤 보고서를 고치려 함 | 수정 버튼이 없다. 직접 호출이면 «출장 결과 보고 공문을 보내 고칠 수 없습니다» |
| 취소된 교육 | 상태 «취소» 칩과 취소 사유를 보이고 등록·종료 수단을 내지 않는다. 취소 안내 공문이 남았으면 재난안전과에 그 공문 수단만 |
| 이력이 비는 경우 | 없다. 교육을 만든 순간 등록 이력이 남는다 |

## 4. 화면 구성별 정리

### 4-1. 교육 요약

- 제목과 상태 칩, 구분·일정·합계시간(다회차면 «n일 합계»)·강사·장소·등록 부서와 인원, 접수 중이면 **등록 기한**과 D-day(지나면 «기한 지남»)를 보인다.
- 다회차는 회차별 일자·시간·시간 수를 한 줄로 펼친다. 교육 첨부(참석자 명단·교육 자료)와, 재난안전과가 올린 서명부가 있으면 그 파일명과 올린 날을 보인다(조회 범위 밖 부서에는 파일명을 내지 않는다).
- 교육 전이면 «교육이 끝난 뒤(날짜부터) 각 부서 담당자가 참석자 등록부를 올립니다 — 참석자 · 실제 참석시간 · 서명부 스캔. 등록 기한 (날짜)» 를 밝힌다.
- 이전 방식 교육에 옛 실시 결과 공문이 있으면 제목 옆에 상태 칩과 [공문 보기]가 보인다(§4-4).

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 목록에서 [상세 →] | 그 교육의 요약·회차·공문 요약을 보인다 | 정기교육(SCR-EDU-001)에서 이동 |
| 뒤로 가기 | 들어온 목록으로 돌아간다 | — |
| 없는 식별값 · 안내 전 교육(부서) | 본문 대신 안내만 보인다 | §3 예외 표 |

- 상태: 상태 칩은 **안내 공문 전 / 교육 전 / 등록부 받는 중 / 완료 / 취소** 다섯 가지 중 하나다. 등록 기한은 «마지막 회차 + 교육 등록 때 정한 N일(기본 7일)»이다.

### 4-2. 공문 요약 줄

이 교육에서 나가는 공문의 진행을 한 줄로 보인다. 칩 어휘는 교육 전 화면 공통이다 — **공문 미기안 / 결재 미완료**(온나라 기안함 전송·결재중) **/ 결재 완료 / 반려 / 반송**.

| 보는 사람 | 요약 줄 |
|---|---|
| 재난안전과 · 조회 계층 | **① 교육 안내** (칩) · **② 등록부 제출 공문 n / 대상 m개 부서**(보낸 수 / 교육 대상 부서 수 — 이전 방식 등록부가 섞여 있으면 «이전 방식 등록부 k건은 공문이 필요 없습니다»를 덧붙인다) · **③ 출장 결과 보고** (칩 — 보고서를 아직 안 썼으면 «교육 뒤 작성», 썼지만 안 보냈으면 «보고서 작성함» + 공문 미기안) |
| 부서 담당자 · 부서장 | **우리 부서 등록부 제출 공문** (칩) — 우리 부서가 새 흐름 등록부를 올린 뒤에만 |

- ①을 보내기 전에는 ②·③ 칸을 내지 않는다. 새 흐름 등록부가 하나도 없으면 «이전 방식 등록부는 공문이 필요 없습니다»를 붙인다.
- 출장 결과 보고(③)는 재난안전과 내부 보고라 부서 화면에는 나오지 않는다.

### 4-3. 처리 버튼 — 역할 × 상태

**재난안전과 담당자**

| 상태 | 버튼 |
|---|---|
| 안내 공문 전 | [안내 공문 작성] — ① 작성으로 간다. (교육 정보 수정·삭제는 정기교육 목록에서) |
| 교육 전 | ① 상태 칩 + [공문 보기]. 일시·장소를 바꿔 변경 안내가 필요하면 [변경 안내 공문 보내기] |
| 등록부 받는 중 | [서명부 올리기](올렸으면 [서명부 다시 올리기]) · [출장 결과 보고서 작성](썼으면 ③ 공문 수단 + 보내기 전 [출장 결과 보고서 수정]) · [교육 종료 처리] |
| 완료 | [서명부 올리기] · ③ 수단(보고서를 아직 안 썼으면 [출장 결과 보고서 작성]) |
| 취소 | 취소 안내 공문이 남았으면 그 공문 수단만 |

**부서 담당자**(실무자 계정이 없는 부서는 부서장)

| 상태 | 버튼 |
|---|---|
| 교육 전 | 없음 — 요약의 «교육이 끝난 뒤(날짜부터)…» 안내 |
| 등록부 받는 중 | 미등록 [＋ 참석자 등록부 등록] / 저장만 함 [등록부 공문 보내기] / 보냄 ② 칩 + [공문 보기] / «참석자 없음» + [되돌리기] |
| 완료 | 아직 안 냈으면 [＋ 등록부 추가] · 저장만 했으면 [등록부 공문 보내기] |

- 관리·감독 계층(과장·팀장·군수)은 버튼 대신 «참석자 등록·종료 처리는 담당자가 합니다» 한 줄을 본다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [안내 공문 작성] · [변경 안내 공문 보내기] | ① 공문 작성을 연다 | 미리보기 → [온나라로 보내기] |
| [서명부 올리기] | 한 장 서명부를 올리는 창을 연다(§4-6) | — |
| [출장 결과 보고서 작성] · [수정] | 보고서 창을 연다(§4-7) | — |
| [＋ 참석자 등록부 등록] · [＋ 등록부 추가] | 등록부 창을 연다(§4-5) | — |
| [등록부 공문 보내기] | 그 부서 ② 공문 작성을 연다 | 미리보기 → [온나라로 보내기] |
| [되돌리기](참석자 없음) | «참석자 없음»을 거둔다 | 종료 처리 전까지만 |
| [교육 종료 처리] | 확인창을 연다(§4-8) | — |

### 4-4. 공문 — 작성 · 보내기 · 다시 보내기

- 공문 작성 순서는 하나다 — 작성 창(수신 고정 · 제목 · 본문 직접 작성 · 붙임 고르기) → [문서 미리보기 →] → **[온나라로 보내기]**(결재선 없이 온나라 연계기안함까지) → 확인. 작성 창에는 보내기 수단이 없다. 검토·결재는 담당자가 온나라 기안함에서 지정해 상신한다.
- 본문은 비어 있고 «교육 개요»·«참석 결과» 같은 삽입 칩으로 문장을 넣는다. 붙임은 이미 올려 둔 파일에서 고르고(방금 올린 서명부는 미리 체크), 참석자 명단 별지는 그 부서 사람만 실린다. 붙임은 «n / 5개 · 합계 n / 30MB» 한도 안에서 고른다.

| 공문 | 수신 | 기안 | 언제 |
|---|---|---|---|
| ① 교육 안내(변경·취소 안내 포함) | 대상 부서(고정 · 재난안전과 제외) | 재난안전과 담당자 | 집합교육 저장 직후 · 일시·장소 변경 · 교육 취소 |
| ② 참석자 등록부 제출 | 재난안전과 | 그 부서 담당자 | 등록부 저장 직후 |
| ③ 출장 결과 보고 | 내부결재 | 재난안전과 담당자 | 교육이 끝난 날부터 |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [온나라로 보내기] 성공 | 상태 «결재 미완료» 칩 + [공문 보기] | 그 공문에 딸린 할 일이 끝난다(② 는 부서 «참석자 등록부 등록») |
| 반려 · 반송 회신 | 칩이 «반려»/«반송»으로 바뀌고 사유가 보인다 | 기안한 쪽에 [다시 보내기] — 앞 제목·본문을 이어 쓴다 |
| [공문 보기] | 보낸 공문을 연다 | 조회 전용 |
| 이전 방식 실시 결과 공문이 반려·반송 | 제목 줄에 사유와 재난안전과 [다시 보내기] | 새로 만들지는 않는다 — 돌아온 옛 공문만 다시 보낸다 |

- 상태: 공문마다 **공문 미기안 → 결재 미완료 → 결재 완료**, 또는 **반려·반송**(다시 열림). 결재 완료·반려·반송은 온나라 회신으로만 바뀐다 — 사람이 옮겨 적는 수단은 없다.

### 4-5. 참석자 등록부 등록

- 교육이 끝난 날부터(등록부 받는 중) 그 부서 담당자가 연다. 완료 교육은 아직 안 냈거나 정정한 부서만 [＋ 등록부 추가]로 연다.
- 창 제목은 «참석자 등록부 등록 · (우리 부서)»이고 부서는 바꿀 수 없다.

| 칸 | 내용 |
|---|---|
| 참석자 | 우리 부서 대상자 목록에서 체크 — 현업근로자 교육은 관리감독자를 빼고, 관리감독자 교육은 관리감독자만 |
| 실제 참석시간 | «모두에게 같은 시간»(비우면 전 회차) 하나 + «사람별로 다르게 적기»(일찍 나가거나 늦게 온 사람만) |
| 서명부 * | «재난안전과가 올린 서명부 사용(파일명)» / «직접 올리기» — 직접이면 서명부 스캔 한 파일 |
| 참석자 없음 | 창 아래 [참석자 없음] — 대상자는 있는데 아무도 참석하지 않았을 때(공문 없음) |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [저장하고 공문 작성 →] | 등록부를 저장하고 같은 창이 ② 작성으로 바뀐다 | 창을 닫으면 등록부는 남고 공문만 «공문 미기안» |
| 저장 거절(미선택·서명부 없음·모집단·중복) | 창을 닫지 않고 사유를 창 안에 남긴다 | §5 |
| [참석자 없음] | 우리 부서를 «참석자 없음»으로 두고 할 일을 끝낸다 | «(부서) — 참석자 없음으로 처리했습니다» · 이수 기록은 생기지 않는다 |
| [취소] | 아무것도 저장하지 않고 닫는다 | — |

- 상태: 등록부는 **등록부 받는 중**에만 새로 받고(완료 뒤에는 [＋ 등록부 추가]), 교육 전·취소 교육에서는 열리지 않는다. 종료 뒤 추가한 등록부는 저장과 함께 사람마다 실제 참석시간으로 이수 기록이 남는다.

### 4-6. 서명부 올리기 (재난안전과)

- 집합교육 서명부는 한 장에 여러 부서가 섞여 서명하고 재난안전과 손에 있다. 재난안전과 담당자가 교육이 끝난 뒤 **한 번** 올리면 부서가 등록부 창에서 골라 쓴다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [저장] | 교육에 서명부를 붙이고 아직 등록부를 안 올린 대상 부서에 알린다 | «서명부를 올렸습니다 — 아직 등록부를 안 올린 n개 부서에 알렸습니다» |
| [필요 없음(부서가 따로 받음)] | 서명부 할 일을 끝낸다 | «서명부는 부서가 따로 올립니다» |
| 서명부 없이 [저장] | 막는다 | «서명부를 올려 주세요» |

### 4-7. 출장 결과 보고서 (재난안전과 → ③)

| 칸 | 필수 | 내용 |
|---|---|---|
| 교육 자료 | ○ | 등록 때 올린 교육 자료를 불러와 보인다(«등록 때 올린 파일») — 빼거나 더할 수 있다 |
| 교육 사진 | ○ | 사진 업로드 |
| 참석 인원 | ○ | 1 이상 숫자 · 대략적인 수. 옆에 참고로 «등록부 기준 n명(현재)» — 대신 채우지 않는다 |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [저장하고 공문 작성 →] | 보고서를 저장하고 같은 창이 ③ 작성으로 바뀐다 | — |
| 필수 칸 누락 | 막는다 | «교육 자료를 올려 주세요» · «교육 사진을 올려 주세요» · «참석 인원을 1명 이상 적어 주세요» |

- 상태: 교육이 끝난 날부터 쓰고 ③ 을 보내기 전까지 [출장 결과 보고서 수정]으로 고친다. 참석 인원은 보고용이고 이수 판정에 쓰지 않는다.

### 4-8. 교육 종료 처리

- 교육이 끝난 뒤 재난안전과 담당자가 한다. 확인창에 등록 부서 수·인원과 «등록부별 실제 참석시간을 카운트합니다», 남은 것(등록부 미등록 · 등록부 공문 미기안 · 출장 결과 보고서), 등록 기한 전이면 그 사실을 밝힌다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [교육 종료 처리] | 확인창을 연다 | 등록이 0건이어도 열린다 |
| 확인창 [종료 처리] | 등록한 사람마다 그 등록부의 실제 참석시간으로 이수 기록을 남기고 «완료» | «교육 종료 · n명 카운트 완료» |

- 상태: **등록부 받는 중**에서만 나타나고 되돌리는 수단은 없다. ② 를 안 보낸 부서의 등록부도 이수로 센다(등록부가 참석 증빙) — 그 부서의 «등록부 공문 보내기» 할 일은 종료 뒤에도 남는다.

### 4-9. 등록 현황

- 제목은 «등록 현황 (n개 부서 · n명)» — 부서 수는 줄 수가 아니라 서로 다른 부서 수다.
- 열: 부서(옛 기록의 «일괄 등록»·«대리 등록» 표시, 정정한 줄은 «정정됨») · 참석자 명단 · 인원 · 실제 참석(사람별로 따로 적은 시간은 이름과 함께) · 서명부(«재난안전과 서명부» 또는 파일명) · 등록일 · **공문** · 처리.
- 재난안전과·조회 계층에는 **대상 부서 전부**가 줄로 보인다 — 아직 안 낸 부서는 «미등록», 참석자가 없던 부서는 «참석자 없음» 칩과 독촉 횟수. 부서 담당자에게는 등록한 줄만 보인다.
- 다른 부서 줄은 조회 범위를 따른다 — 범위 밖 부서의 참석자 이름은 «#번호», 서명부는 «제출됨»으로만 보이고 열 수 없으며, 공문 칸은 «—»다.

**«공문» 칸**

| 줄 | 보는 사람 | 칸 내용 |
|---|---|---|
| 새 흐름 등록부 · 우리 부서 | 그 부서 담당자 | 공문 미기안이면 [공문 보내기] · 보냈으면 칩 + [공문 보기] · 반려·반송이면 사유 + [다시 보내기] |
| 새 흐름 등록부 · 다른 부서 | 재난안전과 · 조회 계층 | 칩 + [공문 보기](보냈을 때). 공문 미기안·반려·반송이면 재난안전과에 [독촉] |
| 미등록 부서 | 재난안전과 · 조회 계층 | 독촉 횟수 + 접수 중이면 재난안전과에 [독촉] |
| 이전 방식 등록부 | 누구나 | «이전 방식» — 공문 없음 |
| 정정된 줄 | 누구나 | «—» |

**«처리» 칸**

| 상황 | 칸 내용 |
|---|---|
| 우리 부서 줄 · ② 전(또는 반려·반송) · 종료 전 | [등록 취소] |
| 우리 부서 줄 · ② 전(또는 반려·반송) · 종료 뒤 | [이수 기록 정정] |
| ② 를 보낸 줄(결재 미완료·결재 완료) | 비어 있다 — 고치는 버튼이 없는 것이 잠금이다 |
| 다른 부서 줄 | 비어 있다 — 그 부서가 올린 기록은 그 부서만 고친다 |
| 옛 «일괄 등록» 줄을 그 부서가 볼 때 | «일괄 등록 — 정정은 재난안전과» |
| 정정된 줄 | 정정 사유와 정정 시각 |
| 재난안전과 줄(재난안전과에 대상자가 있을 때 · 접수 중) | [＋ 우리 부서 등록부 등록] |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [등록 취소] | 확인창(«등록부와 서명부 파일이 삭제됩니다») 뒤 등록부를 지운다 | «(부서) 등록부를 취소했습니다» — 같은 부서를 다시 등록할 수 있다 |
| [이수 기록 정정] | 정정 사유(필수)를 받고 원래 등록부를 «정정됨»으로 남기며 그 부서 이 교육 이수시간을 뺀다 | «(부서) 이수 기록을 정정했습니다 — 바른 명단은 [＋ 등록부 추가]로 올립니다» |
| [독촉] | 그 부서 담당자에게 등록부 등록 또는 공문 보내기를 재촉한다 | 독촉 횟수가 오른다 |

- 상태: 활성 등록부가 없으면 «아직 등록한 부서가 없습니다»(①전이면 «안내 공문을 보내면 부서에 알립니다», 교육 전이면 «교육이 끝나면 부서가 참석자 등록부를 올립니다»). 완료 교육에 등록부가 있으면 표 위에 정정 길(정정 → 등록부 추가)을 한 줄로 밝힌다.

### 4-10. 이력

- 교육 등록, 서명부 올림, 참석자 등록부 등록(인원·실제 참석시간·서명부 출처), 참석자 없음·되돌림, 등록 취소, 이수 기록 정정(사유·회수 건수), 출장 결과 보고서 저장, 종료 처리를 일시·유형(«등록»·«처리»)·처리자와 함께 시간순으로 쌓는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 위 처리 발생 | 이력에 자동으로 쌓인다 | 사용자가 직접 쓰는 항목은 없다 |

- 상태: 조회 전용이고 비는 경우가 없다(교육을 만든 순간 등록 이력이 남는다). 처리자는 실제 접속자로 남는다.
- **부서 화면의 이력은 재난안전과 공용 기록과 우리 부서 기록만** 보인다 — 출장 결과 보고(재난안전과 내부 보고)와 다른 부서의 등록부 줄은 빠진다(등록 현황 표가 다른 부서를 «#번호»로 가리는 것과 같은 이유, 2026-11-17).

## 6. 정책

- **과정마다 온나라 공문이 나간다 (2026-11-16 1차 통화)** — 이 화면에서 ① 교육 안내 · ② 참석자 등록부 제출 · ③ 출장 결과 보고가 나간다(§4-4). 공문을 보내야 그 일이 끝난다 — ② 를 보내야 부서 «참석자 등록부 등록» 할 일이 끝나고([참석자 없음]도 끝), ③ 을 보내야 재난안전과 «출장 결과 보고서 작성»이 끝난다.
- **등록부는 그 부서 담당자가 올리고 그 부서가 보낸다** — 대리 등록·일괄 등록은 없다. 판정은 «같은 부서 + 담당자(실무자 계정이 없는 부서만 부서장)» 하나이고, 재난안전과 담당자도 남의 부서 줄을 올리거나 고치지 않는다. 재난안전과에 대상자가 있으면 재난안전과 줄에서만 자기 부서 몫을 올린다. 옛 기록의 «일괄 등록»·«대리 등록» 표시는 남기고, 옛 일괄 등록 줄의 정정은 올린 쪽(재난안전과)만 한다.
- **한 장 서명부는 재난안전과가 한 번 올린다** — 부서는 «재난안전과가 올린 서명부 사용»으로 그 파일을 가리킨다. 같은 증빙을 두 벌 만들지 않으며, 공문 붙임 후보에도 같은 파일이 체크돼 나온다.
- **교육 종료 처리 · 서명부 올리기 · 출장 결과 보고서 · 독촉은 재난안전과 담당자가 한다.** 관리·감독 계층(재난안전과 과장·팀장, 부서장, 군수)은 조회만 한다. 처리자는 실제 접속자로 남는다.
- **«안내 공문 전» 교육은 재난안전과에만 보인다** — 목록·상세 주소·내 할일이 같은 판정이다. 한 번 보낸 교육은 ① 이 반려돼도 계속 보인다.
- **등록부는 교육이 끝난 뒤 등록 기한 안에 받는다** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 기한은 집합교육 등록 때 «마지막 회차 뒤 N일»(1~30일, 기본 7일)로 정하고, 부서 내 할일 카드는 교육이 끝난 날 생겨 이 기한을 단다. 사전 신청·불참자 처리는 없다.
- **집합교육의 사람별 인정시간은 등록부의 실제 참석시간이다** — 교육 종료는 예정시간을 일괄 인정하지 않고 등록부마다(사람별로 따로 적은 시간 포함) 반영한다. 회차를 고쳐도 적어 둔 참석시간은 덮지 않고, 참석시간을 따로 적지 않은 등록부만 새 합계를 따른다. 합계를 참석시간보다 작게 줄이려면 그 등록부를 먼저 정정한다.
- **잠금은 공문 상태로만 정한다** — ② 를 보낸 부서 등록부는 취소·정정할 수 없다(결재 미완료·결재 완료 = 잠금, 반려·반송 = 풀림). 부서가 ② 를 한 곳이라도 보내면 교육의 회차·시간도 고칠 수 없다(정기교육 목록). ③ 을 보내면 출장 결과 보고서를 고칠 수 없다. ① 은 잠그지 않는다 — 고치면 변경 안내 공문을 보낸다. 잠금은 자물쇠 버튼이 아니라 **고치는 버튼이 없음**으로 나타내고, 상태는 공문 칸의 칩 하나가 말한다. 결재 뒤 고칠 일은 온나라에서 정정한 뒤 재난안전과에 알린다 — 시스템만 고치면 나간 문서와 기록이 갈린다.
- **완료기록은 지우지 않는다** — 종료 뒤 정정은 원래 등록부를 «정정됨»으로 남기고 사유·처리자·시각을 적은 뒤 그 부서 이 교육 이수시간만 집계에서 뺀다. 바른 명단은 [＋ 등록부 추가]로 다시 올린다. 정정된 줄은 이수율 계산에서 빠지되 조회에는 남는다.
- **한 부서는 한 번만 등록한다** — 두 번 쌓이면 그 부서 인원의 이수기록이 이중으로 붙어 이수 판정과 공문 별지의 인원이 함께 부푼다. 정정된 등록부는 «이미 등록한 부서»로 세지 않는다 — 세면 정정한 부서가 다시 등록하지 못한다.
- **종료 처리는 공문을 기다리지 않는다** — 남은 것을 수로 밝히되 막지 않는다. 기한을 넘긴 부서 때문에 종료가 막히면 이수현황이 비어 있게 된다.
- **결재선을 받지 않는다** — 운영 결정(2026-11-06 «온나라로 기안까지만»)대로 공문은 결재선 없이 온나라 연계기안함까지 보낸다. 결재 결과를 사람이 옮겨 적는 수단은 없다 — 연계 회신만 상태를 바꾼다.
- **다른 부서 참석자 정보는 조회 범위를 따른다(2026-11-05 운영 P05)** — 범위 밖 부서의 이름과 서명부(이름·서명이 있다)는 가린다. 근로자 명단·채용시교육이 범위를 좁힌 것과 같은 근거다.
- **이 상세는 집합교육 전용이다** — 부서 자체교육은 정기교육 목록의 카드에서 결재 상태 칩 + [공문 보기]로 끝나고(SCR-EDU-001), 교육 자체의 수정·취소·삭제는 정기교육 목록에서 한다.
- **이전 방식** — 이 흐름 전에 만든 교육·등록부는 공문 할 일이 없다. 옛 실시 결과 공문은 새로 만들지 않고, 반려·반송된 것만 재난안전과가 제목 줄의 [다시 보내기]로 다시 보낸다.

### 경위 (대체된 결정 — 따르지 말 것)

- **종료 뒤 «[공문 기안]» 실시 결과 공문(교육 1건 단위)** — 종료 처리된 교육의 실시 결과를 재난안전과가 한 번 기안하던 흐름은 2026-11-16 과정별 공문(①·②·③)으로 대체됐다. 이전 방식 교육에만 남는다.
- **재난안전과 일괄 등록(2026-11-11)·대리 등록** — 2026-11-16 «재난안전과 담당자는 참석자 등록부를 등록할 필요가 없어요»로 걷었다. 한 장 서명부 문제는 [서명부 올리기]가 맡는다.
- **잠금 표시 자물쇠 버튼** — 상태 칩과 함께 «결재 완료가 두 개»로 읽혀 2차 통화에서 걷었다.
- **«합계시간을 신청자 전원에게 반영»** — 2026-10-06 기획확인 4차에서 «등록부의 실제 참석시간»으로 정정했다.
- **«신청»(사전 신청)** — 2026-11-12 «교육이 끝난 뒤 등록부»로 바꾸며 화면 어휘도 «등록»으로 맞췄다.
