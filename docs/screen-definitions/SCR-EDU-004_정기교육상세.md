### 분기 로직

- **교육 상태가 화면의 절반을 가른다** — 상태는 **교육 전 → 등록부 받는 중 → 완료** 셋이다. **교육 전**(마지막 회차 전)에는 등록·종료 수단 대신 언제부터 받는지를 밝히고, **등록부 받는 중**(마지막 회차가 끝난 날부터)이면 참석자 등록부 등록과 교육 종료 처리가 나타나며, **완료**면 둘 다 사라진다.
- **등록부는 교육이 끝난 뒤에만 받는다(2026-11-12)** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 교육 전에 받으면 서명은 «예정»이 되고 참석시간은 모르는 값을 적게 된다. 사전 신청·불참자 처리는 두지 않는다 — 부서가 하는 일은 «끝나고 한 번 올린다» 하나다.
- **회차 수에 따라 일정 표시가 달라진다** — 단일 회차는 일자·시간을 그대로 쓰고, 다회차는 **회차별 일자·시간과 합계**를 함께 보인다.
- **종료 전 취소와 완료 기록 정정을 구분한다** — 종료 전이면 아직 이수기록이 없으므로 등록부를 회수한다. 완료 교육이면 원 등록부를 삭제·수정하지 않고 `등록취소` 상태와 정정 사유·처리자·시각을 남긴 뒤 연결 이수기록만 집계에서 제외한다. 정정값은 새 등록부로 다시 등록한다.
- **같은 교육에 여러 부서의 등록부가 누적된다 — 다만 한 부서는 한 번만 등록한다.** 이미 등록한 부서로 다시 등록하려 하면 막고, 인원·서명부를 고치려면 **등록 취소 후 다시 등록**한다(대상자를 바꾸는 경로와 같다).
  - 같은 부서가 두 번 쌓이면 그 부서 인원에게 **이수기록이 이중으로 붙어** 이수 판정(완료율)과 공문 붙임 별지의 인원이 함께 부풀고, 등록은 행 단위인데 취소는 부서 단위라 되돌리는 단위까지 어긋난다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 없는 교육 식별값으로 진입 | 본문을 내지 않고 "교육을 찾을 수 없습니다"만 표시한다 |
| 참석자 등록부에서 근로자를 한 명도 고르지 않음 | 저장을 막고 "근로자를 1명 이상 선택하세요" |
| 교육이 끝나기 전에 등록부를 올리려 함 | 막고 «교육이 끝난 뒤(날짜부터) 참석자 등록부를 올립니다» — 화면 두 곳(목록 카드·상세)과 저장 모두 같은 판정 |
| 서명부 스캔 없이 등록부 저장 | 저장을 막는다 — 서명은 참석 사실의 증빙이라 선택이 아니다 |
| 실제 참석시간이 0 이하이거나 예정시간 초과 | 저장을 막고 허용 범위를 알린다 |
| 등록이 0건인 상태로 교육 종료 | **종료할 수 있다**(교육이 끝난 뒤). 아무도 등록하지 않은 교육을 남겨 두면 목록이 계속 어지럽다 |
| 교육이 끝나기 전에 종료 처리 | 막는다 — «교육이 끝난 뒤 종료 처리합니다» |
| 등록 기한 전에 종료 처리 | 할 수 있으나 확인창에 «아직 등록 기한 전 — 지금 종료하면 그 뒤에 올리려던 부서는 이수가 0» 을 밝힌다 |
| 교육 종료 실행 | 되돌리는 수단이 없으므로 등록 부서·인원과 반영될 교육시간을 확인창에 밝힌다 |
| 완료된 교육에서 정정 | 정정 사유를 필수로 받고 원행 보존·이수기록 집계 제외 범위를 밝힌다 |
| 이미 등록한 부서로 다시 등록 | 저장을 막고 사유를 알린다 — “이미 등록된 부서입니다 · 등록 취소 후 다시 등록하세요” |
| 결재가 올라간 교육에서 등록 취소 | 잠근다. 판정은 결재 상태 한 곳에서만 하고, 취소 수단 자체를 잠금 표시로 바꾼다 |
| 첨부파일·교육 사진이 비어 있음 | 정상으로 본다 — 등록 시점에는 아직 실시 전이므로 결측으로 표시하지 않는다 |
| 이력이 비는 경우 | 없다. 교육을 만든 순간 등록 이력이 남는다 |

## 4. 화면 구성별 정리

### 4-1. 교육 요약
- 상태, 교육 구분, 일정, 합계시간, 강사, 장소, 등록 부서·인원, 등록 기한, 첨부파일과 교육 사진을 표시한다.
- 다회차 교육은 회차별 일자·시간과 회차 합계를 표시한다.
- 존재하지 않는 식별값이면 “교육을 찾을 수 없습니다”를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 목록에서 교육 선택해 진입 | 그 교육의 요약과 회차를 표시한다 | 정기교육(SCR-EDU-001)에서 이동 |
| 뒤로 가기 | 들어온 목록 화면으로 돌아간다 | — |
| 없는 식별값으로 진입 | 입력 수단을 내지 않고 안내만 표시한다 | “교육을 찾을 수 없습니다” |

- 상태: 교육의 단계상태는 **교육 전 → 등록부 받는 중 → 완료**이며 요약 머리에 표시된다. 머리에는 **등록 기한**(마지막 회차 + 교육 등록 때 정한 N일, 기본 7일)과 D-day도 보인다. 회차 축은 **단일 회차**와 **다회차**(회차별 일자·시간과 합계를 함께 표시)로 갈린다. 첨부·교육 사진이 비어 있는 것은 정상이며(등록 시점에는 아직 실시 전) 오류로 표시하지 않는다. 없는 식별값으로 들어오면 본문을 내지 않고 안내만 표시한다.

### 4-2. 참석자 등록부 등록
- 교육이 끝난 날부터(등록부 받는 중) 부서, 해당 부서 대상 근로자, 실제 참석시간과 서명부 스캔을 등록한다. 서명부는 재난안전과가 교육 첨부 «참석자 명단(서명 포함)»으로 준 명단·출석부에 참석자가 서명한 것이다.
- 같은 교육에 여러 부서의 등록부를 누적한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [참석자 등록부 등록] | 부서·근로자·실제 참석시간·서명부 스캔을 받는 입력을 연다 | 교육이 끝난 뒤 종료 전까지만 나타난다 |
| 부서 선택 | 그 부서의 대상 근로자만 후보로 보여준다 — 현업근로자 교육은 관리감독자를 빼고, 관리감독자 교육은 관리감독자만 | 조직도에서 고른다. 저장할 때도 같은 기준으로 다시 본다(2026-11-05 운영 E19) |
| 서명부 스캔 없이 [등록] | 막고 사유를 알린다 | “서명부 스캔을 올려 주세요 (필수)” |
| 근로자 미선택 상태로 [등록] | 막고 사유를 알린다 | “근로자를 1명 이상 선택하세요” |
| 실제 참석시간 오류 | 0보다 크고 교육 예정시간 이하인지 검증 | 허용 범위 안내 후 저장 차단 |
| [등록] 성공 | 그 부서의 등록부를 등록 현황에 더한다. 재난안전과가 다른 부서 몫을 올렸으면 «대리 등록»으로 남긴다 | “(부서) · N명 참석자 등록부 등록” |

- 상태: **등록부 받는 중**일 때만 나타나고 교육 전·종료된 교육에서는 사라진다. 같은 교육에 여러 부서의 등록부가 누적되며, 부서·대상 근로자·실제 참석시간·서명부 스캔 중 하나라도 비면 저장할 수 없다.

**일괄 등록 (2026-11-11 2차 교육 1회차 발표안 27장)** — 집합교육 서명부는 한 장에 여러 부서가 섞여 재난안전과 손에 있다. 부서 수만큼 쪼개 올리지 않도록 재난안전과 담당자에게 `[일괄 등록 (여러 부서)]`를 둔다.
- 대상자를 **부서별 묶음**(부서 전체 체크 + 사람별 체크)으로 한 번에 고르고, 실제 참석시간(기본 = 교육 합계) 하나와 서명부 스캔 **한 파일**을 붙인다. 이미 등록한 부서는 «등록됨»으로 고를 수 없다.
- 저장하면 **부서별 등록 줄로 나뉘어** 들어가고 각 줄에 «일괄 등록»이 붙는다 — 한 부서 한 번·모집단·교육 뒤 판정은 부서 등록과 똑같이 지난다. 거절된 부서는 사유와 함께 밝히고 등록 수에서 뺀다.
- **일괄 등록 줄은 올린 쪽(재난안전과)만 정정한다** — 그 부서 담당자 화면에는 취소 수단 대신 «일괄 등록 — 정정은 재난안전과»가 보인다. 부서가 지우면 재난안전과가 가진 서명부와 기록이 갈린다.
- 일찍 나간 사람처럼 참석시간이 다른 사람은 그 부서 줄을 정정해 다시 올린다.
- «교육이 끝난 뒤 한 번» 원칙은 같다 — 사전 신청을 되살리지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [일괄 등록 (여러 부서)] | 부서별 묶음 대상자·실제 참석시간·서명부 한 파일을 받는 입력을 연다 | 재난안전과 담당자에게만, 등록부 받는 중에만 나타난다 |
| [N개 부서 등록] | 부서별 등록 줄로 나눠 저장한다 | “N개 부서 · M명 일괄 등록” (거절 부서가 있으면 사유 함께) |
| 부서 담당자가 일괄 등록 줄 취소 시도 | 막는다 | “일괄 등록한 등록부는 재난안전과 담당자가 정정합니다” |

### 4-3. 등록 현황
- 부서(대리 등록 · 일괄 등록 표시), 참석자 명단, 인원, **실제 참석시간**, 서명부, 등록일과 관리 수단을 표시한다.
- 완료 교육에서는 줄마다 `이수 기록 정정`, 위에 `＋ 정정 등록부 올리기`를 둔다(2026-11-13 문구 정리 — 종전 «완료기록 정정»·«취소이력»). 정정하면 원래 등록부는 지우지 않고 «정정됨»으로 남고 사유·정정 시각이 표시되며 그 부서 이 교육 이수시간만 집계에서 빠진다. 바른 명단은 `＋ 정정 등록부 올리기`로 다시 올린다. 실시 결과 공문을 보내기 전까지만 할 수 있다.
- **공문을 온나라로 보낸 뒤에는 취소 수단을 내지 않는다** — 버튼을 잠금 표시로 바꾸고 표 위에 사유를 함께 낸다. 누르면 거절하는 버튼을 남겨 두면 담당자가 이유를 모른 채 두 번 누른다.
- **'N개 부서'는 행 수가 아니라 서로 다른 부서 수로 센다.**
- **다른 부서 등록 줄은 가린다(2026-11-05 운영 P05)** — 조회 범위 밖 부서의 참석자 이름은 «#번호»로, 서명부는 «제출됨»으로만 보이고 열 수 없다. 취소·정정 수단도 내지 않는다. 그 부서와 재난안전과·총괄 책임자는 그대로 본다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 종료 전 [등록 취소] | 아직 완료되지 않은 등록부를 회수한다 | “(부서) 등록부를 취소했습니다” |
| 완료 후 [이수 기록 정정] | 사유 입력 후 원래 등록부를 «정정됨»으로 보존하고 그 부서 이수기록을 집계 제외 | “(부서) 이수 기록을 정정했습니다 — 바른 명단은 [＋ 정정 등록부 올리기]로 올립니다.” |
| 등록 내역이 없는 부서에 취소 시도 | 아무것도 지우지 않고 알린다 | “등록 내역이 없습니다” |
| 결재가 올라간 교육에서 [등록 취소] | 수단을 잠금 표시로 바꾸고 사유를 낸다 | “결재 (상태) — 이수자 명단이 공문 붙임으로 올라가 있어 취소할 수 없습니다. 반려 후 다시 시도하세요” |

- 상태: 활성 등록부는 **0건 / 있음**, 과거 정정행은 **등록취소**로 구분한다. 0건이어도 종료 처리는 가능하다. 완료 후 정정은 원행을 보존하고 이수기록만 집계에서 제외하며, 같은 부서를 다시 등록할 수 있다. **공문을 보낸 뒤에는 정정도 잠긴다**(§4-5).

### 4-4. 교육 종료 처리
- 교육이 끝난 뒤에만 할 수 있다. 등록 기한이 지나면 재난안전과가 종료한다.
- 등록 부서·인원과 등록부별 실제 참석시간을 확인창에 표시한다. 등록 기한 전이면 그 사실을 함께 밝힌다.
- 종료 후 등록한 사람에게 각 등록부의 실제 참석시간을 기록하고 교육 상태를 완료로 바꾼다.
- 등록이 0명인 경우도 종료 버튼과 확인창을 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [교육 종료 처리] | 등록 부서·인원과 실제 참석시간 반영 원칙을 확인창에 표시한다 | 등록이 0명이어도 열린다 |
| 확인창에서 실행 | 등록한 사람에게 등록부별 실제 참석시간을 기록하고 완료로 바꾼다 | “교육 종료 · N명 카운트 완료” |

- 상태: **등록부 받는 중**에서만 나타나며 한 번 종료하면 원 완료기록을 직접 수정하지 않는다. **등록이 0명이어도 종료할 수 있다**. 종료하면 사람마다 해당 등록부의 실제 참석시간이 기록된다.

### 4-5. 공문 기안

- 종료 처리가 끝난 교육에만 **[공문 기안]**이 나타난다. 진행 중인 교육의 실시 결과를 보고할 수 없기 때문이며, 종료 처리와 공문은 **끝내고 → 보고한다**는 한 방향이다. 되돌리는 순서는 없다.
- [온나라로 보내기]는 이 화면이 아니라 **문서 미리보기**에만 있다. 기안 화면에서 곧바로 보내는 수단을 만들지 않는다. 결재선은 받지 않는다 — 온나라 기안함까지만 보내고 검토·결재는 담당자가 온나라에서 지정한다(2026-11-12).
- 붙임 후보는 **이미 올려 둔 파일**이다 — 이 교육에 올려 둔 첨부(집합교육은 **참석자 명단·교육 자료**)와, 부서가 참석자 등록부에 올린 **서명파일**이 부서별로 나열된다. 담당자가 고른 것만 붙임에 오른다. 여기서 파일을 새로 받지 않는다.
- 이수자 명단은 파일이 아니라 **붙임 별지**로 만든다 — 부서·이름·이수시간을 표로 붙인다. 사람이 따로 만들어 올리던 것을 시스템이 대신 짠다. 보내면 별지는 **PDF 파일로 만들어 붙임으로** 나간다 — 지면에 «붙임»으로 적은 것은 실제로 붙어 나가야 하기 때문이다(2026-10-07).
- **붙임 한도는 고르는 단계에서 검사한다(2026-10-07)** — 온나라 확인 전 설정값은 파일당 10MB · 5개 · 합계 30MB이고 별지 PDF도 함께 센다. 참석 부서가 많으면 서명파일만으로 개수를 넘을 수 있다 — 그때는 담당자가 고르고, 자동으로 묶거나 조용히 빼지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [공문 기안] | 이 교육 1건의 실시 결과 공문 작성을 연다 | 종료 처리 전에는 버튼 대신 “교육을 종료 처리한 뒤 기안할 수 있습니다”를 보인다(기안할 수 있는 사람에게만). 기안·미리보기·확인·보내기 네 경로가 같은 조건을 다시 본다(2026-11-05 운영 23건 #1) |
| 붙임 목록 | 교육 첨부와 부서별 서명파일을 나열한다 | 부서명과 함께 어느 부서 것인지 밝힌다 |
| 붙임 체크 | 체크한 파일이 붙임에 오른다 | 체크를 풀면 내려간다. 한도를 넘는 파일은 체크할 수 없고 사유를 밝힌다("온나라 붙임 한도(파일당 10MB) 초과 — 시스템에는 남아 있고 공문에는 붙지 않습니다") |
| 붙임 개수·합계 초과 | 미리보기의 [온나라로 보내기]를 비활성으로 두고 무엇을 줄일지 밝힌다 | 목록 아래에 “붙임 n / 5개 · 합계 n / 30MB”만 늘 보인다(합계는 고른 파일의 크기를 모두 알 때만) |
| 이수자 명단 체크 | 부서·이름·이수시간·이수일 표를 별지로 만든다 | 인원 수를 함께 표시한다 |
| [문서 미리보기 →] | 공문 지면을 연다 | 이 화면에는 보내기 수단이 없다. 지면 수신은 «내부결재», 서명란은 기안자만 |
| 공문을 보낸 교육 | 기안 수단 대신 [문서 보기]와 상태 배지(«기안함 전송» 등)를 낸다 | 기안한 사람에게는 «온나라 기안함에서 검토·결재를 지정해 상신하세요»를 함께 보인다. 반려·반송·결재완료는 온나라 회신으로만 생기므로 연동 전에는 재기안 경로가 없다. 회신이 붙으면 그대로 반영한다 |
| 반려·반송 회신 | 잠금이 풀리고 [공문 기안]이 다시 나타난다 | 반려 사유·반송 사유(온나라가 보낸 문장 그대로)를 함께 보이고 기안자에게 알린다 |

- 상태: 이 영역은 **종료 전**(수단 없음) · **기안 전** · **기안됨** · **기안함 전송** 넷이다. 보낸 뒤에는 이 교육의 **수정·삭제·참석자 등록부 취소 셋이 모두** 잠긴다 — 공문에 붙어 나간 기록을 뒤에서 바꾸는 것은 문서 위조이기 때문이다. 세 수단을 각각 판정하지 않고 **공문 상태(기안함 전송·결재중·결재완료) 한 곳에서만** 판정한다. 반려되거나 온나라가 접수하지 않으면(반송) 잠금이 풀리지만, 둘 다 온나라 회신으로만 생기므로 **연동 전에는 도달할 수 없는 상태**다.

### 4-6. 이력
- 교육 등록, 참석자 등록부 등록, 등록 취소와 종료 처리를 일자·유형·처리자와 함께 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 등록·취소·종료 발생 | 그 사실이 이력에 자동으로 쌓인다 | 사용자가 직접 쓰는 항목은 없다 |

- 상태: 이력은 비는 경우가 없다(교육을 만든 순간 등록 이력이 남는다). 조회 전용이며 이 화면에서 고치거나 지울 수 없다. 등록·참석자 등록부·등록 취소·종료가 유형으로 구분되어 시간순으로 쌓인다.

## 6. 정책

- **실제 참석시간은 사람별이다 (2026-11-13 실습 검수)** — 등록부·일괄 등록 모두 «모두에게 같은 시간»(비우면 전 회차) 하나와 «사람별로 다르게 적기»(일찍 나가거나 늦게 온 사람만)를 둔다. 0보다 크고 회차 합계 이하만 저장한다. 종료 뒤 잘못 올린 등록부는 [이수 기록 정정]으로 거두고 [＋ 정정 등록부 올리기]로 다시 올린다 — 실시 결과 공문을 보내기 전까지만. 서명부 칸은 한 파일(«최대 1개»)이다.

- 상세 화면은 집합교육에만 사용하며 자체교육 상세는 목록의 인라인 상세로 제공한다.
- **등록부는 교육이 끝난 뒤 등록 기한 안에 받는다(2026-11-12)** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 등록 기한은 집합교육을 등록할 때 «마지막 회차 뒤 N일»(1~30일, 기본 7일)로 정하고, 부서 내 할일 카드는 교육이 끝난 날 생겨 이 기한을 단다. 07-16 «신청 = 참석 증빙 한 단계» 결정(사전 신청·불참자 처리 없음)은 그대로다.
- 교육 종료는 참석자 등록부의 실제 참석시간을 각 등록자에게 반영한다. 예정시간을 일괄 인정하지 않는다. **이 규칙이 집합교육 인정시간의 정본이다(2026-10-06 기획확인 4차 확정)** — 정기교육 목록 정의서(SCR-EDU-001 §6)의 «합계시간을 신청자 전원에게 반영»은 이 규칙으로 정정했다.
- **교육 정보(회차)를 고쳐도 등록부 참석시간은 바꾸지 않는다** — 종료 뒤에도 공문을 보내기 전에는 정기교육 목록에서 회차를 고칠 수 있으나, 적어 둔 참석시간은 그대로 두고 참석시간을 따로 적지 않은 등록부만 새 합계를 따른다. 합계를 참석시간보다 작게 줄이려면 그 등록부를 먼저 정정한다(아래).
- 완료기록은 불변이다. 정정은 원행을 `등록취소`로 보존하고 사유·처리자·시각을 남긴 뒤 새 등록부를 등록하는 방식으로만 한다.
- **일괄 등록은 재난안전과 담당자만 하고, 그 줄의 정정도 재난안전과만 한다(2026-11-11)** — 서명부 한 파일을 여러 부서 줄이 함께 가리킨다. 공문 붙임 후보에는 같은 파일이 한 번만 나온다.
- **처리 주체** — 교육 종료 처리는 그 교육을 연 재난안전과 담당자가 한다. 참석자 등록부 등록·등록 취소·완료기록 정정은 **그 부서의 담당자**(재난안전과 담당자는 전 부서 — 다른 부서 몫을 올리면 «대리 등록»으로 남는다)가 하고, 다른 부서 행에는 취소·정정 수단이 나타나지 않는다. 관리·감독 계층은 조회만 한다. 처리자는 실제 접속자로 남는다.
- 완료 후 교육 자체의 수정·삭제는 정기교육 목록에서 수행한다.
- **다른 부서 참석자 정보는 조회 범위를 따른다(2026-11-05 운영 P05)** — 등록 현황은 전 부서 줄을 한 표로 보이되, 범위 밖 부서의 이름과 서명등록부(이름·서명이 있다)는 가린다. 근로자 명단·채용시교육 목록이 범위를 좁힌 것과 같은 근거이고, 판정은 조회 범위 한 곳이다.
- **보내기 수단은 이 화면에 두지 않는다** — 공문 기안은 §4-5에서 시작하고 [온나라로 보내기]는 문서 미리보기에만 있다. 이 순서를 건너뛰는 진입점을 만들지 않는다.
- **결재선을 받지 않는다 (2026-11-12)** — 운영 결정(2026-11-06 «온나라로 기안까지만»)을 교육 공문에도 적용했다(흐름전환 v2 E-4 · 정본 SCR-EDU-001 §6). 종전 «3단계 결재선 지정»은 대체했다.
- **한 부서는 한 번만 등록한다** — 이미 등록한 부서의 재등록을 막고, 인원·서명부 정정은 등록 취소 후 재등록으로 처리한다. **등록 취소(정정)된 등록부는 «이미 등록한 부서»로 세지 않는다** — 세면 정정한 부서가 영영 다시 등록하지 못해 정정 경로가 막다른 길이 된다. 두 번 쌓이면 그 부서 인원의 이수기록이 이중으로 붙어 이수 판정과 공문 붙임 별지의 인원이 함께 부풀고, 등록은 행 단위인데 취소는 부서 단위라 되돌리는 단위까지 어긋난다.
- 프로토타입도 실제 참석시간 입력과 완료기록 취소이력 보존 UX를 제공한다. 본개발은 같은 상태 계약을 영속 저장하고, 취소행은 이수율 분모·분자 계산에서 제외하되 감사 조회에는 계속 포함한다.
