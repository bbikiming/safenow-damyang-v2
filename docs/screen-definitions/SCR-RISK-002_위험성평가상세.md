## 4. 화면 구성별 정리

### 4-1. 이동 동작
- 유효한 평가 식별값은 해당 연도를 포함한 정기 위험성평가 주소로 바꾼다.
- 업무 콘텐츠, 입력 폼이나 독립 상세 레이아웃을 표시하지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 유효한 평가 식별값으로 진입 | 그 평가의 연도를 붙여 정기 위험성평가로 보낸다 | rsk-list.html?year= |
| 식별값이 없거나 유효하지 않음 | 연도 없이 정기 위험성평가로 보낸다 | rsk-list.html |
| 이동 완료 | 이 주소에는 아무 내용도 남기지 않는다 | 뒤로 가기 시 원래 화면으로 돌아간다 |

- 상태: 이 주소는 화면이 아니라 **경유지**라 표시 상태를 갖지 않는다. 갈래는 **식별값 유효**(연도를 붙여 이동)와 **식별값 없음·무효**(연도 없이 이동) 둘이고, 어느 쪽이든 이 주소에 머무르지 않는다. 빈 상태·로딩·오류 화면을 두지 않는 것이 의도다 — 잠깐 보였다 사라지는 안내는 읽히지 않고, 이동 실패는 곧 목록 화면이 대신 받는다. 이 파일이 남아 있는 이유는 기존 링크·즐겨찾기를 끊지 않기 위해서다.

## 5. 유효성 검사

- 사용자 입력은 없다.
- 유효하지 않은 식별값은 정기 위험성평가 기본 화면으로 복구한다.

## 6. 정책

- 신규 메뉴와 신규 링크의 목적지로 사용하지 않는다.
