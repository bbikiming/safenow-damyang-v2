# 화면 정의서 — 보고서·제증명

> 화면 ID: SCR-RPT-002 · 화면 유형: 출력 · 기획 관점(v6) · 구현 정합 2026-08-12
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.

## 1. 화면 정보

| 항목 | 내용 |

| 화면 유형 | 출력 |

시스템에 쌓인 이행 기록을 **밖으로 낼 수 있는 문서 형태**로 만드는 화면이다. 안전보건 이행은 감사·점검·의회 요구처럼 시스템 밖에서 증명해야 하는 일이 생기는데, 그때마다 여러 화면을 옮겨 다니며 손으로 옮겨 적으면 옮기는 과정에서 틀린다. 구성은 보고서 미리보기와 출력 이력 두 덩어리이며, 수치는 모두 각 업무 자료에서 파생한다.

---

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 보고서 계열의 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- **증명서 계열은 다르다** — `개인 안전보건교육 이수 확인서`는 특정 개인의 이수 내역을 담으므로 **개인 이수이력 열람 범위**(본인 / 소속 부서장·부서 담당자 / 주관부서·군수)를 그대로 따른다. **발급은 열람보다 강한 행위이므로 범위가 열람보다 넓을 수 없다.**
- 출력한 문서는 **밖으로 나가는 자료**라 누가 언제 뽑았는지가 이력에 남는다(§6).

| 진입 | 교육 이수현황(SCR-EDU-005) | 대상자를 지정해 개인 이수 확인서를 발급할 때 (**미구현 — 잔여 후속**) |
| 이탈 | 각 업무 화면 | 수치의 근거를 확인할 때 |

|:--:|---|---|

### 분기 로직

- **보고서 종류가 내용을 정한다** — 총괄보고서는 기간의 이행 전반을, 제증명은 특정 사실 하나를 증명한다.
- **개인 안전보건교육 이수 확인서도 이 화면이 발급한다** — 한 사람의 이수 내역은 결재를 태울 사안이 아니라 증명 발급이다. 지면 자체가 증명이라 별도 붙임을 두지 않는다. 교육 이수현황(SCR-EDU-005)에서 대상자 행으로 넘어오는 경로가 설계상 짝이지만 **아직 양쪽 다 미구현**이라, 현재는 이 화면에서 서식을 직접 골라 발급한다. 앞은 여러 축을 모으고 뒤는 한 축만 확인한다.
- **대상 기간이 수치를 정한다** — 반기·연간처럼 기간을 고르면 그 기간의 자료로 다시 계산한다. 기간을 바꿨는데 수치가 그대로면 어느 기간의 값인지 알 수 없다.
- **수치는 파생값이지 입력값이 아니다** — 보고서에 들어가는 숫자를 여기서 고칠 수 없다. 고칠 수 있으면 그것은 보고서가 아니라 작문이다.
- **미리보기와 출력물이 같아야 한다** — 화면에서 본 것과 나간 것이 다르면 미리보기가 의미를 잃는다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 조회 범위 밖 대상자의 확인서 발급 시도 | 발급하지 않고 사유를 알린다 — 발급 범위는 개인 이수이력 열람 범위를 넘을 수 없다 |
| 증명서 계열에서 결재를 올리려 함 | 수단 자체가 없다. 전역 경로로 시도해도 거절하고 이유를 알린다 |
| 대상 기간에 자료가 없음 | 0으로 채우지 않고 **자료 없음**으로 표시한다 — 0건과 기록이 없는 것은 다르다 |
| 일부 축만 자료가 있음 | 있는 축은 수치로, 없는 축은 자료 없음으로 표시한다 — 없는 축을 빼면 무엇이 빠졌는지 모른다 |
| 아직 확정되지 않은 문서가 섞임 | 확정 기준을 밝히고 그에 맞는 것만 센다 |
| 담양군 고유 기관정보가 아직 없음 | 지면에 **미등록**으로 표시한다 — 빈칸으로 두면 값이 없는 것인지 안 넣은 것인지 모른다 |
| 출력 실행 | 누가 언제 무엇을 뽑았는지 이력에 남긴다 |
| 프로토타입에서 출력 | 실제 파일이 만들어지지 않는다는 사실을 밝힌다 |

## 4. 화면 구성별 정리

### 4-1. 보고서 미리보기

- 구성: 서식 종류·대상 기간 선택 + 지면 형태의 미리보기.
- **서식은 두 계열이고 지면 구성이 다르다.**
  - **보고서 계열**(총괄 · 의무이행 점검 결과 · 위험성평가 결과 · 안전보건교육 실적 · 개선조치 현황) — 기간 단위 집계를 `구분·내용` 표로 싣는다. 제목은 `{기간} 중대재해예방 {서식명}`이다.
  - **증명서 계열**(개인 안전보건교육 이수 확인서 · 이행사실 확인서) — 대상이 기간이 아니라 **사람 또는 사실**이라 집계 표를 쓰지 않는다. 제목에 `중대재해예방` 접두를 붙이지 않는다 — 붙이면 문장이 성립하지 않는다.
  - 개인 이수 확인서 지면 항목: 대상자·소속·구분(사무/판매/현업/관리감독자)·대상 사이클·필요시간·인정시간·미달시간·판정·발급일·발급기관.
- **증명서 계열에는 결재 수단을 두지 않는다** — 증명 발급은 신청인에게 내주는 행위이지 내부 의사결정이 아니다. 서식을 증명서로 바꾸면 결재 수단이 화면에서 사라진다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 서식 종류 선택 | 그 계열의 지면 구성으로 바꾼다 | 보고서 계열과 증명서 계열은 지면·제목 조립이 다르다 |
| [PDF 출력] | 지면 그대로 파일로 낸다 | 전 서식에 나타난다 |
| [온나라 결재] | 그 보고서의 결재 상신을 연다 | **보고서 계열에만 나타난다** — 증명서 계열에서는 수단 자체를 내지 않는다 |
| 대상자를 지정해 들어옴 | 개인 이수 확인서로 서식을 고정하고 그 대상자의 지면을 그린다 | 대상자 없이 이 서식을 고르면 대상자를 먼저 고르게 한다 (**미구현 — 잔여 후속**) |
| 대상 기간 선택 | 그 기간의 수치로 다시 계산한다 | 수치는 업무 자료에서 파생한다 |
| 수치를 고치려 함 | 고칠 수 없다 | 근거는 각 업무 화면에서 바꾼다 |
| 자료가 없는 항목 | 자료 없음으로 표시한다 | 0으로 채우지 않는다 |
| [출력] | 지면 그대로 낸다 | 미리보기와 다르지 않다 |

- 상태: **자료 있음 / 일부 있음 / 없음** 세 가지다. 담양군 고유 기관정보가 비어 있으면 그 자리를 미등록으로 표시한다. 계열 축은 **보고서 / 증명서** 둘이며 계열이 지면 구성·제목 조립·결재 수단 노출을 함께 정한다. 대상 기간의 종료일은 **기준일(오늘)을 넘길 수 없다** — 아직 오지 않은 기간의 실적을 밖으로 낼 수 없다.

### 4-2. 출력 이력

- 구성: 보고서 · 출력일 · 출력자 세 열.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 출력 실행 | 이력에 한 줄을 남긴다 | 누가 언제 무엇을 뽑았는지 |
| 화면 진입 | 최근 출력을 최신 순으로 보여 준다 | — |
| 이력이 0건 | 아직 출력이 없음을 표시한다 | — |

- 상태: **없음 / 있음** 둘이며 조회 전용이다. 고치거나 지울 수 없다 — 밖으로 나간 자료의 기록이기 때문이다.

## 6. 정책

- **수치를 이 화면에서 고칠 수 없다** — 보고서에 들어가는 숫자는 업무 자료에서 파생한다. 고칠 수 있으면 그것은 보고서가 아니라 작문이고, 밖으로 나간 뒤 근거를 대지 못한다.
- **미리보기와 출력물을 같게 한다** — 다르면 미리보기가 의미를 잃고, 무엇이 나갔는지 확인할 방법이 없다.
- **자료 없음을 0으로 채우지 않는다** — 0건인 것과 기록이 없는 것은 다르다. 특히 밖으로 나가는 문서에서 이 둘을 섞으면 "안 했다"와 "기록이 없다"가 구분되지 않는다.
- **없는 축을 빼지 않는다** — 자료가 없는 축도 지면에 남기고 자료 없음으로 표시한다. 빼면 무엇이 빠졌는지 알 수 없다.
- **출력 이력을 남기고 지우지 않는다** — 밖으로 나간 자료라 누가 언제 뽑았는지가 사후에 문제가 됐을 때 근거가 된다.
- **담양군 고유값의 공백을 드러낸다** — 기관정보가 아직 없으면 미등록으로 표시한다. 빈칸으로 두면 값이 없는 것인지 안 넣은 것인지 모른다.
- **법령 근거를 붙이지 않는다** — 보고서 출력은 이행 결과를 밖으로 내는 형식이지 그 자체가 법령이 명한 의무의 직접 이행 수단이 아니다. 근거는 보고서가 담는 **각 업무**에 있으며, 규칙은 공통 근거 연계(SCR-COM-008)를 따른다.
  - ⚠ **현행 매핑과 어긋나 있다** — 근거 매핑 정본이 이 화면에 산업안전보건법 제15조(안전보건관리책임자의 업무)를 붙여 두고 있는데, 그 조문이 정하는 것은 보고서 출력이 아니라 책임자의 업무 범위다. 검증 기준(“관련이 있다”가 아니라 “그 의무의 직접 이행 수단인가”)을 통과하지 못하므로 **근거 없음으로 정정하는 것이 맞다.** 매핑은 생성물이라 화면에서 고치지 않고 재생성으로 반영한다.
- **증명서 계열에는 결재 절차를 두지 않는다** — 증명 발급은 신청인에게 내주는 행위이지 내부 의사결정이 아니다. 화면에 결재 수단을 두면 담당자가 증명서를 결재에 올리려다 막히는 길이 생긴다.
- **날짜는 장식이 아니라 내용이다** — 발급일과 기간 상한은 시연 기준일에서 파생한다. 지면에 날짜를 고정값으로 박아 두면 기준일이 바뀌는 순간 증명서가 거짓을 말한다.

## 7. 미결사항

없음. 보고서 종류·대상 기간 선택, 수치의 편집 불가·미리보기와 출력물의 일치·자료 없음의 표시·빈 축 처리·출력 이력의 보관·고유값 공백 표시·법령 근거의 위치는 모두 §4·§6에서 확정했다. 프로토타입은 조건 변경 UX를 제공하며 실제 파일·결재 생성 없이 시연임을 알린다.

**담양군 기관정보**는 이 화면의 미결이 아니라 담양군이 제공할 자료이며, 그때까지 지면에 미등록으로 드러낸다.
