## 3. 진입 / 이탈 경로 및 사용자 시나리오

> **이 화면은 폐지됐다** — 현행 메뉴에 노출되지 않으며 파일만 보존한다. 아래는 폐지 시점의 동작 기록이다.

**진입 / 이탈**

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 위험성평가 상세(rsk-detail.html) | 공정 행 선택 |
| 진입 | 담당 공정 평가 요청 안내 | 담당 평가자 |
| 이탈 | 위험성평가 상세 | 임시저장·완료 후 |
| 이탈 | 개선조치 목록(rsk-imp.html) | 감소대책 배정 확인 |

**사용자 시나리오**

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 추정 기법을 고른다 | 척도·등급 기준이 기법에 맞게 바뀐다 |
| 2 | 요인별 빈도·강도를 입력한다 | 위험성 등급과 허용/허용초과가 즉시 색으로 표시된다 |
| 3 | 허용초과 요인에 [대책 입력]을 누른다 | 대책·담당자·기한·조치 전 사진 입력 패널을 펼친다 |
| 4 | [이 공정 평가 완료]를 누른다 | 입력·대책 충족을 확인하고 잠금 상태로 전환 |
| 5 | 조치 완료 후 [재평가]를 누른다 | 조치 후 상태로 재추정한다 |

**분기 로직**

- **고른 추정 기법이 척도와 등급 기준을 결정한다** — 기법을 바꾸면 입력 항목과 등급 판정 기준이 함께 바뀐다. 체크리스트 계열은 빈도·강도 대신 항목 판정으로 입력 형태가 달라진다.
- **허용 여부가 후속 입력을 가른다** — 위험성이 허용 범위를 넘는 요인에만 감소대책 입력 패널이 열리고, 허용 범위 안의 요인은 판정만 남기고 대책을 요구하지 않는다.
- **평가 완료는 대책이 채워져야 열린다** — 허용초과 요인에 담당자가 지정되지 않으면 완료로 넘어가지 않고 담당자를 고르라고 알린다.
- **완료 후에는 잠기고, 재평가로만 다시 연다** — 조치가 끝난 뒤 [재평가]로 들어가면 조치 후 상태를 다시 추정하는 별도 회차가 된다.
- **감소대책은 이 화면에서 끝나지 않는다** — 완료 시 각 대책이 개선조치로 넘어가 담당자에게 배정된다.

**엣지케이스**

- **대상을 찾을 수 없으면** 화면에 값을 그리지 않고 대상 없음을 표시한다.
- **불러올 요인이 없으면** 앞 단계인 작업공정 관리에서 요인을 먼저 정리해야 한다 — 이 화면은 요인을 새로 만들지 않고 넘겨받는다.
- **임시저장은 판정이 덜 끝나도 가능하다** — 완료와 달리 충족 검사를 하지 않는다.
- **사진 업로드는 안내만 표시한다** — 실제 파일이 붙지 않는다.
- **폐지 이후 이 주소로 직접 들어오면** 화면은 그려지지만 메뉴에서는 도달할 수 없다. 현행은 용역 보고서를 첨부하고 지적사항을 옮겨 적는 방식(SCR-RISK-001)으로 대체됐다.

## 4. 화면 구성별 정리

### 4-1. 헤더·기법 선택
- 구성: 공정명·담당 평가자·평가명, 추정 기법 선택(빈도·강도 / 3단계 판단법 / 체크리스트법).
- 상태: 완료 잠금 상태에서는 기법·입력이 비활성이며 보기 모드로 전환된다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 그 공정의 평가명·담당 평가자를 표시하고 기본 기법을 고른 상태로 연다 | — |
| 추정 기법 변경 | 표의 입력 칸 구성을 그 기법에 맞게 바꾼다 | 이미 입력한 값이 있으면 무엇이 비워지는지 밝힌다 |
| 완료된 평가로 진입 | 기법 선택과 입력을 잠그고 보기 모드로 연다 | 고치려면 재평가를 거친다 |

- 상태: 단계상태는 **작성 전 → 작성 중 → 완료(잠김) → 재평가 중**이다. 완료 상태에서는 기법·입력이 모두 비활성이고 보기 모드로 전환되며, 되돌리는 유일한 경로가 재평가다. 담당 평가자가 지정되지 않은 공정으로 들어오면 그 사실을 표시하되 작성 자체는 막지 않는다.

### 4-2. 유해위험요인 추정 표
- 구성: 유해위험요인(자동 호출)·법령근거, 빈도·강도(또는 판정), 위험성 등급, 허용 여부, 감소대책.
- 이벤트:

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 빈도·강도 입력 | 등급·허용 여부를 즉시 산정·표시 | 색으로 허용/허용초과 구분 |
| 허용초과 [대책 입력] | 감소대책 입력 패널을 펼친다 | 카드 안 인라인, 적층 팝업 없음 |

- 상태: 행 단위 상태는 **미입력 → 입력됨(허용) / 입력됨(허용초과)**이며, 허용초과 행에만 감소대책 입력 수단이 나타난다. 표가 비는 경우는 **그 공정에 유해위험요인이 하나도 구성되지 않았을 때**이고, 이때는 작업공정 관리(SCR-PRC-001)에서 먼저 구성하도록 안내한다 — 이 화면이 요인을 만들지는 않는다. 법령 근거가 없는 요인은 '법령 매핑 대기'로 표시되며 이는 오류가 아니다.

### 4-3. 감소대책 입력(허용초과 시)
- 구성: 대책 내용(표준안 자동 채움), 담당자, 조치 기한, 조치 전 사진.
- 이벤트:

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [개선조치 생성] | 감소대책을 개선조치로 배정 | "감소대책이 개선조치로 배정되었습니다" |

- 상태: **허용초과 행에서만** 나타난다. 입력 단계는 **미작성 → 작성 중 → 개선조치 생성됨**이고, 생성된 뒤에는 이 패널이 조회 형태로 바뀐다. 담당자·기한·조치 전 사진이 비어 있는 것은 정상 시작 상태이며, 이후 개선조치 화면(SCR-IMP-002)에서 채워진다.

### 4-4. 완료·재평가
- 구성: [임시저장]·[이 공정 평가 완료], 조치 후 [재평가].
- 이벤트:

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [이 공정 평가 완료] | 입력·대책 충족 확인 후 잠금 | 미충족 시 부족 항목 안내 |
| [재평가] | 조치 후 상태로 재추정 시작 | 허용이면 종결, 허용초과이면 추가 대책 |

---

- 상태: **완료 불가**(허용초과 행에 감소대책이 없음)와 **완료 가능**이 갈리며, 불가일 때 무엇이 부족한지 항목으로 알린다. 완료하면 잠기고, 조치가 끝난 뒤 재평가를 시작하면 **재평가 중**으로 풀린다. 재평가 결과가 허용이면 종결하고 허용초과면 추가 대책을 받는다 — 즉 이 화면은 한 번으로 끝나지 않고 순환한다.

## 6. 정책

- **자동 호출:** 작업공정에서 정리한 유해위험요인을 그대로 불러오며 재입력하지 않는다.
- **기법·허용기준:** 추정 기법과 허용기준은 설정에서 관리하며, 평가 실시 시 전환할 수 있다. (근거: 위험성평가 고시)
- **허용초과 처리:** 허용초과 항목은 감소대책 입력이 있어야 평가를 완료할 수 있고, 감소대책은 개선조치로 일원화된다.
- **조치 후 재평가:** 조치 완료 후 동일 요인을 재추정해 허용 여부를 재확인하며, 이력은 보존한다. (근거: 산업안전보건법 제36조)
