|---|---|---|

|:--:|---|---|

### 분기 로직

- **원료와 제조물은 성격이 다르다** — 원료는 **들여와 쓰는 것**이고 제조물은 **만들어 내보내는 것**이다. 위험이 미치는 대상이 각각 종사자 쪽과 이용자 쪽으로 갈리므로 구분을 반드시 받는다.
- **안전자료는 세 상태다** — 보유 / 미보유 / 해당 없음. 제조물에 물질안전보건자료가 적용되지 않을 수 있으므로 미보유와 해당 없음을 합치지 않고, 해당 없음에는 사유를 받는다.
- **사용처가 소관을 정한다** — 어느 부서가 그 품목을 다루는지가 정해져야 점검·교육의 대상 부서가 나온다.
- **이 화면은 판정하지 않는다** — 공중이용시설 탭과 달리 규모 기준으로 자동 판정할 대상이 아니다. 무엇을 관리대상으로 볼지는 담양군이 확정한다(§6).

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 품목이 0건 | 등록을 안내한다. **0건이 "해당 없음"을 뜻하지 않는다** — 확인해서 없는 것과 아직 안 넣은 것을 구분해 밝힌다 |
| 안전자료가 없는 품목 | 미보유로 드러낸다 — 감추지 않는다. 자료 없이 취급 중이라는 사실 자체가 위험 신호다 |
| 안전자료 해당 없음 | 사유를 함께 표시한다 — 비어 있는 것을 해당 없음으로 간주하지 않는다 |
| 사용처가 비어 있음 | 미확보로 표시한다 — 소관을 모르면 점검 대상도 정해지지 않는다 |
| 원료인지 제조물인지 애매한 품목 | 구분을 비워 두지 않고 판단해 넣는다. 판단이 어려우면 그 사실을 비고로 남긴다 |
| 같은 품목이 여러 부서에서 쓰임 | 사용처를 여러 곳으로 적는다 — 부서마다 행을 나누면 같은 품목이 여러 건으로 세어진다 |

## 4. 화면 구성별 정리

### 4-1. 축 탭

- 구성: 사업장 · 공중이용시설 · 원료·제조물 세 탭. 이 탭에는 등록 건수를 붙인다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 그 축의 목록으로 바꾼다 | 축마다 표 구성이 다르다 |
| 건수 표시 | 등록된 품목 수를 보여 준다 | 확정 여부와 등록 수는 다른 개념이다 |

- 상태: 세 축의 확정 방식이 달라 같은 형식의 수치로 나란히 두지 않는다. 이 탭은 **등록 건수**를 보여 준다.

### 4-2. 원료·제조물 목록

- 구성: 품목 · 구분(원료/제조물) · 사용처 · 안전자료 · 운영 상태 · 관리 여섯 열.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 등록된 품목을 표로 보여 준다 | — |
| [+ 등록] | 품목 등록 입력을 연다 | 개별 등록 |
| [수정] | 기존 식별값을 유지한 채 등록 폼을 연다 | 저장 후 목록 즉시 갱신 |
| [사용 중지] | 사유를 필수로 받고 신규 후속 업무에서 제외한다 | 과거 기록과 행은 보존 |
| [다시 사용] | 같은 식별값으로 활성화한다 | 중지 사유는 이력에 보존 |
| 자료 미보유 품목 | 그 사실을 열에 드러낸다 | 감추지 않는다 |
| 사용처가 빈 행 | 미확보로 표시한다 | 소관을 모르면 점검 대상이 안 나온다 |
| 여러 건 등록 | 지금은 개별 등록을 반복한다 | 일괄등록 서식은 관리대상이 확정된 뒤 만든다(SCR-BASE-004 §6) |

- 상태: 품목별로 **보유 / 미보유 / 해당 없음** 안전자료 상태와 **사용 중 / 사용 중지** 운영 상태가 독립적으로 표시된다. 목록이 비면 등록을 안내하되 "해당 없음"으로 단정하지 않는다.

## 6. 정책

- **0건을 "해당 없음"으로 단정하지 않는다** — 확인해서 없는 것과 아직 안 넣은 것은 다르다. 전자라면 그 확인 사실을 남기고, 후자라면 등록을 안내한다. 이 구분이 없으면 관리대상이 비어 있는 이유를 아무도 설명할 수 없다.
- **원료와 제조물을 반드시 구분한다** — 위험이 미치는 대상이 다르다. 구분이 비면 후속 업무의 대상도 정해지지 않는다.
- **안전자료의 3상태를 유지한다(BASE-MAT-01 확정)** — 보유는 파일이 있어야 하고, 미보유는 확보 과제이며, 해당 없음은 사유가 있어야 한다. 공란을 해당 없음으로 자동 해석하지 않는다.
- **품목 하나에 행 하나를 유지한다** — 여러 부서가 쓰면 사용처를 여러 곳으로 적는다. 부서마다 행을 나누면 같은 품목이 여러 건으로 세어져 관리대상 수가 부풀려진다.
- **이 탭이 품목 대장의 단일 출처다(BASE-MAT-02 확정)** — 별도 대장을 만들지 않고 등록·수정·사용 중지를 이 탭에서 수행한다. 삭제하지 않고 중지 사유를 남긴다.
- **이 화면이 법 적용 여부를 자동 판정하지 않는다** — 공중이용시설과 달리 규모 기준 하나로 가릴 수 있는 축이 아니다. 담양군의 생산·판매·유통·관리 실태 자료(EXT-10)로 적용 대상을 확인하며, 자료 미수신 동안 등록된 품목은 `확인 전 자료`임을 밝힌다.
- **일괄등록은 닫고 개별 등록만 둔다(BASE-MAT-03 확정)** — 대상 실목록과 표준 컬럼의 운영 검증 전에는 서식을 배포하지 않는다. 일괄등록 화면에는 제외 사유와 이 탭으로 오는 대체 경로만 표시한다.
- **조회 범위는 사업장 탭과 같은 값을 쓴다** — 같은 화면의 탭이 서로 다른 범위로 보이면 어느 쪽이 실제 현황인지 알 수 없다.
- **법령 근거 표시** — 중대시민재해 확보의무(법률)와 원료·제조물 관련 안전보건관리체계의 구축 및 이행 조치(시행령)를 함께 붙인다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리한다.

## 7. 미결사항

없음. 0건의 해석·원료와 제조물 구분·안전자료 3상태·품목 단위·단일 출처·수정/사용 중지·일괄등록 제외·조회 범위는 모두 §6에서 확정했다.

**무엇을 관리대상 원료·제조물로 볼지**는 담양군 실제 생산·판매·유통·관리 자료가 필요한 외부 준비사항(EXT-10)이다. 미수신 상태와 입력 경로가 정해져 있어 기능·UX 개발은 가능하다.
