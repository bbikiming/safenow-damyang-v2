- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 기본정보 > 관리대상 현황 | 원료·제조물 탭 선택 |
| 이탈 | 사업장 탭 · 공중이용시설 탭 | 탭 전환 |
| 이탈 | 데이터 일괄등록 | 여러 건을 한 번에 넣을 때(SCR-BASE-004) |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 원료·제조물 탭을 연다 | 등록된 품목을 표로 보여 준다 |
| 2 | 품목을 확인한다 | 품목명·구분·사용처·물질안전보건자료 보유 여부를 본다 |
| 3 | 품목을 등록한다 | 개별 등록 또는 일괄등록으로 넣는다 |

### 분기 로직

- **원료와 제조물은 성격이 다르다** — 원료는 **들여와 쓰는 것**이고 제조물은 **만들어 내보내는 것**이다. 위험이 미치는 대상이 각각 종사자 쪽과 이용자 쪽으로 갈리므로 구분을 반드시 받는다.
- **물질안전보건자료 보유 여부가 후속 업무를 가른다** — 자료가 있어야 취급 주의사항·보호구·응급조치를 알 수 있고, 그것이 교육과 게시 의무의 입력이 된다. 그래서 보유 여부를 단순 참고가 아니라 목록의 한 열로 둔다.
- **사용처가 소관을 정한다** — 어느 부서가 그 품목을 다루는지가 정해져야 점검·교육의 대상 부서가 나온다.
- **이 화면은 판정하지 않는다** — 공중이용시설 탭과 달리 규모 기준으로 자동 판정할 대상이 아니다. 무엇을 관리대상으로 볼지는 담양군이 확정한다(§6).

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 품목이 0건 | 등록을 안내한다. **0건이 "해당 없음"을 뜻하지 않는다** — 확인해서 없는 것과 아직 안 넣은 것을 구분해 밝힌다 |
| 물질안전보건자료가 없는 품목 | 보유 없음으로 드러낸다 — 감추지 않는다. 자료 없이 취급 중이라는 사실 자체가 위험 신호다 |
| 사용처가 비어 있음 | 미확보로 표시한다 — 소관을 모르면 점검 대상도 정해지지 않는다 |
| 원료인지 제조물인지 애매한 품목 | 구분을 비워 두지 않고 판단해 넣는다. 판단이 어려우면 그 사실을 비고로 남긴다 |
| 같은 품목이 여러 부서에서 쓰임 | 사용처를 여러 곳으로 적는다 — 부서마다 행을 나누면 같은 품목이 여러 건으로 세어진다 |

## 4. 화면 구성별 정리

### 4-1. 축 탭

- 구성: 사업장 · 공중이용시설 · 원료·제조물 세 탭. 이 탭에는 등록 건수를 붙인다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 그 축의 목록으로 바꾼다 | 축마다 표 구성이 다르다 |
| 건수 표시 | 등록된 품목 수를 보여 준다 | 확정 여부와 등록 수는 다른 개념이다 |

- 상태: 세 축의 확정 방식이 달라 같은 형식의 수치로 나란히 두지 않는다. 이 탭은 **등록 건수**를 보여 준다.

### 4-2. 원료·제조물 목록

- 구성: 품목 · 구분(원료/제조물) · 사용처 · 물질안전보건자료 · 관리 다섯 열.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 등록된 품목을 표로 보여 준다 | — |
| [+ 등록] | 품목 등록 입력을 연다 | 개별 등록 |
| 자료 미보유 품목 | 그 사실을 열에 드러낸다 | 감추지 않는다 |
| 사용처가 빈 행 | 미확보로 표시한다 | 소관을 모르면 점검 대상이 안 나온다 |
| 여러 건 등록 | 일괄등록으로 넣는다 | SCR-BASE-004 |

- 상태: 품목별로 **정보 완비 / 일부 미확보**가 갈리고, 자료 축으로 **보유 / 미보유**가 덧붙는다. 목록이 비면 등록을 안내하되 "해당 없음"으로 단정하지 않는다.

## 6. 정책

- **0건을 "해당 없음"으로 단정하지 않는다** — 확인해서 없는 것과 아직 안 넣은 것은 다르다. 전자라면 그 확인 사실을 남기고, 후자라면 등록을 안내한다. 이 구분이 없으면 관리대상이 비어 있는 이유를 아무도 설명할 수 없다.
- **원료와 제조물을 반드시 구분한다** — 위험이 미치는 대상이 다르다. 구분이 비면 후속 업무의 대상도 정해지지 않는다.
- **물질안전보건자료 미보유를 드러낸다** — 자료 없이 취급 중이라는 사실 자체가 위험 신호이고, 그것이 다음에 할 일이다.
- **품목 하나에 행 하나를 유지한다** — 여러 부서가 쓰면 사용처를 여러 곳으로 적는다. 부서마다 행을 나누면 같은 품목이 여러 건으로 세어져 관리대상 수가 부풀려진다.
- **이 화면이 관리대상 여부를 판정하지 않는다** — 공중이용시설과 달리 규모 기준으로 가릴 수 있는 축이 아니다. 무엇을 대상으로 볼지는 담양군이 확정하며, 확정 전까지는 등록된 품목을 그대로 보여 준다.
- **조회 범위는 사업장 탭과 같은 값을 쓴다** — 같은 화면의 탭이 서로 다른 범위로 보이면 어느 쪽이 실제 현황인지 알 수 없다.
- **법령 근거 표시** — 중대시민재해 확보의무(법률)와 원료·제조물 관련 안전보건관리체계의 구축 및 이행 조치(시행령)를 함께 붙인다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리한다.

---

## 7. 미결사항

없음. 0건의 해석·원료와 제조물의 구분·자료 미보유 표시·품목 단위·판정 주체·조회 범위는 모두 §6에서 확정했다.

**무엇을 관리대상 원료·제조물로 볼지**는 이 화면의 미결이 아니라 담양군이 확정할 사항이며, 확정 전까지 화면은 등록된 품목을 그대로 보여 준다.
