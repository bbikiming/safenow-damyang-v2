# 99. 미결사항·외부 준비 목록

> 2026-08-12 전 메뉴 기준. 화면별 판단은 각 정의서 §6, 공통 기능은 `_규칙.md`, 초기 권한·열람 범위는 `_공통_권한정의.md`가 정본이다.

## 1. 결론

- **자체 기획으로 소거할 수 있는 미결사항: 0건**
- 법령·업무 논리·화면 간 정합으로 정할 수 있는 기능·UX는 모두 확정했다.
- 남은 것은 담양군 제공 자료와 타 기관 연계 규격뿐이다. 아래 항목은 미수신 상태의 표시·대체 동작까지 정했으므로 **개발 착수 차단 조건이 아니다**.
- 프로토타입의 시연값·목업, 아직 구현되지 않은 서버 처리, 실데이터 부족은 기획 미결로 세지 않는다. 본개발 계약과 현재 상태를 구분해 표시한다.

## 5. 개발 착수 판정

- 기능·UX 구현은 현재 정의서로 착수한다.
- 외부 입력 필드는 값이 없어도 `미등록 / 연계 전 / 판정 불가` 상태로 개발·시험한다.
- 외부 입력이 도착하면 구조를 바꾸지 않고 기관값·명단·코드·접속설정만 교체한다.
- 개발자가 다른 결론이 필요하다고 판단하면 해당 화면 §6의 결론과 근거를 기준으로 변경 요청한다. 화면마다 새 미결 질문을 만들지 않는다.
