# 99. 미결사항 목록 (Outstanding Items)

> 담양군 중대재해예방 시스템 프로토타입-v2 전 화면 코드 분석 기반.
> 각 화면 분석의 `undefinedPolicies`(미확정 정책)와, 개발자가 임의 판단하게 되는 4개 취약영역
> (① 버튼 동작·이동경로 / ② 유효성·오류메시지 / ③ 상태 처리 / ④ 미확정 정책)을 통합했습니다.
> 동일 정책이 여러 화면에 영향을 주는 경우 **하나의 공통 항목**으로 통합하고 영향 범위에 전 화면을 표기했습니다.

## 개요

- **총 미결 항목 수: 25건**
- 카테고리별: 버튼동작 7건 · 유효성 2건 · 상태 4건 · 정책 12건
- **이번 검수 범위:** 위험성평가·개선조치·안전보건교육 12개 현행 화면 정의서는 현재 프로토타입의 기능·UX에 맞춰 정리했으며 문서-구현 불일치와 기획 미결사항은 0건이다. 아래 25건은 다른 화면군 또는 프로젝트 공통 구현의 잔여 목록이다. 법령상 보완 필요사항은 활성 화면 기능과 분리한 참고 문서에서 관리한다.
- **공통 전제(전 화면 동일):** 프로토타입-v2는 빌드/프레임워크 없는 정적 HTML + 전역 IIFE 스크립트(layout.js·common.js·edoc.js 등) 구조이며, 데이터는 대부분 하드코딩 또는 localStorage 목업입니다. 서버/DB·인증·외부 연계가 실제로 구현된 곳은 없습니다.
- **2대 전역 미구현(아래 표에서 POL-01 / POL-02로 통합):**
  1. **입력 유효성 검증 부족** — 다수 기존 화면에 형식·범위·정합성·오류 메시지가 부족하다.
  2. **외부 연계·알림 시뮬레이션** — 온나라/e호조/FMS/조직도/SMS·메일의 실연계가 남아 있다.
- 권한은 시스템 관리의 메뉴 관리·권한 관리에서 운영하도록 확정했으므로 업무 화면 기획 미결사항에서 제외했다. 초기값은 `_공통_권한정의.md`를 따른다.

## 4. 권한 처리 (해소)

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 역할별 권한표와 데이터 열람 범위는 업무 화면별 기획 미결사항으로 관리하지 않는다.
- 업무 상태 전이의 수행 주체는 각 화면 정의서의 사용자 시나리오와 정책을 따른다.

## 우선 처리 권고 (개발 임의판단 위험 Top)

1. **POL-06 데이터 정합성 결함** — data.js 문서에 `status` 필드가 없어 통계 이행표·이행률이 전부 0% 출력. 통계/대시보드 핵심 수치가 무의미한 상태로, 상태 데이터 모델 확정이 시급합니다.
2. **STT-02 / STT-04 비가역 확정 + 온나라 미연동** — 확인 절차 없이 확정 시 데이터가 반영되나 반려·정정 경로가 부족합니다.
3. **BTN-05 상세 식별자 전달** — 일부 행 클릭이 고정 화면으로 이동해 선택한 레코드를 구분하지 못합니다.
4. **VAL-01·03 유효성 부족** — 빈 값·미점검 항목이 있어도 등록·확정되는 기존 화면이 남아 있습니다.
