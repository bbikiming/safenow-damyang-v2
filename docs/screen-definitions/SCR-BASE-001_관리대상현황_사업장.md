### 분기 로직

- **세 축이 탭으로 갈린다** — 사업장(중대산업재해) · 공중이용시설(중대시민재해) · 원료·제조물(중대시민재해)이며, **근거 조문과 확정 방법이 각각 다르다**. 한 탭만 채우면 절반만 관리대상을 정한 것이 된다.
- **사업장 마스터와 조직도를 구분한다** — 부서는 조직 단위이고 사업장은 실제 작업 장소다. 부서 하나가 여러 사업장을 가질 수 있고 임시 현장은 조직도에 없으므로 조직도를 사업장 명단으로 간주하지 않는다.
- **대상 판정은 세 상태다** — 대상 / 비대상 / 검토 중. 비대상은 근거가 있어야 하며 값 없음은 검토 중이다.
- **운영 상태와 대상 판정을 분리한다** — 사용 중지는 더 이상 운영하지 않는다는 뜻이고 비대상은 법정 대상이 아니라는 판단이다. 서로 자동 전환하지 않는다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 소관부서가 비어 있는 사업장 | 목록에 남기고 비어 있음을 드러낸다 — 감추면 아무도 채우지 않는다 |
| 판정 근거가 없는 사업장 | 검토 중으로 표시하고 미등록 근거를 드러낸다 |
| 사용 중지 사업장 | 목록에 남기고 사유를 표시하되 후속 업무의 신규 선택지에서는 제외한다 |
| 사업장이 0건 | 사업장 관리에서 먼저 등록하도록 안내한다 |
| 같은 부서에 같은 이름이 둘 이상 | 마스터 등록 단계에서 막고 이 탭은 중복 없는 결과만 표시한다 |

## 4. 화면 구성별 정리

### 4-1. 축 탭

- 구성: 사업장 · 공중이용시설 · 원료·제조물 세 탭. 각 탭에 건수를 붙인다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 그 축의 목록으로 바꾼다 | 축마다 표 구성이 다르다 |
| 화면 진입 | 사업장 탭을 기본으로 연다 | — |
| 판정이 끝나지 않은 축 | 확정 건수 대신 **판정 전**임을 밝힌다 | 미판정을 확정 건수로 세지 않는다 |

- 상태: 탭마다 **확정 건수** 또는 **판정 전**을 표시한다. 세 축의 성격이 달라 같은 형식의 수치로 나란히 두지 않는다.

### 4-2. 사업장 목록

- 구성: 사업장명 · 구분 · 소관부서 · 대상 판정 · 판정 근거 · 운영 상태 여섯 열.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 등록된 사업장을 표로 보여 준다 | — |
| 판정 근거가 빈 행 | 미등록으로 표시한다 | 검토 중 상태와 함께 표시 |
| 사용 중지 행 | 흐리게 표시하고 사유를 병기한다 | 신규 후속 업무에서는 제외 |
| [사업장 관리] | 등록·판정·정정 화면으로 이동한다 | SCR-ADMIN-009 |

- 상태: 사업장별로 **대상 / 비대상 / 검토 중**과 **운영 중 / 사용 중지**가 독립적으로 표시된다. 탭 건수는 운영 중 사업장만 센다.

## 5. 유효성 검사

이 탭에는 저장형 입력이 없다. 사업장명·부서·구분·대상 판정·판정 근거·사용 중지 사유의 검증은 사업장 관리(SCR-ADMIN-009 §5)를 그대로 적용한다. 이 탭이 별도 검증 규칙을 만들지 않는다.

## 6. 정책

- **세 축을 모두 관리한다** — 중대재해처벌법은 중대산업재해와 중대시민재해 두 갈래이고, 시민재해는 다시 공중이용시설과 원료·제조물로 나뉜다. 한 축만 채우면 절반만 대상을 정한 것이다.
- **사업장 정보의 단일 출처는 사업장 관리다(BASE-BIZ-01 확정)** — 이 탭, 작업환경측정, 건강검진이 같은 식별값을 참조한다. 명칭은 화면마다 복제하지 않고 참조 시점 스냅샷만 업무 기록에 남긴다.
- **사업장과 부서는 별개 엔터티다(BASE-BIZ-02 확정)** — 부서는 조직도에서 선택하는 소관값일 뿐 사업장 자체가 아니다.
- **조회 전용이다(BASE-BIZ-03 확정)** — 등록·정정·사용 중지는 사업장 관리에서만 한다. 두 화면에서 같은 필드를 고치지 않는다.
- **세 상태 판정과 운영 상태를 분리한다(BASE-BIZ-04 확정)** — 검토 중을 비대상으로, 사용 중지를 비대상으로 자동 치환하지 않는다.
- **탭 건수는 운영 중 사업장 수다** — 사용 중지 건은 감사 추적을 위해 목록에는 남기되 탭 건수와 신규 후속 업무 선택지에서 제외한다.
- **조회 범위는 공통 권한 관리가 정한다** — 개별 화면에 역할별 범위를 중복 기재하지 않는다.
- **법령 근거 표시** — 중대산업재해 확보의무(법률)와 중대시민재해 확보의무(법률)를 함께 붙인다. 관리대상은 두 축 모두의 출발점이라 한 축만 붙이면 절반만 근거를 댄 것이 된다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리한다.

## 7. 미결사항

없음. 세 축의 관리 범위·사업장 단일 출처·부서와 사업장의 분리·조회 전용·세 상태 판정·운영 상태·건수 기준은 모두 §6에서 확정했다.

조회 범위는 미결이 아니다. 시스템 관리의 권한 관리가 `_공통_권한정의.md`의 초기 데이터 범위를 적용하며, 이 화면과 시설물 대장(SCR-FAC-001)은 같은 범위 판정을 사용한다.
