중대재해처벌법의 **중대산업재해 축이 적용되는 사업장**을 확정해 두는 자리다. 이 목록이 곧 위험성평가·안전보건교육·작업환경측정 같은 후속 업무의 대상 범위가 되므로, 여기가 틀리면 그 위에 쌓이는 모든 이행이 틀린 대상 위에 놓인다. 구성은 탭·요약·사업장 목록 세 덩어리이며, 같은 화면의 다른 탭이 공중이용시설(SCR-BASE-002)과 원료·제조물(SCR-BASE-003)을 다룬다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 이 목록을 전 부서가 보는지 소관 부서만 보는지는 **아직 좁히지 않았다** — 임의로 정하지 않고 확정 필요 항목으로 올려 두었다(§6).

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 기본정보 > 관리대상 현황 | 메뉴 선택(기본 탭) |
| 이탈 | 공중이용시설 탭 | 탭 전환(SCR-BASE-002) |
| 이탈 | 원료·제조물 탭 | 탭 전환(SCR-BASE-003) |
| 이탈 | 데이터 일괄등록 | 여러 건을 한 번에 넣을 때(SCR-BASE-004) |
| 연계 | 정기 위험성평가 | 사업장별 평가 대상 산정(SCR-RISK-001) |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 화면에 들어온다 | 세 축의 건수를 탭에 붙여 보여 준다 |
| 2 | 사업장 목록을 본다 | 사업장명·구분·소관부서·상시근로자·위험성평가 상태를 표시한다 |
| 3 | 사업장을 등록한다 | 개별 등록 또는 일괄등록으로 넣는다 |
| 4 | 위험성평가 상태를 확인한다 | 그 사업장이 평가 대상인지, 했는지를 본다 |

### 분기 로직

- **세 축이 탭으로 갈린다** — 사업장(중대산업재해) · 공중이용시설(중대시민재해) · 원료·제조물(중대시민재해)이며, **근거 조문과 확정 방법이 각각 다르다**. 한 탭만 채우면 절반만 관리대상을 정한 것이 된다.
- **사업장은 조직 단위에서 파생한다** — 담양군의 사업장은 대체로 부서·사업소 단위와 겹치므로, 명단을 따로 만들지 않고 조직 자료를 원본으로 삼는다. 조직에 없는 사업장(임시 현장 등)만 별도로 더한다.
- **상시근로자 수가 적용 범위를 가른다** — 안전보건 의무 중 일부는 인원 규모로 대상이 갈리므로 이 값이 단순 참고가 아니라 판정 입력이다.
- **위험성평가 상태는 이 화면이 만들지 않는다** — 위험성평가 쪽 자료를 읽어 표시만 한다. 여기서 따로 상태를 저장하면 두 화면이 다른 값을 말하게 된다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 소관부서가 비어 있는 사업장 | 목록에 남기고 비어 있음을 드러낸다 — 감추면 아무도 채우지 않는다 |
| 상시근로자 수가 없는 사업장 | 판정에 쓰는 값이므로 미확보로 표시한다 — 0으로 간주하지 않는다 |
| 위험성평가를 아직 안 한 사업장 | 미실시로 표시한다 — 빈칸으로 두지 않는다 |
| 조직에는 있으나 사업장이 아닌 부서 | 목록에 자동으로 넣지 않는다 — 사업장 여부는 판단이 필요하다 |
| 사업장이 0건 | 등록을 안내한다 — 이 상태에서는 후속 업무의 대상이 없다 |
| 같은 사업장이 두 번 등록됨 | 중복을 드러낸다 — 조용히 합치지 않는다 |

## 4. 화면 구성별 정리

### 4-1. 축 탭

- 구성: 사업장 · 공중이용시설 · 원료·제조물 세 탭. 각 탭에 건수를 붙인다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 탭 선택 | 그 축의 목록으로 바꾼다 | 축마다 표 구성이 다르다 |
| 화면 진입 | 사업장 탭을 기본으로 연다 | — |
| 판정이 끝나지 않은 축 | 확정 건수 대신 **판정 전**임을 밝힌다 | 미판정을 확정 건수로 세지 않는다 |

- 상태: 탭마다 **확정 건수** 또는 **판정 전**을 표시한다. 세 축의 성격이 달라 같은 형식의 수치로 나란히 두지 않는다.

### 4-2. 사업장 목록

- 구성: 사업장명 · 구분 · 소관부서 · 상시근로자 · 위험성평가 · 관리 여섯 열.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 등록된 사업장을 표로 보여 준다 | — |
| 소관부서·상시근로자가 빈 행 | 미확보로 표시한다 | 0이나 공백으로 감추지 않는다 |
| 위험성평가 상태 | 위험성평가 자료에서 읽어 표시한다 | 여기서 저장하지 않는다 |
| 등록 | 개별 등록 또는 일괄등록으로 넣는다 | SCR-BASE-004 |

- 상태: 사업장별로 **정보 완비 / 일부 미확보**가 갈리고, 위험성평가 축으로 **미실시 / 실시**가 덧붙는다. 목록이 비면 등록을 안내한다.

## 6. 정책

- **세 축을 모두 관리한다** — 중대재해처벌법은 중대산업재해와 중대시민재해 두 갈래이고, 시민재해는 다시 공중이용시설과 원료·제조물로 나뉜다. 한 축만 채우면 절반만 대상을 정한 것이다.
- **사업장 명단을 조직 자료에서 파생한다** — 대체로 부서·사업소와 겹치므로 따로 만들지 않는다. 다만 **조직에 있다고 자동으로 사업장이 되지는 않는다** — 사업장 여부는 판단이 필요하므로 확정은 사람이 한다.
- **결측을 0으로 간주하지 않는다** — 상시근로자 수가 없는 것과 0명인 것은 다르다. 규모로 적용 범위가 갈리므로 미확보를 그대로 드러낸다.
- **위험성평가 상태를 이 화면이 저장하지 않는다** — 그쪽 자료를 읽어 표시만 한다. 따로 저장하면 두 화면이 다른 값을 말한다.
- **중복을 조용히 합치지 않는다** — 같은 이름이라도 다른 사업장일 수 있다. 드러내고 사람이 판단한다.
- **조회 범위를 임의로 좁히지 않았다** — 관리대상 목록을 전 부서가 보는 것이 맞는지는 정책 판단이라, 확정 필요 항목으로 올려 시연 중 물을 수 있게 해 두었다.
- **법령 근거 표시** — 중대산업재해 확보의무(법률)와 중대시민재해 확보의무(법률)를 함께 붙인다. 관리대상은 두 축 모두의 출발점이라 한 축만 붙이면 절반만 근거를 댄 것이 된다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리한다.

## 7. 미결사항

없음. 세 축의 관리 범위·사업장 명단의 출처와 확정 주체·결측 표시·위험성평가 상태의 소속·중복 처리·조회 범위의 취급은 모두 §6에서 확정했다.

조회 범위는 미결이 아니라 **발주처 확정 창구에 올려 둔 항목**이며, 답이 나오면 이 화면과 시설물 대장에 같은 값을 적용한다.
