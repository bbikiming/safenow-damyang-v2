## 4. 화면 구성별 정리

### 4-1. 요약·필터

- 요약은 현재 연도·반기·부서 조건을 적용한 동일 모집단에서 산출한다.
- 상태 요약은 한 번에 하나만 선택되며 다시 선택하면 전체로 돌아간다.
- 기한 초과는 측정 예정일 경과 미실시 또는 개선조치 기한 경과 미완료다.

### 4-2. 목록

- 부서·사업장, 유해인자, 측정기관, 예정일·실시일, 결과보고서, 결과, 내부 개선기한, 상태, 담당자를 표시한다.
- 결과보고서 첨부 여부와 측정 완료 여부는 다른 상태다. 파일을 붙였다고 측정 완료로 바꾸지 않는다.
- 행 선택은 상세로 이동하고 파일 첨부는 행 이동 없이 처리한다.

### 4-3. 측정계획 등록

- 대상 부서는 조직도, 사업장은 사업장 관리의 활성 사업장, 유해인자는 사업장 정보를 초기값으로 사용한다.
- 사업장 정보는 계획 생성 시 이름과 판정 상태를 함께 보존한다. 이후 마스터 명칭이 바뀌어도 과거 계획을 소급 변경하지 않는다.
- 측정기관 미정은 허용하되 `미지정`으로 드러내며, 예정일과 유해인자는 필수다.

## 6. 정책

- 「산업안전보건법」 제125조와 시행규칙 제186조에 따라 유해인자 노출 작업장을 대상으로 관리한다. 사업장에 유해인자 문구가 있다는 이유만으로 법정 대상을 자동 확정하지 않고 대상·비대상·검토 중 판정을 사용한다.
- 신규 또는 변경으로 대상이 된 작업장은 대상이 된 날부터 30일 이내, 이후에는 시행규칙 제190조의 원칙인 반기 1회 이상을 기본 주기로 안내한다. 법정 예외·주기 조정은 결과보고서 근거를 남겨 별도 판정한다.
- 결과보고서 첨부, 측정 실시, 개선 완료는 서로 다른 사건으로 기록한다. 하나가 다른 상태를 자동 완성하지 않는다.
- 결과 보존은 시행규칙 제241조에 따라 원칙 5년, 고용노동부장관이 정해 고시한 물질의 기록은 30년으로 한다. 사용자가 임의로 `발암성`만 선택해 기간을 바꾸지 않고 고시 대상 여부를 기록한다.
- 인력 평가는 완료 건수와 미완료·개선 필요 건을 참고지표로 읽는다. 작업환경측정 화면이 평가 결과를 직접 작성하지 않는다.
