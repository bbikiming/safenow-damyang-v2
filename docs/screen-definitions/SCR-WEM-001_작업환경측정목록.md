## 4. 화면 구성별 정리

### 4-1. 요약·필터

- 요약은 현재 연도·반기·부서 조건을 적용한 동일 모집단에서 산출한다.
- 상태 요약은 한 번에 하나만 선택되며 다시 선택하면 전체로 돌아간다.
- 기한 초과는 측정 예정일 경과 미실시 또는 개선조치 기한 경과 미완료다.

### 4-2. 목록

- 부서·사업장, 유해인자, 측정기관, 예정일·실시일, 결과보고서, 결과, 내부 개선기한, 상태, 담당자를 표시한다.
- 사업장은 **사업장 관리의 명칭**으로 표시한다. 구체 작업 위치(약품동·탈수기실·기계실)는 목록에 두지 않고 상세의 `대상 근거`가 갖는다 — 목록 칸에 둘을 겹쳐 쓰면 어느 쪽이 마스터의 사업장인지 알 수 없다.
- 결과보고서 첨부 여부와 측정 완료 여부는 다른 상태다. 파일을 붙였다고 측정 완료로 바꾸지 않는다.
- 행 선택은 상세로 이동하고 파일 첨부는 행 이동 없이 처리한다.

### 4-3. 측정계획 등록

- 대상 부서는 조직도, 사업장은 사업장 관리의 활성 사업장, 유해인자는 사업장 정보를 초기값으로 사용한다.
- **부서 담당자의 계획은 소속 부서로 고정된다(2026-10-06 기획확인 4차 확정)** — 부서 칸에 소속 부서가 채워지고 조직도를 열 수 없으며, 주관부서(재난안전과) 담당자만 다른 부서를 고른다. 교육 등록 폼과 같은 규칙이고 작업환경측정·건강검진이 같이 쓴다. 다른 부서로 등록하면 그 계획은 조회 범위 밖이라 등록한 본인 목록에서도 사라진다. 저장할 때도 다시 확인한다.
- **계획은 사업장 식별값으로 연결한다.** 이름은 계획 생성 시점 스냅샷으로 함께 보존하고, 이후 마스터 명칭이 바뀌어도 과거 계획을 소급 변경하지 않는다. 중복 계획 검사와 사업장 사용중 판정이 이 식별값을 쓰므로, 식별값 없이 이름만 저장하면 마스터와 한 글자만 달라도 두 판정이 조용히 어긋난다.
- 판정 상태(대상·비대상·검토 중)도 같은 시점 스냅샷으로 보존하고 **상세에서 표시한다**(SCR-WEM-002 §4-1).
- 측정기관 미정은 허용하되 `미지정`으로 드러내며, 예정일과 유해인자는 필수다.

### 4-4. 결과 안내 공문 (2026-11-16)

근거: 온나라 원장(2024·2025) — 재난안전과가 측정기관에 위탁하고 결과를 받아 해당 부서장에게 «작업환경측정 결과 안내» 공문을 보낸다. 기획 [`기획-작업환경측정-첨부·공문흐름-20261116-v2`](../planning/기획-작업환경측정-첨부·공문흐름-20261116-v2.md).

- **반기마다 한 줄**(재난안전과 담당자에게만): «측정 n / m곳 · 공문 보냄 k곳», [결과 안내 공문 (n곳)], 보낸 공문 [공문 보기], 측정 전 사업장 이름·예정일.
- **실리는 사업장 = 재난안전과가 등록한 측정 · 결과 입력 · 아직 공문 전.** 반기 전체를 기다리지 않는다 — 노출기준 초과 건은 60일 법정 기한이 있어 늦게 알릴 수 없다. 측정이 나뉘면 2차·3차 공문이 된다.
- **부서가 직접 등록한 측정은 자체 측정**이라 공문에 싣지 않는다(결과 첨부·완료로 끝난다 — 온나라 원장의 농업기술센터 사례). 판정은 등록할 때 접속자로 정하고 사람이 고르지 않는다.
- 공문은 결재선 없는 단순 기안(이행점검 시달·위험성평가 요청 공문과 같은 골격 `DYDOC`): 수신 = 그 사업장 부서장(조직도로 고칠 수 있고 빠지면 경고) · 본문은 직접 작성(삽입 조각: 결과 안내 · 개선 요청 · 근로자 알림) · 붙임 = 이미 올린 결과보고서에서 고름 · 별지 = 사업장별 결과표 · 관련 근거는 고른 것만.
- 기안 조건: 실을 사업장 1곳 이상 · 결과보고서 · 개선 필요 건은 오늘 이후 조치기한. 안 되면 사업장 이름으로 밝힌다.
- 보내면 그 사업장의 결과·결과보고서를 잠그고(반려·반송이면 풀림), 개선이 필요한 부서 내 할일에 «작업환경측정 개선조치»가 생긴다. 재난안전과 내 할일에는 «결과 안내 공문 기안»(실을 사업장이 있을 때)이 뜬다.
- 근로자 고지(산안법 §125⑥)는 공문으로 부서에 요청하는 데까지다 — 화면이 고지를 «이행했다»고 말하지 않는다.

## 6. 정책

- 「산업안전보건법」 제125조와 시행규칙 제186조에 따라 유해인자 노출 작업장을 대상으로 관리한다. 사업장에 유해인자 문구가 있다는 이유만으로 법정 대상을 자동 확정하지 않고 대상·비대상·검토 중 판정을 사용한다.
- 신규 또는 변경으로 대상이 된 작업장은 대상이 된 날부터 30일 이내, 이후에는 시행규칙 제190조의 원칙인 반기 1회 이상을 기본 주기로 안내한다. 법정 예외·주기 조정은 결과보고서 근거를 남겨 별도 판정한다.
- 결과보고서 첨부, 측정 실시, 개선 완료는 서로 다른 사건으로 기록한다. 하나가 다른 상태를 자동 완성하지 않는다.
- 결과 보존은 시행규칙 제241조에 따라 원칙 5년, 고용노동부장관이 정해 고시한 물질의 기록은 30년으로 한다. 사용자가 임의로 `발암성`만 선택해 기간을 바꾸지 않고 고시 대상 여부를 기록한다.
- 인력 평가는 완료 건수와 미완료·개선 필요 건을 참고지표로 읽는다. 작업환경측정 화면이 평가 결과를 직접 작성하지 않는다.

## 7. 미결사항

없음. FMS 실데이터·연계 규격은 **연계 구현 범위**다([미결사항 목록 §4](99_미결사항목록.md)). 프로토타입 데이터는 시연용 더미이며, 그 상태로도 이 화면 개발은 가능하다.
