## 4. 화면 구성별 정리

### 4-1. 조회·목록

- 관할 부서, 사업장명, 유형, 유해인자, 측정대상 판정, 판정근거, 사용상태를 표시한다.
- 부서 필터의 전체 건수와 목록 건수는 사용상태 조건을 함께 반영한다.

### 4-2. 등록·수정

- 관할 부서는 조직도 활성 부서에서 고르고 사업장 유형은 관리 목록에서 선택한다.
- 측정대상 판정은 대상·비대상·검토 중 세 상태다.
- 대상·비대상은 근거자료 또는 근거 설명을 필수로 받고, 검토 중은 검토 예정일과 담당자를 표시한다.

### 4-3. 비활성화

- 화면에서는 물리 삭제를 제공하지 않고 비활성화하며 사유·처리자·시각을 남긴다.
- 비활성 사업장은 신규 계획 선택에서 제외하지만 과거 상세에서는 이름을 계속 표시한다.

## 6. 정책

- 부서는 조직 단위이고 사업장은 물리적 작업장이다. 한 부서가 여러 사업장을 가질 수 있고 사업장명만으로 부서를 추정하지 않는다.
- 시행규칙 제186조의 대상 유해인자 노출 작업장 여부를 근거로 측정대상을 판정한다. 유해인자 메모가 비었음을 비대상으로 해석하지 않고 `검토 중`과 구분한다.
- 사업장 식별값은 명칭이 바뀌어도 유지한다. 측정계획은 식별값으로 연결하고 표시 이름은 현재 마스터와 당시 스냅샷을 함께 사용할 수 있게 한다.
- 기준정보는 참조 여부와 관계없이 화면에서 삭제하지 않고 비활성화한다. 감사 이력과 과거 측정계획의 재현성을 보존하기 위해서다.
- **사업장 정보의 단일 출처는 이 화면이다(BASE-BIZ-01 · 2026-09-03 이관)** — 작업환경측정·건강검진이 같은 식별값을 참조한다. 다른 화면이 자체 사업장 명단을 만들지 않는다. 종전에는 관리대상 현황의 사업장 탭이 이 명단을 조회 전용으로 파생했는데, 2026-09-03 에 그 탭을 없애면서 이 화면이 유일한 자리가 됐다.
- **대상 판정과 운영 상태를 분리한다(BASE-BIZ-04 · 2026-09-03 이관)** — 중대재해처벌법 적용 대상 판정은 **대상 / 비대상 / 검토 중** 세 값이고, 사용 중지 같은 운영 상태와 섞지 않는다. **비대상에는 근거가 있어야 하고, 값이 비어 있으면 검토 중이다** — 공란을 비대상으로 자동 치환하면 법 적용 누락이 조용히 생긴다.
- 사업장 관리와 시설물 대장은 목적이 다르다. 같은 장소여도 작업환경 유해인자 관리용 사업장과 시설물안전법 시설물 레코드를 자동 합치지 않고 명시적 연결값이 있을 때만 연계한다.
