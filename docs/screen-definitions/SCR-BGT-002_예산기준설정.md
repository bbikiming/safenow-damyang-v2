## 4. 화면 구성별 정리

### 4-1. 편성·집행 원칙

- 제목, 시행일, 주요 내용, 첨부파일을 가진 문서를 등록한다.
- 시행일이 가장 늦고 폐지되지 않은 문서 한 건만 현행본으로 표시한다.
- 수정은 기존 확정본을 덮어쓰지 않고 개정본을 추가하는 방식이 원칙이다.

### 4-2. 예방관련 예산 항목

- 깊이 제한 없는 트리로 분류하되 점검표에는 말단 항목만 선택한다.
- 이름은 같은 부모 아래에서 중복될 수 없다.
- 사용 중 항목은 이름 변경 시 과거 점검표의 선택 당시 명칭을 보존하고 새 점검표부터 새 이름을 사용한다.

### 4-3. 점검 대상

- 기관은 조직도 활성 부서, 시설은 시설물 대장의 유효 시설에서 복수 선택한다.
- 원천 식별값, 표시 이름, 원천, 시설 종별·등급의 선택 당시 값을 저장한다.
- 마스터에서 제외된 대상은 신규 점검표에서 선택하지 못하게 하되 과거 점검표와 결재 이력은 보존한다.

## 6. 정책

- 예산 원칙은 확정 문서이므로 개정 이력을 보존한다. 편집으로 과거 시행 문서를 덮어쓰지 않는다.
- 대상의 단일 출처는 기관의 경우 조직도, 시설의 경우 시설물 대장이다. 화면 안에 별도 수기 원본이나 별도 FMS 명단을 만들지 않는다.
- 점검표가 참조한 항목·대상은 삭제하지 않는다. 운영 목록에서 제외하려면 비활성화하고 과거 스냅샷을 유지한다.
- 시설물의 명칭·등급 변경은 현재 선택목록에는 반영하지만 이미 승인된 예산 점검표에는 선택 당시 값을 유지한다.
- FMS 실데이터 미수신은 기획 미결이 아니다. 시연자료·연계 전 상태와 파일 반입 대체 동작으로 개발하고 EXT-04 수신 뒤 원천 어댑터만 교체한다.
