### 분기 로직

- **선임 구분이 요구 서류를 가른다** — 안전관리자·보건관리자·안전보건관리책임자·관리감독자 중 무엇이냐에 따라 자격 요건과 신고 대상이 다르다. 화면은 구분을 먼저 받고, 선임계·자격증 사본을 함께 받는다.
- **조직도는 파생값이고 선임 현황은 등록값이다** — 부서와 인원 수는 조직도 한 곳에서 가져오고 이 화면이 따로 명단을 갖지 않는다. 반면 누구를 어느 자리에 선임했는지는 이 화면에서 등록한다. 두 축이 섞이면 조직 개편 때 선임 현황만 옛 상태로 남는다.
- **수행평가는 점수형이고 후속조치는 서술형이다** — 평가는 항목마다 점수를 매겨 수준을 보고, 후속조치는 무엇을 어떻게 했는지 적는다. 두 서식이 다른 이유는 재는 것이 다르기 때문이다.
- **평가 결과가 낮다고 개선조치가 자동으로 생기지 않는다** — 낮은 점수가 곧 법 위반은 아니므로, 조치가 필요한지는 사람이 판단해 후속조치로 잇는다.
- **인력 배치 판정은 법정 기준과 현재 인원의 비교값이다** — 직역별 필요 인원 기준과 현재 선임 인원을 비교하고, 기준 산정에 필요한 업종·상시근로자·공사금액 자료가 없으면 0명으로 보지 않고 `판정 대기`로 둔다.
- **공사 자료의 출처를 합치되 지우지 않는다** — 차세대 e호조 수신 건과 직접 등록 건을 같은 표에서 관리하지만 출처를 항상 표시한다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 선임되지 않은 자리가 있음 | 그 사실을 현황에 드러낸다 — 빈칸으로 두지 않는다. 선임 공백은 그 자체가 법정 의무 미이행이다 |
| 조직도에 없는 사람을 선임하려 함 | 조직도에서 고르게 한다 — 이름을 직접 적으면 같은 사람이 여러 표기로 쌓인다 |
| 선임계 없이 등록 | 막지 않는다 — 서류가 나중에 오는 경우가 있다. 다만 첨부 없는 선임은 현황에 그대로 드러낸다 |
| 반기 수행평가를 아직 안 함 | 평가 서식의 상태를 작성 전으로 두고 반기 주기를 함께 표시한다 |
| 평가는 했으나 후속조치가 없음 | 정상으로 본다 — 미흡 항목이 없으면 조치할 것이 없다 |
| 관리·감독 계층으로 진입 | 등록·작성 수단을 내지 않고 조회만 하게 한다 |
| 법정 배치인원 미달 | 선임 현황 점검 완료를 차단하고 미달 직역을 표시한다. 다른 업무 전체를 막지는 않는다 |
| 법정 기준 산정 자료가 없음 | `판정 대기`로 표시하고 선임 현황 점검 완료를 차단한다 |
| 공사 안전관리자 미선임 | 공사별 상태를 진행으로 둘 수 있으나 완료는 차단한다 |
| e호조 연계 전 공사 | 직접 등록할 수 있고 출처를 `직접 등록`으로 표시한다 |

## 4. 화면 구성별 정리

### 4-1. 조직도 현황

- 구성: 경영책임자(군수) · 전담조직 · 부서별 인원을 요약한 카드. 인원 수는 조직도에서 파생한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 조직도의 실제 인원으로 요약을 그린다 | 고정 숫자를 쓰지 않는다 |
| 조직이 개편됨 | 이 화면이 자동으로 따라온다 | 명단을 따로 갖지 않기 때문이다 |

- 상태: 조회 전용이며 비는 경우가 없다. 부서 명단이 아직 다 확보되지 않았다는 사실은 이 시스템 전반의 표시 규칙을 따른다.

### 4-2. 선임 현황

- 구성: 구분 · 성명 · 자격 · 선임일 · 선임계 첨부 여부를 보여 주는 목록과 [선임 등록].

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [선임 등록] | 구분·성명·선임일·자격·선임계를 받는 입력을 연다 | 성명은 조직도에서 고른다 |
| 등록 완료 | 현황에 반영하고 신고 안내를 낸다 | 고용노동부 선임 신고가 별도로 필요하다 |
| 선임 공백이 있는 구분 | 비어 있음을 드러낸다 | 빈칸으로 감추지 않는다 |
| 조회 전용 접속자 | 등록 수단을 내지 않는다 | 수행 주체를 함께 밝힌다 |

- 상태: 구분별로 **선임됨 / 공백**이 갈리고, 선임된 건은 **선임계 있음 / 없음**이 덧붙는다. 공백과 서류 미비는 다른 문제라 구분해 표시한다.

### 4-3. 수행평가 · 후속조치

- 구성: 반기 수행평가 서식(점수형) · 후속조치 서식 · 두 서식의 현재 상태 표시.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [수행평가 작성] | 점수형 평가 서식을 연다 | SCR-EDOC-006 |
| [후속조치 등록] | 조치 서식을 연다 | SCR-EDOC-007 |
| 평가에서 미흡이 나옴 | 사람이 판단해 후속조치로 잇는다 | 자동으로 만들지 않는다 |
| 실제 평가 수행 | 인력 평가 화면에서 한다 | SCR-EVL-001 |

- 상태: 서식마다 **작성중 → 등록완료 → 확정** 세 단계를 갖는다. 주기는 **반기 1회**이며 아직 하지 않은 반기는 작성 전으로 표시한다.

### 4-4. 법정 배치인원 자동 점검(SFR-010)

- 구성: 직역 · 법정 기준 인원 · 현재 선임 인원 · 판정 · 기준 출처, [점검 완료 확정]. 버튼 문구는 현재 상태가 이미 완료됐다는 표지가 아니라 완료 확정 동작임을 분명히 한다.
- 법정 기준은 업종·사업장 규모·상시근로자 수 등 해당 직역의 산정 입력에서 파생한다. 프로토타입 숫자는 시연용이며 기준 출처에 그 사실을 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 직역별 필요 인원과 현재 유효 선임 인원을 자동 비교 | 충족 / 미달 / 판정 대기 |
| [점검 완료 확정] | 모든 직역이 충족이면 완료 | 미달이면 `법정 배치 기준 미달 N건`, 산정자료 미등록이면 `배치 기준 미등록 N건`으로 차단 |

- `정해진 수 이하일 경우 진행 중단`은 **선임 현황 점검의 완료 확정**을 막는 것으로 구현한다. 관계없는 업무 전체를 막으면 자료 보완 자체도 못 하므로 전 시스템 차단으로 확대하지 않는다.

### 4-5. 공사별 안전관리자 선임 현황(SFR-010)

- 구성: 발주처 · 공사명 · 공사기간 · 공사금액 · 안전관리자 · 출처 · 점검상태 · 관리, [공사 직접 등록].

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [공사 직접 등록] | 발주처·공사명·기간·금액·안전관리자를 입력하고 `미시행`으로 생성 | e호조 연계 전 보조 경로 |
| [수정] | 공사 기본정보·안전관리자 수정 | 연계 건의 정본 필드는 본개발에서 읽기 전용, 보완 필드만 수정 |

## 6. 정책

- **조직도 명단을 이 화면이 갖지 않는다** — 부서와 인원은 한 곳에서 가져온다. 화면마다 명단을 두면 조직 개편 때 여기만 옛 상태로 남는다.
- **선임 공백을 감추지 않는다** — 비어 있는 자리는 그 자체가 법정 의무 미이행이다. 빈칸으로 두면 아무도 채우지 않는다.
- **성명을 직접 입력받지 않는다** — 조직도에서 고른다. 직접 입력은 같은 사람이 여러 표기로 쌓이게 만들고 부서별 집계를 어긋나게 한다.
- **평가 결과로 조치를 자동 생성하지 않는다** — 낮은 점수가 곧 법 위반은 아니다. 조치가 필요한지는 사람이 판단한다.
- **실제 평가는 인력 평가 화면이 한다** — 이 화면은 평가가 있었는지와 그 결과 문서를 보여 주는 자리다. 두 곳에서 평가하면 같은 사람의 점수가 둘이 된다.
- **선임 신고는 시스템 밖의 일이다** — 고용노동부 신고는 이 시스템이 대신하지 않으며, 등록 시 그 사실을 안내한다.
- **관리감독자 지정일은 재난안전과가 확정한다** — 직위명이나 채용일로 자동 추정하지 않는다. 근로자 명단 관리(SCR-EDU-006)의 같은 지정 기록을 이 화면이 조회하고, 지정일이 없으면 "미등록"으로 드러낸다. 정기교육의 연간 16시간 사이클은 이 날짜를 기준으로 계산한다.
- **배치 기준 미달은 해당 점검 완료만 막는다** — RFP SFR-010의 진행 중단을 선임 현황·공사별 점검 완료 게이트에 적용한다. 다른 메뉴까지 차단하면 미달을 해소하기 위한 등록·조치도 할 수 없기 때문이다.
- **공사정보는 e호조 우선, 직접 등록 보조** — 연계 공사는 공사 식별값을 정본으로 쓰고, 미수신 공사는 직접 등록한다. 연계 후 중복이 확인되면 직접 등록 이력을 지우지 않고 연계 식별값으로 승계한다.
- **법령 근거 표시** — 이 화면에는 전담 조직 구성·안전보건관리책임자등의 지정과 평가·전문인력 배치를 요구하는 조문과, 안전보건관리책임자·관리감독자·안전관리자·보건관리자 지정의 법률 근거를 함께 붙인다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리하며 화면이 문구를 따로 적지 않는다.

## 7. 미결사항

없음. 조직도와 선임 현황의 역할 분리·선임 공백 표시·성명 입력 방식·법정 배치 자동 점검·완료 차단 범위·공사별 선임 상태·평가와 조치의 연결·실제 평가의 수행 위치·선임 신고의 범위는 모두 §4·§6에서 확정했다.

부서 명단이 아직 다 확보되지 않은 것은 이 화면의 미결이 아니라 **행정포털 조직도 연계 구현 범위**이며([미결사항 목록 §4](99_미결사항목록.md)), 연계·명단이 오면 조직도 한 곳만 늘리면 이 화면이 따라온다. 그때까지 프로토타입 조직도는 시연용 더미다.
