## 4. 화면 구성별 정리

### 4-1. 교육 기준 표
- 작업내용 변경 시 교육, 특별교육, 건설업 기초안전보건교육의 대상과 최소 교육시간을 표시한다.
- 특별교육 대상 작업 39종을 기준 표 안에서 펼쳐 볼 수 있게 하고, 출처 조문을 함께 밝힌다.
- 관리감독자 화면에도 같은 3종을 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 법정 3종의 대상과 최소 교육시간을 근거와 함께 표시한다 | 근거 조문을 함께 낸다 |
| 특별교육 기준 확인 | 대상 작업 39종을 접힌 목록으로 함께 낸다 | 펼쳐 읽고 해당 여부는 등록자가 판단한다 — 등록 항목으로 받지 않는다 |

- 상태: 기준 표는 상시 노출이며 비는 경우가 없다. 유형별로 **대상 작업 목록 있음**(특별교육 — 39종을 접힌 목록으로 제공)과 **목록 없음**(작업내용 변경 시·건설업 기초 — 조문이 목록을 주지 않는다)이 갈린다. 목록이 확보되지 않은 유형이 생기면 지어내지 않고 미등록으로 드러낸다.

### 4-2. 필터와 목록
- 내용·강사·장소 검색, 교육 분류, 부서, 연도로 조회한다.
- 분류, 교육내용, 부서, 일시, 교육시간, 강사, 장소, 대상 인원과 완료 상태를 표시한다.
- 결과가 없으면 등록된 기타 교육이 없음을 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 검색어 입력 | 내용·강사·장소를 함께 찾아 즉시 좁힌다 | — |
| 분류·부서·연도 선택 | 선택 즉시 목록과 건수를 갱신한다 | — |
| 조회 결과 0건 | 빈 상태 안내를 표시한다 | “등록된 기타 교육이 없습니다” |

- 상태: 교육 1건은 저장 즉시 **완료**이므로 진행 중 상태가 없다 — 실시한 교육을 기록하는 경로이기 때문이다. 조건 축은 검색어·분류·부서·연도이고, 결과 0건이면 목록 자리에 빈 상태를 낸다. 관리감독자 화면도 같은 구조이며 모집단만 다르다.

### 4-3. 등록·수정
- 교육 종류, 단일 일자, 시작시각, 교육시간, 강사, 장소, 내용, 대상자와 첨부파일을 입력한다.
- 교육시간은 종료시각에서 산정하지 않고 사용자가 직접 입력한다.
- 저장 즉시 완료 상태와 대상자별 이수기록을 생성한다.
- 수정에서는 기존 대상자를 바꿀 수 없고 대상 변경이 필요하면 삭제 후 다시 등록하도록 안내한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 종류 선택 | 그 종류의 법정 최소 교육시간을 함께 안내한다 | — |
| 대상자 선택 | 이수기록을 받을 사람을 정한다 | 한 명도 고르지 않으면 “대상자를 1명 이상 선택하세요” |
| [저장](신규) | 완료 상태 교육과 대상자별 이수기록을 함께 만든다 | “(교육 종류) 진행 완료 · N명 카운트” |
| [저장](수정) | 교육 정보만 고친다 | “기타 교육 정보를 저장했습니다” |
| 필수 항목 누락 | 저장을 막고 무엇이 비었는지 알린다 | “일자·시각·시간·내용을 모두 입력하세요” |

- 상태: 등록 단계는 **작성 중 → 저장됨**이고 임시 보관을 두지 않는다. 저장하면 완료 상태와 대상자별 이수기록이 함께 생긴다. 수정 단계에서는 **대상자를 바꾸지 않는다** — 이미 붙은 이수기록과 어긋나므로 대상 변경은 삭제 후 재등록으로만 처리한다. 첨부는 **교육일지 및 교육사진 등** 한 칸이다. 결재가 올라간 건은 수정이 잠긴다.

### 4-4. 삭제
- 교육 삭제 시 연결된 대상자별 이수기록을 함께 삭제한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [삭제] | 회수 규모를 밝힌 확인 단계를 연다 | 회수되는 이수기록 건수를 함께 표시 |
| 확인 단계에서 실행 | 교육과 딸린 이수기록을 함께 지운다 | “기타 교육을 삭제했습니다 · 이수기록 N건 회수” |

- 상태: 삭제는 **회수 규모를 밝힌 확인 단계**를 반드시 거친다 — 몇 명의 이수기록 몇 건이 함께 지워지는지 표시한다. 되돌리는 수단은 두지 않으므로 확인 단계가 마지막 방어선이다. 결재가 올라간 건은 삭제도 잠긴다.

## 6. 정책

- 작업내용 변경 시 교육은 일용근로자와 계약기간 1주 이하 기간제근로자 1시간, 그 밖의 근로자 2시간으로 안내한다.
- 특별교육은 일용근로자와 계약기간 1주 이하 기간제근로자 2시간, 그 밖의 근로자 16시간으로 안내한다.
- 건설업 기초안전보건교육은 건설 일용근로자 4시간으로 안내한다.
- 현업근로자와 관리감독자 화면의 종류·시간 안내를 구분하지 않는다.
- 특별교육 대상 작업 목록은 **보여줄 뿐 고르게 하지 않는다** — 하나의 특별교육이 여러 호에 걸칠 수 있고, 목록에 없는 사례를 등록 불가로 만들지 않기 위해서다. 최초 작업일과 단기간·간헐적 작업 여부도 입력받거나 자동 판정하지 않는다.
- 입력한 교육시간을 선택 대상자 전원에게 그대로 기록하고 정기교육 시간에는 합산하지 않는다.
- 완료 교육도 수정·삭제할 수 있다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록하며 대상별 법령 보완안은 별도 문서에서 관리한다.
