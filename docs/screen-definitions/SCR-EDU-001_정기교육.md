- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.

## 4. 화면 구성별 정리

### 4-1. 교육 방식 탭
- 집합교육과 자체교육(부서) 탭을 제공한다.
- 집합교육 탭은 검색어, 진행 상태, 연도, 월로 조회한다.
- 자체교육 탭에는 부서 조건을 추가한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 방식 탭 선택 | 집합교육과 자체교육 목록을 바꿔 표시한다 | 조회 조건 구성도 함께 바뀐다 |
| 검색어 입력 | 입력하는 즉시 목록을 좁힌다 | 입력 도중 커서를 잃지 않는다 |
| 상태·연도·월 선택 | 선택 즉시 목록과 결과 건수를 갱신한다 | — |
| 부서 선택(자체교육) | 그 부서의 자체교육만 남긴다 | — |
| [필터 초기화] | 조건을 모두 해제한다 | 적용 중인 조건 수를 배지로 보여준다 |

### 4-2. 목록 카드
- 상태, 제목, 일시, 합계 교육시간, 강사, 장소, 신청 부서 수와 인원을 표시한다.
- 진행 중 집합교육에는 참석자 등록부 등록을 표시하고 모든 카드에 상세 또는 인라인 상세, 수정, 삭제를 표시한다.
- 완료 카드도 수정·삭제할 수 있으며 수정한 회차 시간은 기존 이수기록에 함께 반영한다.
- 삭제 전 신청 건수와 이수기록 회수 건수를 안내하고 확인 후 함께 삭제한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [상세] | 그 교육의 상세 화면으로 이동한다 | 정기교육 상세(SCR-EDU-004) |
| [참석자 등록부 등록] | 부서와 근로자를 골라 신청하는 입력을 연다 | 진행 중 집합교육에만 나타난다 |
| [수정] | 기존 값이 채워진 등록 입력을 연다 | 완료 교육도 수정할 수 있다 |
| 회차 시간을 바꿔 저장 | 이미 쌓인 이수기록의 인정시간까지 함께 갱신한다 | “교육 정보를 저장했습니다 · 교육시간 Nh · 이수기록 N건 갱신” |
| [삭제] | 회수 규모를 밝힌 확인 단계를 연다 | 신청 부서·인원과 회수되는 이수시간을 함께 표시 |
| 확인 단계에서 [삭제] | 교육과 신청, 딸린 이수기록을 함께 지운다 | “삭제 후에는 되돌릴 수 없습니다” |
| [교육 종료 처리] | 신청자 전원의 이수를 기록하고 완료로 바꾼다 | “교육 종료 · N명 카운트 완료” |

### 4-3. 집합교육 등록·수정
- 회차별 일자·시작·종료, 강사, 장소, 교육내용과 참석자 명단·교육 자료를 입력한다. 집합교육 등록 단계에는 교육 사진 입력을 두지 않는다.
- 회차별 시간을 합산해 교육시간으로 표시하며 회차는 최대 5개까지 등록한다.
- 신규 결재 상신 버튼은 표시하지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [＋ 회차 추가] | 교육 일자를 하나 더 만든다 | 최대 일수를 넘으면 더 추가할 수 없다고 알린다 |
| 회차 시각 입력 | 회차 시간을 합산해 교육시간으로 표시한다 | 교육시간을 직접 입력하는 칸은 두지 않는다 |
| 첨부 슬롯에 파일 추가 | 참석자 명단과 교육 자료를 각각 담는다 | 집합교육 등록 시점에는 교육 사진 칸을 두지 않는다 |
| [저장] | 입력값을 검사한 뒤 저장한다 | 교육 내용이 비면 “교육 내용을 입력하세요” |
| 회차 입력에 오류가 있는 채로 저장 | 문제가 있는 회차 탭으로 이동해 사유를 알린다 | — |

### 4-4. 자체교육 등록·진행
- 부서, 회차, 강사, 장소, 교육내용, 대상자를 등록한다.
- 저장 즉시 완료 상태로 만들고 선택한 대상자에게 합계 교육시간을 반영한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 부서 선택 | 그 부서의 근로자를 대상자 후보로 보여준다 | 조직도에서 고른다 |
| 대상자 선택 | 이수시간을 받을 사람을 정한다 | 한 명도 고르지 않으면 저장할 수 없다 |
| [저장] | 완료 상태의 자체교육을 만들고 대상자에게 시간을 반영한다 | “(부서) 자체교육 완료 · Nh · N명 카운트” |

### 4-5. 빈 상태
- 최초 또는 조건 결과가 없으면 “등록된 교육이 없습니다” 또는 “조건에 맞는 교육이 없습니다”를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 등록된 교육이 하나도 없음 | 목록 자리에 최초 안내를 표시한다 | “등록된 교육이 없습니다” |
| 조회 결과 0건 | 조건을 바꾸도록 안내한다 | “조건에 맞는 교육이 없습니다” |

## 5. 유효성 검사

| 입력 항목 | 필수 | 규칙 | 오류 안내 |
|---|---|---|---|
| 교육내용 | 예 | 공백 불가 | “교육 내용을 입력하세요.” |
| 회차 | 예 | 일자·시작·종료 입력, 종료가 시작보다 늦음 | “회차의 일자·시작·종료 시각을 확인하세요.” |

| 교육 대상자 | 자체교육 시 | 1명 이상 | “교육 대상자를 1명 이상 선택하세요.” |
| 신청 근로자 | 집합교육 신청 시 | 1명 이상 | “근로자를 1명 이상 선택하세요.” |
| 서명파일 | 집합교육 신청 시 | 파일 1개 이상 | “서명파일을 업로드하세요 (필수).” |

## 6. 정책

- 현업근로자는 채용일부터 6개월 주기로 판정하며 사무직·판매업무는 6시간, 그 밖의 근로자는 12시간을 필요시간으로 사용한다.
- 관리감독자는 현재 구현에서도 채용일부터 12개월 주기로 판정하고 16시간을 필요시간으로 사용한다.
- 집합교육 종료 시 신청자별 실제 참석시간을 따로 입력하지 않고 교육 건의 합계시간을 신청자 전원에게 반영한다.
- 자체교육은 별도의 종료 확인 없이 등록 즉시 완료한다.
- 완료 교육도 수정·삭제할 수 있고 관련 이수기록을 갱신하거나 회수한다.
- 기타 교육시간은 정기교육 이수시간에 합산하지 않는다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록한다. 관리감독자 지정일과 완료기록 보존 등 법령 보완 기준은 별도 문서에 두며 현 화면 기능으로 간주하지 않는다.
