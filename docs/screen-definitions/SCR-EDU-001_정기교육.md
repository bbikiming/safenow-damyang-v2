# 화면 정의서 — 정기교육

정기교육 화면은 법정 정기 안전보건교육을 **등록하고, 참석 사실을 모으고, 실시 결과를 공문으로 보고하는** 한 줄기 흐름을 담는다. 담당자가 이 화면에서 답을 얻어야 하는 질문은 셋이다 — 무엇을 언제 열었나, 어느 부서가 몇 명 참석했나, 그 결과를 보고했나.

- 집합교육은 재난안전과 등록, 부서별 참석자 등록부 등록, 교육 종료 처리 순으로 운영한다.
- 자체교육은 부서가 교육과 대상자를 등록하는 즉시 완료 처리한다.
- 현업근로자와 관리감독자 화면은 같은 구조를 사용하고 대상자, 주기와 필요시간만 달리 표시한다.
- **'현업근로자'는 메뉴 이름이자 법정 대상 범위다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육, 제29조~제33조) 적용 제외로 두고, "청소, 시설관리, 조리 등 **현업업무에 종사하는 사람**으로서 고용노동부장관이 정하여 고시하는 사람"만 그 제외에서 다시 뺀다. 이름을 '근로자'로 넓히면 법정 대상 범위를 잘못 말하게 되므로 넓히지 않는다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 등록·수정·삭제와 공문 기안·상신은 §3~§6의 업무 흐름과 상태 전이 조건을 따른다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 현업근로자/관리감독자 정기교육 | 해당 메뉴 선택 |
| 이탈 | 정기교육 상세 | 집합교육의 상세 선택 |
| 이탈 | 이수현황 | 교육 종료 후 반영 결과 확인 |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 집합교육 일정·강사·장소·내용을 등록한다 | 신청 접수 중 교육 카드 생성 |
| 2 | 부서와 근로자를 선택하고 서명파일을 등록한다 | 신청 부서·인원을 집계 |
| 3 | 상세에서 교육 종료 처리한다 | 신청자 전원에게 교육시간 반영 |
| 4 | 자체교육의 부서·대상자·교육 내용을 등록한다 | 등록과 동시에 완료 및 교육시간 반영 |
| 5 | 종료된 교육의 실시 결과를 공문으로 기안한다 | 본문 작성 · 붙임 선택 화면 |
| 6 | 문서를 미리 보고 온나라로 상신한다 | 문서번호 부여 · 결재 이력에 기록 |

### 분기 로직

- **공문은 교육이 끝난 뒤에만 쓴다** — 진행 중인 교육의 실시 결과를 보고할 수 없으므로 기안 수단은 **완료 상태 교육에만** 나타난다 — 집합교육은 종료 처리한 뒤, 자체교육은 이미 실시한 기록이라 등록 즉시다.
- **기안과 상신은 다른 화면이다** — 기안 화면에는 상신 수단이 없고, 상신은 미리보기 화면에만 있다. 이 순서를 뒤집는 진입점을 만들지 않는다(§4-6).
- **교육 방식 탭이 화면 전체를 가른다** — 집합교육은 주관부서가 열고 부서가 신청하는 **2단계 흐름**이고, 자체교육은 부서가 실시한 뒤 기록하는 **1단계 흐름**이다. 같은 등록 팝업을 쓰지만 저장 결과가 다르다.
  - 집합교육 저장 → **접수 중** 상태로 만들고 대상자를 받지 않는다. 누가 오는지는 부서 신청 단계에서 정해진다.
  - 자체교육 저장 → **완료** 상태로 만들고 그 자리에서 선택한 대상자 전원에게 교육시간을 반영한다.
- **자체교육에서만 부서와 대상자를 묻는다** — 집합교육 등록 폼에는 두 칸이 나타나지 않는다. 부서를 바꾸면 이미 고른 대상자 선택이 **초기화된다**(다른 부서 사람이 남아 있으면 안 되기 때문이다).
- **첨부 칸이 방식에 따라 다르다** — 집합교육은 **참석자 명단 · 교육 자료 2칸**(등록 시점은 아직 실시 전이라 교육 사진을 요구하지 않는다), 자체교육은 **교육일지 및 교육사진 등 1칸**(실시 후 기록이라 증빙이 한 파일로 온다).
- **신규 등록과 수정이 다르게 동작한다** — 수정에서는 **대상자를 바꾸지 않는다**. 이미 붙은 이수기록과 어긋나기 때문이며, 대상 변경은 신청 취소 또는 삭제 후 재등록으로만 한다.
- **회차를 고치면 이수기록까지 함께 바뀐다** — 교육시간은 입력값이 아니라 회차 합계에서 파생하므로, 수정으로 시간이 달라지면 이미 쌓인 이수기록의 인정시간도 같이 갱신한다. 갱신 건수를 저장 결과에 함께 알린다.
- **관리감독자 화면은 같은 구조를 그대로 쓴다** — 대상자 모집단이 관리감독자로 바뀌고, 집합·자체는 **부서 지정 여부**로 갈린다(부서를 지정하지 않은 건이 집합, 지정한 건이 자체다). 필요시간 16시간·연간 주기를 쓴다는 점 외에는 화면 구성·분기·검증이 모두 같다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 교육 내용을 비운 채 저장 | 저장을 막고 "교육 내용을 입력하세요" |
| 회차의 일자·시작·종료 중 하나라도 비었거나 종료가 시작보다 앞섬 | 저장을 막고 **그 회차 탭으로 이동**해 몇 회차가 잘못됐는지, 종료가 시작보다 뒤여야 한다는 것까지 알린다 |
| 회차를 6일째 추가하려 함 | 추가하지 않고 최대 일수를 알린다(최대 5일) |
| 자체교육에서 대상자를 한 명도 고르지 않고 저장 | 저장을 막고 "교육 대상자를 1명 이상 선택하세요" |
| 부서 신청에서 서명파일 없이 저장 | 저장을 막는다 — 서명은 참석 사실의 증빙이라 선택이 아니다 |
| 완료된 교육을 수정·삭제 | 허용한다 — 다만 삭제 시 **신청 건수와 회수될 이수기록 건수**를 밝힌 확인 단계를 거친다 |
| 결재가 올라간 교육을 수정·삭제 | 잠근다. 판정은 결재 상태 한 곳에서만 하며 화면이 따로 재구현하지 않는다 |
| 조회 결과가 0건 | 아직 아무것도 등록되지 않은 경우와 조건에 맞는 건이 없는 경우를 **다른 문구**로 구분하고, **탭 이름까지 넣어** 어느 쪽이 비었는지 밝힌다 |
| 등록 폼에서 고른 부서에 대상 근로자가 없음 | 대상자 목록 자리에 “이 부서에 대상자가 없습니다”를 표시한다 |
| 검색어를 입력하는 중 | 입력 도중 포커스·커서가 튀지 않는다 |

## 4. 화면 구성별 정리

### 4-1. 교육 방식 탭
- 집합교육과 자체교육(부서) 탭을 제공한다.
- 집합교육 탭은 검색어와 **상태 · 연도 · 월** 세 조건으로 조회한다 — 주관부서가 여는 교육이라 부서 조건이 없다.
- 자체교육 탭에는 **부서** 조건이 하나 더 붙는다 — 부서가 각자 실시한 교육이기 때문이다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 방식 탭 선택 | 집합교육과 자체교육 목록을 바꿔 표시한다 | 조회 조건 구성도 함께 바뀐다 |
| 검색어 입력 | 입력하는 즉시 목록을 좁힌다 | 입력 도중 커서를 잃지 않는다 |
| 상태·연도·월 선택 | 선택 즉시 목록과 결과 건수를 갱신한다 | — |
| 부서 선택(자체교육) | 그 부서의 자체교육만 남긴다 | — |
| [필터 초기화] | 조건을 모두 해제한다 | 적용 중인 조건 수를 배지로 보여준다 |

- 상태: 탭 축은 **집합교육 / 자체교육(부서)** 둘이고 조건은 탭마다 다르다(자체교육에만 부서 조건이 붙는다). 조건 축은 **조건 없음**과 **조건 적용 중**이며, 적용 중일 때 결과 건수와 조건을 푸는 수단을 함께 낸다. 관리감독자 화면도 같은 구조를 쓰며 대상자 모집단만 다르다.

### 4-2. 목록 카드
- 상태, 제목, 일시, 합계 교육시간, 강사, 장소, 신청 부서 수와 인원을 표시한다.
- 진행 중 집합교육에는 참석자 등록부 등록을 표시하고 모든 카드에 상세 또는 인라인 상세, 수정, 삭제를 표시한다.
- 완료 카드도 수정·삭제할 수 있으며 수정한 회차 시간은 기존 이수기록에 함께 반영한다.
- 삭제 전 신청 건수와 이수기록 회수 건수를 안내하고 확인 후 함께 삭제한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [상세] | 그 교육의 상세 화면으로 이동한다 | 정기교육 상세(SCR-EDU-004) |
| [참석자 등록부 등록] | 부서와 근로자를 골라 신청하는 입력을 연다 | 진행 중 집합교육에만 나타난다 |
| [수정] | 기존 값이 채워진 등록 입력을 연다 | 완료 교육도 수정할 수 있다 |
| 회차 시간을 바꿔 저장 | 이미 쌓인 이수기록의 인정시간까지 함께 갱신한다 | “교육 정보를 저장했습니다 · 교육시간 Nh · 이수기록 N건 갱신” |
| [삭제] | 회수 규모를 밝힌 확인 단계를 연다 | 신청 부서·인원과 회수되는 이수시간을 함께 표시 |
| 확인 단계에서 [삭제] | 교육과 신청, 딸린 이수기록을 함께 지운다 | “삭제 후에는 되돌릴 수 없습니다” |

### 4-3. 집합교육 등록·수정
- 회차별 일자·시작·종료, 강사, 장소, 교육내용과 참석자 명단·교육 자료를 입력한다. 집합교육 등록 단계에는 교육 사진 입력을 두지 않는다.
- 회차별 시간을 합산해 교육시간으로 표시하며 회차는 최대 5개까지 등록한다.
- 등록·수정 팝업에는 상신 수단을 두지 않는다 — 상신은 공문 미리보기 화면에만 있다(§4-6).

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [＋ 회차 추가] | 교육 일자를 하나 더 만든다 | 최대 일수를 넘으면 더 추가할 수 없다고 알린다 |
| 회차 시각 입력 | 회차 시간을 합산해 교육시간으로 표시한다 | 교육시간을 직접 입력하는 칸은 두지 않는다 |
| 첨부 슬롯에 파일 추가 | 참석자 명단과 교육 자료를 각각 담는다 | 집합교육 등록 시점에는 교육 사진 칸을 두지 않는다 |
| [저장] | 입력값을 검사한 뒤 저장한다 | 교육 내용이 비면 “교육 내용을 입력하세요” |
| 회차 입력에 오류가 있는 채로 저장 | 문제가 있는 회차 탭으로 이동해 사유를 알린다 | — |

- 상태: 등록 단계는 **작성 중 → 저장됨**이며 임시 보관을 두지 않는다. 회차는 1개로 시작해 최대 5개까지 늘어나고, 교육시간은 입력받지 않고 **회차 합계에서 파생**되므로 회차가 비면 시간도 0이다. 첨부는 **참석자 명단 / 교육 자료** 두 칸이며 교육 사진 칸을 두지 않는다 — 등록 시점은 아직 실시 전이기 때문이다. 수정 단계에서는 **대상자를 바꾸지 않는다**(이미 붙은 이수기록과 어긋난다). 결재가 올라간 건은 수정이 잠기며, 신규 상신 수단은 현재 어느 상태에서도 나타나지 않는다.

### 4-4. 자체교육 등록·진행
- 부서, 회차, 강사, 장소, 교육내용, 대상자를 등록한다.
- 저장 즉시 완료 상태로 만들고 선택한 대상자에게 합계 교육시간을 반영한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 부서 선택 | 그 부서의 근로자를 대상자 후보로 보여준다 | 조직도에서 고른다 |
| 대상자 선택 | 이수시간을 받을 사람을 정한다 | 한 명도 고르지 않으면 저장할 수 없다 |
| [저장] | 완료 상태의 자체교육을 만들고 대상자에게 시간을 반영한다 | “(부서) 자체교육 완료 · Nh · N명 카운트” |

- 상태: 저장 즉시 **완료**가 되므로 진행 중 상태가 없다 — 이미 실시한 교육을 기록하는 경로이기 때문이다. 첨부는 **교육일지 및 교육사진 등** 한 칸이다(실시 후 기록이라 한 파일로 온다). 대상자를 한 명도 고르지 않으면 저장할 수 없고, 저장 뒤에는 선택한 대상자 전원에게 합계 교육시간이 반영된다.

### 4-6. 공문 기안·상신

- **순서가 이 영역의 전부다** — 진입점은 **[공문 기안] 하나**이고, 상신은 **문서 미리보기 화면에만** 있다. 기안 화면에서 곧바로 상신할 수 없다. 발주처가 종전 [결재 상신]을 지우게 한 이유가 기능이 아니라 **공문 작성 단계 없이 결재만 올라가는 순서**였다(“왜 갑자기 뜬금없이 결재 상신이 있지”). 되살리는 조건도 이것 하나다 — 결재 전에 공문을 쓰는 단계가 생기면 연다.
- **진입점은 교육 카드의 [공문 기안] 한 자리다.** 같은 이름의 버튼을 두 자리에 두고 하는 일을 다르게 하면 담당자가 누를 때마다 어느 쪽인지 판단해야 한다. 새 메뉴·새 화면도 만들지 않는다 — 공문만 따로 모아 두는 분류는 실무에 도움이 되지 않는다는 것이 이미 확인됐다.
- **공문 단위는 교육 1건이다.** 기간을 묶어 올리는 총괄 공문을 두지 않는다 — 분기 실시 결과 제출은 **업무 축이 이미 담당**하고 있어(부서가 기한에 맞춰 제출하고 주관부서가 회수한다) 같은 일을 두 곳에서 하면 어느 쪽이 정본인지 알 수 없게 된다. 한 사람의 **이수 확인서는 공문이 아니라 증명서**이므로 보고서·제증명에서 발급하고 결재를 태우지 않는다.
- **본문은 담당자가 직접 쓴다.** 시스템이 문장을 지어내지 않는다. 대신 붙임을 엮고 수치를 세어 본문에 넣을 수 있는 **삽입 조각**으로 건넨다(교육명·일시·대상 인원·이수 인원 등).
- **붙임은 이미 올려 둔 파일을 그대로 쓴다** — 교육 방식에 따른 첨부(집합교육은 참석자 명단·교육 자료, 자체교육은 교육일지 및 교육사진 등)와 부서가 올린 참석자 서명부를 목록으로 보여 주고, 담당자가 고른 것만 붙임에 오른다. 여기서 새로 올리지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 카드 [공문 기안] | 그 교육 1건의 실시 결과 공문 작성을 연다 | **완료 상태 교육에만** 나타난다 |
| 붙임 체크 | 체크한 파일이 붙임에 오른다 | 이미 올려 둔 파일만 후보로 나온다 — 여기서 새로 올리지 않는다 |
| 붙임 별지 체크 | 이수자 명단을 별지로 붙인다 | 인원 수를 함께 표시한다 |
| 본문 삽입 조각 | 누르면 그 문구가 본문 끝에 들어간다 | 수치만 만들어 준다 — 문장은 담당자가 쓴다 |
| 본문 [문서 미리보기 →] | 공문 지면을 보여 준다 | **이 화면에는 상신 수단이 없다** |
| 미리보기 [← 수정] | 작성 화면으로 되돌아간다 | 쓰던 내용은 유지된다 |
| 미리보기 [온나라로 결재 상신] | 확인 단계를 연다 | **되돌릴 수 없는 것만** 다시 알린다 — 지면에서 이미 본 문서·붙임·결재선을 표로 반복하지 않는다 |
| 상신 확인 [상신] | 문서번호를 받아 결재 이력에 남긴다 | 결재 이력(SCR-EDU-007)에서 조회한다 |

- 상태: 공문의 단계상태는 **기안 전 → 기안됨 → 상신됨**이고, 그 뒤 **결재 완료 / 반려**는 온나라가 회신해야 생긴다. 연동 전에는 상신됨에서 멈추며, 화면은 그 사실을 밝히고 도달할 수 없는 상태를 지표로 걸지 않는다. 세 단계 모두 **되돌아갈 수 있고**, 상신 확인 단계에서 취소해도 아무것도 기록되지 않는다. 상신이 올라간 뒤에는 그 교육의 수정·삭제가 잠긴다(§6).
- **이수율은 기안 조건이 아니다** — 전원이 이수해야 공문을 쓸 수 있게 하면, 이수율이 낮은 부서는 실시 결과를 영영 보고하지 못한다. 보고할 것은 **실시했다는 사실과 그 결과**이고, 미이수는 결과의 일부로 함께 적는다.

### 4-7. 빈 상태
- 탭마다 문구를 나눠 표시한다 — 집합교육은 “등록된 집합교육이 없습니다” 또는 “조건에 맞는 집합교육이 없습니다”, 자체교육은 “등록된 자체교육이 없습니다” 또는 “조건에 맞는 자체교육이 없습니다”.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 등록된 교육이 하나도 없음 | 목록 자리에 최초 안내를 표시한다 | “등록된 교육이 없습니다” |
| 조회 결과 0건 | 조건을 바꾸도록 안내한다 | “조건에 맞는 교육이 없습니다” |

- 상태: 빈 상태는 **아직 아무것도 등록되지 않음**과 **조건에 맞는 건이 없음** 둘이며 문구를 달리한다 — 앞은 시작하라는 안내이고 뒤는 조건을 풀라는 안내라 할 일이 다르다. 로딩·오류 표시는 프로토타입에 없으며 실서비스에서는 이 시스템 공통 규칙을 따른다.

## 6. 정책

- **공문 골격은 전 도메인이 공유한다** — 순서·지면·결재선·상신·확인은 공용 골격이 갖고 있고 교육은 **지면 내용과 저장 위치만** 얹는다. 도메인마다 공문 화면을 새로 만들면 순서가 갈리고, 한쪽에서 고친 것이 다른 쪽에 반영되지 않는다.
- 전체 흐름은 **5단계**(등록 → 신청 → 종료 → 이수 → 공문)로 안내한다.
- **공문 단위와 진입점을 하나로 둔다** — 종전 기획은 총괄·교육별·개인별 세 갈래를 두었으나 둘을 뺐다. **기간 총괄**은 분기 실시 결과 제출을 업무 축이 이미 담당해 같은 일이 두 곳에 생기고, **개인별 이수 확인서**는 결재가 아니라 증명서라 보고서·제증명이 발급한다. 남는 것은 발주처가 유일하게 지목한 **교육 1건 실시 결과**이며, 갈래가 하나면 담당자가 무엇을 고를지 판단하지 않아도 된다.
- **확인 단계는 새 정보만 낸다** — 미리보기 지면에서 이미 본 문서·붙임·결재선을 확인 화면에서 표로 반복하지 않는다. 확인이 필요한 이유는 **되돌릴 수 없다는 사실**(문서번호 채번·수정 잠금) 하나뿐이므로 그것만 말한다. 같은 내용을 세 번 보여주면 아무도 읽지 않는 확인이 된다. 이 규칙은 **이 도메인의 공문**에 적용된다 — 위험성평가 공문은 현행 화면을 유지하기로 확정돼 있어 지금 형태를 바꾸지 않는다.
- **공문 기안이 1차 진입점이고 상신은 미리보기에만 둔다** — 결재 전에 공문을 쓰는 단계가 반드시 앞에 온다. 이 순서가 지켜지지 않으면 상신 수단 자체를 열지 않는다.
- **본문을 자동 생성하지 않는다** — 자동으로 엮기로 한 것은 붙임과 수치뿐이고 문장은 담당자가 쓴다.
- **붙임은 새로 올리지 않고 이미 올려 둔 것을 고른다** — 교육 방식에 따른 첨부(집합교육은 참석자 명단·교육 자료, 자체교육은 교육일지 및 교육사진 등)와 부서가 올린 참석자 서명부가 후보다. 공문 화면에서 파일을 새로 받으면 같은 증빙이 두 벌 생긴다.
- **이수율을 기안 조건으로 걸지 않는다** — 전원 이수를 조건으로 하면 이수율이 낮은 부서가 실시 결과를 영영 보고하지 못한다. 미이수는 막는 사유가 아니라 **보고 내용의 일부**다.
- **기안·상신 권한은 '등록 주체 = 기안 주체'다** — 그 교육을 **등록한 부서의 담당자**와 **재난안전과 담당자**가 기안한다. 자체·기타·채용시 교육은 각 과가 직접 실시하고 등록하므로 그 과가 자기 실시 결과를 보고할 수 있어야 한다. 재난안전과로만 좁히면 전 부서의 공문을 주관부서가 대필하게 되고, 등록한 부서는 자기 교육의 결과를 영영 보고하지 못한다. 관리·감독 계층(군수·과장·소장)은 **조회만** 한다.
  - 여러 부서를 묶은 건(부서가 비어 있는 채용시교육)은 재난안전과가 일괄 처리한 것이므로 주관부서 담당자만 기안한다.
  - 위험성평가 공문이 '주관부서만'인 것과 규칙이 갈리는 것은 **도메인이 실제로 다르기 때문**이다 — 위험성평가는 주관부서가 총괄해 내려보내지만 교육은 각 과가 실시한다.
  - 권한이 없으면 기안 수단을 내지 않고 **누가 기안하는지**를 대신 밝힌다. 판정은 한 곳에서만 하며, 화면·확인·상신 어느 경로로 들어와도 같은 결과가 나온다.
- **상신 뒤의 결재 진행 상황은 이 시스템이 알 수 없다** — 완료·반려는 온나라 회신으로만 생기고 연동이 아직 없다. 그래서 상신 뒤에는 상태 배지와 함께 **문서번호로 온나라에서 확인하라**고 밝힌다. 모른다는 사실을 감추면 담당자가 이 화면에서 결재 결과를 기다리게 된다.
- **상신된 교육은 잠근다** — 공문에 붙어 결재가 올라간 뒤 원본을 고치는 것은 문서 위조다. 잠기는 것은 **수정·삭제·참석자 등록부 신청 취소 셋**이며, 판정은 결재 상태 한 곳에서만 한다. 공문의 이수자 명단은 저장된 사본이 아니라 열 때마다 현재 이수기록에서 다시 만들어지므로, 취소를 열어 두면 이미 올라간 문서의 명단이 사후에 줄어든다.
- **법령 근거를 붙이지 않는다** — 공문 기안과 온나라 이관은 의무를 이행하는 **형식**이지 법령이 직접 명한 행위가 아니다. 교육 실시 자체의 근거는 이 화면 상단에 이미 표시된다.

- 현업근로자는 채용일부터 6개월 주기로 판정하며 사무직·판매업무 직접 종사자는 6시간, 그 밖의 근로자는 12시간을 필요시간으로 사용한다.
- **집계 모집단은 법정 대상보다 넓다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육) 적용 제외로 두고 고시된 **현업업무 종사자만** 대상으로 남기는데, 현재 모집단은 조직도 인원 전원이다. 지정명단은 담양군이 고시 기준으로 정할 자료라 임의로 좁히지 않고 갭으로 드러낸다.
- **별표4 비고 제3호의 교육시간 2분의 1 감면은 담양군에 적용되지 않는다** — 그 감면은 「영 별표1 제1호에 따른 사업」(광산·원자력·항공·선박안전법 적용 사업)과 「상시근로자 50명 미만 도매업·숙박 및 음식점업」 전용이고 담양군은 같은 별표 제4호다.
- **교육시간 면제·감면(시행규칙 제27조)은 적용하지 않는다** — 조문이 *"100분의 50 범위에서 면제할 수 있다"* 는 재량이고, 판정에 필요한 입력(전년도 산업재해 발생 이력·사업장 단위·이직 전 경력)이 시스템에 없다. 필요시간은 별표4 값을 그대로 쓰며 운용 여부는 발주처 확인 대상이다.
- 관리감독자는 재난안전과가 등록한 **지정일**부터 12개월 주기로 판정하고 16시간을 필요시간으로 사용한다. 지정일이 없으면 채용일로 대신하지 않고 "판정 불가 — 지정일 미등록"으로 표시한다.
- 집합교육 종료 시 신청자별 실제 참석시간을 따로 입력하지 않고 교육 건의 합계시간을 신청자 전원에게 반영한다.
- 자체교육은 별도의 종료 확인 없이 등록 즉시 완료한다.
- 완료 교육도 수정·삭제할 수 있고 관련 이수기록을 갱신하거나 회수한다 — **공문이 상신되기 전까지만** 그렇다. 회수 수단이 없으면 오등록을 되돌릴 방법이 사라지고, 상신 뒤에 열어 두면 결재 기록이 흔들린다.
- 기타 교육시간은 정기교육 이수시간에 합산하지 않는다.
- 지정일 등록은 근로자 명단 관리(SCR-EDU-006)에서 한다. 완료기록은 지정·채용 정보가 바뀌어도 삭제하지 않고 당시 판정 기준과 함께 보존한다.
