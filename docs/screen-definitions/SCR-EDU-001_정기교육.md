정기교육 화면은 법정 정기 안전보건교육을 **등록해 이수 기록으로 남기는** 화면이다. 교육 기록의 정본은 이 시스템이다. 담당자가 이 화면에서 답을 얻어야 하는 질문은 셋이다 — 무엇을 언제 열었나, 어느 부서가 참석 증빙을 냈나, 누가 언제 올린 기록인가.

- **집합교육**은 재난안전과가 등록하고, 저장하는 순간 대상 부서에 보이며 예정 안내 알림이 간다. 교육이 끝나면 대상 부서가 참석자 등록부를 올리고, 재난안전과는 출장 결과 보고서를 남긴다.
- **자체교육**은 부서가 실시한 교육을 등록하면 이수가 바로 반영되고 끝난다. 재난안전과는 결과를 본다.
- 현업근로자와 관리감독자 화면은 같은 구조를 사용하고 대상자, 주기와 필요시간만 달리 표시한다.
- **'현업근로자'는 메뉴 이름이자 법정 대상 범위다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육, 제29조~제33조) 적용 제외로 두고, "청소, 시설관리, 조리 등 **현업업무에 종사하는 사람**으로서 고용노동부장관이 정하여 고시하는 사람"만 그 제외에서 다시 뺀다. 이름을 '근로자'로 넓히면 법정 대상 범위를 잘못 말하게 되므로 넓히지 않는다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한표를 두지 않는다. 교육 등록·참석자 등록부·출장 결과 보고서를 **누가 하는지**는 업무 흐름이 정하며 §6 «처리 주체»에 적는다.
- **열람 범위** — 집합교육은 등록하는 순간 모든 부서에 보인다(처리 버튼은 대상 부서에만 나온다). 자체교육은 부서에 자기 부서 것만 보인다(재난안전과·총괄 계층은 전 부서). 범위 밖 부서는 부서 조건 선택지에서도 빠진다.

### 분기 로직

- **교육 방식 탭이 화면 전체를 가른다** — 집합교육은 재난안전과가 열고 부서가 교육 뒤 참석 증빙을 내는 **여러 단계 흐름**이고, 자체교육은 부서가 실시한 뒤 기록하는 **한 단계 흐름**이다. 같은 등록 팝업을 쓰지만 묻는 칸과 저장 결과가 다르다.
  - 집합교육 저장 → **교육 전**으로 만들고 대상자를 받지 않는다. 저장하는 순간 대상 부서에 보인다. 누가 왔는지는 교육이 끝난 뒤 부서 등록부로 정해진다(사전 신청 없음).
  - 자체교육 저장 → **완료**로 만들고 그 자리에서 고른 대상자 전원에게 교육시간을 반영한다. 그것으로 끝이다.
- **집합교육 상태는 셋이다** — **교육 전 → 등록부 받는 중 → 완료**. 마지막 회차 날부터 등록부 받는 중, 종료 처리하면 완료다. 상태 조건도 같은 말로 거른다.
- **수정은 종료한 뒤에도 막지 않는다** — 기록의 정본이 이 시스템이라 고칠 수 있어야 한다. 진행 중인 교육의 일시·장소를 바꾸면 대상 부서에 «변경 안내» 알림이 간다(제목·강사·첨부만 고친 것은 알리지 않는다). 회차·시간은 등록부가 들어온 뒤에도 고칠 수 있고 바뀐 시간은 이수기록에 다시 반영된다. 다만 ① 부서가 적어 둔 참석시간보다 합계를 짧게 줄이는 저장 ② 교육일을 늦추는 저장 가운데 — 종료한 교육을 오늘 뒤로, 또는 부서 기록(등록부·참석자 없음)·서명부·출장 결과 보고서가 있는 교육을 그 기록 가운데 가장 이른 날(과 오늘) 뒤로 옮기는 저장은 막는다 — 등록부는 교육이 끝난 뒤에만 받기 때문이다. 앞당기는 수정은 막지 않는다.
- **삭제는 부서 기록이 아직 하나도 없는 진행 중 교육만** — 부서 등록부 · «참석자 없음» · 서명부 · 출장 결과 보고서 가운데 하나라도 있으면 지우지 않는다(함께 사라진다). 지우면 대상 부서에 «교육 취소» 알림이 간다(교육 당일이어도). 사유를 받아 «취소»로 남기는 수단은 두지 않는다.
- **집합교육 카드는 보는 사람마다 다른 버튼을 낸다** — 재난안전과 담당자는 출장 결과 보고서와 수정·삭제를, 대상 부서 담당자는 자기 부서 등록부를 본다(§4-2). 재난안전과는 카드에서 등록부를 올리지 않는다.
- **자체교육에서만 부서와 대상자를 묻는다** — 부서는 **소속 부서로 고정**되고 고르는 수단이 없다(남의 부서 명의 기록이 섞이지 않게). 대상자 후보는 그 부서의 이 화면 모집단이다 — 현업근로자 화면은 관리감독자를 빼고, 관리감독자 화면은 관리감독자만.
- **자체교육은 수정·삭제가 없다** — 고치는 길은 **[등록 취소] 하나**이고 언제든 된다. 취소한 뒤 바른 내용으로 다시 등록한다.
- **첨부 칸이 방식에 따라 다르다** — 집합교육은 **참석자 명단(서명 포함) · 교육 자료 2칸**(등록 시점은 아직 실시 전이라 교육 사진을 요구하지 않는다 — 사진은 출장 결과 보고서에서 받는다), 자체교육은 **교육일지 및 교육사진 등 1칸**(실시 후 기록이라 증빙이 한 파일로 온다).
- **회차를 고치면 이수기록까지 함께 바뀐다 — 다만 집합교육은 등록부 참석시간이 정본이다** — 교육시간은 입력값이 아니라 회차 합계에서 파생한다. 집합교육은 사람마다 인정시간이 참석자 등록부의 실제 참석시간이라(SCR-EDU-004 §6) 회차를 고쳐도 적어 둔 참석시간은 바꾸지 않고, 참석시간을 따로 적지 않은 등록부(전 회차 참석)만 새 합계를 따른다. 회차(일자·시각)를 바꾸지 않은 수정 — 강사·장소·제목·첨부 — 은 이수기록을 건드리지 않는다. 갱신 건수를 저장 결과에 함께 알린다.
- **집합교육 합계를 등록부 참석시간보다 작게 줄이지 않는다** — 줄인 합계가 어느 부서 등록부의 참석시간보다 작으면 저장을 막고 그 부서와 참석시간을 알린다. 그 등록부를 먼저 정정한 뒤 줄인다.
- **관리감독자 화면은 같은 구조를 그대로 쓴다** — 대상자 모집단이 관리감독자로 바뀌고, 집합·자체는 **부서 지정 여부**로 갈린다(부서를 지정하지 않은 건이 집합, 지정한 건이 자체다). 필요시간 16시간·연간 주기를 쓴다는 점 외에는 화면 구성·분기·검증이 모두 같다.
- **이 흐름 전에 끝난 교육** — 이미 끝난 옛 집합교육에는 서명부·출장 결과 보고서 할 일이 생기지 않고 카드에 [출장 결과 보고서 작성]도 나오지 않는다. 종료 뒤 미등록 부서 할 일도 남지 않는다.

| 자체교육 대상자에 이 화면 모집단 밖의 사람이 섞임 | 교육을 만들기 전에 막고 사유를 알린다 |
| 집합교육 합계를 어느 부서 등록부 참석시간보다 짧게 줄여 저장 | 저장을 막고 그 부서·참석시간과 "그 등록부를 먼저 정정(등록 취소 후 재등록)하세요." |
| 부서가 등록부를 올린 교육을 삭제하려 함 | 지우지 않고 "부서가 참석자 등록부를 올린 교육은 지우지 않습니다 — 부서 기록이 함께 사라집니다." |
| 삭제 확인 창을 띄운 사이 부서가 등록부를 올림 | [삭제]를 누르는 순간 다시 보고 위와 같은 사유로 지우지 않는다 |
| 종료한 교육을 지우려 함 | [삭제]가 없고, 다른 경로로 들어와도 "종료한 교육은 지우지 않습니다." (수정은 된다) |
| 부서 기록·서명부·출장 결과 보고서가 있는 교육의 교육일을 그 기록보다 뒤로 옮김 | 저장을 막고 "… 교육일을 {가장 이른 기록일} 뒤로 옮기지 않습니다 — 그 기록이 교육보다 앞서게 됩니다." |
| 기록 없는 종료 교육의 교육일을 오늘 뒤로 옮김 | 저장을 막고 "종료한 교육은 교육일을 오늘 뒤로 옮기지 않습니다." |
| «참석자 없음»·서명부·출장 결과 보고서가 있는 교육을 지우려 함 | 지우지 않고 그 사유를 밝힌다 |
| 자체교육을 고치려 함 | 수정 창을 열지 않고 "자체교육은 수정·삭제하지 않습니다 — [등록 취소] 후 다시 등록합니다." |
| 다른 부서 사람이 자체교육을 등록 취소하려 함 | 수단이 없고, 다른 경로로 들어와도 거절하며 누가 하는지 알린다 |
| 조회 결과가 0건 | 아직 아무것도 등록되지 않은 경우와 조건에 맞는 건이 없는 경우를 **다른 문구**로 구분하고, **탭 이름까지 넣어** 어느 쪽이 비었는지 밝힌다 |
| 등록 폼의 부서에 대상자가 없음 | 대상자 목록 자리에 "이 부서에 대상자가 없습니다." |
| 검색어를 입력하는 중 | 입력 도중 포커스·커서가 튀지 않는다 |

## 4. 화면 구성별 정리

### 4-1. 교육 방식 탭 · 조회 조건
- 집합교육과 자체교육(부서) 탭을 제공한다. 검색어는 제목·강사·장소를 함께 찾는다.
- 집합교육 탭은 **상태 · 연도 · 월**로 조회한다 — 재난안전과가 여는 교육이라 부서 조건이 없다.
- 자체교육 탭은 **연도 · 월**에 **부서** 조건이 하나 더 붙는다. 상태 조건은 두지 않는다 — 등록하면 끝이라 고를 상태가 없다. 부서 조건은 조회 범위 안 부서만 싣고, 고를 부서가 하나뿐이면 두지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 방식 탭 선택 | 집합교육과 자체교육 목록을 바꿔 표시한다 | 조회 조건 구성도 함께 바뀐다 |
| 검색어 입력 | 입력하는 즉시 목록을 좁힌다 | 입력 도중 커서를 잃지 않는다 |
| 상태 선택(집합교육) | 상태 전체 / 교육 전 / 등록부 받는 중 / 완료 중 하나로 거른다 | 카드의 상태 칩과 같은 말이다 |
| 연도·월·부서 선택 | 선택 즉시 목록과 결과 건수를 갱신한다 | 연도는 등록된 교육에 실재하는 해만 |
| [필터 초기화] | 조건을 모두 해제한다 | 적용 중인 조건 수를 배지로 보여준다 |

- 상태: 조건 축은 **조건 없음**과 **조건 적용 중**이며, 적용 중일 때 결과 건수와 조건을 푸는 수단을 함께 낸다. 관리·감독 계층(군수·과장·소장)에게는 등록 수단 대신 «교육 등록·수정은 담당자가 합니다» 한 줄이 위에 나온다.

### 4-2. 집합교육 목록 카드
- 제목, 상태 칩, 일시(다회차면 «외 N일»), 합계 교육시간, 강사, 장소, 등록 부서 수와 인원을 표시한다. 교육 전에는 «등록부는 (마지막 회차 날)부터 · 등록 기한 (날짜)», 등록부 받는 중에는 등록 기한을 함께 낸다.
- 목록 위에는 재난안전과 담당자에게 [＋ 집합교육 등록](관리감독자 화면은 [＋ 관리감독자 정기(집합) 등록])을, 그 밖에는 «집합교육은 재난안전과 담당자가 등록합니다»를 낸다.
- 버튼은 보는 사람과 상태가 정한다. 모든 카드에 [상세 →]가 있다.

| 상태 | 재난안전과 담당자 | 대상 부서 담당자 |
|---|---|---|
| 교육 전 | [수정] · [삭제] | [상세 →]만 |
| 등록부 받는 중 | [출장 결과 보고서 작성] 또는 «출장 보고 완료» 칩 · [수정] · (부서 기록이 아직 없으면) [삭제] | 미등록 [＋ 참석자 등록부 등록] / 등록했으면 «등록부 등록함» 칩 / «참석자 없음» 칩 |
| 완료 | [출장 결과 보고서 작성] 또는 «출장 보고 완료» 칩 · [수정] | 미등록 대상 부서(이 시스템에서 등록한 교육)에 [＋ 등록부 추가] — 내 할일에 남은 등록부 할 일과 같다 |
| 완료 | [출장 결과 보고서 작성] 또는 «출장 보고 완료» 칩 | «참석자 없음» 칩만 — 등록부를 안 낸 부서의 할 일은 내 할일에 남고 상세에서 올린다 |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [상세 →] | 그 교육의 상세 화면으로 이동한다 | 정기교육 상세(SCR-EDU-004) |
| [＋ 참석자 등록부 등록] | 상세 화면으로 가서 등록부 창을 바로 연다 | 등록부 창은 상세 한 곳에만 있다 — 목록과 상세에 같은 창을 두 벌 두지 않는다 |
| [출장 결과 보고서 작성] | 상세 화면으로 가서 출장 결과 보고서 창을 바로 연다 | 교육 자료·교육 사진·참석 인원 — [저장]하면 끝(SCR-EDU-004) |
| [수정] | 기존 값이 채워진 등록 창을 연다 | §4-3 |
| [삭제] | 대상 부서 알림 여부를 밝힌 확인 단계를 연다 | 진행 중이고 부서 기록(등록부·참석자 없음·서명부·출장 결과 보고서)이 아직 없는 교육에만 나타난다 |

- 상태: 카드 상태는 §3 분기 로직의 셋이며, 그중 «완료»만 사람이 정하고(종료 처리) 나머지는 날짜로 정해진다. 대상 부서가 아닌 부서도 등록 순간부터 카드를 보지만 버튼이 없다. 종전 방식으로 취소해 남은 교육이 있으면 흐리게 «취소» 칩으로만 보이고 버튼이 없다.

### 4-3. 집합교육 등록 · 수정 · 삭제
- 회차별 일자·시작·종료, 강사, 장소, **제목**(한 줄), **참석자 등록부 기한**(마지막 회차 뒤 N일, 1~30일, 기본 7일)과 참석자 명단(서명 포함)·교육 자료를 입력한다. 등록 단계에는 교육 사진 입력을 두지 않는다.
- 회차별 시간을 합산해 교육시간으로 표시하며 회차는 최대 5개까지 등록한다. 교육시간을 직접 넣는 칸은 없다.
- 저장 버튼은 등록·수정 모두 **[저장]**이다. 저장하면 창이 닫히고 끝난다 — 다른 창으로 이어지지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [＋ 회차 추가] | 교육 일자를 하나 더 만든다 | 최대 일수를 넘으면 더 추가할 수 없다고 알린다 |
| 회차 시각 입력 | 회차 시간을 합산해 교육시간으로 표시한다 | — |
| 첨부 칸에 파일 추가 | 참석자 명단(서명 포함)과 교육 자료를 각각 담는다 | — |
| 새 등록 [저장] | 입력값을 검사해 «교육 전» 교육을 만들고 대상 부서에 «집합교육 예정 안내» 알림을 보낸다 | «집합교육을 등록했습니다 — 대상 부서 N곳에 예정 안내를 보냈습니다» · 마지막 회차 날이 이미 온 교육은 예정이 아니라 알리지 않는다 |
| 수정 [저장] | 교육 정보를 갱신한다 | «교육 정보를 저장했습니다 · 교육시간 Nh · 이수기록 N건 갱신» |
| 교육 전 교육의 일시·장소를 바꿔 저장 | 저장하고 대상 부서에 «집합교육 변경 안내» 알림을 보낸다 | 저장 결과 끝에 «대상 부서 N곳에 변경 안내를 보냈습니다» |
| 집합교육 합계를 등록부 참석시간보다 작게 저장 | 저장하지 않는다 | 그 부서·참석시간과 «그 등록부를 먼저 정정하세요» |
| [삭제] → 확인 [삭제] | 교육을 지운다. 지우기 전에 대상 부서에 «집합교육 취소 안내» 알림을 보낸다(교육 당일이어도) | 확인 단계에 «대상 부서 N곳에 «교육 취소» 알림을 보냅니다» · «삭제 후에는 되돌릴 수 없습니다» → «교육을 삭제했습니다 · 대상 부서 N곳에 취소 알림» |

- 상태: 등록 단계는 **작성 중 → 저장됨**이며 임시 보관을 두지 않는다. 회차는 1개로 시작해 최대 5개까지 늘어나고, 회차가 비면 시간도 0이다. 수정은 종료한 뒤에도 열려 있고 회차도 고칠 수 있다(합계를 등록부 참석시간보다 줄이는 저장과, 교육일을 기록·오늘보다 뒤로 늦추는 저장만 막는다). 삭제는 진행 중이고 부서 기록이 아직 없는 교육에만 있다.

### 4-4. 자체교육 목록 카드
- 부서 칩과 제목, 일시, 합계 교육시간, 강사, 장소, **대상자 n명**을 표시한다. 진행 상태 칩은 두지 않는다 — 자체교육은 등록하는 순간 완료이고 남는 상태가 없다.
- 카드 오른쪽에는 **«등록 {부서 이름} {등록한 사람} · {월-일}»** 한 줄을 둔다 — 누가 언제 올린 기록인지가 그 기록의 출처다. 그 부서 담당자에게만 **[등록 취소]**가 붙는다.
- 목록 위: 부서 담당자에게 [＋ 자체교육 등록]. 재난안전과 담당자에게는 **[＋ 우리 부서 자체교육 등록]**(자기 부서 몫만)과 «자체교육은 각 부서 담당자가 등록합니다. 재난안전과는 결과를 봅니다.» 한 줄.

| 보는 사람 | 카드 오른쪽 |
|---|---|
| 그 부서 담당자 | «등록 {부서 이름} {등록한 사람} · {월-일}» · [등록 취소] |
| 재난안전과 · 조회 계층 | «등록 {부서 이름} {등록한 사람} · {월-일}»만 |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [등록 취소] | 한 번에 등록한 묶음 전체와 회수되는 이수기록 건수·인원·이수시간 합계를 밝힌 확인 단계를 연다 | «이 등록과 이수기록 N건(N명 · 이수시간 합계 Nh)을 지웁니다. 그 사람들은 다시 미이수로 보입니다. 바른 내용으로 다시 등록하세요. 되돌릴 수 없습니다.» |
| 확인 [등록 취소] | 교육과 이수기록을 지운다 | «등록을 취소했습니다 · 교육 N건 · 이수기록 N건 회수» |

- 상태: 자체교육 카드에는 상태 축이 없다 — 등록하면 끝이다. [등록 취소]는 언제든 된다. [상세]·[수정]·[삭제]는 두지 않는다(카드 정보로 충분하고, 고치는 길은 등록 취소 하나다).

### 4-5. 자체교육 등록
- 부서(소속 부서로 고정), 회차, 강사, 장소, 제목, 교육일지 및 교육사진 등, 대상자를 입력한다. 부서 칸 아래 «소속 부서로 등록합니다 — 다른 부서 교육은 그 부서 담당자가 등록합니다.»
- 저장 버튼은 **[저장]**이다. 저장 즉시 완료 상태가 되고 고른 대상자에게 합계 교육시간을 반영한 뒤 창이 닫힌다. 할 일은 생기지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 대상자 선택 | 이수시간을 받을 사람을 정한다 | «(n / m명 선택)» · 한 명도 고르지 않으면 저장할 수 없다 |
| [저장] | 완료 상태의 자체교육을 만들고 대상자에게 시간을 반영한다 | «자체교육을 등록했습니다 · 대상자 N명 이수 반영» |

- 상태: 진행 중 상태가 없다 — 이미 실시한 교육을 기록하는 경로이기 때문이다. 등록 한 번이 한 묶음이고, 등록 취소도 그 묶음 단위다.

### 4-6. 빈 상태
- 탭마다 문구를 나눠 표시한다 — 집합교육은 "등록된 집합교육이 없습니다." 또는 "조건에 맞는 집합교육이 없습니다.", 자체교육은 "등록된 자체교육이 없습니다." 또는 "조건에 맞는 자체교육이 없습니다."

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 그 탭에 등록된 교육이 하나도 없음 | 목록 자리에 최초 안내를 표시한다 | "등록된 (탭) 교육이 없습니다." |
| 조회 결과 0건 | 조건을 바꾸도록 안내한다 | "조건에 맞는 (탭) 교육이 없습니다." |

- 상태: 빈 상태는 **아직 아무것도 등록되지 않음**과 **조건에 맞는 건이 없음** 둘이며 문구를 달리한다 — 앞은 시작하라는 안내이고 뒤는 조건을 풀라는 안내라 할 일이 다르다. 로딩·오류 표시는 이 시스템 공통 규칙을 따른다.

## 5. 유효성 검사

| 입력 항목 | 필수 | 규칙 | 오류 안내 |
|---|---|---|---|
| 제목 | 예 | 공백 불가 | "교육 제목을 입력하세요." |
| 회차 | 예 | 일자·시작·종료 입력, 종료가 시작보다 늦음, 최대 5일 | 문제가 있는 회차 탭으로 이동해 사유를 알린다 |
| 참석자 등록부 기한 | 집합교육 | 1~30일 | "참석자 등록부 기한을 1~30일로 정하세요." |
| 교육시간(수정) | 집합교육 | 어느 부서 등록부 참석시간보다 작지 않음 | 그 부서·참석시간과 그 등록부를 먼저 정정하라는 안내 |
| 부서 | 자체교육 | 소속 부서 | 다른 부서 명의 저장은 거절하고 누가 등록하는지 알린다 |
| 교육 대상자 | 자체교육 | 1명 이상 · 이 화면 모집단 안 | "교육 대상자를 1명 이상 선택하세요." / 모집단 불일치 사유 |

- 참석자 등록부(근로자·실제 참석시간·서명부)와 출장 결과 보고서(교육 자료·교육 사진·참석 인원)의 검사는 그 창이 있는 정기교육 상세(SCR-EDU-004 §5)를 따른다.

## 6. 정책
- **기록으로 남긴 파일은 이름을 누르면 내려받는다 (2026-11-24)** — 교육 기록의 정본은 이 시스템이라, 기록으로 받은 파일은 다시 열 수 있어야 한다. 파일 이름은 링크 모양이고 누르면 원본을 내려받는다. 볼 수 있는 사람은 그 화면의 열람 범위 그대로다(범위 밖이면 이름도 내지 않는다). 예시 자료처럼 파일이 없는 이름을 누르면 «예시 자료라 내려받을 파일이 없습니다»로 밝힌다 — 받은 척하지 않는다. 이 화면의 대상: 집합교육 첨부(참석자 명단 · 교육 자료) · 자체교육 카드의 증빙(«등록 {부서} {사람} · {월-일}» 줄 옆 📎).
- **회차를 바꾸지 않은 [수정]은 교육 시간을 다시 계산하지 않는다 (2026-11-17)** — 회차 폭과 인정 시간이 다른 기록(점심시간 등, 예: 09:30~18:30 · 8h)이 장소만 고쳐도 9h 로 바뀌고 이수기록까지 바뀌던 것을 막는다. 시간이 바뀌는 것은 회차(일자·시각)를 고쳤을 때뿐이다.

**등록하면 끝 — 교육 공문 없음 (2026-11-23)**
- **교육은 이 시스템에 등록하면 끝이다** — 교육 기록의 정본은 이 시스템이고, 시스템이 교육 공문을 만들거나 공문이 나가기를 기다리지 않는다. 주무관 «공문 이거 다 없애버리고 … 어차피 여기에도 기록이 남으니까», 주무관이 전한 팀장 판단 «여기에만 기록에 남겨도 상관없다»(2026-11-20 팀장 보고).
- **경계 기준** — 다른 부서에 일을 시키거나 조치를 요구하는 문서는 온나라(위험성평가 설문 요청·조치 요청 등), 이미 한 일을 남기는 기록은 시스템 기록만이다. 교육은 뒤쪽이다. 공문이 꼭 필요하면 담당자가 지금처럼 온나라에서 직접 쓴다 — 시스템은 그 공문을 모르고 알 필요도 없다.
- **저장하면 창이 닫히고 끝난다** — 저장 버튼은 [저장](등록부 창은 [등록])이고 저장 뒤 다른 창으로 이어지지 않는다. 결재 상태 칩·공문 보기·공문 보내기·다시 보내기는 어느 카드에도 없다.
- **집합교육은 등록하는 순간 대상 부서에 보인다** — 저장한 순간 대상 부서(그 교육 모집단에 사람이 있는 부서, 재난안전과 제외)에 «집합교육 예정 안내» 알림이 간다. 교육이 부서에 보이는 시점을 따로 정하는 단계는 없다.
- **예정 교육 알림은 할 일이 아니다 (2026-11-13 확정 X-1)** — 예정 안내를 받은 부서 내 할일에 «예정 교육 — 알림» 카드가 교육이 끝나는 날까지 보이지만 할 일 수·상태 칩에 세지 않는다. 마지막 회차 날이 된 교육은 «예정»이 아니므로 알리지 않는다(바로 등록부 받는 중).
- **진행 중인 교육의 변경·삭제는 알림으로 알린다** — 수정을 막지 않는다. 일시·장소를 바꾸면 «변경 안내», 지우면 «교육 취소» 알림이 대상 부서에 간다(교육 당일이어도 — 등록 순간 이미 알려진 교육이다). 제목·강사·첨부만 고친 것은 알리지 않는다.
- **없애는 수단은 [삭제] 하나다 (2026-11-23 D-3)** — 사유를 받아 «취소»로 남기던 수단은 두지 않는다. 진행 중이고 부서 기록(등록부 · 참석자 없음 · 서명부 · 출장 결과 보고서)이 하나도 없는 교육만 지운다(교육 전 · 교육 당일 · 등록부 받는 중이어도) — 목록에 취소 카드가 쌓이지 않고, 실습에서 만든 자료를 지울 수 있다. 부서 기록이 붙은 교육은 지우지 않는다 — 부서가 올린 기록이 함께 사라지기 때문이다. 지우면 대상 부서에 «교육 취소» 알림이 가고, 누가 언제 지웠는지는 취소 기록에 남는다.
- **교육 할 일은 넷이다** — 재난안전과 담당자: 서명부 올리기 · 출장 결과 보고서 작성(저장하면 끝). 부서: 참석자 등록부 등록(등록 또는 [참석자 없음]으로 끝 — 종료 뒤에도 남는다) · 독촉받은 미이수자. 자체교육은 할 일을 만들지 않는다. 내 할일과 대시보드가 같은 목록을 센다.
- **이수 판정은 바뀌지 않는다** — 이수는 처음부터 공문과 별개였다(등록부·이수 기록 기준). 이수현황 화면은 그대로다.
- **이미 보낸 교육 공문** — 운영에서 이미 온나라로 보낸 옛 교육 공문 기록은 지우지 않는다. 원본은 온나라에 있다. 이 시스템에서는 그 교육 상세(SCR-EDU-004 §4-1)의 «이전 공문 n건» 한 줄로 연다. 결재 이력 메뉴(SCR-EDU-007)는 메뉴에서 뺐다(2026-11-23 D-4).

**처리 주체**
- **집합교육의 등록·수정·삭제·종료 처리와 서명부 올리기·출장 결과 보고서는 재난안전과 담당자가 한다.** 재난안전과는 부서 등록부를 대신 올리지 않는다(«재난안전과 담당자는 참석자 등록부를 등록할 필요가 없어요») — 한 장 서명부는 상세에서 [서명부 올리기]로 교육에 한 번 올리고 부서가 골라 쓴다(SCR-EDU-004). 재난안전과에도 대상자가 있으면 재난안전과 담당자는 상세 등록 현황의 자기 부서 줄에서만 등록부를 낸다.
- **참석자 등록부와 자체교육(등록·등록 취소)은 그 부서 담당자가 한다** — 실무자 계정이 없는 부서만 부서장이 한다. 대리 등록은 없다 — 재난안전과 담당자도 다른 부서 몫은 하지 않고 자기 부서 몫만 «우리 부서 자체교육 등록»으로 한다. 등록 폼의 부서는 소속 부서로 고정되며 저장할 때도 다시 본다.
- **재난안전과는 부서 실시 교육을 본다** — 목록의 «등록 {부서 이름} {등록한 사람} · {월-일}»로 누가 언제 올렸는지 본다. 시스템 안 확인 단계는 두지 않는다(2026-11-16 2차 통화 «검토만»과 같다). 미이수자는 이수현황의 독촉으로 챙긴다.
- **관리·감독 계층(군수·과장·소장)은 조회만 한다** — 버튼 대신 누가 하는지를 밝힌다. 판정은 한 곳에서 하며, 화면·저장 어느 경로로 들어와도 같은 결과가 나온다. 버튼만 감추면 다른 경로로 뚫린다.

**출장 결과 보고서 (2026-11-23 D-2 — 공문만 걷고 보고서는 남긴다)**
- 재난안전과 담당자가 교육이 끝난 날부터(등록부 받는 중·완료) 상세에서 쓴다. 교육 자료(등록 때 올린 파일) · 교육 사진 · 참석 인원(1 이상, 대략)이 필수이고 [저장]하면 끝이다. 공문은 없다.
- 언제든 고친다(종료 뒤에도). 부서에는 보이지 않는다 — 재난안전과 내부 보고다.
- 교육 사진은 여기서 받는다 — 그래서 집합교육 등록의 첨부에 사진 칸을 따로 두지 않는다.
- 참석 인원은 보고용 대략치라 이수 판정에 쓰지 않는다(이수는 등록부 기준).

**잠금 없음 — 고치는 길을 열어 둔다**
- 공문 잠금의 근거는 «온나라로 나간 원본을 시스템에서 고치면 문서 위조»였다. 나가는 원본이 없으니 그 근거가 걸리지 않고, 공문을 기준으로 한 잠금(등록부·회차·등록 묶음·출장 보고)은 모두 없앴다.
- 기록의 정본이 이 시스템이니 **고칠 수 있어야 한다** — 회수 경로가 없으면 잘못 넣은 기록이 영구히 남는다. 집합교육은 종료한 뒤에도 [수정], 등록부는 그 부서가 등록 취소 후 다시 등록, 자체교육은 [등록 취소] 후 다시 등록이다.
- 대신 **누가 언제 무엇을 고쳤는지는 교육 이력에 사람 이름까지 남긴다**(등록 · 등록 취소 · 수정 · 참석자 없음 · 되돌리기 · 출장 보고 저장·수정).
- 남는 제약은 공문이 아니라 기록 정합 때문이다 — 부서 기록이 붙은 교육은 지우지 않고, 합계를 등록부 참석시간보다 줄이지 않고, 교육일을 그 교육에 남은 기록·오늘보다 뒤로 늦추지 않는다. 종료한 교육도 고칠 수 있다.
- 반기 의무이행 점검이 교육 이수를 끌어다 마감 보고를 온나라로 보내게 되면 그 반기 기록을 잠글지는 반기 점검 기획에서 정한다. 이번에는 잠그지 않는다.

**교육시간·대상**
- 현업근로자는 **2026-12-31 까지 채용일 기준 6개월**, **2027-01-01 부터 달력 반기(1~6월 · 7~12월)** 단위로 판정하며(2026-11-13 확정 X-2 · 개발 확인 답신 3-2 — 별표4 «매반기»를 달력 반기로 읽되 반기 중간에 바꾸지 않는다. 전환 뒤에는 반기 중간에 채용된 사람도 그 반기 시간을 채운다) 사무직·판매업무 직접 종사자는 6시간, 그 밖의 근로자는 12시간을 필요시간으로 사용한다.
- 관리감독자는 재난안전과가 등록한 **지정일**이 있어야 판정하고(2027-01-01 부터 해마다 1~12월, 그 전까지 지정일 기준 12개월) 16시간을 필요시간으로 사용한다. 지정일이 없으면 채용일로 대신하지 않고 "판정 불가 — 지정일 미등록"으로 표시한다. 지정일 등록은 현업근로자 명단(SCR-EDU-006)에서 한다.
- **집계 모집단은 법정 대상보다 넓다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육) 적용 제외로 두고 고시된 **현업업무 종사자만** 대상으로 남기는데, 현재 모집단은 조직도 인원 전원이다. 지정명단은 담양군이 고시 기준으로 정할 자료라 임의로 좁히지 않고 갭으로 드러낸다.
- **별표4 비고 제3호의 교육시간 2분의 1 감면은 담양군에 적용되지 않는다** — 그 감면은 「영 별표1 제1호에 따른 사업」(광산·원자력·항공·선박안전법 적용 사업)과 「상시근로자 50명 미만 도매업·숙박 및 음식점업」 전용이고 담양군은 같은 별표 제4호다.
- **교육시간 면제·감면(시행규칙 제27조)은 적용하지 않는다** — 조문이 "100분의 50 범위에서 면제할 수 있다"는 재량이고, 판정에 필요한 입력(전년도 산업재해 발생 이력·사업장 단위·이직 전 경력)이 시스템에 없다. 필요시간은 별표4 값을 그대로 쓴다 — **미적용 확정**이며, 담양군이 운용을 결정하면 변경 요청으로 반영한다.
- **집합교육의 인정시간은 참석자 등록부의 실제 참석시간이다 (2026-10-06 기획확인 4차)** — 등록부를 등록할 때 참석시간을 받고 기본값은 회차 합계이며, 0보다 크고 회차 합계 이하만 받는다(SCR-EDU-004 §4·§6). 다회차 교육에서 하루만 온 사람에게 전체 시간을 주면 하지 않은 교육을 했다고 기록하게 된다.
- **등록부는 교육이 끝난 뒤에만 받는다 (2026-11-12)** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 마지막 회차 날부터 등록 기한(마지막 회차 + 등록부 기한 일수)까지 받고, 기한이 지나도 받고, **종료 처리 뒤에도 받는다** — 미등록 부서는 상세의 [＋ 등록부 추가]로 올리거나 [참석자 없음]으로 끝내며 그때까지 할 일이 남는다(2026-11-17 개발 확인 요청 3-2 회신).
- 자체교육은 별도의 종료 확인 없이 등록 즉시 완료한다. 기타 교육시간은 정기교육 이수시간에 합산하지 않는다.
- 완료기록은 지정·채용 정보가 바뀌어도 삭제하지 않고 당시 판정 기준과 함께 보존한다.
- **프로토타입의 물리 삭제는 예시 데이터 회수 장치다.** 본개발은 완료된 교육·이수기록·증빙을 물리 삭제하지 않는다 — 공통 계약(`_공통_권한정의.md`)대로 **등록취소 상태 전이**로 처리하고 취소 사유·처리자·시각을 보존하며 집계에서만 제외한다.

### 경위 — 대체된 결정 (따르지 말 것)
- **«과정마다 온나라 공문»** (2026-11-16 1·2차 통화) — 교육 안내·변경 안내·취소 안내 · 참석자 등록부 제출 · 출장 결과 보고 · 자체교육 실시 결과 보고 공문과 그 결재 상태 칩·공문 기준 잠금·공문 할 일, «안내 공문 전» 상태와 [교육 취소]는 2026-11-23 팀장 보고 결정으로 걷었다. 교육은 등록하면 끝이고 출장 결과 보고서만 공문 없이 남는다. 아래 항목은 모두 공문이 있던 때의 경위다.
- **«공문 기안 진입점은 종료 처리된 교육 카드의 [공문 기안] 하나 · 공문 단위는 교육 1건 · 기안 조건은 종료 처리»** (2026-08-12) — 11-16 1차 통화로 과정별 공문(①~③)과 부서 실시 교육 공문(④)이 그 자리를 대신했다. 이미 보낸 실시 결과 공문은 «이전 방식»으로 남는다. 총괄·교육별·개인별 3종 단위도 이 전에 걷었다.
- **«기안·상신은 재난안전과 담당자만»** (2026-11-13 답신 3-3) — 11-16 통화로 «기록을 올린 부서가 보낸다»로 다시 정했다(2026-08-13 «등록 주체 = 기안 주체» → 11-13 거둠 → 11-16 재확정).
- **«자체교육은 [수정]·[삭제]·[상세] · 재난안전과는 전 부서 자체교육 등록»** — 11-16 2차 통화로 칩 + [공문 보기]와 등록 취소 하나로 바꿨다. 재난안전과의 대리 등록·[＋ 일괄 등록]·등록부 창의 부서 [조직도]도 1차 통화로 걷었다.
- **«부서 실시 교육은 분기에 한 장(분기 실시 결과 보고)»** (11-16 기획 v2 결정 R) — 같은 날 2차 통화(결정 D-1)로 걷었다. 등록 한 번 = 공문 한 번이다. 이미 보낸 분기 보고는 «이전 방식»으로 열람만 된다.
- **«결재선 3단계(기안 → 검토 → 결재) 지정»** — 2026-11-12 «온나라로 보내기»(결재선 없음)로 대체했다.
