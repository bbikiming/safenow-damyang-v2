정기교육 화면은 법정 정기 안전보건교육을 **등록하고, 그 과정을 온나라 공문으로 남기는** 화면이다. 담당자가 이 화면에서 답을 얻어야 하는 질문은 셋이다 — 무엇을 언제 열었나, 어느 부서가 참석 증빙을 냈나, 그 기록을 공문으로 보냈나.

- **집합교육**은 재난안전과가 등록하고 교육 안내 공문(①)을 보낸다. 교육이 끝나면 대상 부서가 참석자 등록부를 올리며 등록부 제출 공문(②)을 보내고, 재난안전과는 출장 결과 보고서를 써 출장 결과 보고 공문(③)을 보낸다.
- **자체교육**은 부서가 실시한 교육을 등록하면서 바로 실시 결과 보고 공문(④)을 보낸다. 재난안전과는 결과를 본다.
- 현업근로자와 관리감독자 화면은 같은 구조를 사용하고 대상자, 주기와 필요시간만 달리 표시한다.
- **'현업근로자'는 메뉴 이름이자 법정 대상 범위다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육, 제29조~제33조) 적용 제외로 두고, "청소, 시설관리, 조리 등 **현업업무에 종사하는 사람**으로서 고용노동부장관이 정하여 고시하는 사람"만 그 제외에서 다시 뺀다. 이름을 '근로자'로 넓히면 법정 대상 범위를 잘못 말하게 되므로 넓히지 않는다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한표를 두지 않는다. 교육 등록·공문 기안을 **누가 하는지**는 업무 흐름이 정하며 §6 «처리 주체»에 적는다.
- **열람 범위가 두 가지 걸려 있다** — 안내 공문(①)을 보내기 전 집합교육은 재난안전과에만 보이고, 자체교육은 부서에 자기 부서 것만 보인다(재난안전과·총괄 계층은 전 부서). 범위 밖 부서는 부서 조건 선택지에서도 빠진다.

### 분기 로직

- **교육 방식 탭이 화면 전체를 가른다** — 집합교육은 재난안전과가 열고 부서가 교육 뒤 참석 증빙을 내는 **여러 단계 흐름**이고, 자체교육은 부서가 실시한 뒤 기록하는 **한 단계 흐름**이다. 같은 등록 팝업을 쓰지만 묻는 칸과 저장 결과가 다르다.
  - 집합교육 저장 → **안내 공문 전**으로 만들고 대상자를 받지 않는다. 누가 왔는지는 교육이 끝난 뒤 부서 등록부로 정해진다(사전 신청 없음).
  - 자체교육 저장 → **완료**로 만들고 그 자리에서 고른 대상자 전원에게 교육시간을 반영한다.
- **집합교육 상태는 다섯이다** — **안내 공문 전 → 교육 전 → 등록부 받는 중 → 완료**, 그리고 **취소**. 안내 공문을 보내면 교육 전, 마지막 회차 날부터 등록부 받는 중, 종료 처리하면 완료다. 상태 조건도 같은 다섯 말로 거른다.
- **안내 공문을 보냈는가가 수정·삭제를 가른다** — 보내기 전에는 [수정][삭제]. 보낸 뒤에는 지우지 않고 [수정]과 **[교육 취소]**(교육 전에만 · 사유 필수)를 둔다. 이미 안내를 받은 부서가 있어 기록 없이 사라지면 안 되기 때문이다.
- **안내 공문을 보낸 뒤 일시·장소를 바꾸면 변경 안내 공문을 보낸다** — 저장하는 순간 변경 안내 공문 작성 창이 열리고, 닫아도 카드와 내 할일에 «변경 안내 공문 보내기»가 남는다. 제목·강사·첨부만 고친 것은 공문을 요구하지 않는다.
- **회차는 부서가 등록부 공문을 보낸 뒤 잠긴다** — 한 부서라도 ② 를 보냈으면 일시·시간을 바꾸지 못한다(그 공문에 실제 참석시간이 실려 나갔다). 강사·장소·제목은 그 뒤에도 고친다.
- **집합교육 카드는 보는 사람마다 다른 버튼을 낸다** — 재난안전과 담당자는 안내 공문·출장 결과 보고를, 대상 부서 담당자는 자기 부서 등록부를 본다(§4-2). 재난안전과는 카드에서 등록부를 올리지 않는다.
- **자체교육에서만 부서와 대상자를 묻는다** — 부서는 **소속 부서로 고정**되고 고르는 수단이 없다(남의 부서 실시 결과 보고 공문이 섞이지 않게). 대상자 후보는 그 부서의 이 화면 모집단이다 — 현업근로자 화면은 관리감독자를 빼고, 관리감독자 화면은 관리감독자만.
- **자체교육은 수정·삭제가 없다** — 고치는 길은 공문을 보내기 전이나 반려·반송됐을 때의 **[등록 취소] 하나**이고, 취소한 뒤 바른 내용으로 다시 등록한다. 공문이 나간 뒤에는 시스템에서 고치지 않는다(온나라에서 정정한 뒤 재난안전과에 알린다).
- **첨부 칸이 방식에 따라 다르다** — 집합교육은 **참석자 명단(서명 포함) · 교육 자료 2칸**(등록 시점은 아직 실시 전이라 교육 사진을 요구하지 않는다), 자체교육은 **교육일지 및 교육사진 등 1칸**(실시 후 기록이라 증빙이 한 파일로 온다).
- **회차를 고치면 이수기록까지 함께 바뀐다 — 다만 집합교육은 등록부 참석시간이 정본이다** — 교육시간은 입력값이 아니라 회차 합계에서 파생한다. 집합교육은 사람마다 인정시간이 참석자 등록부의 실제 참석시간이라(SCR-EDU-004 §6) 회차를 고쳐도 적어 둔 참석시간은 바꾸지 않고, 참석시간을 따로 적지 않은 등록부(전 회차 참석)만 새 합계를 따른다. 회차(일자·시각)를 바꾸지 않은 수정 — 강사·장소·제목·첨부 — 은 이수기록을 건드리지 않는다. 갱신 건수를 저장 결과에 함께 알린다.
- **집합교육 합계를 등록부 참석시간보다 작게 줄이지 않는다** — 줄인 합계가 어느 부서 등록부의 참석시간보다 작으면 저장을 막고 그 부서와 참석시간을 알린다. 그 등록부를 먼저 정정한 뒤 줄인다.
- **관리감독자 화면은 같은 구조를 그대로 쓴다** — 대상자 모집단이 관리감독자로 바뀌고, 집합·자체는 **부서 지정 여부**로 갈린다(부서를 지정하지 않은 건이 집합, 지정한 건이 자체다). 필요시간 16시간·연간 주기를 쓴다는 점 외에는 화면 구성·분기·검증이 모두 같다.
- **이전 방식 기록** — 이 흐름 전에 만든 교육은 공문 할 일이 없다. 그때 재난안전과가 보낸 실시 결과 공문이 있으면 그 결재 상태 칩과 [공문 보기]를 보이고, 없으면 «이전 방식»이라고만 적는다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 제목을 비운 채 저장 | 저장을 막고 "교육 제목을 입력하세요." |
| 회차의 일자·시작·종료 중 하나라도 비었거나 종료가 시작보다 앞섬 | 저장을 막고 **그 회차 탭으로 이동**해 몇 회차가 잘못됐는지, 종료가 시작보다 뒤여야 한다는 것까지 알린다 |
| 회차를 6일째 추가하려 함 | 추가하지 않고 최대 일수를 알린다(최대 5일) |
| 자체교육에서 대상자를 한 명도 고르지 않고 저장 | 저장을 막고 "교육 대상자를 1명 이상 선택하세요." |
| 자체교육 대상자에 이 화면 모집단 밖의 사람이 섞임 | 교육을 만들기 전에 막고 사유를 알린다 |
| 공문 작성 창을 그냥 닫음 | 교육 기록(자체교육은 이수까지)은 남고 공문만 «공문 미기안». 내 할일에 «공문 보내기»가 남는다 |
| 안내 공문을 보낸 교육을 삭제하려 함 | 지우지 않고 "안내 공문을 보낸 교육은 지우지 않고 [교육 취소]로 취소 안내를 보냅니다." |
| 교육이 시작된 뒤(등록부 받는 중) 교육 취소 | 받지 않는다 — "교육 취소는 교육 전에만 합니다." |
| 부서가 등록부 공문을 보낸 뒤 회차를 바꿔 저장 | 저장을 막고 "부서가 등록부 공문을 보낸 교육이라 일시·시간을 바꿀 수 없습니다 — 강사·장소·제목은 고칠 수 있습니다." |
| 자체교육을 고치려 함 | 수정 창을 열지 않고 공문 전·반려·반송 때의 «등록 취소» 후 다시 등록을 안내한다 |
| 공문을 보낸 자체교육을 등록 취소하려 함 | 막고 "온나라에서 정정한 뒤 재난안전과에 알려 주세요" |
| 조회 결과가 0건 | 아직 아무것도 등록되지 않은 경우와 조건에 맞는 건이 없는 경우를 **다른 문구**로 구분하고, **탭 이름까지 넣어** 어느 쪽이 비었는지 밝힌다 |
| 등록 폼의 부서에 대상자가 없음 | 대상자 목록 자리에 "이 부서에 대상자가 없습니다." |
| 검색어를 입력하는 중 | 입력 도중 포커스·커서가 튀지 않는다 |

## 4. 화면 구성별 정리

### 4-1. 교육 방식 탭 · 조회 조건
- 집합교육과 자체교육(부서) 탭을 제공한다. 검색어는 제목·강사·장소를 함께 찾는다.
- 집합교육 탭은 **상태 · 연도 · 월**로 조회한다 — 재난안전과가 여는 교육이라 부서 조건이 없다. 상태 «안내 공문 전»은 재난안전과와 총괄 계층에게만 선택지로 나온다(부서에는 그 교육이 보이지 않는다).
- 자체교육 탭은 **공문 상태 · 연도 · 월**에 **부서** 조건이 하나 더 붙는다. 부서 조건은 조회 범위 안 부서만 싣고, 고를 부서가 하나뿐이면 두지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 교육 방식 탭 선택 | 집합교육과 자체교육 목록을 바꿔 표시한다 | 조회 조건 구성도 함께 바뀐다 |
| 검색어 입력 | 입력하는 즉시 목록을 좁힌다 | 입력 도중 커서를 잃지 않는다 |
| 상태 선택(집합교육) | 안내 공문 전 / 교육 전 / 등록부 받는 중 / 완료 / 취소 중 하나만 남긴다 | 카드의 상태 칩과 같은 말이다 |
| 공문 상태 선택(자체교육) | 공문 미기안 / 결재 미완료 / 결재 완료 / 반려·반송 중 하나만 남긴다 | 카드의 결재 상태 칩과 같은 말이다 |
| 연도·월·부서 선택 | 선택 즉시 목록과 결과 건수를 갱신한다 | 연도는 등록된 교육에 실재하는 해만 |
| [필터 초기화] | 조건을 모두 해제한다 | 적용 중인 조건 수를 배지로 보여준다 |

- 상태: 조건 축은 **조건 없음**과 **조건 적용 중**이며, 적용 중일 때 결과 건수와 조건을 푸는 수단을 함께 낸다. 관리·감독 계층(군수·과장·소장)에게는 등록 수단 대신 «교육 등록·수정은 담당자가 합니다» 한 줄이 위에 나온다.

### 4-2. 집합교육 목록 카드
- 제목, 상태 칩, 일시(다회차면 «외 N일»), 합계 교육시간, 강사, 장소, 등록 부서 수와 인원을 표시한다. 교육 전에는 «등록부는 (마지막 회차 날)부터 · 등록 기한 (날짜)», 등록부 받는 중에는 등록 기한을 함께 낸다.
- 목록 위에는 재난안전과 담당자에게 [＋ 집합교육 등록](관리감독자 화면은 [＋ 관리감독자 정기(집합) 등록])을, 그 밖에는 «집합교육은 재난안전과 담당자가 등록합니다»를 낸다.
- 버튼은 보는 사람과 상태가 정한다. 공문이 있는 자리에는 **결재 상태 칩 + [공문 보기]**가 나오고(칩 어휘는 §4-6), 반려·반송이면 사유와 [다시 보내기]가 붙는다. 모든 카드에 [상세 →]가 있다.

| 상태 | 재난안전과 담당자 | 대상 부서 담당자 |
|---|---|---|
| 안내 공문 전 | [안내 공문 작성] · [수정] · [삭제] | 카드가 보이지 않는다 |
| 교육 전 | ① 교육 안내 칩 + [공문 보기] · [수정] · [교육 취소] · (일시·장소를 바꾼 뒤) [변경 안내 공문 보내기] | [상세 →]만 |
| 등록부 받는 중 | 보고서 전 [출장 결과 보고서 작성] / 저장 뒤 [출장 결과 보고 공문 보내기] / 보낸 뒤 ③ 칩 + [공문 보기] · [수정] | 미등록 [＋ 참석자 등록부 등록] / 저장만 [등록부 공문 보내기] / 보낸 뒤 ② 칩 + [공문 보기] / «참석자 없음» 칩 |
| 완료 | ③ 칩 또는 [출장 결과 보고서 작성] | 등록부를 올린 부서: ② 칩 + [공문 보기], 아직 안 보냈으면 [등록부 공문 보내기] — 종료 뒤에도 할 일로 남는다 |
| 취소 | 흐리게 표시 · «취소» 칩 · 취소 안내 공문 칩 또는 [취소 안내 공문 보내기] | «취소» 칩 |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [상세 →] | 그 교육의 상세 화면으로 이동한다 | 정기교육 상세(SCR-EDU-004) |
| [안내 공문 작성] | 교육 안내 공문(①) 작성 창을 연다 | §4-6 순서 |
| [＋ 참석자 등록부 등록] | 상세 화면으로 가서 등록부 창을 바로 연다 | 등록부 창은 상세 한 곳에만 있다 — 목록과 상세에 같은 창을 두 벌 두지 않는다 |
| [등록부 공문 보내기] | 저장한 등록부의 등록부 제출 공문(②) 작성 창을 연다 | 수신 재난안전과(고정) |
| [출장 결과 보고서 작성] | 상세 화면으로 가서 출장 결과 보고서 창을 바로 연다 | 교육 자료·교육 사진·참석 인원 — 상세(SCR-EDU-004) |
| [출장 결과 보고 공문 보내기] | 출장 결과 보고 공문(③) 작성 창을 연다 | 수신 «내부결재» |
| [수정] | 기존 값이 채워진 등록 창을 연다 | §4-3 |
| [교육 취소] | 사유를 받는 창을 연다 | §4-3 |
| [삭제] | 회수 규모를 밝힌 확인 단계를 연다 | 안내 공문 전 교육에만 나타난다 |
| 이전 방식 교육 | 그때 보낸 실시 결과 공문의 칩 + [공문 보기]. 반려·반송이면 재난안전과 담당자에게 [다시 보내기] · 잠기지 않았으면 [수정][삭제] | 새 실시 결과 공문은 만들지 않는다 |

- 상태: 카드 상태는 §3 분기 로직의 다섯이며, 그중 «완료»와 «취소»만 사람이 정하고(종료 처리·교육 취소) 나머지는 안내 공문 발송과 날짜로 정해진다. 대상 부서가 아닌 부서는 교육 전부터 카드를 보지만 버튼이 없다.

### 4-3. 집합교육 등록 · 수정 · 취소 · 삭제
- 회차별 일자·시작·종료, 강사, 장소, **제목**(한 줄), **참석자 등록부 기한**(마지막 회차 뒤 N일, 1~30일, 기본 7일)과 참석자 명단(서명 포함)·교육 자료를 입력한다. 등록 단계에는 교육 사진 입력을 두지 않는다.
- 회차별 시간을 합산해 교육시간으로 표시하며 회차는 최대 5개까지 등록한다. 교육시간을 직접 넣는 칸은 없다.
- 새 등록의 저장 버튼은 **[저장하고 안내 공문 작성 →]**, 수정은 [저장]이다. 이 창에는 온나라로 보내는 수단이 없다 — 보내기는 공문 미리보기에만 있다(§4-6).

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [＋ 회차 추가] | 교육 일자를 하나 더 만든다 | 최대 일수를 넘으면 더 추가할 수 없다고 알린다 |
| 회차 시각 입력 | 회차 시간을 합산해 교육시간으로 표시한다 | — |
| 첨부 칸에 파일 추가 | 참석자 명단(서명 포함)과 교육 자료를 각각 담는다 | — |
| [저장하고 안내 공문 작성 →] | 입력값을 검사해 «안내 공문 전» 교육을 만들고, 같은 창을 교육 안내 공문(①) 작성으로 바꾼다 | 맨 위 «교육을 저장했습니다 — 이 안내 공문을 온나라로 보내야 대상 부서에 교육이 알려집니다» |
| 수정 [저장] | 교육 정보를 갱신한다 | «교육 정보를 저장했습니다 · 교육시간 Nh · 이수기록 N건 갱신» |
| 안내 공문을 보낸 교육의 일시·장소를 바꿔 저장 | 저장하고 변경 안내 공문 작성 창을 연다 | «일시·장소를 바꿨습니다 — 변경 안내 공문을 보냅니다.» |
| 집합교육 합계를 등록부 참석시간보다 작게 저장 | 저장하지 않는다 | 그 부서·참석시간과 «그 등록부를 먼저 정정하세요» |
| [교육 취소] → 사유 입력 → [취소하고 취소 안내 공문 작성 →] | 교육을 «취소»로 남기고 취소 안내 공문 작성 창을 연다 | 취소한 교육은 할 일·예정 안내·이수 집계에서 빠진다 |
| [삭제] → 확인 [삭제] | 교육과 딸린 등록부·이수기록을 함께 지운다 | 확인 단계에 등록 부서·인원과 회수되는 이수시간을 밝힌다 · «삭제 후에는 되돌릴 수 없습니다» |

- 상태: 등록 단계는 **작성 중 → 저장됨**이며 임시 보관을 두지 않는다. 회차는 1개로 시작해 최대 5개까지 늘어나고, 회차가 비면 시간도 0이다. 수정은 종료 처리 전까지 열려 있고(안내 공문을 보낸 뒤에도), 회차만 부서의 등록부 공문 발송으로 잠긴다. 교육 취소는 **교육 전**, 삭제는 **안내 공문 전**에만 있다.

### 4-4. 자체교육 목록 카드
- 부서 칩과 제목, 일시, 합계 교육시간, 강사, 장소, **대상자 n명**을 표시한다. 진행 상태 칩은 두지 않는다 — 자체교육은 등록하는 순간 완료이고, 남는 상태는 공문뿐이다.
- 카드 오른쪽에는 **결재 상태 칩 하나와 [공문 보기]** 둘만 둔다. 그 부서 담당자에게만 처리 수단이 더 붙는다.
- 목록 위: 부서 담당자에게 [＋ 자체교육 등록]. 재난안전과 담당자에게는 **[＋ 우리 부서 자체교육 등록]**(자기 부서 몫만)과 «자체교육은 각 부서 담당자가 등록하고 실시 결과 보고 공문을 보냅니다. 재난안전과는 결과를 봅니다.» 한 줄.

| 공문 상태 | 그 부서 담당자 | 재난안전과 · 조회 계층 |
|---|---|---|
| 공문 미기안 | «공문 미기안» 칩 · [공문 보내기] · «등록 취소» | «공문 미기안» 칩 |
| 결재 미완료 · 결재 완료 | 칩 + [공문 보기] | 칩 + [공문 보기] |
| 반려 · 반송 | 칩 · 사유 한 줄 · [다시 보내기] · [공문 보기] · «기록이 틀렸으면 등록 취소» | 칩 + [공문 보기] |
| 이전 방식 | 옛 실시 결과 공문이 있으면 칩 + [공문 보기], 없으면 «이전 방식» | 같음 — 옛 공문이 반려·반송이면 재난안전과 담당자에게 [다시 보내기] |

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [공문 보내기] · [다시 보내기] | 실시 결과 보고 공문(④) 작성 창을 연다 | 다시 보낼 때는 앞 제목·본문과 반려 사유를 이어 보인다 |
| [공문 보기] | 보낸 공문 지면을 연다 | 공문이 없으면 버튼을 내지 않는다 |
| «등록 취소» | 그 등록 묶음 전체와 이수기록 회수 수를 밝힌 확인 단계를 연다 | «이 등록과 이수기록 N건을 지웁니다. 바른 내용으로 다시 등록하세요. 되돌릴 수 없습니다.» |
| 확인 [등록 취소] | 교육과 이수기록을 지운다 | «등록을 취소했습니다 · 교육 N건 · 이수기록 N건 회수» |

- 상태: 공문 축은 **공문 미기안 → 결재 미완료 → 결재 완료**, 그리고 돌아온 **반려 / 반송**이다. 잠금은 버튼으로 표시하지 않는다 — 공문이 나간 기록에는 고치는 버튼 자체가 없다. [상세]·[수정]·[삭제]는 두지 않는다(카드 정보로 충분하고, 고치는 길은 등록 취소 하나다).

### 4-5. 자체교육 등록
- 부서(소속 부서로 고정), 회차, 강사, 장소, 제목, 교육일지 및 교육사진 등, 대상자를 입력한다. 부서 칸 아래 «소속 부서로 등록합니다 — 다른 부서 교육은 그 부서 담당자가 등록하고 실시 결과 보고 공문을 보냅니다.»
- 저장 버튼은 **[저장하고 공문 작성 →]**이다. 저장 즉시 완료 상태가 되고 고른 대상자에게 합계 교육시간을 반영한 뒤, 같은 창이 실시 결과 보고 공문(④) 작성으로 바뀐다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 대상자 선택 | 이수시간을 받을 사람을 정한다 | «(n / m명 선택)» · 한 명도 고르지 않으면 저장할 수 없다 |
| [저장하고 공문 작성 →] | 완료 상태의 자체교육을 만들고 대상자에게 시간을 반영한 뒤 공문 작성 창으로 바꾼다 | 맨 위 «교육 기록과 이수는 저장됐습니다 — 이 공문을 온나라로 보내야 할 일이 끝납니다» |
| 공문 작성 창을 닫음 | 기록·이수는 남고 공문만 미기안 | 내 할일 «공문 보내기» — 기한은 등록한 날부터 7일 |

- 상태: 진행 중 상태가 없다 — 이미 실시한 교육을 기록하는 경로이기 때문이다. 공문 단위는 **등록 한 번**이다.

### 4-6. 공문 작성 · 온나라로 보내기
이 화면의 공문은 네 종이고 모두 같은 순서를 따른다 — 작성 → [문서 미리보기 →] → [온나라로 보내기] → 확인 → [보내기]. 결재선은 받지 않고 온나라 연계기안함까지 보내며, 검토·결재는 담당자가 온나라에서 지정해 상신한다.

| 공문 | 언제 | 기안 | 수신 | 붙임 후보 |
|---|---|---|---|---|
| ① 교육 안내(변경·취소 안내 포함) | 집합교육 저장 직후 · 일시·장소 변경 · 교육 취소 | 재난안전과 담당자 | 그 교육 대상 부서 전부(고정 · 재난안전과 제외) | 등록 때 올린 교육 자료·참석자 명단 |
| ② 참석자 등록부 제출 | 부서가 등록부를 저장한 직후(상세) | 그 부서 담당자 | 재난안전과(고정) | 서명부 · 참석자 명단 별지(그 부서만) |
| ③ 출장 결과 보고 | 출장 결과 보고서를 저장한 직후(상세) | 재난안전과 담당자 | 내부결재 | 교육 자료 · 교육 사진 |
| ④ 실시 결과 보고 | 자체교육을 등록한 직후 | 그 부서 담당자 | 재난안전과(고정) | 방금 올린 교육일지·사진(미리 체크) · 이수자 명단 별지 |

- **본문은 담당자가 직접 쓴다.** 시스템이 문장을 지어내지 않는다. 수치를 세어 본문에 넣을 수 있는 **삽입 조각**으로 건넨다(교육 개요·참석 대상·등록부 제출 안내·실시 결과·근거 문구 등). 제목은 기본값이 채워지고 고칠 수 있다(예: «… 집합교육 실시 안내», «… 실시 결과 보고(부서)»).
- **붙임은 이미 올려 둔 파일에서 고른다** — 공문 화면에서 새로 올리지 않는다. 명단·별지는 PDF 파일로 만들어 붙임으로 나간다.
- 결재 상태 칩 어휘는 교육 전 화면이 같다: **공문 미기안 · 결재 미완료(기안함 전송·결재중) · 결재 완료 · 반려 · 반송**. «결재 미완료»에 마우스를 올리면 «온나라 기안함에서 검토·결재를 지정해 상신하세요 — 진행은 온나라에서 봅니다».

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 붙임 체크 | 체크한 파일이 붙임에 오른다 | 한도 «n / 5개 · n / 30MB» |
| 붙임 한도를 넘는 파일 | 체크할 수 없게 하고 사유를 밝힌다 | «온나라 붙임 한도(파일당 10MB) 초과 — 시스템에는 남아 있고 공문에는 붙지 않습니다» |
| 붙임 개수·합계가 한도를 넘음 | 미리보기의 [온나라로 보내기]를 비활성으로 두고 무엇을 줄일지 밝힌다 | 별지 PDF도 개수·합계에 함께 센다 |
| 본문 삽입 조각 | 누르면 그 문구가 본문 끝에 들어간다 | 수치만 만들어 준다 — 문장은 담당자가 쓴다 |
| [문서 미리보기 →] | 공문 지면을 보여 준다 | **작성 화면에는 보내기 수단이 없다** · 서명란은 기안자만 |
| 미리보기 [← 수정] | 작성 화면으로 되돌아간다 | 쓰던 내용은 유지된다 |
| 미리보기 [온나라로 보내기] | 확인 단계를 연다 | **되돌릴 수 없는 것만** 다시 알린다 |
| 확인 [보내기] | 공문을 온나라 연계기안함으로 보내고 결재 이력에 남긴다 | 결과 창 «온나라 결재 상태 — 기안함 전송». 문서번호(생산등록번호)는 결재가 끝나면 붙는다 |
| 연계 실패 | 기록은 그대로, 공문은 미기안 | «온나라로 보내지 못했습니다 — [다시 보내기]» — 보낸 척하지 않는다 |

- 상태: 공문은 **미기안 → 기안함 전송**이고, 담당자가 온나라에서 상신하면 **결재중**, 그 뒤 **결재 완료 / 반려**는 온나라 회신으로만 생긴다. 온나라가 접수하지 않은 것은 **반송**이다(반려와 다르다). 보내기 전까지는 되돌아갈 수 있고, 확인 단계에서 취소하면 아무것도 기록되지 않는다. 반려·반송이 오면 그 공문을 다시 보낼 수 있다.

### 4-7. 빈 상태
- 탭마다 문구를 나눠 표시한다 — 집합교육은 "등록된 집합교육이 없습니다." 또는 "조건에 맞는 집합교육이 없습니다.", 자체교육은 "등록된 자체교육이 없습니다." 또는 "조건에 맞는 자체교육이 없습니다."

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 그 탭에 등록된 교육이 하나도 없음 | 목록 자리에 최초 안내를 표시한다 | "등록된 (탭) 교육이 없습니다." |
| 조회 결과 0건 | 조건을 바꾸도록 안내한다 | "조건에 맞는 (탭) 교육이 없습니다." |

- 상태: 빈 상태는 **아직 아무것도 등록되지 않음**과 **조건에 맞는 건이 없음** 둘이며 문구를 달리한다 — 앞은 시작하라는 안내이고 뒤는 조건을 풀라는 안내라 할 일이 다르다. 로딩·오류 표시는 이 시스템 공통 규칙을 따른다.

## 6. 정책
- **회차를 바꾸지 않은 [수정]은 교육 시간을 다시 계산하지 않는다 (2026-11-17)** — 회차 폭과 인정 시간이 다른 기록(점심시간 등, 예: 09:30~18:30 · 8h)이 장소만 고쳐도 9h 로 바뀌고 이수기록까지 바뀌던 것을 막는다. 시간이 바뀌는 것은 회차(일자·시각)를 고쳤을 때뿐이다.

**과정마다 온나라 공문**
- **시스템에 증빙을 올리는 단계마다 온나라 공문이 나간다 (2026-11-16 1차 통화)** — 주무관 «결과 공문만 끝났다 이것만 하는 게 아니라 그 과정들도 다 내부적으로 문서 대장에 등록이 다 돼야 돼요». 편리함보다 문서대장 기록이 원칙이다. 이 화면의 공문은 §4-6 의 네 종이다.
- **공문을 보내야 그 일이 끝난다** — 등록부를 저장만 하고 ② 를 보내지 않았으면 그 부서 할 일이 남고, 자체교육을 등록만 하고 ④ 를 보내지 않았으면 «공문 보내기» 할 일이 남는다(기한은 등록일 + 7일 — 지난 교육을 올리는 순간 «지연»이 되지 않게 교육일이 아닌 등록일 기준). 교육 종료 처리 뒤에도 보내지 않은 ② 할 일은 남는다.
- **저장 버튼이 곧 공문 입구다** — 증빙 창과 기안 창이 따로 놀면 «등록만 하고 끝난 줄 아는» 부서가 생긴다. 그래서 저장하면 같은 창이 그 공문 작성으로 바뀐다(단일 모달). 닫아도 기록은 남고 공문만 미기안이다.
- **«안내 공문 전» 교육은 재난안전과에만 보인다** — 목록·상세 주소·내 할일이 같은 판정을 쓴다. 한 번 보낸 교육은 안내 공문이 반려·반송돼도 부서에 계속 보인다(이미 알림을 받은 부서에서 갑자기 사라지면 더 헷갈린다).
- **안내 공문을 보내지 않으면 부서는 교육을 모른다** — 예정 안내 알림도, 등록부 할 일도 안내 공문을 보낸 교육에만 생긴다.
- **예정 교육 알림은 할 일이 아니다 (2026-11-13 확정 X-1)** — 안내 공문을 보내는 순간 그 교육 모집단에 사람이 있는 부서에 헤더 알림 «집합교육 예정 안내»가 가고, 그 부서 내 할일에 «예정 교육 — 알림» 카드가 교육이 끝나는 날까지 보인다. 할 일 수·상태 칩에 세지 않는다. 마지막 회차 날이 된 교육은 «예정»이 아니므로 알리지 않는다(바로 등록부 받는 중).
- **안내 공문 뒤의 변경·취소** — 수정을 막지 않는다. 일시·장소를 바꾸면 변경 안내 공문을, 교육을 없애려면 교육 전에만 [교육 취소](사유 필수)로 취소 안내 공문을 보낸다. 취소한 교육은 «취소»로 남고 할 일·예정 안내·이수 집계에서 빠진다. 안내 공문을 보낸 교육은 삭제하지 않는다.
- **새 기록만 새 흐름이다** — 이 흐름으로 바뀐 뒤 이 시스템에서 새로 만든 교육·등록부만 공문 할 일이 생긴다. 그 전 기록은 «이전 방식»이며, 이전 방식 실시 결과 공문은 새로 만들지 않고 반려·반송된 것만 다시 보낸다.

**처리 주체**
- **집합교육의 등록·수정·교육 취소·삭제·종료 처리와 ①·③ 은 재난안전과 담당자가 한다.** 재난안전과는 부서 등록부를 대신 올리지 않는다(«재난안전과 담당자는 참석자 등록부를 등록할 필요가 없어요») — 한 장 서명부는 상세에서 [서명부 올리기]로 교육에 한 번 올리고 부서가 골라 쓴다(SCR-EDU-004). 재난안전과에도 대상자가 있으면 재난안전과 담당자는 상세 등록 현황의 자기 부서 줄에서만 등록부·② 를 낸다.
- **② 와 자체교육(등록·④·등록 취소·다시 보내기)은 그 부서 담당자가 한다** — 실무자 계정이 없는 부서만 부서장이 한다. 대리 등록·대리 기안은 없다 — 재난안전과 담당자도 다른 부서 몫은 하지 않고 자기 부서 몫만 «우리 부서 자체교육 등록»으로 한다. 등록 폼의 부서는 소속 부서로 고정되며 저장할 때도 다시 본다.
- **재난안전과는 부서 실시 교육을 검토만 한다 (2026-11-16 2차 통화)** — 화면에서는 결재 상태 칩과 [공문 보기]로 보고, 접수·검토는 온나라에서 한다. 시스템 안 확인 단계는 두지 않는다. 미기안·반려 부서에 별도 독촉 버튼을 두지 않는다 — 그 부서 내 할일에 «공문 보내기 / 다시 보내기»가 이미 있다.
- **관리·감독 계층(군수·과장·소장)은 조회만 한다** — 버튼 대신 누가 하는지를 밝힌다. 판정은 한 곳에서 하며, 화면·저장·공문 작성·미리보기·보내기 어느 경로로 들어와도 같은 결과가 나온다. 버튼만 감추면 다른 경로로 뚫린다.

**잠금**
- **공문이 나간 기록은 고치지 않는다** — «공문을 여기다 첨부하면은 … 더 이상 수정이 안 돼요. 이건 문서 위조예요.» 보낸 순간(기안함 전송)부터 잠그고, 반려·반송이면 풀린다. 잠금은 버튼이 아니라 **고치는 버튼이 없음**으로 표현한다(자물쇠 버튼이 상태 칩과 함께 «결재 완료가 두 개»로 읽혔다).
- **집합교육은 교육 전체를 잠그지 않는다** — 잠기는 것은 그 부서의 등록부(② 가 나간 뒤)와 회차(어느 부서든 ② 가 한 곳이라도 나간 뒤) 둘이다. 강사·장소·제목은 계속 고친다.
- **자체교육은 ④ 가 나가면 그 등록 묶음이 잠긴다** — 한 번에 등록한 묶음이 공문 하나라 등록 취소도 묶음 전체로 한다. 공문의 이수자 명단은 저장된 사본이 아니라 열 때마다 현재 이수기록에서 다시 만들어지므로, 보낸 뒤 취소를 열어 두면 이미 올라간 문서의 명단이 사후에 줄어든다.
- **이전 방식 교육은 그때 보낸 실시 결과 공문이 잠근다** — 수정·삭제·등록부 등록 취소가 잠긴다.

**공문 골격**
- **공문 골격은 전 도메인이 공유한다** — 순서·지면·보내기·확인은 공용 골격이 갖고 있고 교육은 **지면 내용과 저장 위치만** 얹는다. 도메인마다 공문 화면을 새로 만들면 순서가 갈린다.
- **작성이 먼저이고 보내기는 미리보기에만 둔다** — 발주처가 종전 [결재 상신]을 지우게 한 이유가 기능이 아니라 «공문 작성 단계 없이 결재만 올라가는 순서»였다(«왜 갑자기 뜬금없이 결재 상신이 있지»).
- **결재선을 받지 않는다 — 온나라 기안함까지만 보낸다 (2026-11-12)** — 운영 결정(2026-11-06 «온나라로 기안까지만»)이다. 결재 결과를 사람이 옮겨 적는 수단은 두지 않고, 완료·반려는 연계 회신으로만 반영한다(공통 권한 정의 §7-4). 연동 전에는 진행을 온나라에서 확인하라고 밝힌다 — 상신 직후에는 문서번호가 아직 없으므로 «문서번호로 확인»이라고 쓰지 않는다.
- **확인 단계는 새 정보만 낸다** — 미리보기에서 본 문서·붙임을 반복하지 않고 되돌릴 수 없다는 사실만 말한다. 이 규칙은 이 도메인의 공문에 적용된다 — 위험성평가 공문은 현행 화면을 유지하기로 확정돼 있다.
- **본문을 자동 생성하지 않는다** — «이게 다 직접 타이핑 하셔야 돼». 자동으로 엮는 것은 붙임과 수치뿐이다.
- **붙임은 새로 올리지 않고 이미 올려 둔 것을 고른다** — 공문 화면에서 파일을 새로 받으면 같은 증빙이 두 벌 생긴다.
- **붙임으로 적은 것은 실제 파일로 나간다 (2026-10-07)** — 지면의 «붙임»은 첨부물의 명칭과 수량을 적는 자리라(「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제4조제4항) 별지(명단)는 PDF로 만들어 보내고, 보낼 수 없는 파일은 붙임 목록에 올리지 않는다. 붙임 한도는 온나라 확인 전 설정값(파일당 10MB · 5개 · 합계 30MB)이며 고르는 단계에서 검사한다. 넘는 파일을 조용히 빼거나 압축·분할하지 않는다. 이 한도는 업로드 기준(파일당 20MB)보다 작아 정상으로 올린 파일이 공문에 붙지 못할 수 있으며, 사유 문구가 그 사실을 알린다.
- **공개구분은 업무별 기본값을 넘긴다 (2026-10-07)** — 교육 공문의 임시 기본값은 **부분공개(제6호)**다(명단이 실린다). 화면에 입력 칸을 두지 않고, 바꾸려면 온나라에서 바꾼다. 담양군 비공개 세부 기준을 받으면 기본값만 바뀐다(`99_미결사항목록` §5 EXT-21).
- **이수율은 어떤 공문의 조건도 아니다** — 전원 이수를 조건으로 하면 이수율이 낮은 부서가 보고를 영영 못 한다. 미이수는 보고 내용의 일부다. 출장 결과 보고서의 참석 인원도 보고용 대략치라 이수 판정에 쓰지 않는다(이수는 등록부 기준).
- **법령 근거를 붙이지 않는다** — 공문 기안과 온나라 이관은 의무를 이행하는 **형식**이지 법령이 직접 명한 행위가 아니다. 교육 실시 자체의 근거는 이 화면 상단에 이미 표시된다. 본문에 넣는 근거 문구는 담당자가 고른 것만 들어간다.

**교육시간·대상**
- 현업근로자는 **2026-12-31 까지 채용일 기준 6개월**, **2027-01-01 부터 달력 반기(1~6월 · 7~12월)** 단위로 판정하며(2026-11-13 확정 X-2 · 개발 확인 답신 3-2 — 별표4 «매반기»를 달력 반기로 읽되 반기 중간에 바꾸지 않는다. 전환 뒤에는 반기 중간에 채용된 사람도 그 반기 시간을 채운다) 사무직·판매업무 직접 종사자는 6시간, 그 밖의 근로자는 12시간을 필요시간으로 사용한다.
- 관리감독자는 재난안전과가 등록한 **지정일**이 있어야 판정하고(2027-01-01 부터 해마다 1~12월, 그 전까지 지정일 기준 12개월) 16시간을 필요시간으로 사용한다. 지정일이 없으면 채용일로 대신하지 않고 "판정 불가 — 지정일 미등록"으로 표시한다. 지정일 등록은 현업근로자 명단(SCR-EDU-006)에서 한다.
- **집계 모집단은 법정 대상보다 넓다** — 산업안전보건법 시행령 별표1 제4호가목이 공공행정을 같은 법 제3장(안전보건교육) 적용 제외로 두고 고시된 **현업업무 종사자만** 대상으로 남기는데, 현재 모집단은 조직도 인원 전원이다. 지정명단은 담양군이 고시 기준으로 정할 자료라 임의로 좁히지 않고 갭으로 드러낸다.
- **별표4 비고 제3호의 교육시간 2분의 1 감면은 담양군에 적용되지 않는다** — 그 감면은 「영 별표1 제1호에 따른 사업」(광산·원자력·항공·선박안전법 적용 사업)과 「상시근로자 50명 미만 도매업·숙박 및 음식점업」 전용이고 담양군은 같은 별표 제4호다.
- **교육시간 면제·감면(시행규칙 제27조)은 적용하지 않는다** — 조문이 "100분의 50 범위에서 면제할 수 있다"는 재량이고, 판정에 필요한 입력(전년도 산업재해 발생 이력·사업장 단위·이직 전 경력)이 시스템에 없다. 필요시간은 별표4 값을 그대로 쓴다 — **미적용 확정**이며, 담양군이 운용을 결정하면 변경 요청으로 반영한다.
- **집합교육의 인정시간은 참석자 등록부의 실제 참석시간이다 (2026-10-06 기획확인 4차)** — 등록부를 등록할 때 참석시간을 받고 기본값은 회차 합계이며, 0보다 크고 회차 합계 이하만 받는다(SCR-EDU-004 §4·§6). 다회차 교육에서 하루만 온 사람에게 전체 시간을 주면 하지 않은 교육을 했다고 기록하게 된다.
- **등록부는 교육이 끝난 뒤에만 받는다 (2026-11-12)** — 서명은 참석 사실의 증빙이고 실제 참석시간은 교육이 끝나야 정해진다. 마지막 회차 날부터 등록 기한(마지막 회차 + 등록부 기한 일수)까지 받고, 기한이 지나도 종료 처리 전까지 받는다.
- 자체교육은 별도의 종료 확인 없이 등록 즉시 완료한다. 기타 교육시간은 정기교육 이수시간에 합산하지 않는다.
- 완료기록은 지정·채용 정보가 바뀌어도 삭제하지 않고 당시 판정 기준과 함께 보존한다.
- **프로토타입의 물리 삭제는 예시 데이터 회수 장치다.** 본개발은 완료된 교육·이수기록·증빙을 물리 삭제하지 않는다 — 공통 계약(`_공통_권한정의.md`)대로 **등록취소 상태 전이**로 처리하고 취소 사유·처리자·시각을 보존하며 집계에서만 제외한다.

### 경위 — 대체된 결정 (따르지 말 것)
- **«공문 기안 진입점은 종료 처리된 교육 카드의 [공문 기안] 하나 · 공문 단위는 교육 1건 · 기안 조건은 종료 처리»** (2026-08-12) — 11-16 1차 통화로 과정별 공문(①~③)과 부서 실시 교육 공문(④)이 그 자리를 대신했다. 이미 보낸 실시 결과 공문은 «이전 방식»으로 남는다. 총괄·교육별·개인별 3종 단위도 이 전에 걷었다.
- **«기안·상신은 재난안전과 담당자만»** (2026-11-13 답신 3-3) — 11-16 통화로 «기록을 올린 부서가 보낸다»로 다시 정했다(2026-08-13 «등록 주체 = 기안 주체» → 11-13 거둠 → 11-16 재확정).
- **«자체교육은 [수정]·[삭제]·[상세] · 재난안전과는 전 부서 자체교육 등록»** — 11-16 2차 통화로 칩 + [공문 보기]와 등록 취소 하나로 바꿨다. 재난안전과의 대리 등록·[＋ 일괄 등록]·등록부 창의 부서 [조직도]도 1차 통화로 걷었다.
- **«부서 실시 교육은 분기에 한 장(분기 실시 결과 보고)»** (11-16 기획 v2 결정 R) — 같은 날 2차 통화(결정 D-1)로 걷었다. 등록 한 번 = 공문 한 번이다. 이미 보낸 분기 보고는 «이전 방식»으로 열람만 된다.
- **«결재선 3단계(기안 → 검토 → 결재) 지정»** — 2026-11-12 «온나라로 보내기»(결재선 없음)로 대체했다.
