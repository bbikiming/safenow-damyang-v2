| 2 | 완료 처리 창구 안내를 확인한다 | 내 할일 또는 위험성평가 화면으로 연결한다 |
| 3 | 재난안전과가 다른 화면에서 완료 확인 또는 반려한다 | 반려 시 이 화면에 사유와 제출 회차 표시 |
| 4 | 반려 건의 증빙을 보완해 재제출한다 | 완료 상태와 확인대기 회차 갱신 |

**분기 로직**

- **누구에게도 조치 입력이 나오지 않는다** — 담당 부서 사용자에게도 이 화면은 조회이고, 완료 처리 창구(내 할일 · 위험성평가 조치 상세 카드)로 안내한다. 같은 일을 세 화면에서 할 수 있으면 어느 것이 정본인지 알 수 없어진다.
- **상태에 따라 본문이 셋으로 갈린다** — 진행 중이면 조치 요구일·담당자와 완료 처리 창구 안내, 완료면 결과 요약(조치 내용·완료일·서명·사진), 반려면 반려 사유와 회차를 함께 표시한다.
- **반려 건은 완료 상태여도 할 일로 취급한다** — 상태만 보면 완료라 완료 탭에 묻히는데, 그러면 재제출 수단이 사라진다. 그래서 완료와 반려를 함께 보고 판정하며, 재제출도 위 두 창구에서 한다.
- **확인·반려 버튼은 이 화면에 없다** — 담당자가 제출하는 화면과 주관부서가 확인하는 화면을 분리했다. 확인은 정기·수시 위험성평가의 조치 상세 카드에서 한다.
- **출처에 따라 되돌아갈 곳이 다르다** — 정기평가 출처는 그 평가로, 수시평가 출처는 수시평가 식별값을 함께 표시한다.

**엣지케이스**

- **개선 후 사진이 없으면 완료할 수 없다** — 증빙 없는 완료는 소명되지 않는다. 이 조건은 완료 처리를 수행하는 두 창구(내 할일 · 위험성평가 조치 상세 카드)가 검사한다.
- **재제출해도 이전 반려 기록은 지우지 않는다** — 사유와 회차가 함께 남아야 무엇을 고쳐 다시 올렸는지 되짚을 수 있다.
- **없는 식별값으로 들어오면** 찾을 수 없다는 안내만 표시한다.
- **기한이 없는 건은 기한 자리를 비우지 않고 미지정임을 밝힌다** — 기한 초과 집계에서 빠진다는 사실을 함께 드러낸다.
- **시설물 축은 세 상태를 물려받는다** — 지정 / 해당 없음(확인 결과 붙지 않음) / 미지정(아직 판단 안 함). **미지정만** 항목 자체를 내지 않는다(빈 항목을 남기면 채워야 할 값으로 읽힌다). ‘해당 없음’은 앞 단계에서 확인이 끝난 결과이므로 그대로 낸다 — 감추면 담당자가 되돌아가 같은 확인을 다시 한다.
- **완료 확인이 끝난 건도 이 화면에서 다시 열린다** — 다만 결과를 보여줄 뿐 값을 바꾸지 않는다. 끝난 기록을 고치는 것은 조작이다.
- **어느 상태에서도 이 화면은 값을 저장하지 않는다** — 완료 전이든 반려 후든 입력란을 내지 않고 처리 창구로 안내한다. 창구가 셋이면 개발자가 어디를 정본으로 볼지 알 수 없다.

## 4. 화면 구성별 정리

### 4-1. 개요와 원본
- 출처, 대책 제목, 관리대상, 유해위험요인, 담당자, 기한과 원본 평가 식별값을 표시한다.
- 수시평가 출처는 수시평가 식별값을 표시한다.
- 시설물이 지정된 건은 시설물명(없으면 시설물번호)을, ‘해당 없음’으로 확인된 건은 “해당 없음”을 표시한다. 미지정만 항목을 내지 않는다.
- 조치 전 대책 내용과 사진 존재 여부를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 그 건의 출처·대책·담당·기한과 원본 평가 식별값을 표시한다 | — |
| 시설물 항목 | 지정이면 시설물명, 확인 결과 붙지 않으면 “해당 없음”을 개요에 낸다 | 미지정만 항목을 내지 않는다 |
| 원본 평가 식별값 선택 | 그 평가 화면으로 이동한다 | 정기 위험성평가(SCR-RISK-001) |
| 기한이 없는 건으로 진입 | 기한 자리를 비우지 않고 미지정임을 표시한다 | 기한 초과 집계에서 빠진다는 사실을 드러낸다 |

- 상태: 출처 축은 **정기평가 / 수시평가 / 점검·의견 / 수동** 네 가지이고 출처에 따라 원본 식별값의 연결 대상이 달라진다. 항목 단위로 **시설물 미지정**·**담당자 미지정**·**기한 미지정**이 각각 정상 상태이며, 기한 미지정은 값을 비우지 않고 그 사실을 적어 **기한 초과 집계에서 빠진다**는 것까지 드러낸다. 식별값이 잘못된 진입은 4-5에서 다룬다.

### 4-2. 조치 실시 안내 (조회 전용)
- 조치 요구일, 담당자, 담당 부서를 표시한다.
- **입력란과 완료 버튼을 두지 않는다** — 조치 내용·완료일·개선 후 사진·전자서명은 내 할일 또는 위험성평가 화면의 조치 상세 카드에서 등록한다.
- 그 두 창구로 가는 연결을 함께 낸다 — 조회만 되는 화면을 막다른 길로 두지 않는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 완료 전 건으로 진입 | 조치 요구일·담당자·담당 부서와 처리 창구 안내를 표시한다 | 입력란을 내지 않는다 |
| [내 할일에서 완료 처리] | 내 할일로 이동한다 | 담당자 본인의 처리 창구 |
| [정기/수시 위험성평가 열기] | 출처에 맞는 평가 화면으로 이동한다 | 그 화면의 조치 상세 카드에서 완료 처리한다 |
| 담당 부서가 아닌 사용자로 진입 | 같은 조회 화면을 보여준다 | 계층·부서에 따라 달라지지 않는다 |

- 상태: 이 영역은 **완료 전**과 **반려 후 재제출 대기**에서 나타나고, 확인 대기·확인 완료 상태에서는 완료 결과(4-3)로 대체된다. 어느 계층·부서로 들어와도 **조회 하나**이므로 권한에 따라 갈리는 상태가 없다 — 종전에는 담당 부서에만 입력 폼이 열려 같은 처리를 세 화면에서 할 수 있었다.

### 4-3. 완료 결과
- 완료 상태에는 조치 내용, 조치 요구일, 완료일, 전자서명 이름·일자와 개선 후 사진 파일명을 표시한다.
- 정기평가 출처는 완료율에 반영되었다는 안내를 추가한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 완료 상태로 진입 | 조치 내용·요구일·완료일·서명·사진 파일명을 읽기 형태로 표시한다 | — |
| 완료 상태로 진입 | 개선 후 사진 파일명을 조치 결과에 표시한다 | 별도 사진 확대 기능은 제공하지 않는다 |

- 상태: **완료 이후**에만 나타나며 읽기 형태다. 확인 축으로는 **확인 대기**와 **확인 완료** 둘이 이 영역과 함께 표시되고, 반려된 건은 이 영역 대신 4-4가 나타난다. 정기평가 출처인 건에만 완료율 반영 안내가 붙는다 — 수시평가는 완료율 집계 대상이 아니기 때문이다.

### 4-4. 반려·재제출
- 확인 반려 건은 완료 상태여도 반려자·반려일·사유와 제출 회차를 표시한다.
- **재제출도 이 화면에서 하지 않는다** — 증빙을 보완해 다시 올리는 것은 내 할일 또는 위험성평가 조치 상세 카드에서 하며, 저장되면 확인대기로 되돌아가고 제출 회차가 올라간다.
- 재난안전과의 확인·반려 버튼은 이 상세 화면이 아니라 정기·수시 위험성평가의 조치 상세 카드에서 제공한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 반려된 건으로 진입 | 반려자·반려일·사유와 제출 회차를 표시한다 | 완료 상태여도 할 일로 다시 올라온다 |
| 재제출하려는 경우 | 처리 창구 안내(4-2)로 연결한다 | 재제출은 내 할일 또는 위험성평가 조치 상세 카드에서 한다 |

- 상태: **반려됨**일 때만 나타난다. 조치 상태는 완료 그대로이고 확인 축만 반려로 바뀌므로, 화면에는 **완료이면서 반려됨**이 함께 보인다 — 이 조합이 정상이라는 것이 이 영역의 요점이다. 재제출이 저장되면 확인 대기로 되돌아가고 제출 회차가 올라가며, 이전 회차의 사유는 이력에 남는다. 확인·반려도 재제출도 수행 수단은 이 화면에 없다.

### 4-5. 오류 상태
- 식별값에 해당하는 개선조치가 없으면 “개선조치를 찾을 수 없습니다”를 표시한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 없는 식별값으로 진입 | 입력 수단을 내지 않고 안내만 표시한다 | “개선조치를 찾을 수 없습니다” |

- 상태: **찾을 수 없음** 하나다. 식별값이 없거나 조회 범위 밖인 건으로 들어오면 입력 수단을 일절 내지 않고 안내만 표시한다 — 범위 밖 건을 주소로 여는 것을 막기 위해 두 경우를 같은 화면으로 수렴시킨다.

## 6. 정책

- **이 화면은 조회 전용이다(2026-08-14)** — 완료 처리·재제출의 창구는 내 할일과 위험성평가 화면의 조치 상세 카드 둘뿐이며, 이 주소로 들어온 사용자에게는 그 창구를 안내한다.
- 담당 부서의 완료 처리는 개선조치 상태를 완료로 바꾸고 정기평가 출처이면 완료율에 즉시 반영한다.
- 완료와 동시에 재난안전과 확인 상태는 확인대기로 초기화한다.
- 반려되어도 목록의 개선조치 상태는 완료로 남고 담당자의 재조치 필요 여부를 별도로 표시한다.
- 재제출은 기존 확인 회차를 증가시키고 다시 확인대기로 전환한다.
- 조치 전 사진은 선택이며 개선 후 사진, 조치 내용과 전자서명 이름은 완료 필수값이다.
- 시설물 연결은 세 상태 그대로 표시용으로 승계하며 이 화면에서 시설물을 변경하지 않는다.
- 본 문서는 현재 프로토타입의 기능·UX를 기록한다.
