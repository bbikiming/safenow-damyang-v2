### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 파일 종류인데 파일을 아직 고르지 않음 | 저장은 되지만 상태를 `자료 없음`으로 표시하고 헤더에는 내지 않는다 — 누르면 오류가 나는 버튼을 두지 않는다 |
| 영상·주소 종류인데 주소가 `https://`로 시작하지 않음 | 저장을 막는다 |
| 등록된 자료가 0건 | 목록은 «등록된 가이드가 없습니다», 헤더 모달도 같은 한 줄을 보인다 |
| 사용 중인 자료를 삭제 | 확인 창에 «헤더에서 바로 사라진다»를 밝히고, 잠시 내리려면 `[사용 끄기]`를 쓰라고 안내한다 |
| 조회만 할 수 있는 사람이 들어옴 | 등록·수정·순서·사용·삭제 버튼을 내지 않는다. 저장 경로도 같은 판정으로 막는다 |

## 4. 화면 구성별 정리

### 4-1. 목록

- 열: 순서 · 자료(제목 + 설명) · 형식·분량 · 파일·주소 · 헤더 · 관리.
- 형식·분량은 헤더 모달에 찍히는 문구와 같다 — 파일이면 `형식 · 쪽수 · 용량 · 기준일·비고`, 영상·주소면 `형식 · 기준일·비고`.
- 헤더 열은 `보임` / `사용 안 함` / `자료 없음` 세 상태다.
- 제목 줄 오른쪽에 `[헤더 목록 미리보기]`와 `[＋ 자료 등록]`을 둔다.

### 4-2. 등록·수정

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 종류 선택 | 파일이면 업로드 칸·쪽수, 영상·주소면 주소·형식 칸을 보인다 | 입력한 제목·설명은 유지한다 |
| 파일 선택 | 파일 이름·용량을 보이고 형식을 확장자에서 정한다 | — |
| `[등록]`·`[저장]` | 검사를 지나면 목록과 헤더 모달에 반영한다 | 헤더에 보이지 않는 상태로 저장되면 그 이유(사용 끔·자료 없음)를 함께 말한다 |

### 4-3. 헤더 모달(전역 GNB)과의 관계

- 모달은 이 목록에서 **사용 중이고 자료가 있는** 항목만 표시 순서대로 그린다.
- 파일은 `[다운로드]`, 영상·주소는 `[열기]`(새 탭)다. 버튼의 접근성 이름에 형식·분량과 새 탭 여부를 함께 담는다.
- 시스템과 함께 배포된 기본 자료 2건(업무 관리 확인 가이드 · 중대재해 업무단계 길잡이)이 처음 상태다.

## 6. 정책

- **목록은 하나다** — 헤더 `[가이드 다운로드]` 모달은 이 화면의 목록만 읽는다. 화면 코드에 자료를 따로 적어 두면 관리 화면에서 바꾼 것이 반영되지 않는다.
- **도움말(`[?]`)과 섞지 않는다** — 도움말은 «이 화면» 사용법이고, 이 자료는 화면과 무관하게 어디서든 받아야 한다(2026-10-16 확정). 자료 목록은 `[가이드 다운로드]` 한 곳에 둔다(2026-11-05 기획 확인 회신 1-4).
- **누르면 오류가 나는 항목을 헤더에 내지 않는다** — 파일·주소가 없거나 사용을 끈 항목은 모달에서 뺀다. 관리 화면에서는 그 상태를 `자료 없음`·`사용 안 함`으로 드러낸다.
- **용량은 파일에서 잰다** — 손으로 적으면 파일을 바꿀 때 어긋난다. 표시는 MB 소수 한 자리다. 쪽수·기준일은 파일에서 안정적으로 뽑기 어려우므로 사람이 적는다.
- **영상은 주소로 둔다** — 영상 파일을 시스템에 올리지 않고 바깥 주소를 새 탭으로 연다. 군 내부망에서 그 주소가 열리는지는 등록하는 사람이 확인한다.
- **삭제와 내리기를 나눈다** — 잠시 내릴 때는 `[사용 끄기]`(목록에 남는다), 다시 쓰지 않을 때만 `[삭제]`다. 삭제 확인은 같은 창 안에서 하고 헤더에서 사라진다는 사실을 밝힌다.
- **법령 근거를 붙이지 않는다** — 시스템 운영 기능이다(SCR-COM-008).
