# 화면 정의서 — 메뉴 관리

> 화면 ID: SCR-ADMIN-005 · 화면 유형: 설정 (마스터-디테일) · 기획 관점(v6)
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.

---

## 1. 화면 정보

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-ADMIN-005 |
| 화면명 | 메뉴 관리 |
| URL 경로 | admin-menus.html |
| 상위 메뉴 | 시스템 관리 > 사용자·권한 > 메뉴 관리 |
| 화면 유형 | 설정 (마스터-디테일) |

**목적·설명** — 시스템의 기능별 활용 여부를 조회하고, 대메뉴 9개·중메뉴 각각에 대해 "누가 이 화면을 볼 수 있고(보기), 등록·수정·삭제·상신까지 할 수 있는가(수정)"를 지정하는 화면이다. 상단 `메뉴 이용 현황`은 접속·화면 이용 기록을 기간별로 집계해 미사용 기능을 찾고, 하단 마스터-디테일은 접근 권한을 설정한다. 권한 관리(SCR-ADMIN-006)가 "누구인가"를 정의하면 이 화면은 "어느 메뉴에 무엇을 할 수 있는가"를 확정한다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 이 화면은 시스템 관리 메뉴군에 속하며 **권한 설정 자체를 다루는 화면**이다. 지정 부여·회수, 사용 여부 전환, 일괄 적용은 §3~§6의 업무 흐름과 상태 전이 조건을 따른다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

**진입 / 이탈**

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|
| 진입 | 시스템 관리 메뉴(GNB) | 시스템 관리 > 메뉴 관리 선택 |
| 진입 | 권한 관리(SCR-ADMIN-006) | 등급 정의·구성원 변경 후 메뉴별 적용을 위해 이동 |
| 진입 | 사용자 관리(SCR-ADMIN-001) | 사용자별 실효 권한 역조회에서 특정 메뉴 설정을 점검하러 이동 |
| 이탈 | 공용 조직도 선택기(팝업) | 부서·사용자 직접 지정 시 열림 → [적용]/[취소]로 닫고 원래 패널로 복귀 |
| 이탈 | 다른 메뉴 설정 복사(팝업) | 복사 실행/취소 후 닫고 원래 패널로 복귀 |
| 이탈 | 원래 화면 유지 | 좌측 트리에서 다른 메뉴로 이동(미저장 시 이탈 확인) |

**사용자 시나리오**

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 좌측 트리에서 중메뉴 클릭 | 우측에 기본 정보 + 현재 지정 목록 로드. 상단에 "전체 권한 등급 1개(시스템 관리자)는 항상 접근·수정 가능합니다…" 안내 |
| 2 | "권한 등급 불러오기" 선택 → 등급 고르고 [추가] | 통합 목록에 등급 지정 행 추가(기본 보기 체크·수정 해제). 등급 선택 없이 [추가] 시 "추가할 등급을 선택하세요." |
| 3 | "부서·사용자 직접 지정" 선택 → [조직도에서 선택] | 공용 조직도 선택기(단일 모달) 열림 — 제목 "직접 지정 — {메뉴명}" |
| 4 | 부서·사용자 복수 체크 후 [적용 (N건)] | 각 대상이 지정 행으로 추가. "N건 추가"(중복 있으면 "· N건 중복 제외") |
| 5 | 각 행에서 보기/수정 체크 | 수정 체크 시 보기 자동 체크·잠금. 둘 다 해제하면 "권한 없음 — 저장 시 제거" 배지 |
| 6 | [저장] | 트리 배지·요약 즉시 갱신. "저장되었습니다."(무권한 행 있으면 "…보기·수정이 모두 없는 지정 N건을 제거했습니다.") |
| 7 | 저장 전 다른 트리 노드 클릭 | "저장하지 않은 변경사항이 있습니다…" 이탈 확인. 취소 시 현재 상태 유지 |
| 8 | 대메뉴 노드 클릭 | 우측이 하위 중메뉴 요약표 + 하위 일괄 적용으로 전환 |

**분기 로직**

- **좌측에서 무엇을 고르느냐로 우측이 세 갈래로 갈린다** — 아무것도 고르지 않으면 "좌측에서 메뉴를 선택하면…" 안내, **대메뉴**를 고르면 하위 중메뉴 요약표와 일괄 적용, **중메뉴**를 고르면 그 메뉴의 지정 목록과 편집 도구가 나온다.
- **지정 방식이 두 갈래다** — 등급으로 부여하면 그 등급의 구성원 전원이 대상이 되고(행을 펼쳐 구성원 미리보기), 부서·사용자로 직접 지정하면 그 대상만 걸린다. 두 방식은 한 메뉴에 함께 걸릴 수 있고, 같은 사람에게 겹치면 넓은 쪽이 적용된다.
- **수정을 체크하면 보기가 자동으로 켜지고 잠긴다** — 고칠 수 있는데 볼 수 없는 상태는 성립하지 않기 때문이다. 반대로 보기만 해제하는 것은 가능하다.
- **보기·수정이 둘 다 없는 행은 저장 시 사라진다** — 화면에서는 "권한 없음 — 저장 시 제거" 배지로 미리 알리고, 저장 후 몇 건이 제거됐는지 함께 알린다. 권한 없는 지정 행을 남겨 두면 "지정은 했는데 아무것도 안 되는" 상태가 목록에 쌓인다.
- **설정 복사는 더하기가 아니라 대체다** — 다른 메뉴의 설정을 불러오면 현재 목록에 합쳐지지 않고 통째로 바뀐다. 저장 전이라 되돌릴 수 있다는 사실을 팝업에 함께 적는다.
- **기준 메뉴가 미설정이면 복사·일괄 적용이 경고를 띄운다** — 미설정을 복사한다는 것은 대상 메뉴의 지정을 전부 지워 기본 차단으로 만든다는 뜻이라, 무엇이 일어나는지 문장으로 밝히고 확인을 받는다.
- **시스템 관리 대메뉴는 지정 대상에서 빠진다** — 복사·일괄 적용의 기준 메뉴 목록에도 나타나지 않는다. 전체 권한 등급이 자동 적용되는 영역이라 설정 대상이 아니다.

**엣지케이스**

- **저장하지 않고 다른 메뉴로 이동하면 확인을 받는다** — 트리의 다른 노드를 누르거나 대메뉴로 올라갈 때 모두 같은 확인이 뜨고, 취소하면 고치던 내용이 그대로 남는다.
- **같은 메뉴를 다시 누르면 아무 일도 일어나지 않는다** — 편집 중이던 내용이 초기화되지 않도록 같은 선택은 무시한다.
- **이미 있는 대상을 다시 추가하면 중복으로 세어 알린다** — 조직도에서 여러 명을 골랐을 때 "N건 추가 · N건 중복 제외"로 실제 추가된 수와 걸러진 수를 나눠 보여준다.
- **등급을 고르지 않고 [추가]를 누르면** "추가할 등급을 선택하세요"로 막는다. 복사 팝업에서 대상 메뉴를 고르지 않았을 때도 같다.
- **검색 결과가 없으면** 트리 자리에 "검색 결과가 없습니다"를 표시한다. 검색 중에는 대메뉴가 모두 펼쳐진 상태로 보인다.
- **지정이 하나도 없는 메뉴**는 목록 자리에 "지정된 권한이 없습니다 … (미설정 = 기본 차단, 시스템 관리자 제외)"를 띄운다. 빈 목록을 "아무나 들어올 수 있다"로 오독하지 않게 하는 문구다.
- **사용 여부를 꺼도 실제 내비게이션은 아직 바뀌지 않는다** — 프로토타입은 표시만 하며 그 사실을 안내에 밝힌다(§6 확정).
- **[초기화]는 저장 전 편집 내용만 되돌린다** — 이미 저장된 지정에는 영향이 없다. 저장분까지 되돌리는 것은 별도의 데모 데이터 초기화다.

## 4. 화면 구성별 정리

### 4-1. 상단 안내 바 · 데모 데이터 초기화
- 구성: 좌측에 화면 성격 안내 문구, 우측에 [데모 데이터 초기화] 버튼.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| (안내 문구) | 화면 성격 상시 표기 | "메뉴별 접근 권한을 설정합니다. 미설정 메뉴는 기본 차단(시스템 관리자 제외)이며, 실제 내비게이션 노출에는 영향을 주지 않습니다(프로토타입)." |
| [데모 데이터 초기화] | 확인 후 등급·지정·사용 여부를 초기 시드로 복원 | 확인: "메뉴·권한 데모 데이터를 초기 시드로 되돌립니다. 이 화면에서 변경한 내용이 모두 사라집니다. 계속하시겠습니까?" / 완료: "데모 데이터를 초기화했습니다." |

- 상태: 초기화 후에는 우측 패널 선택이 해제되어 "좌측에서 메뉴를 선택하면 접근 권한을 설정할 수 있습니다." 안내로 돌아간다.

### 4-2. 좌측 메뉴 트리
- 구성: 상단 검색 입력("메뉴명 검색"), 아래 대메뉴 > 중메뉴 카탈로그(현재 내비게이션 구성과 단일 출처, 메뉴에서 뺀 화면 포함). 개수는 메뉴 정의에서 파생하므로 이 문서에 적지 않는다. 각 중메뉴에 상태 배지, 대메뉴에 펼침/접힘 화살표. 같은 대메뉴 안에서 메뉴명이 겹치면 `구분 · 메뉴명`으로 표시한다(예: `현업근로자 · 정기교육`, `관리감독자 · 정기교육`).
- 상태 배지 4종: `설정 N건`(지정 있음) · `미설정`(지정 0건 = 기본 차단) · `사용 안 함`(사용 여부 꺼짐) · `관리자 전용`(시스템 관리 하위 메뉴).
- **메뉴에서 뺀 화면은 `메뉴 제외`로 함께 표시한다(2026-09-03)** — 트리·이용 통계·대메뉴 요약·복사 대상 드롭다운 모두. 그 화면들은 주소로 열리므로 **권한은 계속 설정한다** — 밝히는 것은 «지금 메뉴에는 없다»는 사실뿐이다. 표시하지 않으면 관리자가 권한을 주고도 대메뉴·좌측 메뉴에 왜 나타나지 않는지 알 수 없다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 메뉴명 검색 입력 | 메뉴명·구분명·대메뉴명이 일치하는 중메뉴만 남기고 대메뉴는 펼쳐 노출. 일치하는 대메뉴명은 하위 전체 노출 | 결과 없으면 "검색 결과가 없습니다." |
| 대메뉴 화살표 | 해당 대메뉴 하위 중메뉴 펼침/접힘 | — |
| 대메뉴명 클릭 | 우측을 하위 요약 패널(4-8)로 전환 | 미저장 시 이탈 확인 |
| 중메뉴 클릭 | 우측을 그 메뉴 설정 패널(4-3~4-6)로 전환. 같은 메뉴 재클릭은 무시 | 미저장 시 이탈 확인 |

- 상태: 빈 상태(검색 미일치) "검색 결과가 없습니다.". 단계상태 = 각 중메뉴가 `설정 N건`→(전체 해제·저장)→`미설정`, 사용 여부에 따라 `사용 안 함`, 시스템 관리 하위는 항상 `관리자 전용`. 저장 시 배지가 즉시 갱신된다.

### 4-3. 우측 패널 — 기본 정보(중메뉴 선택 시)
- 구성: 메뉴명 · 대메뉴 · 경로 · 연결 화면 코드(모두 조회 전용) + 사용 여부 토글. 메뉴의 신설·삭제·순서 변경·명칭 수정은 이 화면 범위가 아니다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 사용 여부 토글(켬) | 이 메뉴를 사용으로 전환, 즉시 적용 | "메뉴 사용으로 설정되었습니다." / 텍스트 "사용" |
| 사용 여부 토글(끔) | 이 메뉴를 사용 안 함으로 전환(내비게이션 숨김 대상), 즉시 적용 | "메뉴 사용 안 함으로 설정되었습니다. (프로토타입 — 실제 내비게이션에는 영향 없음)" / 텍스트 "사용 안 함 (메뉴 숨김 대상 — 프로토타입은 표시만)" |

- 상태: 사용 여부는 접근 권한 지정과 무관하게 최우선 스위치다(꺼짐이면 전 등급에서 숨김 대상). 토글은 확정 저장을 기다리지 않고 즉시 반영되어 트리 배지가 `사용 안 함`으로 바뀐다.

### 4-4. 우측 패널 — 접근 권한(추가 수단)
- 구성: 전체 권한 자동 적용 안내줄 + 추가 방식 라디오("권한 등급 불러오기" / "부서·사용자 직접 지정") + 방식별 추가 속성창. 라디오는 메뉴별 배타 선택이 아니라 추가 입력 수단을 전환하는 토글이며, 두 방식으로 넣은 결과는 하나의 통합 목록(4-5)에 누적(합집합)된다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 전체 권한 안내줄 | 시스템 관리자 등급이 목록과 무관하게 자동 적용됨을 상시 표기 | "전체 권한 등급 1개(시스템 관리자)는 항상 접근·수정 가능합니다. 아래 목록과 무관하게 자동 적용됩니다." |
| "권한 등급 불러오기" 선택 | 등급 선택 목록 + [추가] 노출. 목록은 전체 권한 등급과 이미 추가된 등급을 제외. 남는 등급이 없으면 "추가할 등급 없음" | — |

### 4-5. 우측 패널 — 통합 지정 목록
- 구성: 유형(권한등급 / 부서 / 사용자) · 대상 · 보기 · 수정 · 관리 5열 표. 각 행에 유형 배지, 대상명, 보기·수정 체크박스, [제거]. 등급 행은 구성원 미리보기 펼침, 부서 행은 `하위 포함`/`직속만` 표기.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 수정 체크 | 해당 행 수정 부여 + 보기 자동 체크·잠금(수정 ⊃ 보기) | 하단 "'수정'은 등록·수정·삭제·상신을 포함합니다. 수정 체크 시 보기는 자동 포함됩니다." |
| 보기 체크 해제(수정 없음) | 보기 해제. 보기·수정 모두 해제 시 무권한 행 처리 | 행에 "권한 없음 — 저장 시 제거" 배지 |
| 등급 행 펼침 | 그 등급의 구성원(부서·인원) 미리보기 표시(조회 전용) | "구성원 미리보기 (N명)". 일반 공무원 등급은 "SSO 로그인 사용자 전원이 자동 포함됩니다." |
| [제거] | 해당 지정 행 삭제 | — |

- 상태: 부서 행은 조직도 선택 시의 포함 범위에 따라 `직속만` 또는 `하위 포함`으로 표기. 무권한 행은 강조 표시되며 저장 시 자동 제거된다(저장 결과 토스트에 제거 건수 포함). 단계상태 = 통합 목록 유무가 트리 배지 `설정 N건`↔`미설정`을 결정한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |

## 6. 정책

- **미설정 = 기본 차단** — 지정 행이 하나도 없는 메뉴는 시스템 관리자를 제외한 전원에게 기본 차단되고, 트리에 `미설정` 배지가 붙는다. "설정을 깜빡하면 열리는" 사고를 막는 화이트리스트 방식이다. **강제 차단 규칙도 확정돼 있다(MENU-01·MENU-06 확정)** — 프로토타입에 로그인이 없어 아직 동작하지 않을 뿐, 무엇을 어떻게 막을지는 정해져 있다. ① **대메뉴는 하위 중메뉴가 하나라도 접근 가능할 때만 보인다** — 눌러도 아무것도 없는 대메뉴는 없는 것보다 나쁘다. ② **차단된 메뉴는 숨기고, 주소로 직접 들어와도 막는다** — 화면에서만 지우면 주소를 아는 사람은 그대로 들어간다. ③ **사용 여부 토글이 메뉴 지정보다 우선한다** — 사용 안 함으로 끈 메뉴는 접근 권한이 있어도 보이지 않는다. 앞은 "이 기능을 쓰지 않는다"는 시스템 차원의 결정이고 뒤는 "누가 쓰는가"라서, 순서가 반대면 끈 기능이 일부 사람에게 계속 보인다.
- **합집합·수정 우선** — 한 대상이 등급 경유와 직접 지정 등 여러 경로로 같은 메뉴에 권한을 받으면 가장 넓은 권한(수정 > 보기)을 실효값으로 삼는다. '수정'은 등록·수정·삭제·상신을 포함하며, 승인·반려·완료·공표 등 결재 단계 권한은 이 화면이 정하지 않고 각 화면 정책·온나라 결재선을 따른다(공통 권한 정의서 §4·§7).
- **전체 권한 등급의 자동 적용·설정 제외** — 전체 권한 등급(시스템 관리자)은 모든 메뉴에 자동 적용되며 메뉴별 지정 대상 목록에 나타나지 않는다. 관리자가 실수로 자기 접근을 없애는 셀프 잠금을 원천 차단한다.
- **명시 저장** — 접근 권한 변경은 [저장]으로만 확정한다(자동 저장 없음). 미저장 상태 이탈은 확인 다이얼로그로 보호한다. 반면 사용 여부 토글·일괄 적용·데모 초기화는 즉시 반영된다.
- **대체 방식 복사·일괄 적용** — [다른 메뉴 설정 복사]와 [하위 전체에 복사]는 대상 메뉴의 기존 설정을 대체하며, 실행 전 대상 수·대체 사실을 확인한다. 자기 자신·시스템 관리 메뉴는 소스/대상에서 제외하고, 미설정 소스를 고르면 기본 차단 경고를 추가한다. 시스템 관리 대메뉴는 일괄 적용 자체를 제공하지 않는다.
- **활용 여부는 메뉴 단위로 집계한다** — SFR-001의 목적은 쓰이지 않는 기능을 찾아 운영 여부를 점검하는 것이다. 조회 기간의 메뉴 진입/화면 이용 건수와 최종 이용일만 제공하고 사용자별 감시 지표는 만들지 않는다. `0건`은 선택 기간 안에 이용 로그가 없다는 뜻이지 메뉴 폐지 판정이 아니다.
- **조직도 단일 출처** — 직접 지정에 쓰는 조직도는 경영방침(SCR-SBM-001)·의견청취(SCR-OPN-001)·인력 평가(SCR-EVL-001) 등 다른 화면의 조직도와 동일한 부서·인원을 참조하며, 부서 지정은 특정 시점 인원 스냅숏이 아니라 그 부서 소속 전체를 가리키는 동적 참조다.
- **프로토타입 표현 한계** — 로그인·실제 접근 강제가 없어 이 화면의 저장 결과·사용 여부 토글은 설정 데이터로만 존재하고 실제 내비게이션 노출에는 아직 영향을 주지 않는다(상단 안내로 명시).
- **지정 변경은 전부 이력으로 남긴다(MENU-02 확정)** — 접근 권한은 "누가 무엇을 볼 수 있었나"를 사후에 따지는 대상이라 변경 기록이 없으면 아무것도 설명할 수 없다. **등급·구성원 변경 이력(SCR-ADMIN-006)과 한 곳에 통합**한다 — 나눠 두면 "이 사람이 이 메뉴를 볼 수 있게 된 경위"를 두 화면을 오가며 맞춰야 하는데, 실제로는 등급이 바뀌어서일 수도 지정이 바뀌어서일 수도 있다. 남기는 것은 일시·처리자·대상(메뉴·등급·사람)·이전 값·이후 값이며, 이력은 고치거나 지우지 않는다.
- **감사용 열람 계정을 별도 등급으로 둔다(MENU-03·PERM-006 확정)** — 외부 점검·감사에 대비해 **읽기 전용 등급**을 하나 만든다. 구성원 자동 포함을 쓰지 않고 **개별 지정만** 허용하며, 지정할 때 유효 기간을 함께 받는다 — 감사가 끝나도 남아 있는 열람 계정이 가장 흔한 사고 경로다. 이 등급에는 '수정' 권한을 줄 수 없게 막고, 부여·회수는 전부 위 이력에 남는다. **기본 상태는 구성원 0명**이다 — 필요할 때 넣고 끝나면 뺀다.
- **프리셋은 오픈 시 1회만 적용하고, 이후에는 되돌림 수단으로만 둔다(MENU-04 확정)** — 시스템 관리자가 최초 1회 적용하며, 적용 시점에 이미 지정 행이 있으면 **덮어쓰지 않고 멈춘다** — 운영 중에 프리셋이 다시 적용되면 그동안 조정한 권한이 통째로 날아간다. 재적용이 필요하면 **메뉴 단위로만** 되돌릴 수 있게 하고 전체 재적용은 두지 않는다. **데모 초기화와 실서비스 초기화를 같은 버튼으로 두지 않는다** — 데모 초기화는 시연 환경에만 노출하고 운영 환경에는 나타나지 않게 한다.
- **조회 범위는 권한 관리가 등급 기본값으로 다룬다(MENU-05 확정)** — "본인·배정업무 / 소속 부서 / 소관 조직 / 전체"는 메뉴 접근과 다른 축이다. 메뉴 관리는 "이 화면에 들어갈 수 있는가"를 정하고, 권한 관리(SCR-ADMIN-006)는 "들어가서 어느 범위까지 보이는가"를 정한다. 업무 화면은 이 값을 적용할 뿐 별도 질문이나 자체 예외를 만들지 않는다.
- **조직도는 행정포털에서 받고 자체로 관리하지 않는다(MENU-07 확정)** — 인원 출처는 담양군 행정포털(SSO·조직도)이며 이 시스템이 명단을 따로 갖지 않는다. **전입·전출은 로그인 시점에 반영**한다 — 주기 동기화로 두면 발령 다음 날 전입자가 못 들어오는 상황이 생기는데, 로그인 때 확인하면 그 순간부터 맞는다. **외부 인력(용역·위탁)은 조직도에 없으므로 개별 지정으로만** 넣고 유효 기간을 함께 받는다. 부서 지정은 특정 시점 명단이 아니라 동적 참조라 전입자가 자동 포함되고 전출자는 자동 제외된다.
- **일괄 적용은 대체 방식만 둔다(MENU-08 확정)** — 합집합 추가 옵션을 병행하지 않는다. 두 방식을 함께 두면 누를 때마다 "이번엔 대체인가 추가인가"를 확인해야 하고, 잘못 고르면 되돌릴 수단이 없다. **대체는 결과가 하나로 정해져 예측 가능**하고, 실행 전에 대상 수와 대체 사실을 확인받으므로 안전하다. 일부만 더하고 싶으면 그 메뉴를 직접 고쳐 넣는다 — 일괄 적용은 여러 메뉴를 같은 상태로 맞추는 수단이지 조금씩 더하는 수단이 아니다.
- **연계** — 등급 정의·구성원은 권한 관리(SCR-ADMIN-006)에서 관리하고, 사용자별 실효 권한(등급+개별 지정 합집합)은 사용자 관리(SCR-ADMIN-001)의 접근 메뉴 역조회에서 확인한다. 초기 세팅 프리셋은 시스템 오픈 시 이 화면의 지정 행 기본값으로 일괄 제공된다.

## 7. 미결사항

없음. 차단 규칙과 우선순위·지정 변경 이력·감사용 열람 계정·프리셋 적용 절차·조회 범위 축의 소속·조직도 동기화·일괄 적용 방식은 모두 §6에서 확정했다.

로그인 연동과 실제 접근 강제는 미결이 아니라 **본개발 구현 범위**다 — 무엇을 어떻게 막을지는 §6에 정해져 있고, 프로토타입에 로그인이 없어 아직 동작하지 않을 뿐이다.
