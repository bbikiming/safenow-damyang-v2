# 화면 정의서 — 이행관리(이행점검)

> 화면 ID: SCR-SBM-006 · 화면 유형: 현황 + 점검 · 기획 관점(v6) · 구현 정합 2026-08-12
> 판단이 필요했던 항목은 §6 정책에서 확정했습니다.

| 화면 유형 | 현황 + 점검 |

법이 요구하는 것을 **실제로 하고 있는지 주기마다 확인하는** 화면이다. 중대재해처벌법은 안전보건관리체계가 갖춰졌는지를 반기마다, 공중이용시설 축은 연 1회 점검하도록 요구하며, 관계 법령 의무이행도 같은 주기로 확인해야 한다. 그래서 이 화면은 **부서별 전수 이행 현황 · 체계 점검(반기) · 매뉴얼/업무처리절차 점검 · 관계 법령 점검 · 예산 편성·집행** 다섯 영역으로 구성되고, 미이행은 개선조치(SCR-IMP-001)로 이어진다.

## 2. 권한 정보

- 메뉴 접근·보기·수정은 시스템 관리의 메뉴 관리(SCR-ADMIN-005)와 권한 관리(SCR-ADMIN-006)에서 설정한다.
- 이 화면 정의서에서는 역할별 권한과 열람 범위를 별도로 정하지 않는다.
- 부서별 이행 등록은 **그 부서 담당자 본인**이 하고 관리·감독 계층은 조회만 한다. 수행 주체는 §3~§6의 업무 흐름을 따른다.

## 3. 진입 / 이탈 경로 및 사용자 시나리오

| 구분 | 연결 화면 | 조건 / 트리거 |
|---|---|---|

| 이탈 | 개선조치 | 미이행 항목 조치(SCR-IMP-001) |
| 이탈 | 경영방침 게시 현황 | 같은 부서 축을 공유하는 화면(SCR-SBM-001) |
| 연계 | 전자문서 서식 | 체계 점검표(F5) 작성 |

| 단계 | 사용자 행동 | 화면 반응 |
|:--:|---|---|
| 1 | 화면에 들어온다 | 부서별 이행 현황을 전수로 보여 준다 |
| 2 | 부서가 자기 행을 채운다 | 이행·미이행·해당없음 중 하나와 증빙을 받는다 |
| 3 | 반기 체계 점검을 작성한다 | 점검표 서식을 열고 미흡은 조치로 잇는다 |
| 4 | 관계 법령 이행을 점검한다 | 산업재해 축은 반기, 공중이용시설 축은 연 1회 |
| 5 | 매뉴얼·업무처리절차의 제정·조치 여부를 확인한다 | 원문은 문서 목록(SCR-CMP-002)에서 찾고, 회차별 점검·증빙은 이행 관리(SCR-CMP-001)로 이동한다 |

### 분기 로직

- **법률이 두 축이라 주기가 다르다** — **중대산업재해 축**(종사자)은 관계 법령 의무이행과 교육 실시를 **반기 1회**, **중대시민재해 축**(공중이용시설)은 **연 1회** 점검한다. 한 축만 두면 절반만 점검한 것이 된다.
- **이행 상태는 세 갈래다** — **이행 / 미이행 / 해당없음**. 상태는 코드로 저장하고 화면에 보이는 말은 화면이 정한다 — 이행점검에서는 "이행·미이행"으로, 경영방침 게시 현황에서는 "게시·미게시"로 읽혀야 하는데 표시 문구를 저장하면 라벨을 바꿀 때 데이터가 깨진다.
- **이행으로 등록하려면 증빙과 위치가 있어야 한다** — 무엇을 근거로 했다고 하는지 없으면 점검이 성립하지 않는다.
- **해당없음은 사유 없이 저장할 수 없다** — 종이 서식에서 가장 흔한 회피 경로가 '해당 없음'이다. 필수 표시만 하고 통과시키면 종이 서식의 문제를 그대로 옮긴다.
- **회차가 데이터의 단위다** — 상반기와 하반기가 같은 행을 공유하면 5월에 찍은 이행이 11월 점검을 발행 즉시 완료로 만든다. 부서·항목만이 아니라 **회차까지 포함해** 구분한다.

### 예외·경계 시나리오

| 상황 | 화면 반응 |
|---|---|
| 증빙 없이 이행으로 등록 | 저장을 막는다 — 근거 없는 이행은 점검이 아니다 |
| 해당없음에 사유를 비움 | 저장을 막는다 |
| 사유가 없는 기존 데이터 | 행에 **사유 미기재 — 확인 필요**로 계속 드러낸다 — 조용히 통과시키지 않는다 |
| 대상 부서 명단이 다 확보되지 않음 | 등록된 부서 수와 전체 대상 수를 함께 표시한다 — 부서를 지어내 채우지 않는다 |
| 다른 부서 행을 등록하려 함 | 막고 수행 주체를 알린다 |
| 관계 법령 목록이 아직 없음 | **목록 미등록**으로 드러내고 담양군 제공 범위와 미수신 대체 동작을 안내한다 |
| 새 회차가 시작됨 | 이전 회차 값을 이어받지 않는다 — 회차마다 새로 확인한다 |
| 관리·감독 계층으로 진입 | 등록 수단을 내지 않고 조회만 하게 한다 |

## 4. 화면 구성별 정리

### 4-1. 부서별 이행 현황(전수)

- 구성: 과·사업소를 전수로 늘어놓은 표. 부서 · 이행 상태 · 증빙 · 위치 · 사유 · 등록 수단.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 부서 담당자가 상태 선택 | 이행·미이행·해당없음 중 하나를 고른다 | 자기 부서만 고를 수 있다 |
| 이행으로 등록 | 증빙과 위치를 함께 받는다 | 둘 다 없으면 저장하지 않는다 |
| 해당없음으로 등록 | 사유를 받는다 | 사유 없이 저장하지 않는다 |
| 사유 없는 기존 행 | 확인이 필요함을 행에 표시한다 | 감추지 않는다 |
| 미이행 부서에 재촉 | 재촉 이력을 남긴다 | 보낸 사람은 실제 접속자로 기록된다 |

- 상태: 부서·회차 단위로 **미등록 / 이행 / 미이행 / 해당없음** 네 가지다. 화면 위에 **등록된 부서 수 / 전체 대상 수**를 함께 표시해 명단 갭을 감추지 않는다.

### 4-2. 안전보건관리체계 점검(반기)

- 구성: 점검표 서식과 그 상태. 미흡 항목은 개선조치로 이어진다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [점검표 작성] | 점검표 서식을 연다 | SCR-EDOC-005 |
| 미흡 판정 | 확정 시 개선조치로 자동 등록된다 | SCR-IMP-001 |
| 확정 이후 | 입력이 잠긴다 | 고치려면 개정한다 |

- 상태: **작성 전 → 작성중 → 등록완료 → 확정** 이며 주기는 반기 1회다. 아직 하지 않은 반기는 작성 전으로 표시하고 주기를 함께 낸다.

### 4-3. 중대재해 예방 매뉴얼·업무처리절차 점검(SFR-012)

- 구성: `제정·개정 원문 / 제정·조치 여부 점검` 두 행과 각 정본 위치·상태·이동 수단.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [문서 찾기] | 문서 목록으로 이동 | SCR-CMP-002 |
| [이행 점검] | 이행 관리로 이동 | SCR-CMP-001 — 회차별 제정·개정·교육·조치 여부와 증빙 등록 |

- 상태: 이행은 회차별 **미등록 / 진행 / 완료 / 미시행**을 사용한다. 같은 원문 파일을 두 화면에 중복 업로드하지 않는다.
- **문서별 버전 이력은 두지 않는다(2026-09-03)** — 그 기능은 기준문서함(SCR-DOC-001)에만 있었고 그 화면이 메뉴에서 빠지면서 대체가 없다. 표의 상태 칸이 그 사실을 그대로 밝히고, 원문을 찾는 자리만 문서 목록으로 잇는다. 없어진 기능을 있는 것처럼 적지 않는다.

### 4-4. 관계 법령 의무이행 점검

- 구성: 두 축(산업재해 · 공중이용시설)의 점검 항목과 주기, 그리고 관계 법령 목록.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 축마다 다른 주기를 함께 표시한다 | 산업재해 반기 1회 · 공중이용시설 연 1회 |
| 관계 법령 목록이 없음 | **목록 미등록**을 드러낸다 | 담양군 제공 범위와 미수신 대체 동작 안내 |
| 교육 이수 점검 | 안전관리자 교육 이수 여부를 연 1회 확인한다 | 공중이용시설 축의 별도 항목이다 |

- 상태: 항목마다 **미점검 / 점검 완료**이며, 관계 법령 목록 자체는 **미등록** 상태다. 목록이 정해지기 전에는 점검 항목을 지어내지 않는다.

### 4-5. 안전보건 예산 편성·집행

- 구성: 편성액과 집행 현황을 보여 주는 요약.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 편성·집행 현황을 보여 준다 | 상세는 인력·예산 메뉴에서 다룬다 |
| 집행이 편성에 크게 못 미침 | 그 사실이 수치로 드러난다 | 감추지 않는다 |

- 상태: **편성 전 / 편성됨 / 집행 중**이며, 이 화면은 요약만 보여 주고 편성·집행 자체는 인력·예산 메뉴에서 한다.

## 6. 정책

- **반기 마감 보고 상신은 결재선을 지정해야 한다(2026-08-28)** — 「상신」을 말하는 모든 경로는 결재선 지정 단계를 거치고 「기안 → 검토 → 결재 3단계 · 서로 다른 계정」 검사를 통과한다(공통 권한 정의 §7). 종전에는 이 버튼만 결재선을 묻지 않아 검증되지 않은 결재선이 상신된 것처럼 표시됐다.
- **상신 사실과 결재선은 회차별로 남긴다** — 상신된 회차는 버튼 대신 그 결재선과 「진행은 온나라에서 문서번호로 확인」을 표시하고, 같은 회차를 두 번 상신하지 않는다. 회차 표기는 화면에서 고른 반기를 따른다.
- **이행점검은 결재 결과를 받지 않는다**(공통 §7-4) — 결재 결과가 후속 업무를 열지 않으므로 이 시스템이 만드는 상태는 `결재중` 하나다.

- **조작 수단이 없는 사람에게는 왜 없는지 상시 밝힌다** — 관리·감독 계층과 소관이 아닌 부서에는 등록 수단을 내지 않는데, 안내를 버튼 눌렀을 때만 내면 **버튼이 없으므로 그 안내에 도달할 길이 없다.** 표 위에 조회 전용임을 밝히고 누가 등록하는지 함께 적는다.
- **증빙 삭제도 등록과 같은 권한 축이다** — 남의 부서 행에 삭제 수단이 보이면 담당자는 자기가 할 수 있는 일로 읽는다. 저장 경로에 가드가 있어 실제로 지워지지는 않지만, 도달할 수 없는 행동을 버튼으로 약속하지 않는다.

- **두 축을 모두 점검한다** — 중대산업재해와 중대시민재해는 근거 조문도 주기도 다르다. 한 축만 두면 절반만 점검한 것이 된다.
- **이행 상태를 코드로 저장하고 표시 문구는 화면이 정한다** — 같은 구조를 경영방침 게시 현황도 쓰는데, 거기서는 "게시·미게시"로 읽혀야 한다. 표시 문구를 저장하면 라벨을 바꿀 때 데이터가 깨진다.
- **증빙과 위치 없이 이행으로 등록할 수 없다** — 근거 없는 이행은 점검이 아니다.
- **해당없음에 사유를 강제한다** — 종이 서식에서 실제로 문제가 된 것은 미이행이 아니라 '해당 없음'으로 적고 빠져나가는 것이었다. 필수 표시만 하고 통과시키면 그 문제를 그대로 옮긴다.
- **회차를 데이터 단위에 포함한다** — 상·하반기가 한 행을 공유하면 앞 회차 값이 뒤 회차를 즉시 완료로 만든다.
- **부서 명단 갭을 감추지 않는다** — 등록된 부서 수와 전체 대상 수를 함께 노출한다. 실제 명단을 받으면 조직도 한 곳만 늘리면 이 화면과 경영방침 게시 현황이 함께 따라온다.
- **관계 법령 목록을 임의로 채우지 않는다** — 시행령이 관계 법령을 정의만 하고 기관별 목록을 주지 않으므로 담양군 제공 자료로 관리한다. 미수신 동안 목록 미등록을 드러내고 확인된 공통 항목만 운영하며, 화면에는 제공받을 범위와 대체 동작을 안내한다.
- **매뉴얼 원문과 이행 증빙의 정본을 나눈다** — 제정·개정 원문·버전은 기준문서함, 제정·조치 여부와 회차별 증빙은 이행 목록이 맡는다. 원문 파일을 두 곳에 복사하면 어느 것이 최신인지 정할 수 없으므로 링크로 연결한다.
- **법령 근거 표시** — 관계 법령 의무이행에 필요한 관리상의 조치를 요구하는 법률 조문(중대산업재해 축·중대시민재해 축)과, 각 축의 점검 주기를 정하는 시행령 조문을 함께 붙인다. 근거 조문은 공통 근거 연계(SCR-COM-008)가 관리한다.

---

## 7. 미결사항

없음. 두 축의 주기·상태 저장 방식·증빙과 사유 강제·회차 단위·부서 명단 갭 표시·매뉴얼/업무처리절차의 원문·이행 정본 분리·관계 법령 목록의 처리는 모두 §4·§6에서 확정했다.

**부서 명단 39개**는 행정포털 조직도 **연계 구현 범위**이고([미결사항 목록 §4](99_미결사항목록.md)), **관계 법령 목록**은 관리대상 실태 확정(같은 목록 §5 EXT-09·10)의 파생물이다 — 법령 관리가 법리 기반 후보를 제시하고 실태가 확정되면 목록이 따라온다. 그때까지 화면이 미완결 사실을 드러낸다.
