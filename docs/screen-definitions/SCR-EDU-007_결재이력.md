### 분기 로직

- **신규 상신이 막혀 있어 화면 전체가 조회 전용이다** — 신규 상신·결재 완료·반려·재상신 수단이 **어느 상태에서도 나타나지 않는다**. 되살아나는 조건은 하나다 — 결재 전에 공문을 작성하는 단계가 생기면 차단을 푼다.
- **재상신 건은 이전 건을 덮지 않는다** — 별도 이력으로 남고, **최신이 아닌 건에는 이전 배지**가 붙으며 상태를 바꿀 수 없다. 이력 변조를 막기 위해서다.
- **이력이 있는 건에만 문서 보기·결재 상태 보기가 나타난다** — 저장된 이력이 없으면 그 수단 자체를 내지 않는다.
- **데이터를 이 화면이 직접 읽지 않는다** — 결재 모듈이 주는 목록만 소비하고 저장 구조·라벨을 화면이 다시 해석하지 않는다. 두 곳이 다르게 해석하면 같은 건이 화면마다 다른 상태로 보인다.

## 4. 화면 구성별 정리

### 4-1. 상신 경로 안내

- 상신은 **교육 카드의 [공문 기안]** 에서 시작한다(SCR-EDU-001 §4-6). 이 화면은 그렇게 올라간 문서를 **조회만** 한다 — 여기서 새로 상신하거나 상태를 바꾸지 않는다.
- **차단 안내는 조건부다** — 공문 흐름이 갖춰지기 전에는 왜 상신이 막혀 있는지 밝혔고, 갖춰진 뒤에는 그 안내가 사라진다. 안내 문구를 화면에 박아 두지 않는 이유는, 흐름이 열린 뒤에도 "막혀 있습니다"가 남으면 화면이 스스로 거짓말을 하기 때문이다.
- **이력은 상신을 실제로 수행하는 곳에서 읽는다** — 상신 경로가 바뀌면 이력 출처도 함께 옮긴다. 옛 경로만 읽으면 공문을 올려도 목록이 0건으로 남는다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 화면 진입 | 상신된 문서를 최신순으로 모아 보여 준다 | 상신 경로가 열려 있으면 차단 안내를 내지 않는다 |
| 상신 경로가 막혀 있을 때 | 왜 막혔는지와 언제 열리는지 밝힌다 | 도달할 수 없는 행동을 안내하지 않는다 |

- 상태: 이 화면은 **조회 전용** 하나이며 상신·상태 변경 수단을 두지 않는다. 상신 경로의 개폐에 따라 **차단 안내 있음 / 없음** 두 국면을 가진다.

### 4-2. 요약과 필터
- 전체 상신, 결재중, 결재완료, 반려 건수를 표시한다.
- 문서번호·문서명·대상 검색, 구분, 상태와 상신연도로 조회한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 검색어 입력 | 문서번호·문서명·대상을 함께 찾아 즉시 좁힌다 | — |
| 구분·상태·상신연도 선택 | 선택 즉시 목록과 요약 건수를 갱신한다 | — |

- 상태: 요약 지표는 **전체 상신 / 결재중 / 결재완료 / 반려** 넷이며 이력이 없으면 전부 0으로 표시한다 — 0을 감추지 않는다. 조건 축은 검색어·구분·상태·상신연도이고, 조건 결과가 0건이면 목록 자리에 빈 상태를 낸다.

### 4-3. 이력 목록
- 문서번호, 상신일, 구분, 문서명, 대상, 결재선, 상태와 관리 액션을 표시한다.
- 저장된 이력이 있으면 문서 보기와 결재 상태 보기를 제공한다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| [문서 보기] | 상신한 문서를 그대로 다시 연다 | 조회 전용으로 연다 |
| [결재 상태] | 그 건의 결재 진행 상태를 연다 | 상태를 바꾸는 수단은 내지 않는다 |
| 재상신 건 | 이전 건을 덮지 않고 별도 이력으로 표시한다 | 최신이 아닌 건은 상태를 바꿀 수 없다 |

- 상태: 한 건의 상태는 **결재중 / 결재완료 / 반려** 셋이다. **재상신 건은 이전 건을 덮지 않고 별도 이력으로 남으며**, 최신이 아닌 건은 상태를 바꿀 수 없다 — 이력 변조를 막기 위해서다. 이력이 있는 건에만 문서 보기·결재 상태 보기가 나타난다.

### 4-4. 빈 상태
- 실데이터가 없으면 모든 지표를 0으로 표시한다.
- **빈 상태는 도달 가능한 행동만 약속한다** — 상신이 막혀 있는 동안에는 “각 교육 화면의 상신에서 올리면 쌓입니다”라고 쓰지 않는다. 바로 위에 “현재 신규 상신은 막혀 있습니다”가 있는데 그 아래에서 없는 버튼을 가리키면 한 화면이 스스로 모순된다. 차단 중에는 **새로 쌓이지 않는다는 사실과 언제부터 쌓이는지**를 밝히고, 되살아나면 원래 안내문으로 돌아간다.

| 트리거 | 동작 결과 | 이동 / 메시지 |
|---|---|---|
| 이력이 하나도 없음 | 요약 지표를 0으로 두고 빈 상태 안내를 표시한다 | 무엇이 생기면 채워지는지 함께 밝힌다 |
| 상신이 막혀 있는 동안 | 빈 상태 문구를 **차단 중 문구로 바꾼다** | 없는 버튼을 가리키지 않는다 |

- 상태: 현재는 상신 자체가 막혀 있어 **항상 빈 상태**이며, 그 사실과 이유를 함께 밝힌다 — 단순히 '없습니다'로 두면 기능이 고장 난 것으로 읽힌다. 상신이 되살아나면 각 교육 화면에서 올린 문서가 여기에 쌓인다.

## 6. 정책

- 메뉴명은 실제 화면과 동일하게 “결재 이력”으로 사용한다.
- **이 화면은 조회 전용이다** — 신규 상신은 교육 카드의 [공문 기안]에서 하고(SCR-EDU-001 §4-6) 여기서는 올라간 문서를 보기만 한다. 상신 수단을 이 화면에 두면 공문 작성 단계를 건너뛰는 길이 생긴다.
- 실데이터가 없는 상태를 정상 0건으로 처리한다.
- 문서번호·상태 등은 저장된 연계 결과를 표시하며 이 화면에서 수정하지 않는다.
- **문서 지면은 공용 골격이 그린다** — 표준 공문 서식(기안문·시행문)을 전 도메인이 공유하므로 이 화면이 지면을 따로 정하지 않는다. 아직 없는 것은 **발주처가 실제로 쓰는 공문 본문 샘플**이며, 그것이 오면 본문 문구만 맞춘다.
- **빈 상태는 도달 가능한 경로만 가리킨다** — 상신이 열려 있으면 [공문 기안]을 가리키고, 막혀 있으면 새로 쌓이지 않는다는 사실을 밝힌다. 없는 버튼을 안내하지 않는다.
