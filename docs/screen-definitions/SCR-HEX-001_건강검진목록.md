## 4. 화면 구성별 정리

### 4-1. 관점 선택

- 집계형은 대상·수검·미검진 인원과 증빙·사후관리만 표시한다.
- 개인별 상세형은 권한이 있을 때만 개인 결과를 표시한다.
- 절차 진행형은 대상자 선정, 문진표 안내, 결과 제출, 결과 알림의 네 단계를 순서대로 관리한다.
- 관점 변경은 표시 방식만 바꾸며 상태·수검자 수·증빙을 복제하지 않는다.

### 4-2. 요약·목록

- 대상, 수검, 미검진, 사후관리, 기한 초과를 같은 필터 조건으로 합산한다.
- 대상자 수 미등록은 0명으로 계산하지 않고 별도 경고한다.
- 결과 문서 제출, 실시 완료, 미검진 보완, 사후관리 완료는 각각 구분한다.

### 4-3. 검진계획 등록

- 일반건강진단은 사무직 여부에 따른 기본 주기를 안내한다.
- 특수건강진단은 대상 유해인자와 법정 시기·주기 근거를 계획에 보존한다.
- 30년 보존은 고시 대상 물질 취급 여부로 판정하며 임의 체크만으로 확정하지 않는다.

## 6. 정책

- 「산업안전보건법」 제129조에 따른 일반건강진단과 제130조에 따른 특수건강진단을 서로 다른 유형으로 관리한다.
- 시행규칙 제197조에 따라 일반건강진단은 사무직 2년에 1회 이상, 그 밖의 근로자는 1년에 1회 이상을 기본으로 안내한다. 특수건강진단은 시행규칙 제202조와 별표의 유해인자별 시기·주기를 적용한다.
- 대상 수, 수검 수, 개인 결과는 목적이 다르다. 목록·통계는 최소한의 집계를 사용하고 개인 결과는 별도 권한과 열람기록이 있을 때만 제공한다.
- 결과 보존은 시행규칙 제241조에 따라 원칙 5년, 고시 대상 물질 취급 근로자의 결과는 30년으로 한다.
- 결과 제출이 완료됐다는 이유만으로 미검진자나 사후관리까지 완료로 만들지 않는다. 각 상태를 독립적으로 관리한다.

없음. 전체 인사명단과 행정포털 연계는 **연계 구현 범위**다([미결사항 목록 §4](99_미결사항목록.md)) — 연계 전에는 출처를 밝힌 일부 명단·직접 등록으로 개발하며, 프로토타입 명단은 시연용 더미다.
