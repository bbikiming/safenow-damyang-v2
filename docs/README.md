## screen-definitions/ — 화면 정의서

`00_화면목록.md`가 전체 목록, `_규칙.md`·`_화면정의서_템플릿_v6.md`가 작성 기준이다.
정의서를 고친 뒤에는 반드시 `python3 _build-data.py`로 `js/screen-defs-data.js`를 재생성한다(뷰어가 이 파일을 읽는다).

> 안전보건교육 정의서(SCR-EDU-001~006)는 현행 7메뉴 구조로 재작성 완료(2026-07-21), 온나라 결재 상신 공통 절 반영(2026-07-24, SCR-EDU-005 §4-6). `_build-data.py` 재생성 완료.

> 시설물 안전관리 정의서(SCR-FAC-001~005) 신규 작성(2026-08-11) — 기획 근거는 [`planning/기획-시설물관리-FMS연계-PRD-v1.md`](planning/기획-시설물관리-FMS연계-PRD-v1.md). PRD가 다루지 않던 **관리대상 판정 규칙 · 법정 점검주기 · 자동 현행화 범위 · 수신 파일 유효성·오류 처리 · 권한 매트릭스**를 각 정의서 §5~§7에 담았다. `_공통_권한정의.md` §6에 5개 행 추가, `_inventory_rows.json`·`00_화면목록.md` 반영, `_build-data.py` 재생성 완료.

> FMS 대장을 업무에 실제로 연결(2026-08-11 후속) — 위험성평가 검수 행에 시설물 지정 열 신설(SCR-RISK-001 §4-5), 그 값이 개선조치까지 승계되어 개선조치 목록·상세·내 할일과 시설물 상세에 표시(SCR-IMP-001·002, SCR-FAC-002 §4-4). 관리대상 현황 공중이용시설 탭은 자체 목록을 버리고 대장 파생으로 전환(SCR-BASE-002 **신규 작성**), 연계 관리의 시설물 건수도 대장에서 파생(SCR-ADMIN-004 **신규 작성**). 「시설물의 안전 및 유지관리에 관한 특별법」 **법률 4건 + 시행령 5건**을 법제처에서 수집해 `js/law-map.js`에 수록(법 제7·11·16·24조 / 영 제12·18·19조·별표3·별표8). 조문 대조로 프로토타입 결함 3건을 바로잡았다 — ① 중대결함 **완료기한 기산점**이 통보일이 아니라 **착수일**(영 §19) ② 중대결함 목록에서 제1항 제5호 누락·제10호 분할·**제2항 공중이용부위 4종 통째 누락** ③ 정기안전점검 주기 근거 부재(영 별표3 — A·B·C 반기 1회, D·E 연 3회·해빙기/우기/동절기 전). FDT-13은 **해소**되고 국토교통부령 위임분만 남았다.

> 시설물 관련 정의서 7건(SCR-FAC-001~005 · SCR-BASE-002 · SCR-ADMIN-004)을 **새 권한 표준으로 전환**(2026-08-11) — [`_공통_권한정의.md`](screen-definitions/_공통_권한정의.md) 개정에 따라 §2 역할표를 걷어내고 표준 3줄로 통일했다. 권한 미결 7건은 지우기만 하지 않고 **상태를 바꾸는 행위는 §6 정책의 상태 전이 조건으로 이관**했다(FMS 전송=외부 정본 변경 · 수신 반영=되돌릴 수 없음 · 초기화=복구 불가 · 재시도=외부 재요청 · 착수 결정=계획 절차). §7에 '권한' 표기 0건. 이어서 **나머지 13건도 전환 완료**(2026-08-11) — 작성된 정의서 **32건 전부**가 새 권한 표준을 따른다(§2 역할표 0 · §7 권한 항목 0 · 폐지된 「§6 화면별 권한 매핑」 참조 0). 메뉴가 없는 공통 요소(전자문서 폼·전역 근거 표시)는 첫 줄을 "호출한 화면의 메뉴 권한을 따른다"로 바꿔 적용했다. `SCR-RISK-003` 의 비표준 §7 표제를 표준으로 맞춰 **린트 위반 0건**.
