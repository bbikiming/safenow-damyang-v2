## 보낼 문구

**제목:** [중대재해 통합관리시스템] e호조 계약대장 정정·재추출 요청

안녕하세요. 중대재해 통합관리시스템 구축 업무를 맡고 있는 ○○○입니다.

지난번 보내 주신 e호조 계약대장(2026년 계약 866건)은 시스템에 잘 반영해 확인했습니다. 감사합니다. 확인하는 과정에서 **정정이 필요한 계약 19건**과 **빠져 있는 범위**가 있어, 정정한 파일을 한 번 더 받고자 요청드립니다. 붙임 엑셀에 대상과 조건을 정리했습니다.

**1. 정정이 필요한 계약 19건** (붙임 ①시트)
- 준공예정일자가 계약일자보다 이른 계약 16건 — 점검 기간을 계산할 수 없어 반기 점검표가 생기지 않습니다.
- 준공예정일자가 2062년인 계약 2건 — 입력 오류로 보이며, 그대로 두면 2062년까지 반기마다 점검 대상이 됩니다.
- 총계약금액이 0원인 계약 1건 — 금액으로 정해지는 법정 기준(산업안전보건관리비·기술지도·안전관리자 선임)을 판정할 수 없습니다.

e호조에서 정정해 주시면 됩니다. 값이 실제로 맞는 경우에는 붙임 ①시트 «처리» 칸에 «값 그대로가 맞음»으로 표시해 주십시오. 시스템에서는 원장 값을 직접 고치지 않습니다(다음 반입 때 덮어써지기 때문입니다).

**2. 추가로 필요한 범위** (붙임 ②시트)
- **관서 전체** — 받은 파일은 관서가 모두 «본청»이라 **사업소·읍면이 계약한 건이 빠져 있습니다.** 중대재해처벌법상 의무는 담양군 전체에 걸려 사업소·읍면 계약도 필요합니다.
- **준공예정일자 2026-01-01 이후 계약 전부(계약 연도 무관)** — 작년 이전에 계약해 올해 진행 중인 공사까지 들어와야 반기 점검과 공사별 안전관리자 현황이 맞습니다. 연도 조건으로만 뽑을 수 있으면 2024·2025·2026년을 각각 뽑아 주셔도 됩니다.
- 파일 모양은 지금과 같은 양식이면 됩니다. 같은 계약대장관리번호는 기존 계약에 값만 갱신되어 중복으로 쌓이지 않습니다.

**3. 보내실 것** — 위 1·2를 반영한 엑셀 파일 1개와 추출한 날짜(목록의 기준일로 표시됩니다). 1번 정정과 2번 추출을 한 파일로 주시면 됩니다.

**참고 — 이후 운영 방식**
계약 금액·기간 변경이나 해지는 e호조에서 처리하신 뒤, 재난안전과 담당자가 계약대장 엑셀을 다시 올려 반영합니다. 반기 점검 회차가 시작되기 전(1월·7월 첫 주)에 한 번, 그리고 매월 한 번 올리는 것을 기본으로 합니다. 시스템에서 정한 점검 판정·착공일 등은 다시 올려도 지워지지 않습니다. 이후 e호조 API 연계가 붙으면 자동으로 반영됩니다.

자료가 오기 전에도 지금 받은 866건으로 시스템 구축은 계속 진행됩니다. 바쁘신 중에 번거롭게 해 드려 죄송합니다.

감사합니다.

## 기록 — 왜 이 요청인가

| 항목 | 우리가 정한 것 | 담양군이 해 줄 것 |
|---|---|---|
| 정정 19건 | 이상값은 자동으로 고치지 않고 «기간 확인 필요»·«금액 확인 필요»로 드러낸다(정의서 §5-4) | 실제 값으로 정정 — 계약서를 가진 담양군만 안다 |
| 추가 범위 | 관서 전체 · 준공예정일자 2026 이후 · 관리번호로 갱신(정의서 §6) | e호조에서 추출 — e호조 접근 권한은 담양군에만 있다 |
| 변경 반영 | 재난안전과 담당자 재반입 · 반기 시작 전 + 매월(정의서 §6, 2026-10-16) | 없음 — 알리는 내용 |

- 19건 = 개발 1차 확인 요청의 부록 가와 같다(자동 표시 17건 + 2062년 2건).
- 3번 «운영 방식»은 질문이 아니라 알리는 내용이다 — 담양군에 확인받지 않는다.
