## 1. 정기 위험성평가

### 1-1. 지금 흐름

1. 재난안전과 — 평가 생성(대상 부서 · 부서별 점검일)
2. (설문조사표 — 2026년은 생략: 생성 → 보고서 첨부)
3. 재난안전과 — 용역 통합 보고서 첨부 → 부서별로 빈 작성표가 열린다
4. 재난안전과 + 그 부서 담당자 — 작성표에 행 추가: 유해위험요인 · 분류 · 원인 · 개선조치 · 담당자 · **개선 전·후 사진 · 완료 체크**
5. 재난안전과 — `[작성완료 · 조치기한 설정]` → 일괄 기한 또는 부서별 기한 → `[전달]`
6. 부서 — 담당자 지정 → `[완료 처리]`(조치 내용 · 완료일 · 개선 후 사진 · 전자서명 — 넷 다 필수)
7. 재난안전과 — 건마다 확인 / 반려(사유 필수) → 전 건 확인되면 공문 기안

### 1-2. 눌러 보며 확인할 것

- [ ] 보고서 첨부 창에서 지금 받는 것은 **파일 하나뿐**이다
- [ ] 조치기한은 **작성을 다 마친 뒤**(`[작성완료 · 조치기한 설정]`)에야 정한다 — 부서는 기한을 모른 채 작성표를 적는다
- [ ] 작성표 행에 개선 전·후 사진과 완료 체크가 있다 — 내 할일 `[완료 처리]`에도 사진을 또 받는다(사진 올리는 곳이 두 군데)
- [ ] 전달 뒤 기한을 바꾸는 곳: 조치 카드 `[변경]` — 재난안전과 담당자는 담당자·기한 모두, 부서 담당자는 **담당자만** 바꾼다. 바꾼 이력이 카드에 남는다
- [ ] 전달 뒤에는 작성표가 조회 전용이 되고, **개선조치를 한 건 더 넣을 수단이 없다**

### 1-3. 여러 계정 동시 작업 — 눌러 볼 순서

계정: **A** 재난안전과 담당자 · **B** 부서 담당자 · **B′** 같은 부서의 다른 담당자(없으면 **C** 다른 부서 담당자)

- [ ] B 가 자기 부서 블록에 행을 추가한다 → A 가 새로고침하면 그 행이 보이는가
- [ ] A 와 B 가 같은 부서 블록에 거의 동시에 행을 추가한다 → **두 행 모두 남는가**(한쪽이 사라지지 않는가)
- [ ] A 와 B 가 **같은 행**을 동시에 고친다 → 나중에 저장한 쪽이 앞 내용을 덮어쓰는가 · 경고가 뜨는가
- [ ] B 가 행을 적는 도중에 A 가 `[작성완료 · 조치기한 설정]` → `[전달]` → B 가 적던 행은 전달에 들어가는가 · 저장하지 않은 입력은 어떻게 되는가
- [ ] B 가 A(또는 B′)가 만든 행을 지울 수 있는가
- [ ] C 가 B 부서 블록을 볼 수 없고, 주소로 들어와도 고칠 수 없는가
- [ ] A 가 보고서를 취소·재첨부하면 B 가 적은 행까지 지워진다는 안내가 확인 창에 나오는가
- [ ] 같은 개선조치를 B 와 B′ 가 동시에 `[완료 처리]` 하면 어떻게 되는가
- [ ] A 가 확인 창을 열어 둔 사이 B 가 재제출하면 A 는 어느 회차를 확인한 것으로 남는가

## 2. 안전보건교육 (집합교육 · 참석자 등록부)

### 2-1. 설계 이력

| 날짜 | 정한 것 | 출처 |
|---|---|---|
| 07-16 | **신청과 참석 증빙을 한 단계로 합쳤다** — 서명은 신청할 때 올린다 · 불참자 처리 없음 · 신청 명단 = 이수 대상 · 정원 · 마감일 없음 | 교육 결정사항 B-3 |
| 07-30 | 화면 이름 «부서 신청» → **«참석자 등록부 등록»** | 07-30 회의 |
| 08-13 | 위 결정 재확인 · 한 부서는 한 번만 등록 · 인원 · 서명을 고치려면 신청 취소 후 다시 등록 · 공문 상신 뒤에는 취소도 잠김 | 교육 결정사항 B-3 확인 |
| 10-06 | 사람별 인정시간 = 등록부에 적은 **실제 참석시간**(예정시간을 일괄 인정하지 않음) | 기획확인 4차 |
| 11-05 | 등록부 대상자는 그 교육의 대상 안에서만(현업근로자 교육에 관리감독자 불가) · 다른 부서 이름 · 서명은 가림 | 운영 점검 E19 · P05 |

**지금 생기는 모순** — 등록부는 교육을 등록한 순간(«접수 중»)부터 열린다. 내 할일 카드도 그때 «등록부를 등록하세요»라고 한다. 그런데 등록부에는 **서명파일과 실제 참석시간**이 필수다. 교육 전에 등록하면 서명은 참석 증빙이 아니라 예정이 되고, 실제 참석시간도 알 수 없는 값을 적게 된다.

### 2-2. 지금 흐름

1. 재난안전과 — 집합교육 등록(회차 · 강사 · 장소 · 첨부 «참석자 명단» · «교육 자료»)
2. 부서 담당자 — 교육 상세 `[＋ 참석자 등록부 등록]`: 부서(소속 부서 고정) · 근로자 선택 · 실제 참석시간 · 서명파일(필수) → «신청 완료»
3. 재난안전과 — `[교육 종료 처리]` → 등록부별 실제 참석시간이 각 사람에게 인정된다
4. 재난안전과 — 실시 결과 공문 기안 → 온나라 상신

### 2-3. 눌러 보며 확인할 것

- [ ] 교육 날짜가 오기 전에도 `[＋ 참석자 등록부 등록]`이 눌리고, 서명파일을 올릴 수 있다
- [ ] 재난안전과가 올리는 첨부 «참석자 명단»이 무엇인가 — 부서에 주는 **서명부 양식**인가, 재난안전과가 받은 결과인가
- [ ] 등록 버튼이 보이는 사람: 그 부서 담당자 · 재난안전과 담당자. 관리·감독 계층(군수 · 과장 · 소장)에게는 안 보인다
- [ ] 같은 부서의 «일반 공무원» 등급 계정에는 버튼이 보이는가(운영은 메뉴 권한이 등급으로 갈린다)
- [ ] 등록부에서 고를 수 있는 근로자 = 우리 부서 근로자 명단 중 그 교육 대상. 명단에 없는 사람이 참석했다면 등록할 방법이 있는가
- [ ] 등록 마감이 없다 — 재난안전과가 종료 처리를 누르면 그때까지 등록하지 않은 부서는 그 교육 이수가 0 이다

## 3. 반기 의무이행 점검

> 상세 기획: `docs/planning/기획-이행점검-배포·제출·확인-흐름보완-v1.md`

### 3-1. 바꾸려는 방향

**점검 서식을 먼저 배포하고, 부서가 기입해 올린다.**
재난안전과 배포(양식 · 안내 · 기한 · 대상 부서) → 부서 내려받기 · 작성(부서장 확인) → `[결과 제출]` → 재난안전과 `[확인]` / `[보완 요청]` → `[반기 마감 · 온나라 상신]`(군수 보고) → 회차 잠금 → 미이행 조치 결과

근거 — 5년간 실제 공문이 이 순서다(5월 · 11월 «자체점검 실시 통보» → 반기 말 «자체점검표 제출» → 12월 촉구). 분류기준 IND-10 도 «시달 → 부서 결과 제출 → 경영책임자 보고»로 나눠 두었다.

### 3-2. 이슈

| # | 이슈 | 지금 화면에서 |
|---|---|---|
| 1 | **양식 배포 단계 누락** | 양식 · 기한 · 대상을 올릴 자리가 없다. 양식은 공문으로 따로 간다 |
| 2 | **재난안전과 확인 단계 누락** | 부서가 저장하면 곧 확정이다. 엉뚱한 파일이어도 «이행»으로 군수 보고까지 간다 |
| 3 | 미제출과 미이행이 같은 상태 | 아무도 손대지 않은 줄이 «미이행»으로 보이고, 미이행을 정직하게 적은 부서의 할 일이 끝나지 않는다 |
| 4 | 미이행 뒤 조치가 없다 | 시행령이 요구하는 «미이행이면 필요한 조치»를 적을 곳이 없다 |
| 5 | 시민재해 탭도 전 부서가 대상 | 시설 없는 부서가 매번 «미이행» 또는 «해당없음»을 적는다 |
| 6 | 마감 상신 뒤에도 고쳐진다 | 군수에게 올라간 보고와 시스템 값이 갈린다 |

### 3-3. 눌러 보며 확인할 것

- [ ] 재난안전과 계정 — 이행점검 화면에 양식 · 기한 · 대상을 올릴 자리가 없다
- [ ] 부서 계정 — 우리 줄 `[확인 등록]`을 열어도 «무엇을 점검하라는지»는 화면에서 알 수 없다
- [ ] 손대지 않은 줄이 «미이행»으로 보인다
- [ ] 중대시민재해 탭에 공중이용시설이 없는 부서도 줄이 있다
- [ ] `[반기 마감 · 온나라 상신]` 뒤에 부서 줄을 고칠 수 있다
