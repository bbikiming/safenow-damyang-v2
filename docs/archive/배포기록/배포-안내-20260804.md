## 이 폴더는 무엇인가

`프로토타입-v2` 저장소에서 **웹 배포에 필요한 것만** 추린 사본입니다.
Vercel 대시보드 드래그 업로드는 `.vercelignore` 를 읽지 않아 `.git`(약 960개 파일)까지
올라가면서 "Too many files (max 1000)" 에 걸립니다. 이 폴더는 그 문제를 피하기 위한
업로드 전용 사본입니다.

| 포함 | 제외 |
|---|---|
| `*.html` 54개 | `.git` · `.claude` · `.vercel` |
| `js/` 64개 | `docs/` (기획·정의서) |
| `css/` 2개 | `CLAUDE.md` · `README.md` · `.gitignore` · `.vercelignore` |
| `vercel.json` | |

총 **121개 파일 · 약 3.8MB** (Vercel 한도 1000개).

## 배포 방법

Vercel 대시보드에서 **이 폴더를 통째로 드래그**해 업로드합니다.
CLI 로 한다면 소스 저장소에서 `vercel --prod` 를 쓰면 되고, 그때는 `.vercelignore` 가
같은 역할을 하므로 이 폴더가 필요 없습니다.

## 로컬 확인

```
python3 -m http.server 8788
```
후 `index.html` 접속. 빌드·의존성 설치가 필요 없는 정적 HTML 입니다.

## 이 배포본을 다시 만들 때

소스 저장소에서 아래 4가지만 복사하면 됩니다 — 스크립트가 따로 없습니다.

```
cp *.html vercel.json <대상>/
cp -R js css <대상>/
```
