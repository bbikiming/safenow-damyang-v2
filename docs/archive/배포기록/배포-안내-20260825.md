### 종전 배포본과 달라진 두 가지

**① `docs/` 를 넣었다.** 종전에는 Vercel 파일 수를 아끼려 뺐는데, 그 결과
**README 의 링크 7개가 전부 죽어 있었다** — 「개발자께: 이것부터 읽어 주세요」가
가리키는 화면정의서·미결사항목록이 폴더에 없었다는 뜻이다. 실제로 세어 보니
docs 를 다 넣어도 316개라 한도의 3분의 1이다. 아낄 이유가 없었다.

**② `tools/` 와 `data/` 를 넣었다.** 생성물(`js/doc-taxonomy-data.js` ·
`doc-history-data.js` · `doc-seed-2026.js`)은 «손으로 고치지 말고 재생성하라»가
규칙인데 생성기가 없으면 그 규칙을 지킬 수 없다.

## 다시 만들 때

저장소 루트에서:

```bash
rsync -a --exclude='.git' --exclude='.claude' --exclude='.vercel' \
  --exclude='.vercelignore' --exclude='.gitignore' --exclude='.DS_Store' \
  --exclude='docs/archive/audit' --exclude='*.pyc' --exclude='__pycache__' \
  ./ ../프로토타입-v2-배포-<날짜>/
```

만든 뒤 **README 의 내부 링크가 살아 있는지 반드시 확인한다** — 종전 배포본이
7개 전부 죽은 채 나갔다.
